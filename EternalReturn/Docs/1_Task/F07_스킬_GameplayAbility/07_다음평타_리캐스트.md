## 할 일

**다음 기본 공격 강화**(공용 1벌)와 **재사용 윈도우**를 만든다.

```
재키 W — 사용 후 다음 평타에 둔화 0.85초
재키 Q — 적중 후 3초 내 재사용 가능
```

## ⭐ 공용 1벌로 만든다

*"다음 평타 강화(**공용 1벌**)"* — 역기획서 우선순위 7.
캐릭터마다 따로 만들면 같은 코드가 복제된다.

태그는 이미 있다 — `Ability.Form.NextAttackBuff`.
⚠ **무장 해제(F06)가 이것도 막는다.** 그 연결을 확인한다.

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- 재키 W 후 **다음 평타에만** 둔화가 붙는다
- 그 다음 평타에는 안 붙는다 (1회성)
- 재키 Q 적중 후 **3초 내에만** 재사용된다
- 윈도우가 지나면 재사용이 안 된다
- ⭐ **무장 해제 중에는 평타 강화도 막힌다**

## 구현 (2026-09-14)

⚠ **기본 공격 어빌리티가 F00~F17 어디에도 없었다.** 여기서 `UERBasicAttackAbility`(파이프라인 파생, 슬롯 `Ability.Slot.Attack`,
쿨다운 = 1/AttackSpeed, 사거리 = AttackRange 어트리뷰트)를 같이 만들었다. 오토 어택은 별도 Task.
- 강화: `UERSkillData.bGrantsNextAttackBuff` → GE `State.NextAttackBuff`(컨텍스트 SourceObject = 그 스킬 데이터) → 평타 적중 시 그 스킬의 피해·적중 효과를 얹고 제거
- 리캐스트: `bRecastOnHit` → GE `Recast.Slot.*` (RecastWindow 초) → `CheckCooldown` 우회 → 재발동 시 소비, 쿨은 첫 시전 것 (자체 결정값)
- 적중 시 CC: `OnHitEffect` + 레벨별 지속·둔화율 → `ERCC::ApplyCC` (SlowPercent 인자 추가)
근거 [`../../4_Argument/19_평타_다음평타강화_리캐스트_구조.md`](../../4_Argument/19_평타_다음평타강화_리캐스트_구조.md)

## 주의점

- ⭐ **캐릭터마다 따로 만들지 않는다** — 공용 1벌
- ⚠ 평타 강화가 **1회성**임을 보장한다 (안 쓰면 남아 있을지 정한다)
- 리캐스트 윈도우를 `FTimerManager` 가 아니라 **GE Duration** 으로 잰다

```
F05 입력 → F07 어빌리티 → F04 판정 → F03 데미지 → F02 어트리뷰트
                ↑
             F06 CC 가 막는다
```

역기획서가 **잘라내도 된다**고 명시한 것:

- **F(전술) 슬롯** — 로비 UI 와 14종 데이터가 선행. UI 문서도 *"D/F 슬롯은 컷"*
- **충전형 · 진짜 토글** — 6인 중 요구 없음 → **죽은 코드가 된다**
- **커스텀 이동 모드**(매그너스 R) — M3
- **클라이언트 예측** — `CLAUDE.md` §8

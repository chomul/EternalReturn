## 할 일

**코스트**를 Cost GE 로, **스킬 포인트 배분**을 서버 검증으로 만든다.

## ⭐ 체력 코스트 — 하한을 어빌리티가 처리한다

시셀라의 두 가지는 **서로 다른 경로**다 (사용자 정정, `Docs/4_Argument/3_어트리뷰트셋_구조⭐.md` D절):

| | 무엇 | 하한 |
|---|---|---|
| Q · W | HP **코스트** | 1 |
| R | **자기 피해** | 100 |

⭐ **어트리뷰트셋에는 하한 장치가 없다.** F02-04 가 일부러 안 만들었다 —
*"하한이 데미지 경로에 섞이면 죽어야 할 때 안 죽는다."*

→ **어빌리티가 값을 미리 깎아서** 넘긴다. Cost GE 의 크기를 `현재HP - 1` 로 계산하는 식이다.

## 스킬 포인트 (§2.1)

~~상한 **5/5/5/3** (Q/W/E/R).~~ → ⭐ **사용자 정정 (2026-09-13): 상한·시작 레벨은 캐릭터마다 다르다** —
E 가 1레벨로 시작하는 실험체, R 이 4레벨까지 오르는 실험체가 있다. 그래서 **슬롯이 아니라 `UERSkillData` 가 규칙을 든다**:
`InitialLevel`(기본 0 = 미습득) · `MaxLevel`(기본 5) · `bUsesSkillPoints`(P · D 는 false). 코드에 "R 이면 3" 분기가 없다.

⭐ **서버가 검증**한다 — 클라가 보낸 배분을 그대로 믿지 않는다. `AERPlayerState::ServerLevelUpSkill(SlotTag)`:
포인트 > 0 → `ERSkill::LevelUpSkill` (슬롯 존재 · `bUsesSkillPoints` · `Level < MaxLevel`) → 성공 시에만 포인트 −1.

⚠ **실험체 레벨이 아직 없다** (F10). 지급 · R 해금 레벨 · P 자동 강화는 F10 에서 같은 애셋에 필드를 붙인다.
R 해금 레벨은 인터넷 조사로도 못 찾았다 (나무위키 가이드 · fandom 402 · 공식 wiki 접속 불가) — **(미확인)**.

⭐ 스킬은 **레벨 0(미습득)으로 시작**한다 — "시작 시 1포인트로 Q/W/E 중 하나 습득" (나무위키 가이드).
`UERGameplayAbility::CanActivateAbility` 가 레벨 0 을 막는다. GAS 는 레벨을 검사하지 않는다.

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 코스트가 모자라면 **발동하지 않는다**
- ⭐ 시셀라 W 사용 시 서버에서 체력 차감, **1 이하로 안 내려간다**
- ⭐ 시셀라 R 자기 피해가 **100 에서 멈춘다** (F03-06 검증 완결) → ⏸ **F07-05** — 피해를 주는 어빌리티가 있어야 한다. 코스트가 아니라 피해 경로다
- 스킬 포인트 상한을 넘겨 배분하면 **서버가 거부**한다
- 클라가 상한을 우회해도 서버가 막는다

## 주의점

- ⭐ **어트리뷰트셋에 하한을 넣지 않는다** — 어빌리티가 깎아서 넘긴다
- ⭐ 스킬 포인트 배분은 **서버 검증**이다
- ⚠ 코스트 검사(`CanActivateAbility`)와 차감(`CommitAbility`)의 시점을 구분한다

# F07-02 — 쿨다운 GE

> 기능 [F07](00_개요.md) · 근거 [`스킬_프레임워크_역기획서.md`](../../0_GameDesign/Systems/스킬_프레임워크_역기획서.md) §4.3 · 우선순위 2
> 체크리스트 [`../../2_Checklist/F07_스킬_GameplayAbility/02_쿨다운_GE.md`](../../2_Checklist/F07_스킬_GameplayAbility/02_쿨다운_GE.md)

## 할 일

쿨다운을 **Cooldown `UGameplayEffect`** 로 만들고, `SkillHaste` 를 환산한다.

## ⭐ GAS 가 주는 것

`UGameplayAbility::CooldownGameplayEffectClass` 를 지정하면
발동 시 자동으로 걸리고, `CanActivateAbility` 가 자동으로 막는다.

⭐ **`FTimerManager` 로 직접 재지 않는다** (`CLAUDE.md` §8).

## 스킬 가속 환산

`SkillHaste` 어트리뷰트가 F02 에 있다. ⚠ **상한이 없다** —
*"원작에서 상한 없음이 확인됨. '쿨감 30% 상한' 은 구버전 서술"* (F02-03).

환산식과 `bIgnoreCooldownReduction`(가속 무시 스킬)을 정한다.

⚠ 환산식은 **(미확인)** 이다. 흔한 형태는 `쿨다운 / (1 + Haste/100)` 이지만 원작 확인이 안 됐다.

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 쿨다운 중 같은 스킬이 **발동하지 않는다**
- ⭐ 클라 쿨다운 표시가 **서버와 ±0.1초 이내**로 일치한다
- `SkillHaste` 가 오르면 쿨다운이 줄어든다
- `bIgnoreCooldownReduction` 스킬은 가속을 안 받는다
- ⭐ **채널링이 취소돼도 쿨다운이 남는다** (F06-03 검증 완결)

## 주의점

- ⭐ **`FTimerManager` 를 쓰지 않는다** — Cooldown GE 의 Duration
- ⚠ 쿨다운은 **발동 시점**에 건다. 적중 시점이 아니다
- 환산식을 하드코딩하지 않고 **(미확인)** 을 주석에 남긴다

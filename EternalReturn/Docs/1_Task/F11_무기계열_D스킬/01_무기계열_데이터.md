## 할 일

**무기 계열 → (D 스킬 데이터 · 기본 공격 데이터 · 사거리 · 해금 임계값)** 테이블. 행은 8개, enum 자리는 23개(F08-01 에 이미 있다).

```
FERWeaponClassRow : FTableRowBase       // RowName = 계열명 ("Hammer") — EERWeaponType 과 1:1
  WeaponType      : EERWeaponType
  DSkill          : TObjectPtr<UERSkillData>   // SlotTag=Ability.Slot.D · MaxLevel 3 · bUsesSkillPoints=false · InitialLevel 0
  AttackData      : TObjectPtr<UERSkillData>   // SlotTag=Ability.Slot.Attack · 계열별 평타 (사거리 · 판정 형상 — 원거리는 Projectile? (미확인))
  AttackRange     : float   // m. 기본 공격 사거리 — 계열이 정한다 (F04 문서 "기본 공격 사거리는 무기가 정한다")
  UnlockLevel     : int32   // 5   [확인]
  UpgradeLevels   : TArray<int32>  // {10, 15}  [확인]
```

⭐ **`FCharacterWeaponRow`(캐릭터 × 무기 허용)는 만들지 않는다** — F08-02 가 `UERCharacterData.WeaponTypes` 로 이미 해결했다. 같은 표를 두 곳에 두지 않는다.
⭐ **D 강화 0/1/2 = 스킬 레벨 1/2/3.** `UERSkillData` 의 레벨별 배열(쿨다운 25/20/15 · 계수)이 그대로 강화 단계다. 별도 "강화 인덱스" 구조 없음.

## ⚠ 사거리 적용 방식 — Argument 대상

기본 공격 사거리는 `AttackRange` 어트리뷰트(F07-07 평타가 읽는다). 실험체 초기값(F02)이 있고, 무기 계열이 이를 **대체**해야 한다(더하는 게 아니라). 방법이 둘:
- 무기 장착 시 Infinite GE 로 `Override` 모디파이어 (장비 GE 와 별개) — 벗으면 원복
- 계열 사거리를 `UERBasicAttackAbility::GetRangeMax` 가 계열 행에서 직접 읽음 — 어트리뷰트 안 씀
→ `Docs/4_Argument/` 에서 정한다 (02 시작 전).

## 검증

- **빌드 통과** · 8행이 로드되고 `ER.Weapon.Show Hammer` 로 D · 평타 · 사거리 · 임계값이 찍힌다
- `EERWeaponType` 23종 중 행이 없는 계열을 장착하면 **에러 로그**(조용히 D 없음 금지)
- D 스킬 데이터의 `SlotTag != Ability.Slot.D` 면 로드 때 에러

## 주의점

- ⚠ 5 / 10 / 15 를 하드코딩하지 않는다 — 행 값
- ⚠ 계열 행 8개만. 나머지 15 는 나중에 데이터 추가

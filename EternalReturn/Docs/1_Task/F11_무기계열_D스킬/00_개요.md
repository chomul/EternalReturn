## 목표

**무기를 바꾸면 D 스킬 · 기본 공격이 통째로 바뀌고, 숙련도 5/10/15 에 D 가 해금 · 강화된다.** — 원본 §12.5 *"같은 캐릭터를 무기를 바꿔 플레이했을 때 다른 캐릭터로 느껴지는가"*

## ⭐ F07 · F08 · F10 이 이미 만들어 둔 것 — 여기서 잇기만 한다

| 필요한 것 | 어디에 있나 |
|---|---|
| 무기가 소유하는 슬롯 개념 | `Ability.Slot.D` · `Ability.Slot.Attack` 태그, `ERSkill::GrantSkills/TakeSkills` (F07-01 "D 는 무기가 소유") |
| 스킬 데이터 · 레벨 규칙 | `UERSkillData` — D 의 강화 0/1/2 = **스킬 레벨 1/2/3**, `bUsesSkillPoints=false` (F07-03) |
| 기본 공격 | `UERBasicAttackAbility` — 사거리 `AttackRange` 어트리뷰트 (F07-07) |
| 장착 · 무기군 · 복제 | `UERInventoryComponent.Equipped`(전원 복제) + `ERItem::CanEquip` (F08-02 · 03) — **`EquippedWeaponType` 을 따로 만들지 않는다.** 장착 아이템 ID → 행 → `WeaponType` |
| 숙련도 레벨 변화 | `OnWeaponProficiencyLevelUp` 델리게이트 (F10-04) |
| D 의 부품 (넉백 · 벽 · 둔화 · 돌진 · 은신 · 장판) | F06 · F07 공용 — §2.4 "23종 중 새 서브시스템은 4개뿐" |

## ⚠ 이 기능이 하지 않는 것

- **전술 스킬(F) · D↔F 스왑** — 초기 버전 삭제 (§7). "슬롯의 스킬 소스" 는 이미 `SlotTag` 로 표현돼 있어 추가 enum 도 없다
- **무기 메시 · 모션** — 애니메이션 단계. `Equipped` 의 `OnRep` 훅에 자리만
- **나머지 15종 무기** — enum 자리만 (F08-01 에서 이미 23종)
- **신규 서브시스템 4개** (톤파 반사 · 저격총 모드 · 카메라 실명 · 쌍절곤 차지) 중 **저격총 모드만** 05 에 포함 (1단계 6종에 카티야가 있다). 나머지 3 은 8종 밖

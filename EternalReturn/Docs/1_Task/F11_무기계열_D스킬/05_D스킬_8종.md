## 할 일

01~04 가 **프레임워크**다. 여기서는 8종을 **데이터 애셋 + 필요한 파생 어빌리티**로 만든다. 대부분은 F07 베이스 + `UERSkillData` 필드만으로 된다.

> ⭐ 수치는 **역기획서 §2.3.5 (나무위키 확인, 2026-09-19)** 가 근거다 — 아래 표의 효과 설명도 그 기준. 회차: **A** 망치 · 도끼 → **B** 권총 · 방망이 → **C** 암기 · 투척 · 단검 → **D** 저격총.

## ⭐ 프레임워크에 추가되는 필드 (05 를 하면서 `UERSkillData` 에)
- `HealFromDamageRatio` (도끼) · `NextAttackBuffCount` (권총) · `bRecastAlways` / `SelfMove::BlinkBehindTarget` (단검) · 설치물 스킬 데이터 (암기 · 투척 공용)
- 저격 모드: **모드 스킬 데이터**(`ModeAttackData`) — 활성 중 평타 슬롯 교체

## 검증 — 8종 각각 `Play As Listen Server, 2명`
- 1단계 6종이 각 실험체 데이터 애셋으로 동작 — 무기 교체로 D 가 바뀐다 (§12.5 검증)
- 매그너스 망치 ↔ 방망이, 시셀라 암기 ↔ 투척 — 2무기 A/B
- 저격 모드 중 평타가 다르게 나가고, 무기 교체 시 모드 강제 해제 (04)

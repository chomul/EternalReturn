## 할 일

01~04 가 **프레임워크**다. 여기서는 8종을 **데이터 애셋 + 필요한 파생 어빌리티**로 만든다. 대부분은 F07 베이스 + `UERSkillData` 필드만으로 된다.

| 단계 | 계열 | D | F07 부품 | 추가 코드 |
|---|---|---|---|---|
| 1 | **망치** 방어구 파괴 | 전방 타격 + 5초 방어력 −10~20% | `Shape Cone` + `OnHitEffect`(방어력 감소 GE — **%감소 GE 애셋** 1개) | 없음 (GE 애셋) |
| 1 | **도끼** 피의 나선 | 전방 돌진, 준 피해의 60% 회복 | `SelfMove TowardAim` + 피해 | ⚠ **"준 피해의 N% 회복"** — 흡혈 어트리뷰트가 아니라 스킬 고유 → `UERSkillData.HealFromDamageRatio` 필드 + `OnTargetsResolved` 파생 |
| 1 | **단검** 은신 단도 | 1~2초 은신, 재사용 시 대상 뒤 순간이동 | 은신 = **F16**(`State.Stealth` ⏸) · 리캐스트 = `bRecastOnHit` 유사(적중 조건 아님 → `bRecastAlways` 필드) · 순간이동 = `SelfMove` 신규 모드 `BlinkBehindTarget` | 중 — 은신은 F16 전까지 태그만 |
| 1 | **암기** 마름쇠 투척 | 마름쇠 살포(장판), 피해 + 1.5초 둔화 | ⚠ **지속 장판** — 6인 기본 스킬엔 없던 형태(스킬 역기획서 §8 우선순위 3). 설치물 액터 + 주기 판정 | 중 — 첫 설치물 |
| 1 | **저격총** 스나이핑 | 저격 모드 진입 → 3발(정지 2 + 마무리 1) | ⚠ **모드 전환** — 기본 공격 자체를 갈아끼움. `Ability.Slot.Attack` 을 **모드 중 다른 평타 데이터로 교체**하면 프레임워크로 표현 가능 (F11-02 의 부여/회수 재사용) | 높음 — 유일한 신규 축 |
| 1 | **권총** 이동 사격 재장전 | 이속 40~70%, 다음 **2회** 공격 속도 | `OnHitEffect`(자기 버프 GE) + **다음 평타 강화 ×2** — F07-07 의 강화 GE 를 **횟수** 있게 (`NextAttackBuffCount`) | 낮음 |
| 2 | **방망이** 풀스윙 | 전방 스윙 + 넉백, 벽 충돌 시 0.8~1초 기절 | `Shape Cone` + `ERForcedMove::ApplyForcedMove` + `OnForcedMoveWallImpact` → 기절 GE | 낮음 — 매그너스 E 와 같은 파생 |
| 2 | **투척** 연막 | 2.5초 연막, 시야 감소 | 설치물(암기와 공용) + **시야 = F16** | 중 |

## ⭐ 프레임워크에 추가되는 필드 (05 를 하면서 `UERSkillData` 에)
- `HealFromDamageRatio` (도끼) · `NextAttackBuffCount` (권총) · `bRecastAlways` / `SelfMove::BlinkBehindTarget` (단검) · 설치물 스킬 데이터 (암기 · 투척 공용)
- 저격 모드: **모드 스킬 데이터**(`ModeAttackData`) — 활성 중 평타 슬롯 교체

## 검증 — 8종 각각 `Play As Listen Server, 2명`
- 1단계 6종이 각 실험체 데이터 애셋으로 동작 — 무기 교체로 D 가 바뀐다 (§12.5 검증)
- 매그너스 망치 ↔ 방망이, 시셀라 암기 ↔ 투척 — 2무기 A/B
- 저격 모드 중 평타가 다르게 나가고, 무기 교체 시 모드 강제 해제 (04)

## 주의점
- ⚠ 계수는 원본 §5.3 표에서 데이터로 — 코드에 숫자 없음
- ⚠ 은신 · 시야 는 **F16** 이 있어야 완성 — 태그와 자리만 두고 검증은 F16 뒤로
- 순서: 망치 → 권총 → 방망이 → 도끼 → 암기 → 투척 → 단검 → 저격총 (추가 코드 적은 순)

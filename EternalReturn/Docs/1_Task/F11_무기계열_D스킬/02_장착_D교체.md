## 할 일

무기 슬롯이 바뀌면 **이전 계열의 D · 평타 어빌리티를 회수하고 새 계열의 것을 부여**한다. 클라에는 **아이템 ID 하나**만 간다(이미 복제됨).

## ⭐ 복제하지 않는다 — 양쪽이 같은 테이블에서 파생 (§8.1)

```
서버: Equip(무기)  → 인벤토리 훅 OnWeaponChanged(이전 계열, 새 계열)
        → TakeSkills(WeaponSkills)            ← 이전 D · Attack 회수 (F07-01 핸들)
        → GrantSkills({ D(계열행), Attack(계열행) }, WeaponSkills)
클라:  Equipped 복제 → OnRep → 계열 행 조회 → 무기 메시 · D 아이콘 (F17) — 어빌리티 스펙은 ASC 가 복제한다
```

- D 는 `InitialLevel 0` 으로 부여된다 — **잠김**. 03 이 숙련도로 올린다
- 평타(`Ability.Slot.Attack`)는 `InitialLevel 1`
- ⚠ F07-07 테스트에서 실험체 데이터 `Skills` 에 넣어 둔 `DA_Attack_Test` 는 **빼고**, 평타는 무기가 준다 (원래 설계). 무기가 없으면 평타가 없다 — 맨손 (미확인) → `[자체]`: 맨손 평타 행 하나(`WeaponType None`)를 둔다
- 부활 · 재접속 시 `GrantSkills` 가 다시 도는 경로(F07-01 `bSkillsGranted` 빗장)와 무기 스킬 부여가 **중복되지 않게** — 무기 스킬 핸들을 별도(`WeaponSkills`)로

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- ⭐ 망치 장착 → `ER.Skill.Levels` 에 `Ability.Slot.D DA_Skill_Hammer_D Lv.0/3` + `Ability.Slot.Attack …`; 방망이로 교체 → D · Attack 이 **통째로 바뀐다** (로그 `회수 2 · 부여 2`)
- ⭐ 평타 사거리가 계열 값으로 (Argument 결과대로) · 클라 · 서버 동일
- 무기를 벗으면 D · Attack 회수 (맨손 규칙대로)
- 클라가 요청하고 서버가 확정 — F08-03 경로 그대로
- 2인 창에서 상대 무기 교체가 `ER.Item.Equipped` 로 보인다 (전원 복제, 메시는 나중)

## 주의점

- ⭐ 어빌리티를 복제하지 않는다. `Equipped` 만
- ⚠ 부여 전에 **반드시 회수** — 같은 슬롯 스펙이 둘이면 Q 처럼 두 번 나간다 (F07-01 경고)
- ⚠ 시전 중 교체는 04 가 막는다. 여기서는 순서만 (회수 → 부여)

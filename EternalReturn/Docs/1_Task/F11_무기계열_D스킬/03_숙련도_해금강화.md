# F11-03 — 숙련도 5/10/15 → D 해금 · 강화 ⭐

> 체크리스트 [`../../2_Checklist/F11_무기계열_D스킬/03_숙련도_해금강화.md`](../../2_Checklist/F11_무기계열_D스킬/03_숙련도_해금강화.md)

## 할 일

F10-04 의 `OnWeaponProficiencyLevelUp(WeaponType, Level)` 을 받아, **장착 중인 계열**이면 D 스펙 레벨을 올린다.

| 숙련도 | D 스펙 레벨 | 의미 |
|---|---|---|
| 0~4 | **0** | 잠김 — `CanActivateAbility` 가 레벨 0 을 막는다 (F07-03) |
| **5** (`UnlockLevel`) | **1** | 해금 |
| **10** | 2 | 1차 강화 — 쿨다운 · 계수 배열의 [1] |
| **15** | 3 | 2차 강화 — [2] |

- 판정은 **레벨이 변하는 순간의 서버 이벤트** (§6 구현 메모 — 매 프레임 비교 금지)
- 무기를 **바꿔 낀 순간**에도 같은 계산 — 그 계열의 현재 숙련도로 D 레벨을 맞춘다 (02 의 부여 직후)
- `ERSkill::LevelUpSkill` 은 포인트용이라 안 쓴다 — 스펙 레벨을 직접 세팅하는 서버 함수 하나 (`SetSkillLevel(Slot, Level)`, `bUsesSkillPoints=false` 인 스킬만)

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- ⭐ 망치 장착 · 숙련도 4 → D 입력 → 안 나감(Lv.0) · `ER.Growth.*` 로 5 → 로그 `D 해금 Lv.1` → D 나감
- ⭐ 10 → Lv.2 (쿨다운이 [1] 값으로) · 15 → Lv.3
- 도끼(숙련도 0)로 바꾸면 D Lv.0 · 다시 망치 → Lv.3 복원 (계열별 숙련도)
- 클라 `ER.Skill.Levels` 에 D 레벨 복제

## 주의점

- ⚠ 5/10/15 는 계열 행 값 — 코드에 숫자 없음
- ⚠ 숙련도는 OwnerOnly 라 클라는 D 레벨(스펙 복제)로만 안다 — 적의 해금 여부 은닉 (§6)

## 할 일

실험체마다 **들 수 있는 무기군**이 다르다.

| 실험체 | 무기군 |
|---|---|
| 카티야 | 저격총 |
| 매그너스 | 방망이 · 망치 |
| 재키 | 단검 · 양손검 · 도끼 · 쌍검 |
| 다니엘 | 단검 |
| 시셀라 | 투척 · 암기 |
| 레니 | 권총 |

> 검증 기준: *"카티야가 망치를 못 들고, 저격총만 장착됨"*

## ⭐ 어디에 저장하나

실험체가 어떤 무기군을 쓰는지는 **실험체 데이터**다.
→ **`UERCharacterData`(F02-05 에서 만든 데이터 애셋)에 추가**하는 것이 자연스럽다.

⚠ 이건 [`../../6_Lyra참조/03_데이터애셋_구성.md`](../../6_Lyra참조/03_데이터애셋_구성.md) §5 의
*"기능을 붙일 때 그때 정한다"* 항목에 해당한다. 그 체크리스트를 따른다.

## ⭐ 검사는 서버 권위

클라가 장착 요청을 보내고, **서버가 무기군을 검사**한다.
⚠ 클라 UI 에서 막는 것만으로는 부족하다 — 치트 클라가 우회한다.

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 카티야가 **망치를 못 든다**
- 카티야가 저격총은 든다
- ⭐ 클라가 검사를 우회해도 **서버가 거부**한다
- 무기군이 여러 개인 실험체(재키)가 4종 다 든다

## 주의점

- ⭐ **서버가 검사한다.** 클라 UI 만으로 막지 않는다
- ⚠ D 슬롯 스킬이 무기에 딸려 온다 (F11) — 여기서는 **장착 제한만**

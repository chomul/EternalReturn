## 할 일

사망 시 아이템을 **드롭**하고, 여러 명이 동시에 주우려 할 때 **서버가 단독 판정**한다.

## ⭐ 사망 시 드롭은 확인된 사실이다 (§7.1)

*"§7.1 사망 시 드롭은 **확인된 사실**이다"* — 추측이 아니다.

⚠ 다만 **부활 3단계와의 상호작용은 일부 (미확인)** 이다 (§7.2).

## ⭐⭐ 습득 경쟁 — 서버가 단독 판정한다 (§7.4)

> *"습득 권한 — 경쟁을 **서버가 단독 판정**한다"*

두 명이 같은 아이템을 동시에 주우려 하면 **한 명만** 성공해야 한다.

⚠ **클라에서 "내가 먼저 눌렀다" 를 판정하면 안 된다.** 둘 다 성공하거나 아이템이 복제된다.

## 드롭 액터 — 서버 권위 (§7.3)

드롭된 아이템은 **월드에 존재하는 액터**다. 서버가 스폰하고 복제한다.

## ⚠ F14 와의 경계

사망 처리 자체는 **F14**다. 여기서는 *"사망했다는 알림을 받으면 드롭한다"* 까지다.

F02-04 의 `OnOutOfHealth` 델리게이트가 그 알림이다 —
⭐ *"사망 처리를 하지 않는다 — **알리기만** 한다"* 로 만들어 둔 것이 여기서 쓰인다.

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- 사망 시 아이템이 월드에 드롭된다
- 드롭 액터가 **모든 클라에 보인다**
- ⭐⭐ **두 명이 동시에 주우면 한 명만** 성공한다
- ⭐ 클라가 습득을 우회해도 **서버가 거부**한다
- 드롭된 아이템을 주우면 월드에서 사라진다

## 주의점

- ⭐⭐ **습득 경쟁을 서버가 단독 판정한다** — 클라 선착순 판정 금지
- ⭐ 드롭 액터 스폰은 **서버**다
- ⚠ 사망 처리(F14)와 드롭(F08)의 경계를 지킨다
- 부활 시 드롭한 아이템이 어떻게 되는지 **(미확인)** 으로 남긴다

## 할 일

넉백 · 그랩을 **공용 함수 하나**로 만든다. 방향을 인자로 받는다.

```
매그너스 E — 넉백 3m. 벽에 부딪히면 추가 피해 + 기절
```

## ⭐⭐ 역기획서가 "반드시 읽을 것" 으로 표시한 절이다 (§3.5)

강제 이동은 **서버-클라 처리가 가장 까다로운 부분**이다.

| 무엇 | 어디서 |
|---|---|
| 강제 이동 시작 · 방향 · 거리 | ⭐ **서버 권위** |
| 벽 충돌 판정 | ⭐ **서버만** — 클라가 판정하면 결과가 갈린다 |
| 추가 피해 · 기절 | ⭐ **서버만** |
| 실제 이동 표현 | 클라는 **결과를 복제받아 재생**한다 |

⚠ **클라가 벽 충돌을 판정하면 안 된다.** 클라마다 다른 결과가 나온다.

## 엔진이 주는 것부터 본다

`CharacterMovementComponent::AddImpulse` / `LaunchCharacter` 로 시작한다.
⚠ 다만 *"정확히 3m"* 같은 **거리 보장**이 필요하면 임펄스로는 부족하다 —
`UAbilityTask_ApplyRootMotion*` 계열을 검토한다 (`CLAUDE.md` §1).

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 넉백 3m 가 **서버 · 클라 같은 위치**로 끝난다
- ⭐ 벽 충돌 시 **서버에서만** 추가 피해 + 기절이 발생하고 클라는 결과를 받는다
- 넉백 중 이동 입력이 무시된다
- 넉백 중 사망해도 크래시하지 않는다

## 주의점

- ⭐⭐ **벽 충돌 판정을 클라에서 하지 않는다**
- ⚠ 강제 이동 중 CMC 의 일반 이동과 충돌하지 않게 한다
- 방향을 인자로 받아 **넉백 · 그랩(끌어당김)이 같은 함수**를 쓴다
- `State.CCImmune`(이동 방해 면역, 매그너스 R)이 이걸 무시하게 한다 → F06-05

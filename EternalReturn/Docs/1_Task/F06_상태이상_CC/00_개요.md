## 목표

**CC 를 `UGameplayEffect` + `GameplayTag` 로 표현하고, 그 태그가 행동을 막는다.**

⭐ 이게 끝나면 계산식 11단계의 마지막 칸(**무효화 계층**)도 채워진다.

## ⭐ GAS 가 이미 주는 것 — 다시 만들지 않는다

| 하려는 것 | GAS에서 | ❌ 만들지 마라 |
|---|---|---|
| CC 상태 표현 | `UGameplayEffect` + `GameplayTag` | 자체 상태 enum |
| CC 로 시전 차단 | `ActivationBlockedTags` | 수동 플래그 검사 |
| 지속시간 관리 | GE 의 `HasDuration` | `FTimerManager` 직접 |
| 만료 시 자동 해제 | GE 제거 시 태그도 사라짐 | 수동 해제 코드 |
| 중첩 | `StackingType` | 자체 카운터 |

⚠ **태그는 이미 선언돼 있다** — `Source/EternalReturn/GAS/ERGameplayTags.h` (F00-05).
`State.CC.Stun` / `Snare` / `Silence` / `Disarm` / `Slow` / `Blind` / `VisionBlock`,
`State.Stealth` / `State.Invulnerable` / `State.CCImmune`.

## ⚠ 이 기능이 하지 않는 것

- **행동 강제 계열**(공포 · 매혹 · 도발 · 광기) · 수면 · 에어본 · 제압 · 변이 · 춤
  → *"6인 중 요구하는 캐릭터가 없어 **검증할 방법이 없다**"* (역기획서).
  **태그 자리만 만들고 로직은 7번째 캐릭터부터** 붙인다
- **도트(출혈) 중첩** — 9순위. 재키가 붙는 F07 이후
- **스킬 발동** — F07

## 할 일

기절이 **진행 중인 채널링을 끊는다.**

```
카티야 R — 0.8초 채널링. 도중에 기절하면 시전이 취소되고 쿨다운은 남는다
```

## ⭐ GAS 가 주는 것 — `CancelAbilitiesWithTag`

```cpp
// CC GE 에 설정
CancelAbilitiesWithTag = Ability.Form.Channeled
```

`Ability.Form.Channeled` 태그는 `ERGameplayTags.h` 에 **이미 있다** (F00-05).
채널링 어빌리티가 그 태그를 갖고, CC GE 가 그걸 취소한다.

⭐ **자체 취소 상태 머신을 만들지 않는다.**

## ⚠ 쿨다운은 남는다

> *"시전이 취소되고 **쿨다운이 남음**"* — 역기획서 검증 기준

Cooldown GE 는 **발동 시점**에 걸린다. 취소돼도 이미 걸린 쿨다운은 안 사라진다.
⚠ 이건 F07(스킬)의 쿨다운 구현과 맞물린다 — **F07 이 없으면 이 부분을 완전히 검증할 수 없다.**

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 채널링 중 기절 → **시전이 취소된다**
- ⭐ 취소돼도 **쿨다운이 남는다** (⬜ F07 이후)
- 기절이 만료되면 다시 시전할 수 있다
- 채널링이 아닌 즉발 스킬은 영향받지 않는다

## 주의점

- ⭐ **자체 취소 상태 머신을 만들지 않는다** — `CancelAbilitiesWithTag`
- ⚠ 취소 시 **쿨다운을 되돌리지 않는다** (그게 설계다)
- 채널링 어빌리티가 `Ability.Form.Channeled` 태그를 갖는지 F07 에서 확인

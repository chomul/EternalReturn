## 할 일

특수 상태 3종. 태그는 이미 있다 (`State.Stealth` / `State.Invulnerable` / `State.CC.Silence`).

| 상태 | 사례 | 핵심 |
|---|---|---|
| **은신** | 다니엘 E | ⭐ 적 클라에 **위치가 복제되지 않아야** 한다 |
| **무적** | 시셀라 W | ⭐ **피해만** 0. CC 는 그대로 걸린다 |
| **침묵** | 다니엘 R 0.5초 | 스킬만 막히고 **평타는 된다** |

## ⭐⭐ 은신이 가장 어렵다 — 릴리번시

> *"다니엘 E 은신 중 적 클라이언트에 **위치가 복제되지 않음**"* — 역기획서 검증 기준

⚠ **화면에서 안 보이게 하는 것만으로는 부족하다.** 위치가 복제되면
치트 클라가 패킷을 읽어 은신한 적을 본다.

⭐ 이건 **F16(팀 시야)와 같은 문제**다. 릴리번시로 막아야 한다.
→ ⚠ **F16 없이 완전한 구현이 어렵다.** 여기서는 태그와 판정만 만들고,
릴리번시 차단은 **F16 과 함께** 한다. 그 경계를 주석에 남긴다.

## 무적 — 피해만 막는다

⭐ F03 의 계산식 11단계(**무효화 계층**)가 여기서 채워진다.

```cpp
// ERDamageExecution - PreGameplayEffectExecute 또는 계산 종단
if (TargetTags.HasTag(ERTags::State_Invulnerable)) { Damage = 0.f; }
```

⚠ **CC 는 막지 않는다.** 무적 중에도 기절은 걸린다 (역기획서 §3.4).

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 무적 중 **피해 0**, 같은 타이밍의 **기절은 정상 적용**
- ⭐ 침묵 중 **스킬만** 막히고 기본 공격은 된다
- 은신 중 적 화면에서 안 보인다
- ⬜ 은신 중 **위치가 복제되지 않는다** → **F16 과 함께**

## 주의점

- ⭐ **무적이 CC 를 막지 않는다** — 피해만이다
- ⚠ 은신을 "안 보이게" 로만 만들면 **치트에 뚫린다**
- 침묵이 평타를 막지 않는 것을 확인한다 (무장 해제와 다르다)

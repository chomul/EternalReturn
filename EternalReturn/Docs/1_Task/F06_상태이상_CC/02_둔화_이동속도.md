# F06-02 — 둔화 (이동속도)

> 기능 [F06](00_개요.md) · 근거 [`전투판정_상태이상_역기획서.md`](../../0_GameDesign/Systems/전투판정_상태이상_역기획서.md) · 우선순위 2
> 체크리스트 [`../../2_Checklist/F06_상태이상_CC/02_둔화_이동속도.md`](../../2_Checklist/F06_상태이상_CC/02_둔화_이동속도.md)

## 할 일

`MoveSpeed` 어트리뷰트를 **퍼센트로 깎는** GE 를 만든다.

```
매그너스 Q — 60% 둔화
```

## ⭐ 하한 클램프는 이미 있다

F02-03 이 `MoveSpeed` 를 `[MinMoveSpeed, MaxMoveSpeed]` 로 자른다
(기본 1.0 ~ 12.0, `ERStatCapSettings`).

> *"하한이 없으면 둔화가 쌓여 이동 속도 0 → 영구 행동 불능이 된다."*

⭐ **여기서 또 클램프하지 않는다.** 이미 한 곳에서 한다.

## ⚠ 둔화는 `Duration` GE 다 — `Instant` 가 아니다

| | |
|---|---|
| `Instant` | Base 를 바꾼다 → **만료돼도 안 돌아온다** |
| `HasDuration` ✅ | Current 만 바꾼다 → **만료 시 자동 복구** |

⚠ 이건 [`../../4_Argument/5_추가공격력_산출방식.md`](../../4_Argument/5_추가공격력_산출방식.md) 의 규칙과도 이어진다 —
`Instant` 로 만들면 "기본 이동속도가 영구히 깎인" 상태가 된다.

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 매그너스 Q(60%) 적중 시 **서버 · 클라 이동속도가 같다**
- ⭐ **만료되면 원래 속도로 돌아온다**
- 둔화 여러 개가 겹칠 때 하한 아래로 안 내려간다
- ⭐ 실제로 **캐릭터가 느리게 움직인다** (F05-02 의 CMC 반영이 동작한다)

## 주의점

- ⭐ **`HasDuration` 이어야 한다.** `Instant` 면 영구히 깎인다
- ⭐ **여기서 클램프하지 않는다** — F02-03 소관
- ⚠ `MoveSpeed` 어트리뷰트가 CMC 에 반영돼야 눈에 보인다 (F05-02 연결 지점)
- 둔화 저항(`SlowResist`)은 F06-05 에서 붙인다

## 목표

**아이템 2개를 조합해 상위 아이템을 만들고, "이걸 만들려면 무엇이 필요한가" 를 데이터만으로 계산한다.**

## ⭐ 역기획서가 확정한 구조 (§3.1) — 구현이 단순해지는 이유

| 규칙 | 구현 귀결 |
|---|---|
| ① 제작은 **항상 아이템 2개 조합** `A + B → C` | 조합 테이블이 아니라 **결과 행에 재료 2개**(`CraftMaterialA/B`)면 끝 — F08 이 `FERItemRow` 에 이 자리를 비워 뒀다 |
| ② 등급 ≠ 파워 | 제작 시스템은 스탯을 모른다. 등급은 **숙련도 경험치**(F10-04 제작 100~800)에만 쓴다 |
| ③ 전설 · 초월은 보스 재료 | 재료의 획득은 F12 · F14 — 제작은 "있으면 만든다" 만 |
| ④ 초월은 일반 + 최고급 재료로 **건너뛴다** | 트리에 깊이 제한 · 단계 강제가 없다 — 재귀는 데이터가 시키는 대로 |

> 6인이 쓰는 **6종(망치 · 도끼 · 단검 · 암기 · 저격총 · 권총)** 만 데이터로 넣으면 시스템 검증은 끝난다 (§3.1 제안). 망치 17종이 전수 조사돼 있다 (§3 표).

## ⚠ 이 기능이 하지 않는 것

- **파밍 위치 오버레이 UI**(5순위) — F17. ⚠ 역기획서 *"3순위와 세트다. 빼면 안 된다"* — 그 세트의 **데이터**(어느 재료가 어느 지역에서 나오나)는 03 이 만든다. 그림만 F17
- **원격 전송 드론**(7순위) — F15 (크레딧)
- **야생동물 드랍**(가죽 · 깃털) — F12. 03 의 루트 테이블 형식을 F12 가 그대로 쓴다
- **지역별 상자 배치**(어느 지역에 어떤 상자) — F13 이 배치, 03 은 상자 액터와 루트 테이블
- 고유 효과(파열 · 크리티컬 블로우 …) — 6순위 별도

## ⭐ 독립 구현 전략

| 없는 것 | 스텁 |
|---|---|
| 지역(F13) | 상자 · 채집물을 **손으로 맵에 놓는다**. 지역별 종류 차이는 루트 테이블 행 이름으로만 |
| 크레딧(F15) | 드론 없음 — 디버그 `ER.Item.Give` 로 재료 |
| 야생동물(F12) | 없음 |
| UI(F17) | 콘솔 `ER.Craft.*` |

## 할 일

카메라 **잠금/해제**와 **가장자리 스크롤**을 만든다.

## ⭐ 리그는 이미 있다

`AERCharacterBase` 에 SpringArm + Camera 가 **F01 에서 이미 붙어 있다**
(길이 800, -60도, 절대 회전, 충돌 테스트 끔). **다시 만들지 않는다** (`CLAUDE.md` §3).

여기서 추가하는 것은 **잠금 상태**뿐이다.

| 상태 | 동작 |
|---|---|
| **잠금** (기본) | 카메라가 캐릭터를 따라간다 |
| **해제** | 카메라가 제자리에 남고, 마우스를 화면 가장자리로 가져가면 스크롤된다 |

## ⚠ 구조 결정이 하나 있다 — 카메라를 누가 소유하나 (§6.2)

캐릭터에 붙은 카메라는 **부활하면 사라진다.** 폰이 새로 생기기 때문이다.
카메라 상태(잠금 여부 · 스크롤 위치)를 어디에 둘지 정해야 한다.

| | 방안 | |
|---|---|---|
| A | 캐릭터가 소유 (현재 구조) | 단순. ⚠ 부활 시 상태가 날아간다 |
| B | PlayerController 가 소유 | 부활에도 살아남는다. 구조 변경 필요 |

⚠ **방안이 2개라 `Docs/4_Argument/` 문서 대상이다.** 구현 **전에** 쓴다 (`CLAUDE.md` §1.2).

## 검증

- **빌드 통과** (Editor + Server)
- 잠금 상태에서 캐릭터를 따라간다
- 해제 상태에서 가장자리 스크롤이 동작한다
- 토글 키로 두 상태가 오간다
- ⭐ 카메라는 **로컬 전용**이다 — 다른 클라 화면에 영향이 없다

## 주의점

- ⭐ **카메라를 복제하지 않는다.** 각자 자기 것을 본다
- ⚠ 창 모드에서 가장자리 스크롤이 **의도치 않게 발동**한다 — 끌 수 있어야 한다 (§10)
- 스크롤 속도 · 가장자리 두께를 하드코딩하지 않는다

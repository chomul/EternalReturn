## 할 일

CC(기절 · 속박 · 침묵)가 걸렸을 때 **입력을 막는다.**

## ⭐⭐ 이중 게이트 (§9.1)

> 입력 레이어와 GAS **양쪽에서** 막는다. 하나만으로는 부족하다.

| 게이트 | 무엇을 막나 | 없으면 |
|---|---|---|
| **입력 레이어** | 키를 눌러도 요청이 안 나감 | 서버로 쓸데없는 RPC 가 계속 간다 |
| **GAS `ActivationBlockedTags`** | 요청이 와도 어빌리티가 안 나감 | ⭐ **치트 클라가 입력 게이트를 우회한다** |

⚠ **GAS 쪽이 진짜 방어선이다.** 입력 게이트는 대역폭 · 체감용이고,
**권위 판정은 서버의 `ActivationBlockedTags` 가 한다** (`CLAUDE.md` §6).

## CC 축별 반응 (§9.2)

| CC 태그 | 이동 | 기본공격 | 스킬 |
|---|---|---|---|
| `State.CC.Stun` (기절) | ❌ | ❌ | ❌ |
| `State.CC.Snare` (속박) | ❌ | ✅ | ✅ |
| `State.CC.Silence` (침묵) | ✅ | ✅ | ❌ |
| `State.CC.Disarm` (무장 해제) | ✅ | ❌ | ⚠ **평타 판정 스킬도** 막힌다 |

태그는 `Source/EternalReturn/GAS/ERGameplayTags.h` 에 **이미 있다** (F00-05).

## 검증 — `Play As Client, Number of Players: 2`

- **빌드 통과** (Editor + Server)
- ⭐ 기절 중 이동 · 평타 · 스킬이 **전부** 막힌다
- 속박 중 이동만 막히고 공격은 된다
- 침묵 중 스킬만 막힌다
- ⭐ **만료되면 자동으로 풀린다** (수동 해제 코드가 없다)
- ⭐ 입력 게이트를 우회해도 **서버가 거부**한다

## 주의점

- ⭐ **CC 상태를 자체 bool 로 들고 있지 않는다.** 태그를 그때그때 조회한다
- ⚠ 입력 게이트만 만들고 GAS 쪽을 빠뜨리지 않는다 — **치트에 뚫린다**
- 무장 해제가 **평타 판정 스킬**까지 막는 것을 잊지 않는다 (`Ability.Form.NextAttackBuff`)

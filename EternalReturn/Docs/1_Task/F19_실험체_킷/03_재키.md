## 스킬 — 🆕 새로 만들 것 · ✅ 재사용 · ⏸ 기능 의존으로 미룸

| 스킬 | 요약 | 구현 |
|---|---|---|
| P 피의 축제 | 평타 · 스킬 적중 **출혈 최대 5중첩 6초** · 최대 중첩 또는 **킬 관여** 시 아드레날린 5초 | 🆕 **도트 중첩** (주기 GE 스택) · ⏸ 킬 관여 트리거 → F14 (최대 중첩 트리거는 지금) |
| Q 롱소드 | 1.5m 돌진 베기 · +**대상 현재 체력** 5% · 피해 30% 회복 · 최대 출혈 대상 증가 피해 · 적중 시 3초 안 재사용 | `_SelfMove` · `CurHPRatio` ✅ · `HealFromDamageRatio` ✅ · `_Recast` ✅ |
| W 힘줄 절단 | 다음 평타 강화 · 둔화 60~80% 0.85초 · 6초 | `_NextAttackBuff` ✅ |
| E 강습 | 5.5m 위치 도약 + 착지 0.7m · **처치 시 쿨 초기화** · 최대 출혈 대상 평타 시 쿨 −0.5초 | `_SelfMove` 도약 ✅ · 🆕 **처치 시 쿨 초기화** · 🆕 조건부 쿨 감소 |
| R 전기톱 살인마 | 8~10초 · 이속 · 공속 증가 · 지속 중 재사용 **학살**(잃은 체력 비례) · 킬 관여 +5초 | 🆕 **스킬 슬롯 상태 교체** (`_Mode` 일반화 — 지금은 평타 슬롯만) · `LostHPRatio` ✅ · ⏸ 킬 관여 연장 → F14 |

⚠ 무기 **양손검 · 쌍검**의 D 스킬은 F11 (8종)에 없다 — 재키 착수 때 F11 방식으로 2종 추가 (역기획서 무기 §2.3.5 수치 있음)

## 착수 전
- [ ] `(미확인)` 항목 — 검색 → 사용자 확인: 출혈 중첩별 개별 타이머인지 전체 갱신인지 · Q 최대 출혈 증가 피해 수치 · W 강화 대기 만료 시간 · R 연장 누적 · 상한
- [ ] 방안이 둘 이상인 설계 → Argument: 도트 중첩 방식 · 스킬 슬롯 교체 일반화
- [ ] 캐릭터 DA: 기본 스탯 · 레벨당 (§2) · 무기 목록 (§4) · 무기 숙련 증폭

## 연출 (F12.5 파이프라인)
- 스킬마다 모션 세트 슬롯(`Anim.Q` …)에 몽타주 · 적중 Cue (`GameplayCue.Hit.*` / 스킬 전용 Cue)
- 판정은 어빌리티 타이머 — 몽타주는 같은 길이로 맞춘 연출 (Argument 36)
- 시야 밖 가림은 F18

## 검증 — `Play As Listen Server`, 2명 (+ 야생동물 · 보스로 비례 피해 · 관통 확인)
- **빌드 통과**
- 스킬별 로그: 판정 · 피해 (원작 수치 레벨 1 / 최대) · CC · 쿨다운 · 코스트
- 서버 권위: 모든 판정 · 이동 · 상태가 서버 · 클라는 결과만 (클라 창 로그 비교)
- 스킬 모션 · 이펙트 — 서버 · 소유 클라 · 다른 클라 동일

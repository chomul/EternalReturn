### 2. 네트워크

- **서버 권위**: 스폰 · 비행 판정 · 적중 · 피해 · 버프 · 이동 · 스캔 전부 서버
- 투사체 액터: `bReplicates` · **`bReplicateMovement = false`** — 초기값(시작 · 방향 · 속도 · 사거리 · 호밍 대상)만 복제 → 클라가 **같은 직선 / 같은 호밍을 스스로 시뮬레이션** (모습). 서버 소멸 → 클라 소멸
- 이동(E 넘기)은 기존 강제 이동 멀티캐스트 · 버프는 GE 복제 · 모션은 ASC 몽타주 복제 (R 몽타주)

### 3. 세부

- 적중 문맥 `FERSkillContext` 에 **`TravelRatio` (0~1)** · **`ShotIndex`** 추가 → 피해 조각이 읽는다
- 투사체 겹침 대상: 캐릭터 채널만 · 벽(WorldStatic)은 멈춤 — 콜리전은 액터 안에서 설정 (애셋 설정 없음)
- 관통: 기존 `bPenetrate` + 🆕 **`bPierceWildlife`** (R — 야생동물은 지나치고 실험체는 맞음)
- R 발사 간격 `[자체]` 0.15초 (미확인) · 대상 30m 초과면 건너뜀
- E 넘기 여분 `[자체]` 1.5m (미확인 — "조금 더") · 착지 검사 = 캡슐이 들어가고 내비 위
- ~~P 레벨 구간 `[자체]` 캐릭터 Lv 1 / 6 / 11~~ → **P 는 포인트로 찍는다** (1 시작 · 최대 3) — 이미 정해진 규칙 (사용자 2026-09-18 · `ERSkillData.h:377`). 역기획서 "캐릭터 레벨로 자동" 은 따르지 않는다
- 스탯 (K1): `DA_Char_Katja` §2 값 · 무기 숙련 증폭 저격총 행

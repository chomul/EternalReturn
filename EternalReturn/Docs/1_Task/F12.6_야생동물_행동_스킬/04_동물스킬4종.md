## 네트워크

- 전부 서버. 띄우기는 넉백과 같은 Reliable 멀티캐스트 — 모든 머신이 같은 시작 · 끝 · 높이로 같은 포물선
- 판정 순간 애니 = 시작 애니와 같은 규칙 (서버 + 소유 클라 · ServerInitiated · 복제 몽타주)

## 검증

1. 빌드 Editor · Server 에러 0
2. 각 동물 스폰 · 때림 — 스킬 로그 · 몽타주 · 소리 · 효과 (아래 에디터 문서 절차)
3. 띄우기 — 서버 · 클라 화면에서 같은 포물선 · 로그 `높이 150cm`
4. 늑대 — 스폰 자리(2마리 무리)에서 한 마리 처치 → `짝이 죽음 → 스킬 … 발동`

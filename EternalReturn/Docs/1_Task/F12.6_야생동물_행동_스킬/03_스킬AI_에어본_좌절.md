# F12.6-03 — 스킬 AI 틀 · 에어본 · 좌절

> 상위 [00 개요](00_개요.md) · 결정 [Argument 51](../../4_Argument/51_야생동물_행동_스킬_범위와_방식.md) ④ K1 (사용자 "동물 스킬도 어짜피 쿨타임 있어서" → 주기 조건 없음) · 받는 피해 증가 **A — 어트리뷰트 추가** (사용자 2026-09-30)

## 네트워크

- 전부 서버 — AI · 발동 · GE · 피해 계산. 클라는 태그 · 어트리뷰트 복제 · 몽타주 · 큐 (기존 경로)
- `DamageTakenAmp` 는 서버 계산 전용이라 복제 안 함 (`ProportionalDamageResist` 와 같다)

## 검증

1. 빌드 Editor · Server 에러 0
2. 임시 테스트 스킬(곰): 사거리 안이면 스킬 → 쿨 동안 평타 · 로그 `[야생AI] … 스킬 … 거리 N m`
3. 빗나감 → `실패 벌칙 (빗나감)` · 선딜 중 `ER.Wild.CC GE_CC_Stun` → `선딜 취소 (CC)` → `실패 벌칙 (시전 중 CC)` · 좌절 중 피해가 늘어나나 (피해 로그 비교)
4. 에어본 GE 를 자기에게 (`ER.CC.Apply …GE_CC_Airborne_C 3`) → 이동 · 평타 · 스킬 막힘 · 방해 저항 무시

# F12.6-01 — AI 상태 복제 · 등장 · 발견 · 전투 끝

> 상위 [00 개요](00_개요.md) · 결정 [Argument 50](../../4_Argument/50_야생동물_추가동작_사운드.md) N1 · (b) 발견은 소리만 · [E32](../../5_ErrorReport/E32_다시_relevant_된_클라에_시체가_늦게_쓰러진다.md)

## 목표

서버 AI 상태가 바뀌면 모든 클라가 **같은 몸짓 · 소리**를 보고 듣는다. 늦게 relevant 된 클라는 **지난 사건을 다시 틀지 않는다.**

## 구조

| 무엇 | 어디 | 책임 |
|---|---|---|
| `EERWildlifePresState` (Idle · Combat · Return — 02 가 Beware · Sleep 추가) | `Wildlife/ERWildlifeCharacter.h` | 연출용 상태. AI 상태와 따로 — 경계 · 잠은 AI 로는 "대기" 의 하위 |
| `FERWildlifePresState { State · ServerTime }` · `ReplicatedUsing = OnRep_PresState` | `AERWildlifeCharacter` | 한 구조체라 **둘이 같이 도착** (OnRep 때 시각이 이미 있다) |

| `AERWildlifeAIController::SetState` | 기존 | 끝에서 `SetPresState` 한 줄 |

## 사건 → 연출

| 바뀜 | 연출 | 근거 |
|---|---|---|
| (스폰) 첫 Idle | `appear` 몽타주 + 등장음 (보스만 원본에 있음) | Argument 50 원본 표 |
| Idle → Combat | **발견음만** (`<종>WakeUp_Start` · `ready_bear/wolf`) | Argument 50 (b) — 애니가 종마다 있다 없다 해서 |
| Return → Idle (자리 도착) | `endbattle` 몽타주 | `[자체]` — Combat → Return 에 틀면 곧바로 걷기 시작해 미끄러진다 (48 M1 은 "한 번도 멈춘 걸 못 본 몽타주" 는 안 끊는다) |

## 네트워크

- 서버 권위: `SetPresState` 는 서버만. 클라 AI 없음 (역기획서 §7.2)
- 복제: 동물당 **5바이트** (상태 1 + 시각 4) · 바뀔 때만
- 도먼시: 대기 ↔ 전투 전환은 `SetBodyActive` 가 이미 깨운다. 등장은 첫 복제에 실린다
- ⭐ 늦음 판정: `GameState->GetServerWorldTimeSeconds() − ServerTime > 1초` → 몽타주 · 소리 없이 상태만 (E32 와 같은 1초)
- 몽타주는 **각 머신 로컬** (채집 · 사망과 같음) · 데디 서버는 재생 안 함
- ⚠ 새 액터의 OnRep 은 BeginPlay **전** (`DataChannel.cpp:3331 → 3345`) — 애님 인스턴스가 아직 없을 수 있어 **BeginPlay 에서 한 번 더** 확인해 튼다 (등장)

## 세부

- `SetPresState` 는 같은 상태면 건너뛴다 (AI `SetState` 와 같다)
- 로그: `[야생연출] %s 대기 → 전투 · 발견음 wolfWakeUp_Start (클라 · 0.04초)` / 늦으면 `(늦음 6.2초 · 건너뜀)`
- 소리 · 애니 없는 종은 로그 한 줄 (Verbose) 로 건너뛴다

## 검증

1. 빌드 Editor · Server 에러 0
2. PIE 리슨 2인: `ER.Wild.Spawn Bear` → 두 창 `등장` · 때림 → `발견음` · 끌고 가서 10m 넘김 → 귀환 → 도착 때 `endbattle` (서버 · 클라 로그)
3. 늦은 relevant: `ER.Wild.NetCull 30` · B 50m 밖 · A 가 싸움 → B 다가감 → B 로그에 `(늦음 N초 · 건너뜀)` · 몸짓 재생 없음
4. 데디: `(서버)` 연출 줄 없음

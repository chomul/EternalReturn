# F02-04 — 체력 처리 · 사망 알림

> 기능 [F02 어트리뷰트셋](00_개요.md) · 선행 [03 클램프 · 상한](03_클램프_상한.md)
> 체크리스트 [`04_체력처리_사망알림.md`](../../2_Checklist/F02_어트리뷰트셋/04_체력처리_사망알림.md)

## 할 일

`IncomingDamage`(Meta)를 실제 체력 감소로 바꾸고, 체력이 0이 된 사실을 **알린다.**

```cpp
void UERAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    Super::PostGameplayEffectExecute(Data);

    if (Data.EvaluatedData.Attribute == GetIncomingDamageAttribute())
    {
        const float Damage = GetIncomingDamage();
        SetIncomingDamage(0.f);                       // ⭐ 통로를 비운다
        if (Damage > 0.f)
        {
            SetHealth(FMath::Max(GetHealth() - Damage, HealthFloor));
            if (GetHealth() <= 0.f) { /* 사망 델리게이트 */ }
        }
    }
}
```

## 왜 `PostGameplayEffectExecute` 인가

`AttributeSet.h:198-201` 주석:

> *"Called just after a GameplayEffect is **executed** to modify the base value of an attribute. No more changes can be made.
> Note this is only called during an 'execute'. E.g., a modification to the 'base value' of an attribute. **It is not called during an application of a GameplayEffect, such as a 5 second +10 movement speed buff.**"*

⭐ **즉 즉발 피해(execute)에서만 불린다.** 지속 버프에는 안 불린다 — 정확히 우리가 원하는 동작이다.

## ⭐ Meta Attribute를 반드시 비운다

`SetIncomingDamage(0.f)` 를 빠뜨리면 **다음 피해에 이전 값이 남아 중복 적용**된다.
Meta는 "한 번 쓰고 버리는 통로"이므로 **읽는 즉시 비운다.**

## ⭐ 체력 하한은 **여기서 다루지 않는다** (2026-09-07 결정)

어트리뷰트는 **0 하한만** 안다. 하한 파라미터를 받지 않는다.

시셀라에게 두 종류가 있는데 **성격도 값도 다르다.**

| | 무엇 | 하한 | 경로 |
|---|---|---|---|
| Q · W | HP를 **코스트로 소모** | **1** | Cost |
| R | 자기 자신에게 **피해** | **100** | Damage |

⚠ **하한을 어트리뷰트나 데미지 경로에 두면 안 된다.** 모든 피해 경로가 하한을 들고 다니게 되고,
**실수로 하나 남으면 죽어야 할 때 안 죽는다.** 그게 훨씬 위험한 버그다.

대신 **하한을 아는 쪽이 미리 깎아서 넘긴다.**

```
Q/W (코스트) : 실제 소모 = min(코스트,  현재HP - 1)
R  (자기 피해): 실제 피해 = min(계산된 피해, max(0, 현재HP - 100))
```

상세: [`../../4_Argument/3_어트리뷰트셋_구조.md`](../../4_Argument/3_어트리뷰트셋_구조.md) D절

## ⭐ 사망 처리를 여기서 하지 않는다

체력 0을 **알리기만** 한다. 액터를 죽이거나 파괴하지 않는다.

이유는 이전 계획과 같다 — 이 AttributeSet은 **야생동물(F12)·보스도 쓴다.**
여기서 캐릭터 사망 로직을 돌리면 재사용이 안 된다.
사망 반응은 듣는 쪽(캐릭터·야생동물 각자)이 한다.

## 검증

- **빌드 통과** (Editor + Server)
- `IncomingDamage` 를 적용하는 GE 실행 → 체력이 **정확히 그만큼** 줄어든다
- ⭐ 같은 GE를 두 번 실행 → **두 번 다 정확한 양**만 줄어든다 (Meta가 안 남는다)
- 체력이 0 미만으로 안 간다
- 하한 100을 지정하면 100에서 멈춘다
- 체력 0 시 델리게이트가 **서버에서** 발동한다
- 지속 버프 GE에서는 `PostGameplayEffectExecute` 가 **안 불린다**

## 주의점

- ⭐ **`SetIncomingDamage(0.f)` 누락** — 이 Task에서 가장 위험한 실수. 피해가 누적된다.
- ⭐ **여기에 클램프를 또 넣지 않는다.** F02-03의 `PreAttributeChange` 가 이미 한다. 두 곳에서 자르면 추적이 안 된다.
- `Data.Target` / `Data.EffectSpec` 에서 공격자·이펙트 정보를 얻을 수 있다. **필요한 것만 쓴다.**
- 이 함수는 **서버에서만** 불린다 (GE execute는 서버 권위). 별도 `HasAuthority()` 가드는 불필요하지만, 주석에 명시한다.
- 회복량 보정(날씨·전투 중 감소)은 F15 영역이다. **여기서 하지 않는다.**

## 목표

모든 수치를 `UAttributeSet` 으로 정의한다. **체력·공격력·방어력이 GAS 어트리뷰트가 된다.**

## ⚠ 자체 스탯 컴포넌트를 만들지 않는다

이전 계획은 `UERStatComponent` 4레이어 자체 구현이었다. **GAS 결정으로 폐기됐다.**

| 이전 계획 | GAS |
|---|---|
| `UERStatComponent` | ❌ 만들지 않는다 |
| 4레이어(기본/성장/장비/버프) | ✅ **`UGameplayEffect` 가 대신한다** — 장비 착용 = Infinite GE 적용, 벗기 = 제거 |
| `AddModifier` / `RemoveModifier` 핸들 | ✅ **`FActiveGameplayEffectHandle`** |
| 스탯 캡 | ✅ `PreAttributeChange` 클램프 |
| `OnRep_` + 자체 델리게이트 | ✅ `GetGameplayAttributeValueChangeDelegate()` |

⭐ **GAS가 이미 제공하는 것을 다시 만들지 않는다** (`CLAUDE.md` §8).

## Base / Current 이중 구조 — 4레이어의 GAS식 대응

| | 무엇 | 이 게임에서 |
|---|---|---|
| **Base Value** | 영구적인 값 | 실험체 기본 스탯 + 레벨 성장 |
| **Current Value** | Base + 활성 GE 수정자 | 장비·버프·상태이상이 얹힌 값 |

장비를 벗으면 **GE를 제거**하는 것만으로 값이 정확히 복원된다.
자체 구현에서 핸들을 들고 있어야 했던 이유가 GAS에서는 자동으로 해결된다.

## 독립 구현 전략

- ⭐ **F03(데미지 공식)을 모른다.** 어트리뷰트는 값을 들고 클램프할 뿐이다. 계산은 `ExecutionCalculation`(F03)이 한다.
- **UI를 모른다.** 변경을 델리게이트로 알린다.
- 캐릭터 전용이 아니다. **야생동물(F12)도 같은 AttributeSet을 쓴다** ([몬스터 문서](../../0_GameDesign/Systems/몬스터_야생동물_역기획서.md) §6.1 — *"다시 만들지 않는다 … 플레이어와 같은 AttributeSet"*).

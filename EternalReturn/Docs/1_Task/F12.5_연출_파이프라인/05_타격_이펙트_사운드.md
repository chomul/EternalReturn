# F12.5-05 — 타격 이펙트 · 사운드

> 기능 [F12.5](00_개요.md) · 근거 [`Argument 36`](../../4_Argument/36_애니메이션_사운드_연출_레이어.md) · CLAUDE.md §8 (이펙트 · 사운드 = GameplayCue) · 체크리스트 [`../../2_Checklist/F12.5_연출_파이프라인/05_타격_이펙트_사운드.md`](../../2_Checklist/F12.5_연출_파이프라인/05_타격_이펙트_사운드.md)

## 할 일

| 무엇 | 층 | 예 |
|---|---|---|
| 타격 · 피격 | **GameplayCue** `GameplayCue.Hit.*` — 피해 GE 에서 (채널별: 평타 · 스킬 · 고정) | 불꽃 · 타격음 · 치명타 |
| 피격 반응 | Cue 또는 가벼운 애디티브 (판정 영향 없음) | 움찔 |
| 무기 휘두름 · 발사음 | 몽타주 AnimNotify (로컬) | 평타 휘두름 |
| 발소리 | AnimNotify (로컬 · 순수 연출) | 걷기 |
| 야생동물 울음 · 공격음 | Cue / Notify | 곰 포효 |

- ❌ 스킬 안에서 `SpawnSoundAtLocation` 직접 호출 금지 — 서버에서도 돈다 (Argument 36 "하지 말 것")
- Cue 태그는 `ERGameplayTags.h` 에 선언 (CLAUDE.md §8)

## ⚠ 지금 못 하는 것

- **시야 밖 적의 Cue · 소리 차단** — F16 팀 시야 뒤 **F18**. 지금은 전원이 듣는다 (위치가 새는 상태 — 알고 둔다)

## 검증

- 평타 · D · 동물 공격 적중 → 이펙트 · 소리 (서버 · 클라)
- 데디 서버에서 Cue 가 서버 비용을 쓰지 않는다 (서버는 재생 안 함)

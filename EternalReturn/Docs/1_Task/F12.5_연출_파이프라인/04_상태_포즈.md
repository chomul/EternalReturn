# F12.5-04 — 상태 포즈 (복제 값 → AnimBP)

> 기능 [F12.5](00_개요.md) · 근거 [`Argument 36`](../../4_Argument/36_애니메이션_사운드_연출_레이어.md) 원칙 2 · 체크리스트 [`../../2_Checklist/F12.5_연출_파이프라인/04_상태_포즈.md`](../../2_Checklist/F12.5_연출_파이프라인/04_상태_포즈.md)

## 할 일 — 이미 복제되는 값을 AnimBP 가 읽는다 (새 복제 없음이 목표)

| 상태 | 원천 (복제) | 대상 |
|---|---|---|
| 기절 | `State.CC.Stun` 복제 태그 (F06) | 실험체 · 야생동물 · 보스 |
| 속박 · 침묵 · 둔화 | `State.CC.*` | 실험체 (속박은 이동 레이어 정지) |
| 저격 모드 | 모드 활성 (F11 `_Mode`) | 카티야 · 저격총 든 실험체 |
| 채집 중 | 채집 점유 (F09-03 — 표시는 F17 이라 **복제 여부 확인 필요**) | 실험체 |
| **야생동물 시체** | `bDead` 복제 · `IsDead()` BlueprintPure (F12-04) | 동물 7 · 보스 3 — **1분 누워 있다** |

- ⭐ 시체는 **사망 순간 몽타주가 아니라 상태 포즈** — 도먼시로 늦게 relevant 된 클라도 누운 몸을 본다
- 사망 순간 쓰러지는 모션은 `bDead` OnRep 에서 한 번 (재생 중 relevant 된 클라는 누운 포즈로 바로)

## 검증

- CC 걸림 → 포즈 · 풀림 → 복귀 (클라 동일)
- 동물 처치 → 쓰러짐 → 1분 누움 → 사라짐 · 멀리서 다가간 클라(늦은 relevant)도 **누운** 시체를 본다

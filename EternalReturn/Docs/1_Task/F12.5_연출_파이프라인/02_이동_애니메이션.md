# F12.5-02 — 이동 애니메이션 (전원)

> 기능 [F12.5](00_개요.md) · 체크리스트 [`../../2_Checklist/F12.5_연출_파이프라인/02_이동_애니메이션.md`](../../2_Checklist/F12.5_연출_파이프라인/02_이동_애니메이션.md)

## 할 일

**AnimBP 는 BP**(CLAUDE.md §7 — 연출은 BP). 코드는 AnimBP 가 읽을 값만 준다 (속도 · 무기 계열 · 상태).

## 실험체 6

- 공통 AnimBP 1개 + **무기 계열별 Linked Anim Layer** — `EquippedWeaponType` 은 이미 복제된다 (무기계열 역기획서 §8.1)
- 무기 교체 → 레이어 교체 (대기 · 이동 자세가 무기마다 다르다)
- 캐릭터마다 스켈레톤이 다르면 AnimBP 도 캐릭터별 (Linked Layer 인터페이스는 공유)

| 실험체 | 무기 레이어 |
|---|---|
| 카티야 | 저격총 |
| 매그너스 | 방망이 · 망치 |
| 재키 | 단검 · 양손검 · 도끼 · 쌍검 (⚠ 양손검 · 쌍검 D 는 F11 에 아직 없다 — 이동 레이어는 가능) |
| 다니엘 | 단검 |
| 시셀라 | 투척 · 암기 |
| 레니 | 권총 |

## 야생동물 7 · 보스 3

- 종마다 AnimBP (스켈레톤이 다르다) — `UERWildlifeData.AnimClass` 는 이미 있다 (F12-01)
- 대기 · 걷기 · 뛰기 블렌드 — 속도는 CMC 복제 이동이 준다
- ⚠ **대기 중 CMC · 메시 틱이 꺼진다** (F12-04 `SetBodyActive`) — 깨어날 때 포즈가 튀지 않는지 06 에서 확인
- 변이 · 잠식: **스켈레톤이 따로라 AnimBP 도 따로** (본 구성이 같으면 Compatible Skeleton 으로 공유 — (미확인) · Argument 39) · `MeshScale` 1.15 (원작 10~20% 큼 · F12-06) → `ER.Wild.FitHitBox` 재실행

## 검증

- 6명 × 각 무기: 걷기 · 멈춤 · 무기 교체 시 자세 바뀜 (클라에서도)
- 야생동물 · 보스: 추적 · 귀환 중 이동 모션 · 대기 복귀 시 대기 모션
- 이동 속도 버프 · 둔화 → 걷기 속도 블렌드가 따라간다

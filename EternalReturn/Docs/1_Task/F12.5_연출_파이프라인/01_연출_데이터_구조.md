> 기능 [F12.5](00_개요.md) · 근거 [`Argument 36`](../../4_Argument/36_애니메이션_사운드_연출_레이어.md) §"우리 코드에 들어갈 자리"

## 할 일

몽타주 · 애님 세트를 **어디에 두고 누가 고르는지** 정하고, 어빌리티가 그걸 재생하는 훅을 만든다.

## ⭐ 결정할 것 — 착수 전 [`Argument 39`] 로

**평타는 공유 스킬이다** — 실험체는 전부 `DA_BasicAttack`, 야생동물은 전부 `DA_Attack_Wild`. 몽타주를 스킬 DA 에 두면 **모두가 같은 모션**이 된다. 원작은 실험체 × 무기마다 · 종마다 다르다.

| 방안 | 방식 | 요점 |
|---|---|---|
| A | 스킬 DA 에 몽타주 | 단순. 공유 스킬에서 깨진다 — 평타 · D 는 캐릭터마다 다르다 |
| B | **시전자가 "모션 세트"를 든다** — 스킬은 모션 **슬롯 태그**(`Anim.Attack` · `Anim.D` · `Anim.Q` …)만 · 실험체 DA 는 `무기 계열 × 슬롯 → 몽타주`, 야생동물 DA 는 `슬롯 → 몽타주` | 공유 스킬도 시전자별 모션. 캐릭터 고유 스킬(Q~R)은 실험체 DA 에 |
| C | B + 스킬 DA 기본값 — 시전자에 없으면 스킬 DA 몽타주 | 보스 · 특수 스킬 한 번짜리에 편함 |

~~추천 방향은 **C**~~ → 애셋 조사 후 **B** 로 바꿈 (C 의 대체값은 쓸 곳이 없다 · 같은 단검도 재키/다니엘 모션이 다르다). 애셋 형태는 시퀀스 직접 재생 (Y). ⭐ 개정: **스킨 계층**(스킨 → 캐릭터 → 공통 덮어쓰기) · 사운드는 키로 걸고 재생 시 해석 · 표는 캐릭터별 연출 DA + 스킨별 DA (한 장짜리 표는 전 캐릭터를 로드해서 철회) — 스킨 스켈레톤 호환 확인이 선결. → [`Argument 39`](../../4_Argument/39_몽타주_위치_모션세트.md) 사용자 결정 대기

## 코드 훅 (방안 무관 공통)

- `UERGameplayAbility::ExecuteAndRecover` 에서 **판정 타이머는 그대로**, 동시에 `UAbilityTask_PlayMontageAndWait` (서버 시작 → `RepAnimMontageInfo` 로 시뮬레이티드 프록시에 복제)
  - ⚠ ServerInitiated 어빌리티 — 소유 클라 재생 경로를 로그로 확인 (예측 끔 상태 · CLAUDE.md §8)
- 평타 몽타주 **재생 속도 = 공격 속도** (간격 1.0초 기준 몽타주 길이 → `PlayRate = 몽타주 길이 / 평타 간격`)
- 몽타주가 없으면 **연출 없이 판정만** (지금 동작 유지) — 애셋이 일부만 있어도 게임이 돈다
- 몽타주 길이와 어빌리티 시간(시전 · 회복)이 **크게 다르면 경고 로그** — 판정과 모션이 어긋나는 걸 데이터 단계에서 잡는다

## 네트워크

몽타주는 ASC 가 복제한다 (서버가 시작). 사망 · 기절 · 모드는 이미 복제되는 값(`bDead` · CC 태그 · 모드 태그)을 AnimBP 가 읽는다 — **새 복제 없음**이 목표.

## 검증

- **빌드 통과**
- 몽타주 없는 스킬 → 로그 그대로 · 판정 그대로 (회귀 없음)
- 몽타주 있는 평타 → 서버 · 소유 클라 · 다른 클라 모두 같은 모션 (2인)
- 공속 버프 → 몽타주가 빨라진다

### 네트워크

| 무엇 | 어디서 | 경로 |
|---|---|---|
| 스킨 선택 | 서버 (지금은 `ER.Skin.Set` · 서버 RPC) | `SkinIndex` 복제 → 각자 스킨 DA 로드 · 메시 교체 |
| 무기 세트 로드 | 서버 · 각 클라 각자 | 서버 `OnEquippedChanged` · 클라 `OnRep_Equipped` → 비동기 로드 |
| 애니 선택 · 재생 | **서버** — `ASC->PlaySlotAnimationAsDynamicMontage` | `RepAnimMontageInfo` → **다른 클라** 재생 |
| ⚠ 소유 클라 | 엔진이 복제를 **소유자에게는 재생하지 않는다** — `if (!AbilityActorInfo->IsLocallyControlled())` (`AbilitySystemComponent_Abilities.cpp:3145`) · 예측 전제 | **소유 클라의 어빌리티 인스턴스가 같은 `Resolve` 로 직접 재생** (ServerInitiated 라 서버보다 RTT/2 늦게 — 예측 없음 · CLAUDE.md §8) |
| 야생동물 | 서버 AI | 클라는 전부 "소유자 아님" → 복제로 재생 |

### 세부

- 해석 캐시: 스킨 · 무기 · 로드 완료 때 재계산 → `TMap<FGameplayTag, const FERPresentationEntry*>`. 우선순위 ① 스킨(무기 일치) ② 스킨(공통) ③ 무기 세트 ④ 캐릭터 기본 ⑤ 무기 공통
- 평타 재생 속도 `[자체]`: `Rate = max(1, 애니 길이 × 공격 속도)` — 간격보다 긴 애니만 빨라지고 느려지지는 않는다
- 없음 → 재생 안 함 + `Verbose` 로그 (판정은 그대로 — 회귀 없음)
- 애니 길이 > 선딜+후딜 × 1.5 면 `Warning` 1회 (데이터 단계에서 어긋남 발견)
- 동적 재생 슬롯 `DefaultSlot` · 블렌드 0.1/0.2 `[자체]`
- 스폰 전 로드: 지금은 동기 (`LoadSynchronous`) · P7 은 로딩 화면 때

### 단계와 검증

1. 데이터 클래스 · 컴포넌트 · 태그 → 검증: **빌드 (Editor + Server)**
2. `ER.Pres.Fill` → 검증: 재키 · 카티야 DA 생성, 로그에 "채움 n · 규칙 밖 m (목록)"
3. 스킨 · 무기 로드 · 복제 → 검증: `ER.Skin.Set 2` 에 양쪽 화면 메시 교체 · 무기 교체 시 `[연출] 무기 세트 로드` 서버 · 클라 각각 · `obj gc` 후에도 `ER.Pres.Show` 결과 유지 (P2)
4. 어빌리티 재생 → 검증 (2인): 평타 시 서버 `[연출] 재생 Jackie_Axe_atk01 (출처 무기세트)` · 소유 클라 같은 줄 · 다른 클라는 `net.Montage.Debug 1` 로 OnRep 확인 · 애니 없는 스킬은 판정 로그 그대로
5. P1 → 검증: 서버 로그에 메시 틱 옵션 출력 · 판정 · 복제 그대로

### 사용자 준비 (에디터)

- 캐릭터 BP 에 메시 + **`DefaultSlot` 슬롯 노드가 있는 AnimBP** (최소: 대기 포즈 → Slot → Output). 이동 블렌드는 02
- `DA_Char_*` 에 `Presentation` · `Skins` 지정 (Fill 이 만든 DA)
- ⏸ R1 · P5 확인 (스킨 메시 · 변이 메시에서 기본 애니 재생)

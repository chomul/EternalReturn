## 목표

지금까지 만든 **모든 실험체 · 야생동물 · 보스**가 제 모습으로 움직이고 · 때리고 · 맞고 · 쓰러진다.
⭐ **세로 한 줄(1명 + 1종)이 아니라 전원에 한 번에 적용한다** (사용자 2026-09-24) — 캐릭터 · 종마다 스켈레톤 · 무기 · 몸 크기가 달라서, 한 명으로 검증한 틀이 다른 대상에서 깨지는 걸 지금 한꺼번에 잡는다.

## ⭐ 원칙 두 줄 ([`Argument 36`](../../4_Argument/36_애니메이션_사운드_연출_레이어.md))

1. **판정 타이밍을 애니메이션에 걸지 않는다** — 데디 서버는 보는 사람이 없으면 애니를 평가하지 않는다 (`VisibilityBasedAnimTickOption`). 피해 · 쿨다운은 지금처럼 **어빌리티 타이머**가 정하고, 몽타주는 같은 길이로 맞춘 연출이다
2. **상태는 복제 값, 사건은 일회성 신호** — 사망 · 기절 · 모드는 복제 값 → AnimBP. 평타 · 피격은 몽타주 · GameplayCue. 도먼시로 늦게 보이는 클라도 복제 값은 받는다

## ⚠ 기능이 없어서 지금 못 하는 것 — 해당 기능 때

| 항목 | 이유 | 언제 |
|---|---|---|
| 실험체 **Q · W · E · R · P** 스킬 연출 | 스킬이 아직 없다 | **F19** — 스킬을 만들 때 이 파이프라인에 바로 연결 |
| 보스 스킬 (아크 블레이드 · 위클라인 5종) · 동물 스킬 (멧돼지 돌진 · 곰 강타 …) 연출 | 스킬 미구현 | 해당 스킬 작업 |
| 실험체 **사망 · 부활** 연출 | 플레이어 사망 처리가 없다 | F14 |
| 시야 밖 적의 이펙트 · **소리 차단** | 팀 시야가 없다 | F16 → F18 |
| 루팅 창 · UI 사운드 · 인내심 게이지 | UI | F17 |
| 위클라인 · 까마귀 **배회 동작** | AI 배회 미구현 (이동 애님 자체는 02 에서) | F13 |

## 사용자 준비물 (애셋)

- 실험체 6명: 스켈레탈 메시 · 스켈레톤 · 무기 메시 · 애니메이션 (대기 · 걷기/뛰기 · **무기별** 평타 · D 스킬 · 피격 · 기절 · 채집)
- 야생동물 7 + 보스 3: 대기 · 이동 · 평타 · 피격 · 사망 (변이 · 잠식은 폴더별 사본 — 본 구성이 같은지 (미확인))
- 타격 이펙트(나이아가라) · 타격음 · 발소리 — 임시여도 된다
⚠ FBX 는 UE 로 넘기기 전에 **Blender 에서 스켈레톤 · 레스트 포즈 · 동작을 먼저 확인** (memory: verify-in-blender-before-ue)

## 할 일

직선 방향 판정. **관통과 비관통**을 나눈다.

```cpp
static FTargetResult QueryProjectile(const UWorld* World, const FTargetQuery& Q);
// Q.bPenetrate == false → 첫 액터만
// Q.bPenetrate == true  → 경로상 전부 (가까운 순)
```

요구 사례: **카티야 Q** · **다니엘 Q**

## ⭐ 판정과 실제 투사체 액터는 다르다

이 함수는 **"직선상에 누가 있나"** 만 답한다.

실제 투사체(날아가는 액터, 속도 15~40m/s)는 **F07(스킬)이 스폰**하고, 그 액터가 부딪힐 때 이 함수를 다시 부르거나 자체 히트를 쓴다.
**여기서 액터를 스폰하지 않는다.**

- 즉발 판정 스킬 → 이 함수 한 번
- 날아가는 투사체 → F07이 액터를 스폰, 액터가 히트 처리

이 구분을 흐리면 F04가 F07에 의존하게 된다.

## 검증

- **빌드 통과**
- 비관통 — 일직선에 3명이 있을 때 **가장 가까운 1명만** 반환
- 관통 — 같은 상황에서 **3명 전부**, **가까운 순**
- 사거리 밖 액터는 제외
- ⭐ `RangeMin` 보다 가까운 액터는 **제외** (시셀라 Q 하한 1.0m)
- 방향 벡터가 정규화되지 않아도 동작한다
- 아무도 없을 때 빈 배열

## 주의점

- ⭐ **`Direction` 을 정규화한다.** 호출자가 정규화를 잊어도 동작해야 한다.
- 직선 판정의 **두께**를 정한다. 폭이 0인 라인 트레이스는 실전에서 잘 안 맞는다 — 스윕(구/캡슐)이 필요한지 판단하고 **자체 결정값으로 주석에 남긴다.**
- 관통 시 **최대 대상 수 상한**을 둘지 정한다 — **(미확인)**.
- ⭐ **벽·지형에 막히는지 여기서 정한다.** 스킬이 벽을 통과하는지는 게임 느낌을 크게 바꾼다. 레이피어 D는 *"벽 통과 가능"* 이므로 **인자로 열어둔다.**
- `RangeMin` 처리를 빠뜨리기 쉽다. F04-01에서 필드를 만들어 둔 이유가 이것이다.

## 목표

**"어느 위치에 어떤 모양을 그렸을 때 누가 맞았는가"** 에 답하는 순수 함수 묶음.
스킬이 무엇인지, 피해가 얼마인지는 **모른다.** 모양과 히트 배열만 다룬다.

## 왜 L0인가

기하 계산은 아무것도 의존하지 않는다. 월드와 콜리전만 있으면 된다.
**F07(스킬)을 만들기 전에 완성해두면 스킬 38개가 전부 이걸 재사용한다.**

Source/EternalReturn/Combat/ERTargeting.h / .cpp        (정적 함수 묶음)

## 독립 구현 전략

- ⭐ **정적 함수로 만든다.** 컴포넌트가 아니다. 상태를 갖지 않는다.
- **피해를 주지 않는다.** 히트 배열을 반환하고 끝난다.
- 팀 필터는 **인자로 받는다.** F01의 `ERTeamStatics` 를 헤더에서 include 하지 않고, 호출자가 팀 ID를 넘기게 한다 — 의존을 **헤더가 아니라 인자**로 만든다.

## ⚠ GAS로 바뀌어도 이 기능은 그대로다

**GAS는 판정 형상을 계산해주지 않는다.** 부채꼴·이중 반경·관통은 **직접 만들어야 한다** (`CLAUDE.md` §8 「그래도 직접 만드는 것」).

GAS가 제공하는 것은 **결과를 담는 그릇**뿐이다.

| | 누가 |
|---|---|
| "부채꼴 65° 안에 누가 있나" 계산 | ⭐ **F04 (직접 만든다)** |
| 그 결과를 어빌리티 → GE로 넘기는 형식 | `FGameplayAbilityTargetData` (GAS) |
| 조준 데이터를 클라 → 서버로 보내기 | `UAbilityTask_WaitTargetData` (GAS) |

**그래서 F04는 GAS 결정의 영향을 거의 받지 않는다.** 지금 문서 그대로 진행한다.

다만 **연결 지점 하나만 기억한다** — F07(스킬)에서 `FTargetResult` 를 `FGameplayAbilityTargetData` 로 감싸는 변환이 필요하다.
⭐ **그 변환을 F04 안에 넣지 않는다.** 넣으면 F04가 GAS에 묶이고, 순수 기하 함수가 아니게 된다.

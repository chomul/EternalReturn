> 기능 [F04 판정 · 타게팅](00_개요.md) · 선행 [05 이중 반경](05_이중반경.md)
> 체크리스트 [`06_거리보간_팀필터.md`](../../2_Checklist/F04_판정_타게팅/06_거리보간_팀필터.md)

## 할 일

두 가지를 마무리한다.

### 1. 거리 비례 보간 헬퍼

```cpp
/** 사거리 하한~상한 사이에서 0.0~1.0 반환 */
static float GetDistanceAlpha(float Distance, float RangeMin, float RangeMax);
```

⭐ **카티야 Q** — *"기본 피해와 계수를 **각각** 보간, **적중 시점** 계산"*.
두 값을 각각 보간하므로 **알파만 돌려주고 보간은 호출자가** 한다.

### 2. 팀 필터

`FTargetQuery::TeamFilter` 를 실제로 적용한다.

| 필터 | 결과 |
|---|---|
| `Enemy` | `InstigatorTeamId` 와 **다른** 팀 |
| `Ally` | **같은** 팀 |
| `All` | 전부 |

⭐ **레니 Q·W·E 전부** — *"하나의 판정이 적=피해 / 아군=회복·이속·보호막으로 갈린다"*.

## ⭐ 팀 판정을 어떻게 하나 — F01에 의존하지 않는 방법

이 함수는 `ERTeamStatics` 를 **include 하지 않는다.**

```
호출자:  Q.InstigatorTeamId = ERTeamStatics::GetTeamId(Caster);   ← 호출자가 채운다
F04:     후보 액터의 팀 ID를 어떻게 아나?
```

**후보 액터의 팀 ID는 알아야 한다.** 두 가지 방법:

| 방법 | 장단 |
|---|---|
| **A. 함수 포인터/람다를 인자로 받는다** | F04가 F01을 전혀 모른다. 호출부가 조금 번거롭다 |
| **B. `ERTeamStatics` 를 `.cpp` 에서만 include** | 헤더 의존이 없어 빌드는 독립. 링크는 F01 필요 |

⭐ **B를 권장한다.** 헤더 의존이 없으면 F04를 단독으로 설계·테스트할 수 있고,
`ERTeamStatics` 는 F01-04에서 **`nullptr` 안전하게 만들어 둔 순수 조회 함수**라 순환 의존이 생기지 않는다.
**A는 과설계다** (`CLAUDE.md` §2).

단 이 경우 F04 완료 검증은 **F01-04 이후**로 미뤄진다 — 그 사실을 체크리스트에 명시한다.

## 검증

- **빌드 통과**
- `GetDistanceAlpha` — 하한에서 **0.0**, 상한에서 **1.0**, 중간에서 0.5
- 하한 == 상한일 때 **0으로 나누지 않는다**
- 사거리 밖 값이 들어와도 0~1로 클램프된다
- `Enemy` 필터 — 아군이 결과에 없다
- `Ally` 필터 — 적이 결과에 없다
- ⭐ **팀 없는 액터(야생동물)가 `Ally` 로 잡히지 않는다**
- 레니 W + 이중 반경 + `All` 필터 → 중앙/외곽 × 아군/적 4분류가 가능하다

## 주의점

- ⭐ **팀 없는 액터 처리.** `ERTeamStatics::IsSameTeam` 은 무소속이면 `false` 를 반환한다(F01-04). 그러면 야생동물은 `Ally` 에도 `Enemy` 에도 안 잡힌다 — **`Enemy` 필터에는 포함되어야 한다.** 곰을 못 때리면 안 된다. **필터 로직을 `IsSameTeam` 부정으로 짜지 말고 명시적으로** 쓴다.
- 보간을 여기서 하지 않는다. **알파만 반환**한다. 카티야 Q는 두 값을 각각 보간한다.
- 적중 "시점" 계산 — 투사체가 날아가는 스킬은 **맞는 순간의 거리**로 계산해야 한다. 이 함수는 거리를 받을 뿐이므로, **언제 호출하는지는 F07의 책임**이다. 주석에 명시한다.

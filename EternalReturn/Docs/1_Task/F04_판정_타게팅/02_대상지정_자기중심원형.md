## 할 일

가장 단순한 판정 두 개를 만든다. **여기서 정한 규칙이 나머지 판정 전부의 기준이 된다.**

```cpp
static FTargetResult QuerySingleTarget(const UWorld* World, const FTargetQuery& Q);
static FTargetResult QuerySelfRadius (const UWorld* World, const FTargetQuery& Q);
```

- **대상 지정** — 지정된 액터 1개가 사거리 안이고 필터를 통과하는지 확인
- **자기중심 원형** — `Origin` 기준 `RangeMax` 반경 안의 액터 전부

## 왜 이 둘을 먼저 하나

이 Task에서 **공통 뼈대**가 만들어진다. 나머지 판정은 전부 여기에 모양만 바꿔 얹는다.

| 공통 뼈대 | 여기서 정한다 |
|---|---|
| 오버랩 질의 방식 | `OverlapMultiByChannel` 등 |
| 판정 기준점 | 캡슐 중심 / 발밑 / 바운딩 — **(미확인), 여기서 결정** |
| m ↔ uu 변환 지점 | ⭐ **한 곳** |
| 결과 정렬 | **가까운 순** (카티야 R이 요구) |
| 제외 대상 처리 | `IgnoredActors`, 시전자 본인 |

## 만질 파일

```
Source/EternalReturn/Combat/ERTargeting.h / .cpp    (신규)
```

## 검증 — 테스트 액터 하나로 확인한다

- **빌드 통과**
- 반경 5m 안의 액터만 반환된다
- 반경 밖 액터는 반환되지 않는다
- ⭐ 결과가 **가까운 순으로 정렬**되어 있다
- 시전자 본인이 결과에 포함되지 않는다 (또는 규칙대로 포함된다)
- `IgnoredActors` 에 넣은 액터가 제외된다
- 대상이 하나도 없을 때 **빈 배열**이 반환된다 (크래시 아님)

## 주의점

- ⭐ **m ↔ uu 변환을 함수 진입부 한 곳에서** 한다. 각 판정 함수마다 곱하면 언젠가 하나를 빠뜨린다.
- ⭐ **정렬을 여기서 확정한다.** 카티야 R이 *"가까운 순 3발 순차"* 를 요구한다. 나중에 정렬을 추가하면 이미 만든 판정 5종을 다 고친다.
- 콜리전 채널을 새로 만들면 `Config/DefaultEngine.ini` 가 바뀐다 — **변경 내용을 보고**한다 (`CLAUDE.md` §9).
- `Cast<T>()` 결과를 항상 검사한다. 오버랩 결과에는 스태틱 메시·트리거 볼륨도 섞여 온다.
- 자기중심 원형은 **매그너스 계열이 쓴다.** 특정 캐릭터 전용 분기를 넣지 않는다.
- `World` 가 `nullptr` 일 수 있다 (에디터 종료 중). 조기 반환한다.

## 미확인

| 항목 | 상태 |
|---|---|
| 판정 기준점 | ⭐ **이 Task에서 결정하고 주석에 자체 결정값 표기** |

| 사용할 콜리전 채널 | **(미확인)** — 새로 만들지 기존 채널을 쓸지 |

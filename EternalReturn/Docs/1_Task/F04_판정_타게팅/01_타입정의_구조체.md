## 할 일

판정 종류와 입출력 구조체를 정의한다.

```cpp
UENUM(BlueprintType)
enum class ESkillTargeting : uint8
{
    SingleTarget,   // 대상 지정
    SelfRadius,     // 자기중심 원형
    Projectile,     // 방향 투사체
    GroundCircle,   // 위치 지정 원형
    Cone,           // 부채꼴
    DualRadius,     // ⭐ 이중 반경 (레니 W)
};

UENUM()
enum class ETargetTeamFilter : uint8 { Enemy, Ally, All };

USTRUCT()
struct FTargetQuery
{
    GENERATED_BODY()
    ESkillTargeting   Shape      = ESkillTargeting::SingleTarget;
    ETargetTeamFilter TeamFilter = ETargetTeamFilter::Enemy;

    FVector Origin    = FVector::ZeroVector;
    FVector Direction = FVector::ForwardVector;

    // 단위: m (내부에서 uu 로 변환)
    float RangeMax    = 0.f;
    float RangeMin    = 0.f;   // ⭐ 시셀라 Q 하한 1.0
    float RadiusInner = 0.f;   // ⭐ 레니 W 1.25
    float RadiusOuter = 0.f;   // ⭐ 레니 W 2.25
    float AngleDeg    = 0.f;   // ⭐ 다니엘 Q 65
    bool  bPenetrate  = false;

    int32 InstigatorTeamId = INDEX_NONE;   // ⭐ 호출자가 채운다
    TArray<AActor*> IgnoredActors;
};

USTRUCT()
struct FTargetResult
{
    GENERATED_BODY()
    TArray<AActor*> HitActors;       // 가까운 순 정렬
    TArray<AActor*> InnerHitActors;  // ⭐ 이중 반경의 중앙
    TArray<float>   Distances;       // 거리 비례 보간용
};
```

## 왜 이렇게 하나

- ⭐ **`InstigatorTeamId` 를 인자로 받는 이유:** 팀 판정을 이 함수가 하면 `ERTeamStatics`(F01)를 include 해야 한다. **인자로 받으면 F04가 F01 없이 빌드된다.** 호출자가 `ERTeamStatics::GetTeamId()` 로 채워 넘긴다.
- **`Distances` 를 결과에 담는 이유:** 카티야 Q가 *"적중 시점에 거리 비례 보간"* 을 요구한다. 판정 후 호출자가 다시 거리를 재면 **두 번 계산**하게 되고, 그 사이에 대상이 움직이면 값이 달라진다.
- **`InnerHitActors` 를 따로 두는 이유:** 레니 W는 중앙과 외곽이 **다른 효과**다. 하나의 배열로 돌려주면 호출자가 다시 거리로 갈라야 한다.

## 검증

- **빌드 통과**
- 구조체를 손으로 채워 만들 수 있다 (다른 기능 없이)

## 주의점

- ⭐ **단위를 m 로 통일하고, uu 변환 지점을 한 곳에 둔다.** 문서 수치가 전부 m 기준이고 언리얼은 uu(1m = 100uu)다. 섞이면 사거리가 100배 틀린다.
- ⭐ **`RangeMin` 을 처음부터 넣는다.** 시셀라 Q는 **사거리 하한 1.0m** 가 있다 — 너무 가까우면 안 나간다. 나중에 끼우면 호출부를 다 고친다.
- `TArray<AActor*>` 를 `USTRUCT` 에 넣을 때 **`UPROPERTY()` 를 붙인다.** 안 붙이면 GC로 dangling된다 (`CLAUDE.md` §5).
- 열거형 값은 **끝에 추가**한다. 데이터 테이블이 인덱스를 참조한다.

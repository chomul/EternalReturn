# F03-03 — 방어 관통

> 기능 [F03 데미지 ExecutionCalculation](00_개요.md) · 선행 [02 핵심 계산 · 방어력 공식](02_핵심계산_방어력공식.md)
> 체크리스트 [`03_방어관통.md`](../../2_Checklist/F03_데미지_ExecutionCalc/03_방어관통.md)

## 할 일

방어력을 깎는 두 종류를 **정해진 순서로** 적용한다.

```
적용 방어력 = max(0, (Target 방어력 × (1 - 관통%)) - 관통 고정)
                    └────── 1단계 ──────┘   └── 2단계 ──┘
```

관통 값은 **Source 캡처**에서 온다 (F03-01).

## ⭐ 순서가 결과를 바꾼다

| 순서 | 방어력 100 + 관통 50% + 고정 30 | 결과 |
|---|---|---|
| **% 먼저** (채택) | (100 × 0.5) − 30 = 20 | **20** |
| 고정 먼저 | (100 − 30) × 0.5 = 35 | 35 |

[스탯 문서 §7 3순위](../../0_GameDesign/Systems/스탯_데미지공식_역기획서.md) 검증 기준이 **20** 이다.
**퍼센트를 먼저 적용한다.**

## ⭐ 0 클램프는 선택이 아니다

관통이 방어력보다 크면 적용 방어력이 **음수**가 된다.
`100 / (100 + DEF)` 에 음수를 넣으면 분모가 100보다 작아져 **피해가 증폭**되고, DEF가 −100이면 **0으로 나눈다.**

## GAS에서 주의할 점

⭐ **관통을 GE 수정자로 Target 방어력에 직접 걸지 않는다.**

그렇게 하면 **다른 공격자의 피해까지** 방어력이 깎인 상태로 계산된다.
관통은 **이 피해 1회에만** 적용되는 값이므로, **Execution 안에서 지역 변수로** 계산한다.

## 만질 파일

```
Source/EternalReturn/GAS/ERDamageExecution.cpp
```

## 검증

| 입력 | 기대 |
|---|---|
| 방어력 100, 관통 50%, 고정 30 | ⭐ 적용 방어력 **20** |
| 방어력 100, 관통 0%, 고정 0 | 100 |
| 방어력 100, 관통 100%, 고정 0 | 0 |
| 방어력 100, 관통 50%, 고정 999 | **0** (음수 아님) |
| 방어력 0, 관통 50%, 고정 30 | **0** |

- **빌드 통과** (Editor + Server)
- 고정 피해 태그에서는 관통이 **무의미하다**
- ⭐ 관통 공격 후 **Target의 실제 Defense 어트리뷰트가 안 변한다**

## 주의점

- ⭐ **0 클램프 누락** — 이 Task에서 가장 중요한 한 줄.
- ⭐ **Target 어트리뷰트를 수정하지 않는다** — 지역 변수로만 계산한다.
- 관통%의 단위(`0.5` vs `50`)를 정하고 **어트리뷰트 주석에 명시**한다. 섞이면 피해가 100배 틀린다.
- 계산 순서를 코드 주석으로 남긴다. **나중에 누군가 "더 자연스럽게" 바꾸려 한다.**
- 관통이 여러 소스(장비·특성)에서 오면 **GAS가 어트리뷰트 레벨에서 이미 합산**해준다 — 자체 구현과 달리 호출자가 합칠 필요가 없다. 다만 가산인지 승산인지는 GE 수정자 설정에 달렸다 — **(미확인)**.

## 미확인

| 항목 | 상태 |
|---|---|
| 관통 여러 소스의 합산 규칙 | **(미확인)** — GE 수정자 op로 결정됨 |
| 관통 상한 | **(미확인)** — 100% 초과 처리 |

# F03-01 — 어트리뷰트 캡처 정의

> 기능 [F03 데미지 ExecutionCalculation](00_개요.md) · 선행 [F02-01 어트리뷰트 정의](../F02_어트리뷰트셋/01_어트리뷰트_정의.md)
> 체크리스트 [`01_어트리뷰트_캡처정의.md`](../../2_Checklist/F03_데미지_ExecutionCalc/01_어트리뷰트_캡처정의.md)

## 할 일

Execution이 읽을 어트리뷰트를 **캡처 정의**로 선언한다.

```cpp
struct FERDamageStatics
{
    DECLARE_ATTRIBUTE_CAPTUREDEF(AttackPower)     // Source(공격자)
    DECLARE_ATTRIBUTE_CAPTUREDEF(CritChance)
    DECLARE_ATTRIBUTE_CAPTUREDEF(CritDamage)
    DECLARE_ATTRIBUTE_CAPTUREDEF(DefensePenPct)
    DECLARE_ATTRIBUTE_CAPTUREDEF(DefensePenFlat)

    DECLARE_ATTRIBUTE_CAPTUREDEF(Defense)         // Target(피격자)
    DECLARE_ATTRIBUTE_CAPTUREDEF(MaxHealth)
    DECLARE_ATTRIBUTE_CAPTUREDEF(Health)

    FERDamageStatics()
    {
        DEFINE_ATTRIBUTE_CAPTUREDEF(UERAttributeSet, AttackPower, Source, true);
        DEFINE_ATTRIBUTE_CAPTUREDEF(UERAttributeSet, Defense,     Target, false);
        // ...
    }
};
```

## ⭐ 이게 이전 계획의 `FDamageContext` 를 대체한다

자체 구현에서는 호출자가 구조체를 손으로 채웠다.
GAS에서는 **캡처 정의만 선언하면 엔진이 공격자·피격자에서 값을 가져온다.**

호출부(스킬)는 아무것도 안 채운다. **채우는 코드가 사라지므로 채우다 빠뜨릴 일도 없다.**

## Source / Target 을 정확히 나눈다

| 어트리뷰트 | 어디서 | 이유 |
|---|---|---|
| `AttackPower` `CritChance` `CritDamage` `DefensePen*` | **Source** | 때리는 쪽 능력 |
| `Defense` `MaxHealth` `Health` | **Target** | 맞는 쪽 상태 |

⭐ **뒤집으면 자기 방어력으로 자기 피해를 깎는다.** 증상이 "피해가 이상하다" 정도로만 나와서 찾기 어렵다.

## ⭐ Snapshot 인자 — 마지막 `bool`

`DEFINE_ATTRIBUTE_CAPTUREDEF` 의 마지막 인자가 **스냅샷 여부**다.

| 값 | 언제 읽나 | 써야 할 곳 |
|---|---|---|
| `true` (스냅샷) | **GE Spec을 만든 시점** | 공격자 능력치 — 투사체가 날아가는 동안 공격자가 장비를 바꿔도 처음 값 |
| `false` | **적용되는 시점** | 피격자 방어력 — 맞는 순간의 값이어야 한다 |

⭐ **Target을 `true` 로 하면 방어 아이템을 낀 게 반영이 안 된다.**

⚠ 매그너스 W는 *"타격 횟수 = 11 + floor(추가방어력/35), **시전 시점 확정**"* 이다 ([스킬 문서](../../0_GameDesign/Systems/스킬_프레임워크_역기획서.md) §8).
이건 **Source 스냅샷이 맞는 사례**다.

## 만들 파일

```
Source/EternalReturn/GAS/ERDamageStatics.h    (캡처 정의)
```

## 검증

- **빌드 통과** (Editor + Server)
- Execution에서 캡처한 값을 읽을 수 있다
- Source 어트리뷰트가 **공격자** 값이다
- Target 어트리뷰트가 **피격자** 값이다

## 주의점

- ⭐ **Source/Target 혼동** — 이 Task에서 가장 위험한 실수. 각 정의에 주석으로 근거를 남긴다.
- ⭐ **스냅샷 플래그를 생각 없이 복붙하지 않는다.** 위 표대로 나눈다.
- 캡처 정의 구조체는 **정적 싱글턴**으로 만드는 것이 관례다 (`static FERDamageStatics DmgStatics; return DmgStatics;`).
- 어트리뷰트를 추가할 때마다 **`RelevantAttributesToCapture` 에도 추가**한다. 빠뜨리면 값이 0으로 읽힌다.
- `IncomingDamage`(Meta)는 **캡처하지 않는다.** 출력 대상이지 입력이 아니다.

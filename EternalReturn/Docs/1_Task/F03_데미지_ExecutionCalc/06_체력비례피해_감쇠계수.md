# F03-06 — 체력 비례 피해 · 감쇠 계수 ⭐

> 기능 [F03 데미지 ExecutionCalculation](00_개요.md) · 선행 [05 흡혈](05_흡혈.md)
> 체크리스트 [`06_체력비례피해_감쇠계수.md`](../../2_Checklist/F03_데미지_ExecutionCalc/06_체력비례피해_감쇠계수.md)

## 할 일

체력 비례 피해 4종을 처리하고 **대상별 감쇠 계수**를 곱한다.

| 종류 | 사례 | 캡처 |
|---|---|---|
| 대상 **최대** 체력 비례 | 매그너스 W 2.5%/타 · E 8% · 레니 R 8% · 채찍 D 12% | Target `MaxHealth` |
| 대상 **현재** 체력 비례 | 재키 Q 5% · 다니엘 단검 D 8% | Target `Health` |
| 자신의 **잃은** 체력 비례 | 시셀라 R (2~3배) · 재키 R | Source `MaxHealth` − `Health` |
| 자기 자신 대상 피해 | 시셀라 R (⭐ 체력 하한 100) | — |

## ⭐ 감쇠 계수가 없으면 게임이 무너진다

[몬스터 문서 §5.1](../../0_GameDesign/Systems/몬스터_야생동물_역기획서.md) — **위클라인은 체력 비례 피해를 50%만 받는다.**

> *"이 한 줄이 없으면 게임이 무너진다. 보스는 체력이 압도적으로 높으므로, 비례 피해에 감쇠가 없으면 **탱커 한 명이 보스를 혼자 녹인다.**"*

매그너스 W 하나가 11타 이상 × 2.5% = **최대 체력의 27%** 다. 감쇠 없이는 보스가 두 번 맞고 죽는다.

## ⭐ 감쇠 계수를 어떻게 아는가 — 태그로 판별한다

```cpp
float Scale = 1.f;
if (TargetTags.HasTag(ERTags::Actor_Type_Boss))
    Scale = 0.5f;
```

⭐ **`Cast<ABossActor>` 를 하지 않는다.** 하면 F03이 F12에 의존한다.
보스에 태그를 붙이는 것은 F12의 책임이고, Execution은 태그만 본다.

> **더 나은 방법:** 감쇠 계수를 **Target 어트리뷰트**(`ProportionalDamageResist`)로 두면
> 태그 하드코딩 없이 "특정 장비가 비례 피해를 줄인다" 같은 것도 자연스럽게 처리된다.
> **어느 쪽으로 갈지 구현하며 정하고 주석에 남긴다** — 현재 **(미확인)**.

## ⭐ 감쇠는 비례 피해에만 곱한다

일반 피해에 곱하면 **보스가 모든 피해를 절반만 받는** 완전히 다른 게임이 된다.

## 「최대」와 「현재」를 혼동하지 않는다

재키 Q는 **현재** 체력 5%다 — 대상이 죽어갈수록 약해진다.
최대로 계산하면 **처형기가 된다.** 정반대 성격이 된다.

## 다단 히트

매그너스 W는 11타다. **타마다 이 계산을 다시 한다** — 대상 현재 체력이 타마다 줄기 때문이다.
GAS에서는 **타마다 GE를 적용**하는 구조가 되므로 자연스럽게 해결된다 (F07에서 `UAbilityTask` 로 반복).

## 자기 자신 대상 피해

시셀라 R은 자기에게 피해를 주되 **체력 하한 100** 이다.
F02-04가 하한을 받을 수 있게 만들어 뒀다 — **그걸 쓴다.**

## 검증

| 입력 | 기대 |
|---|---|
| ⭐ 최대 체력 10000, 8% 비례, **보스 태그** | **400** (실효 4%) |
| 최대 체력 10000, 8% 비례, 일반 대상 | **800** |
| 현재 체력 3000 (최대 10000), 5% 현재 비례 | **150** |
| 자신 잃은 체력 4000, 2배 | **8000** |
| ⭐ 시셀라 R 자기 피해 | **체력 100에서 멈춘다** |
| ⭐ 매그너스 W 11타 × 2.5% + 보스 | 실효 **약 13.75%** (감쇠 없으면 27.5%) |

- **빌드 통과** (Editor + Server)

## 주의점

- ⭐ **감쇠가 일반 피해에 곱해지지 않는다** — 가장 위험한 실수.
- ⭐ **「최대」와 「현재」를 혼동하지 않는다.**
- ⭐ **`Cast<>` 로 대상 클래스를 검사하지 않는다** — 태그 또는 어트리뷰트로.
- 비례 피해에 방어력이 적용되는지 **(미확인)** — 채널 규칙을 따르고 주석에 남긴다.
- Source 자신의 잃은 체력은 **Source 캡처**가 필요하다 (F03-01에 `MaxHealth`/`Health` Source 캡처 추가).

## 미확인

| 항목 | 상태 |
|---|---|
| 감쇠 판별 방식 (태그 / 어트리뷰트) | **(미확인)** — 구현하며 확정 |
| 보스 외 대상의 감쇠 계수 | **(미확인)** — 야생동물·구조물. 지금 1.0 |

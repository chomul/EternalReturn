## 목표

**실험체 경험치의 입구는 숙련도 적립 하나.** 무기(무기군별) · 방어 · 사냥 · 제작 · 탐색 · 이동 6종에 쌓인 경험치가 그대로(× 비율) 실험체 레벨을 올린다 — 원작 "실험체 레벨은 사실상 전체 숙련도". F10-01 의 `AddExp` · 처치 경험치 500 · 야생동물 경험치는 **삭제**.

## 구조

```
UERGrowthComponent (PlayerState)
  AddProficiencyExp(FERProficiencyKey, Amount, Reason)      ← ⭐ 유일한 입구 [서버]
    ① 그 트랙 레벨업 — DT_ProficiencyExp[Track][Lv] (6열 · 19행 · 인게임 확인) → OnProficiencyLevelUp(Key, Lv)
    ② AddCharacterExp(Amount × LevelExpPerProficiencyExp)  → DT_LevelExp 로 실험체 레벨업 (기존 while · ApplyLevelGrowth · OnLevelUp)
  적립 훅 (이벤트가 부른다)
    OnDamageDealt(대상, 피해)  → 무기 (실험체 100당 50 [확인] · 야생동물 5)      PS OnDamageTaken(가해자 쪽)
    OnDamageTaken(피해)         → 방어 (100당 50 [자체])                           PS OnDamageTaken(피격자 쪽)
    OnPlayerKilled(적 레벨)     → 무기 (100 + 10×레벨 [자체] — 원작 "적 레벨에 따라")  PS OnOutOfHealth(처치자 쪽)
    OnWildlifeKilled(동물 레벨) → 사냥 (100 + 20×레벨 [자체])                       F12 가 부른다 (지금은 훅만)
    OnItemCrafted(결과, 최초)   → 제작 (등급 50~300 [자체]) + 무기면 무기군 (100~600 [확인]) · 최초 +25%   Inventory->OnItemCrafted
    OnBoxOpened(행)             → 탐색 (상자당 100 [자체])                          Inventory->OnBoxOpened (상자 첫 개봉 1회)
    SampleMovement()            → 이동 (100m 당 10 [자체]) — 서버 1초 타이머, 폰 위치 차이. 20m 넘는 점프(순간이동 · 부활)는 무시
  RefreshProficiencyBonus()     → 든 무기군 Lv × (증폭 + **공속** AttackSpeedPerLevel)  (E18 A9)
FERProficiencyKey { Track, WeaponType }  · FERProficiency { Key, Exp, Level }  · FERProficiencyExpRow { Weapon, Defense, Hunt, Craft, Search, Move }
UERGrowthSettings: ProficiencyExpTable · LevelExpPerProficiencyExp 1.0 [자체] · 트랙별 획득량
```

## 네트워크

변화 없음 — `Level` 전원 · `Exp`(float) · `Proficiencies` 소유자만. 판정 전부 서버. 이동 표본도 서버 폰 위치.

## 세부

- 5종 트랙(방어 · 사냥 · 제작 · 탐색 · 이동)의 **레벨 효과는 (미확인)** — 적립 · 레벨업 · 델리게이트까지. 효과 GE 는 인게임 값이 나오면 데이터
- 무기 트랙은 F11-03 · F10-04 그대로 (D 해금 5/10/15 · 증폭) + 공속
- 실험체 최대 레벨이어도 숙련도는 오르고, 숙련도 최대여도 실험체 경험치는 들어간다 `[자체]`
- 디버그: `ER.Growth.ProfExp <n> [Track|무기군]` · `ER.Growth.Prof` (6종) · `ER.Growth.Show`. `ER.Growth.AddExp` 삭제

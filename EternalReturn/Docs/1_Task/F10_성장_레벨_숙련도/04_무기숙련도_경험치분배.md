## 할 일

**들고 있는 무기군**의 숙련도가 교전으로 오르고, 레벨마다 증폭(스킬 증폭 **또는** 기본 공격 증폭)이 스탯에 붙는다.

## 경험치 — 확인값이 있다 (§3.1)

| 행동 | 숙련도 EXP |
|---|---|
| 실험체에게 피해 100당 | **63** |
| 야생동물에게 피해 100당 | **5** |
| 실험체 처치 | **100** |
| 무기 제작 (등급별) | 100 / 200 / 350 / 550 / 800 (+25% 최초) — **F09** 가 부른다 |

⭐ **데미지 파이프라인 종단**에서 분배한다 — 기능목록 "통합 순서 6. F03 → F10". `UERAttributeSet::PostGameplayEffectExecute` 가 최종 피해와 `Instigator` 를 안다. 거기서 **한 줄** — `ERGrowth::OnDamageDealt(Instigator, Target, Damage)`.
대상이 실험체인지 야생동물인지는 **태그**(`Actor.Type.Wildlife`, F03-05 와 같은 방식)로 — F12 가 없어도 동작한다.

✅ 필요 경험치 **Lv2 230 · 레벨당 +270** [확인 — 나무위키 가이드 "무기 숙련도", 2026-09-18] → 테이블 없이 설정값 2개. 상한 레벨 (미확인) → 20 `[자체]`.

## 어느 무기군의 숙련도인가

`UERInventoryComponent` 의 **장착 무기**(`GetEquippedItem(Weapon)` → `FERItemRow.WeaponType`)다. 무기가 없으면 (미확인) — 맨손은 숙련도 축적 없음 `[자체]`.
숙련도는 **무기군별로 따로** 쌓인다 (재키가 도끼 5 · 단검 2 를 동시에 가질 수 있다) → `TArray<FERWeaponProficiency{WeaponType, Exp, Level}>` (TMap 은 복제 불가), `COND_OwnerOnly` (§7 권고 — 적의 D 해금 여부 은닉).

## 증폭 — 레벨당 계수는 실험체 × 무기 조합 (§3.2)

```
UERCharacterData.WeaponProficiencyAmp : TMap<EERWeaponType, FERWeaponAmp>   // ⭐ 테이블이 아니라 실험체 애셋 (Argument 23 — 실험체 키가 애셋뿐)
FERWeaponAmp
  AmpType         : EERAmpType   // BasicAttack | Skill — ⭐ 둘 중 하나만
  AmpPerLevel     : float (%)    // 레니 권총 4.4 · 시셀라 암기 4.0 · 재키 단검 2.4 · 도끼 2.1 [확인] · 나머지 [자체: 스킬형 4%대 / 평타형 2%대]
```
(공속 · 공격력 레벨당 (미확인) → 필드 없음)

⭐ 적용은 **Infinite GE** (`UERProficiencyEffect`, F08-03 장비 GE 와 같은 패턴 — CurrentValue 만) — 숙련도는 무기를 바꾸면 사라지는 **조건부** 보너스라 장비와 같은 부류다.
레벨이 오르거나 무기가 바뀌면 **제거 후 재적용** (핸들 하나). "증폭 계수는 데미지 계산 한 곳에서만 소비" 는 이미 지켜진다 — `SkillAmp/BasicAtkAmp` 어트리뷰트를 `ERDamageExecution` 만 읽는다.

## D스킬 해금 — 여기서는 **알리기만**

숙련도 레벨이 오를 때 `OnWeaponProficiencyLevelUp(WeaponType, NewLevel)` 델리게이트를 쏜다. 5 / 10 / 15 를 해석해 D 를 부여·강화하는 것은 **F11**.

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- ⭐ 단검 장착 후 상대 실험체에게 평타로 100 피해 → `Dagger 숙련도 +63` · 야생동물 태그를 단 대상에 100 → +5 · 처치 → +100
- 테이블 `Lv1 = 100 [자체]` 로 두고 → 숙련도 Lv.2 → `ER.Item.Stats` 에 `BasicAtkAmp` 추가 +2.1%(재키 도끼 행) — **추가**분으로 잡힌다 (Infinite)
- 무기를 벗으면 증폭이 사라지고, 다시 끼면 돌아온다 · 다른 무기군은 별도 숙련도
- 클라에서 남의 숙련도는 안 보인다
- 숙련도 5 도달 시 델리게이트 로그 (F11 이 받을 자리)

## 주의점

- ⭐ 분배는 **서버** (PostGameplayEffectExecute 가 서버 전용)
- ⚠ F03 을 고치지 않는다 — 종단에 호출 **한 줄**만 (F03 이 F10 을 알게 되는 것은 감수. 반대로 F10 이 F03 내부를 알면 안 된다)
- ⚠ 증폭 GE 는 **Infinite** (장비와 같음). 레벨 성장(02)의 Instant 와 헷갈리지 않는다
- ⚠ AmpType 은 enum + 값 1개 — "둘 다 두고 한쪽 0" 금지 (§8)

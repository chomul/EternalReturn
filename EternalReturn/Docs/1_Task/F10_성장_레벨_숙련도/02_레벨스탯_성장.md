# F10-02 — 레벨당 스탯 성장 = Instant GE ⭐⭐

> 체크리스트 [`../../2_Checklist/F10_성장_레벨_숙련도/02_레벨스탯_성장.md`](../../2_Checklist/F10_성장_레벨_숙련도/02_레벨스탯_성장.md)

## 할 일

레벨이 오를 때 **체력 · 공격력 · 방어력 · 체력 재생**의 **기본값(BaseValue)** 을 레벨당 증가분만큼 올린다.

## ⭐⭐ Instant 여야 한다 — F08 과 정반대

| | GE 종류 | 바꾸는 것 | 이유 |
|---|---|---|---|
| 장비 (F08-03) | **Infinite** | CurrentValue 만 | 벗으면 원복 · 추가분 = `EvaluateBonus()` |
| **레벨 성장 (여기)** | **Instant** | **BaseValue** | 영구적이고 "기본 공격력" 의 일부다. 추가 공격력에 **들어가면 안 된다** |

⚠⚠ 레벨 성장을 Infinite 로 만들면 레벨 19 만큼의 공격력이 전부 **추가 공격력**으로 잡혀 `BonusAPRatio` 스킬(재키 W 등)이 폭주한다. F08-03 의 경고와 **정반대 방향**의 같은 함정이다.
근거: [`../../4_Argument/5_추가공격력_산출방식.md`](../../4_Argument/5_추가공격력_산출방식.md) · F02-05 (초기값도 Instant 로 Base 를 세팅했다 — 같은 경로를 탄다)

## 데이터 — `UERCharacterData` 에 레벨당 증가 (테이블 아님)

성장이 **선형**이라 (§2.4 실측) 20행 테이블 대신 `기본값 + 레벨당 증가` 다. 기본값은 이미 `BaseStats` 에 있다 → **레벨당 증가 4개**만 붙인다:

```
FERCharStatGrowth   // UERCharacterData.Growth
  MaxHPPerLevel        : float   // 재키 95 · 아야 76 · 매그너스 95  [확인]
  AttackPowerPerLevel  : float   // 4.7 · 4.1 · 4.4                  [확인]
  DefensePerLevel      : float   // 3 · 2.3 · 3.2                    [확인]
  HPRegenPerLevel      : float   // 0.077 · 0.06 · 0.85              [확인]
```

이동 속도 · 공격 속도 · 나머지는 **필드가 없다** — 레벨로 안 오른다 (§2.4). 필드가 없으면 실수로도 못 올린다.
⚠ 실험체마다 다르다 (12.2: 아드리아나 체력 성장 하향, 블레어 상향) — **개별 밸런싱 파라미터**라 실험체 애셋에 있는 게 맞다.

## 적용 — 레벨업마다 Instant GE 한 번

네이티브 `UERLevelUpEffect`(Instant · Additive · SetByCaller 4개 — 기존 `SetByCaller.MaxHP` 등 재사용). F10-01 의 레벨업 훅에서 서버가 1회 적용.
⚠ 최대 체력이 오를 때 **현재 체력**을 같이 올릴지(비율 유지 / 증가분만큼 / 그대로) — 원작 (미확인) → `[자체]` 로 정하고 기록. LoL 관례는 "증가분만큼 현재 체력도 증가".

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- ⭐⭐ 재키 값(95 / 4.7 / 3)으로 Lv.2 → `ER.Item.Stats`: MaxHP **기본** +95 · AttackPower **기본** +4.7 · **추가 +0** (Base 가 올랐고 Bonus 는 0)
- ⭐ 장비를 낀 채 레벨업 → 추가분은 장비분 그대로, 기본만 오른다 (두 경로가 섞이지 않는다)
- Lv.20 까지 올리면 재키 체력 2,745 · 공격력 125 · 방어력 107 — §2.4 표와 **정확히** 일치
- 이동 속도 · 공격 속도는 그대로
- 클라에 복제된다 (F02 경로)

## 주의점

- ⭐⭐ **Instant.** Infinite 로 만들지 않는다
- ⚠ 어트리뷰트를 직접 `Set` 하지 않는다 — 클램프와 복제 경로를 우회한다 (F02-05 · E05)
- ⚠ 여러 레벨 연속 상승 시 GE 를 레벨 수만큼 적용 (또는 배수 하나) — 어느 쪽이든 결과가 같아야 한다

## 목표

**경험치가 쌓여 레벨이 오르면 스탯이 자라고 스킬 포인트가 생기며, 싸운 만큼 무기 숙련도가 오른다.**

## ⭐ 이 기능이 F07 이 남긴 구멍을 닫는다

F07-03 이 스킬 포인트 **배분**(서버 검증)은 만들었지만 **지급**은 디버그 명령(`ER.Skill.Points`)뿐이다.
`UERSkillData` 의 레벨 규칙(`InitialLevel` / `MaxLevel` / `bUsesSkillPoints`)은 있지만 **"몇 레벨에 R 을 찍을 수 있나"** 는 실험체 레벨이 없어서 비워 뒀다.
F10 이 실험체 레벨을 만들면 그 자리(`UERSkillData` 필드)를 채운다.

## ⭐ 역기획서가 확정한 것 · 잘라낸 것

| 항목 | 상태 |
|---|---|
| 최대 레벨 20 · 레벨당 포인트 1 · Q/W/E 5 · R 3 · **P 1 시작 + 포인트 2** (= 20, 수지 일치) | 확인 (§2.1 · 사용자 정정 2026-09-18) |
| 성장은 **선형** — `기본값 + 레벨당 증가` 두 필드면 된다 (재키 `940 + 95×19 = 2,745`) | 확인 (§2.4) — **20행 레벨 테이블을 만들지 않는다** |
| 이동 속도 · 공격 속도는 레벨로 안 오른다 | 확인 (§2.4) |
| 필요 경험치 1→2 = 800, 5→6 = 2,500, 나머지 | **(미확인)** — 테이블 `[자체]` 로 채운다 |
| 무기 숙련도 경험치: 실험체 피해 100당 63 · 야생동물 5 · 처치 100 · 제작 100~800 | 확인 (§3.1) |
| D 해금 5 / 강화 10·15 | 확인 — **D 자체는 F11** |
| 나머지 숙련도 5종 · 전술 스킬(F) | ❌ 초기 버전 삭제 (§9) |
| 특성 48종 → 12종 3슬롯 | ⚠ 축소 유지 (§9) — **이 기능 문서 밖.** 트리거형 효과 핸들러라 별도 Task 후보 (`F10-05 특성` 로 나중에 추가) |

## ⚠ 이 기능이 하지 않는 것

- **D스킬 해금 · 무기 교체 시 D 교체** — F11 (숙련도 레벨은 여기서 만들고, 그 값을 F11 이 읽는다)
- **야생동물 처치 경험치의 값** — F12 (여기서는 "죽은 액터가 야생동물이면" 분기만 — `Actor.Type.Wildlife` 태그, F03 과 같은 방식)
- **특성** — 별도 Task 후보
- **파워 스파이크 스케줄러** — F14
- **레벨업 연출 · HUD 게이지** — F17. `OnRep_Level` 훅만 둔다

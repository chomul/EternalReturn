## 할 일

야생동물이 죽으면 **서버가** 루트를 굴려 드롭 액터를 만들고, 처치자에게 경험치 · 숙련도를 준다.

## 재사용 — 새 경로 없음

| | 어디 것 |
|---|---|
| 사망 알림 | F02-04 `OnOutOfHealth(Instigator)` — 야생동물 폰이 구독 (플레이어는 PlayerState 가 구독했다) |
| 드롭 액터 · 습득 | F08-05 `AERItemDropActor` + `ServerPickup` · 루트 롤은 F09-03 `FERLootRow` |
| 경험치 | F10-01 `AddExp(ExpReward × 변이 2.0, Source=Wildlife)` — 처치자 PlayerState |
| 숙련도 | F10-04 가 피해 시점에 이미 5/100 을 준다 (태그 분기) — 여기서 할 일 없음 |

## 두 패턴 (§4 설계 의도)
- **범용 확정** (가죽 — 박쥐 · 까마귀 빼고 전부) → 루트 행 가중치 100% / RollCount 보장
- **한정 확률** (깃털 — 닭만) → 확률 행
- **지역 재료 1개** → 루트 행 이름을 지역별로 (F13 배치가 행을 고른다)
⚠ ⭐ 확률 롤은 **서버 전용** — 깃털 · 루프 카드키-γ 를 클라가 굴리면 조작된다 (§7.1)

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- ⭐ 닭 처치 → 시체(드롭 액터)에 가죽 확정 + 깃털 확률 (10마리 잡아 비율 확인) · 박쥐는 가죽 없음
- ⭐ 처치자 경험치 +`ExpReward` · 변이 닭은 ×2
- 클라가 죽여도 롤 · 스폰은 서버 (로그) · 클라 창에서 시체가 보인다
- 어시스트(관여) 분배는 (미확인) → 처치자만 `[자체]`

## 주의점

- ⭐ 롤은 서버
- ⚠ 새 드롭 액터 · 새 습득 RPC 를 만들지 않는다

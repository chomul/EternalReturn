## 목표

**사냥할 이유가 있는 야생동물** — 잡으면 경험치 · 재료가 나오고, 시간이 지나면 강해지며, 보스는 정해진 시각에 영웅 재료를 준다.

## ⭐ 이 기능이 F02 · F03 의 두 번째 소비자다

| 이미 만들어진 것 | 여기서 |
|---|---|
| ASC + `UERAttributeSet` (플레이어와 같은 세트) | 야생동물에도 **같은 세트**. ⚠ PlayerState 가 없으니 **ASC 를 Pawn 에**, 복제 모드 **`Minimal`** (CLAUDE.md §8 · Argument 3) |
| F03-05 `Actor.Type.Wildlife` · `Actor.Type.Boss` 태그로 흡혈 감소 · 비례 피해 감쇠 | 야생동물 · 보스 액터가 **태그를 단다**. F03 이 F12 를 몰라도 되게 태그로 갈라 둔 것을 여기서 채운다 |
| F08-05 · F09-03 드롭 액터 · 루트 테이블 · `ServerPickup` | 사망 시 **같은 액터**에 루트 롤 결과를 담는다 |
| F10-01 `AddExp` 입구 · F10-04 숙련도 (야생동물 피해 100당 5) | 처치 시 호출 · 태그로 분기 |
| F06 CC 전부 | 곰의 기절기는 F06 CC GE 그대로 |

## ⭐ 역기획서 우선순위 그대로 — **AI 는 마지막**

> *"순서를 바꾸면 '잘 싸우지만 아무도 사냥할 이유가 없는 몬스터'가 만들어진다."*

- **지역 배치**(어느 지역에 어떤 종이 몇 마리) — F13 이 배치, 03 은 테이블 형식과 스케줄러

- **팀 시야와 야생동물** — §7.4 미결, F16

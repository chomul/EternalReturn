## 할 일

**선공 / 비선공 · 어그로 · 귀환** — 최소 AI. 그리고 **도먼시 전환**을 같은 이벤트에 건다 (§7.3 "AI 와 복제 상태가 같은 이벤트를 공유").

## ⭐ AI 는 서버에만 있다 (§7.2)
`AAIController` 는 클라에 복제되지 않는다 (`Controller.cpp:51` `bOnlyRelevantToOwner`). BT · 블랙보드 · `AIPerception` 전부 서버. 클라는 위치 보간과 애니만.

| 상태 | 전환 | 도먼시 |
|---|---|---|
| 대기 | 스폰 · 귀환 완료 | **`DORM_DormantAll`**, `NetUpdateFrequency 5` |
| 전투 | 피격(비선공) 또는 감지(선공) → 어그로 | `FlushNetDormancy()` → `DORM_Awake`, 20 |
| 귀환 | 어그로 대상이 범위 밖 · 사망 | 원위치 도달 시 다시 DormantAll + **체력 회복** (미확인 → `[자체]`) |

- 공격 = **F07-07 평타 어빌리티** 재사용 (야생동물용 `DA_Attack_Bear` — 사거리 · 피해 계수). 곰 기절기 = F06 CC GE 를 `OnHitEffect` 로
- 선공 종 (미확인) → `[자체]` 곰 · 늑대 선공, 나머지 비선공
- 이동은 `SimpleMoveToActor`(NavMesh, F13) — 지금 맵의 네비메시 그대로

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- ⭐ 곰에게 접근 → 선공 · 닭은 때릴 때까지 가만 · 멀리 도망가면 귀환
- ⭐ `stat net` / `NET ACTIVE`: 대기 중 야생동물이 복제 목록에 **없고**, 어그로 순간 나타난다 · 100마리 스폰 시 대역폭이 대기 중엔 거의 0
- 클라 창에서 움직임이 보간되어 보인다 (20Hz) · AI 로그는 서버에만
- 곰 평타에 맞으면 기절 (F06)

## 주의점

- ⭐ AI 를 클라에서 돌리지 않는다
- ⚠ 도먼시 빈도 5/20/30 은 자체 결정 초기값 — 측정 후 조정 (`ERWildlifeSettings`)
- ⚠ 새 공격 경로 없음 — 평타 어빌리티

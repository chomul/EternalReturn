## 할 일

**지역 × 종 × 마리수** 스폰 테이블과, 매치 시각에 따라 **등장 · 리스폰 · 레벨 상승**을 굴리는 서버 스케줄러.

```
FERWildlifeSpawnRow : FTableRowBase   // RowName = "지역_종" ("Forest_Wolf")
  Zone         : FName               // F13 지역 이름 (지금은 스폰 포인트 액터의 문자열)
  Type         : EERWildlifeType
  Count        : int32               // 12.0 조정 확정값 (§3.2)
  AppearDay    : int32 / bNight      // 늑대 1일차 낮 1분 · 곰 1일차 밤 (§3.1)
  RespawnSec   : float               // (미확인) → [자체]
  MutantChance : float               // (미확인) → [자체]
```

- **야생동물 레벨 = 매치 시간의 함수** (§2 "레벨당 증가" 존재) — 시각 → 레벨 매핑 테이블 `[자체]`. 레벨이 오르면 살아 있는 개체에 01 의 성장 GE 를 서버가 재적용
- 스케줄러는 **서버 전용** · 타이머 (`FTimerManager`, Tick 금지). F14 타임라인이 생기면 시각을 그쪽에서 받고, 그 전엔 디버그 주입

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- ⭐ `ER.Wild.SetTime 1 낮` → 늑대 스폰, 곰 없음 · `1 밤` → 곰 스폰 (§3.1) — 스폰 포인트 손 배치
- 마리수가 행 값과 같다 · 죽이면 `RespawnSec` 뒤 재스폰
- 시각을 올리면 살아 있는 개체의 레벨 · 스탯이 오른다 (`ER.Wild.Show`)
- 클라에는 스폰된 액터만 온다 (스케줄러는 없음)

## 주의점

- ⭐ 스폰 · 리스폰 · 레벨 상승 전부 서버
- ⚠ 지역 이름을 코드에 박지 않는다 — 행 + 배치
- ⚠ 120~200마리 — 04 의 도먼시 없이는 복제 비용이 터진다. 03 검증 시 `stat net` 으로 재고 04 에서 재확인

## 할 일

야생동물 한 마리 = **ASC + `UERAttributeSet` 을 가진 폰**. 종별 스탯 · 레벨당 증가 · 변이 배율은 테이블.

## ⭐ ASC 배치 — Pawn · Minimal (Argument 3 · CLAUDE.md §8)

플레이어는 PlayerState(Mixed), 야생동물은 **Pawn(Minimal)**. 두 배치가 공존한다 — `IAbilitySystemInterface` 로 호출부가 구분하지 않는다 (F01 · F02 가 그렇게 만들었다).
⚠ `Minimal` 은 "소유자가 있는 ASC 에서 동작하지 않는다" — 야생동물은 소유자가 없으니 맞다. **AI 컨트롤러가 소유자가 되지 않게** 주의.

## 데이터

```
FERWildlifeRow : FTableRowBase        // RowName = 종 ("Chicken" · "Bear" …)
  Type              : EERWildlifeType  // 닭 · 박쥐 · 멧돼지 · 까마귀 · 들개 · 늑대 · 곰 · 드론 (+ 보스 3)
  BaseStats         : FERCharStats     // F02 구조체 재사용 — 체력 · 공격력 · 방어력 …  (공격력만 [확인]: 닭 18 · 박쥐 30 · 멧돼지 27 · 곰 90)
  PerLevel          : FERCharStatGrowth // F10-02 구조체 재사용 — 공격력/Lv [확인]: 닭 19 · 박쥐 20 · 멧돼지 21 · 곰 16. 체력 (미확인)
  ExpReward         : int32            // (미확인) → [자체]
  LootRow           : FName            // F09-03 루트 테이블 행 (가죽 확정 · 깃털 확률 · 지역 재료)
  bCanBeMutant      : bool
  Tier              : int32            // 추정 1~4 (§1.1)
```
- **변이체는 별도 행이 아니라 배율** (§1.2 확정): 체력 ×1.5 · 공격력 ×1.4 · 경험치 ×2 — 설정값 3개, 스폰 시 `bIsMutant` 플래그 1회 복제
- 레벨별 스탯 = **F10-02 와 같은 Instant GE** (`기본 + 레벨당 × (레벨−1)`) — 20행 테이블 없음. `UMonsterStatComponent` 를 **다시 만들지 않는다** (§6.1)
- 태그: `Actor.Type.Wildlife` (보스는 `Actor.Type.Boss`) — F03 이 이미 읽는다

## 검증 — `Play As Listen Server, 2명`

- **빌드 통과**
- 맵에 곰 하나 스폰(디버그) → `ER.Wild.Show` 로 스탯 (공격력 90) · 태그 · ASC 복제 모드 Minimal 확인
- ⭐ 플레이어가 곰을 때리면 F03 파이프라인이 그대로 돈다 (방어력 적용 · 흡혈 감소 `Actor.Type.Wildlife`)
- 클라 창에서 곰 체력이 복제되어 보인다 (`OnRep_HP`) · 변이 곰은 체력 ×1.5 · 공격력 155(=90×1.4 반올림? [확인값 155 와 대조])
- 레벨 3 곰 = 90 + 16×2 = 122

## 주의점

- ⭐ ASC 는 Pawn · `Minimal`. Mixed 로 하면 안 된다 (PlayerState 없음)
- ⚠ 야생동물 스탯 GE 는 **Instant** (F10-02 와 같은 이유)
- ⚠ 곰의 공격력 90 은 의도된 진입 장벽 — 값을 "고쳐" 놓지 않는다

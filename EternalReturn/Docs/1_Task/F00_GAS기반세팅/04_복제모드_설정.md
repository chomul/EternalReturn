# F00-04 — 복제 모드 설정

> 기능 [F00 GAS 기반 세팅](00_개요.md) · 선행 [03 ASC 부착 · 초기화](03_ASC_부착_초기화.md)
> 체크리스트 [`04_복제모드_설정.md`](../../2_Checklist/F00_GAS기반세팅/04_복제모드_설정.md)

## 할 일

ASC의 게임플레이 이펙트 복제 모드를 정한다. **24명 규모에서 대역폭을 결정하는 설정이다.**

```cpp
AbilitySystemComponent->SetReplicationMode(EGameplayEffectReplicationMode::Mixed);
```

## 세 가지 모드 — 엔진 주석 그대로

`AbilitySystemComponent.h:85-93`

| 모드 | 엔진 주석 | 이 프로젝트 |
|---|---|---|
| `Minimal` | *"Only replicate minimal gameplay effect info. **Note: this does not work for Owned AbilitySystemComponents (Use Mixed instead).**"* | 야생동물 · 보스 (F12) |
| `Mixed` | *"Only replicate minimal gameplay effect info to simulated proxies but full info to owners and autonomous proxies"* | ⭐ **플레이어** |
| `Full` | *"Replicate full gameplay info to all"* | 쓰지 않는다 |

## ⭐ 왜 플레이어에 `Mixed` 인가

**`Minimal` 은 플레이어에게 쓸 수 없다.** 엔진 주석이 명시적으로 금지한다 — *"does not work for Owned AbilitySystemComponents"*.
플레이어 ASC는 소유 컨트롤러가 있으므로 `Owned` 다.

**`Full` 은 24명 규모에서 낭비다.** 남의 활성 이펙트 전체 목록을 내가 알 필요가 없다.
`Mixed` 는 **내 것은 전부, 남의 것은 최소**로 보낸다 — 정확히 필요한 만큼이다.

여기에 [팀 시야](../../0_GameDesign/Systems/팀시야_포그오브워_역기획서.md)까지 얹히면 안 보이는 적은 아예 복제가 끊긴다.

## ⭐ PlayerState의 갱신 빈도를 올려야 한다

F00-02에서 ASC를 `AERPlayerState` 에 뒀다. 그런데

> `Engine/Private/PlayerState.cpp:26` — `NetUpdateFrequency = 1`

**초당 1회다.** 그대로 두면 체력바가 1초에 한 번 갱신된다. 전투가 성립하지 않는다.

```cpp
// AERPlayerState 생성자
NetUpdateFrequency = 100.f;   // ⚠ 자체 결정 초기값. 24명 규모에서 측정 후 조정
```

⚠ **이 값은 측정하지 않았다.** [네트워크 문서](../../0_GameDesign/Systems/네트워크_서버아키텍처_역기획서.md) §5.2의 절차(봇 24명 + `NET ACTIVE` + `stat unit`)로 재본 뒤 낮춘다.

## 만질 파일

```
Source/EternalReturn/Core/ERPlayerState.h / .cpp
```

## 검증 — `Play As Client, Number of Players: 3` + Dedicated Server 체크

- **빌드 통과** (Editor + Server)
- 서버에서 이펙트를 걸면 **소유 클라가 전체 정보**를 받는다
- 다른 클라는 **최소 정보**만 받는다
- 체력 변화가 **즉시** 반영된다 (1초 지연이 아니다)

## 주의점

- ⭐ **`SetReplicationMode` 를 호출하는 시점.** ASC 생성 직후(생성자 또는 `PostInitializeComponents`)에 부른다. 이펙트가 이미 붙은 뒤에 바꾸면 상태가 어긋난다.
- ⭐ **야생동물에 `Mixed` 를 쓰지 않는다.** 개체가 120~200마리다 ([몬스터 문서](../../0_GameDesign/Systems/몬스터_야생동물_역기획서.md) §7). `Minimal` 이어야 하고, 야생동물은 소유 컨트롤러가 없으므로 동작한다. 같은 문서 §6.1 이 **ASC를 Pawn에 붙이고 `Minimal`** 로 못 박았다.
- `NetUpdateFrequency` 를 올리면 **24명분이 전부 올라간다.** `APlayerState` 는 `bAlwaysRelevant = true` (`PlayerState.cpp:27`) 이므로 전원에게 간다. **측정 없이 100을 확정하지 않는다.**
- 이 설정은 **게임플레이 이펙트 복제**에 관한 것이다. 어트리뷰트 자체의 복제는 `AttributeSet`(F02)이 따로 다룬다.

## 할 일

`UERAttributeSet` 을 만들고 [스탯 문서 §6.1](../../GameDesign/Systems/스탯_데미지공식_역기획서.md)의 스탯 목록을 어트리뷰트로 정의한다.

```cpp
// 접근자 매크로 — 프로젝트에서 한 번만 정의한다
#define ATTRIBUTE_ACCESSORS(ClassName, PropertyName) \
    GAMEPLAYATTRIBUTE_PROPERTY_GETTER(ClassName, PropertyName) \
    GAMEPLAYATTRIBUTE_VALUE_GETTER(PropertyName) \
    GAMEPLAYATTRIBUTE_VALUE_SETTER(PropertyName) \
    GAMEPLAYATTRIBUTE_VALUE_INITTER(PropertyName)

UCLASS()
class UERAttributeSet : public UAttributeSet
{
    GENERATED_BODY()
public:
    UPROPERTY(BlueprintReadOnly, ReplicatedUsing=OnRep_Health, Category="Vital")
    FGameplayAttributeData Health;
    ATTRIBUTE_ACCESSORS(UERAttributeSet, Health)

    UPROPERTY(BlueprintReadOnly, ReplicatedUsing=OnRep_MaxHealth, Category="Vital")
    FGameplayAttributeData MaxHealth;
    ATTRIBUTE_ACCESSORS(UERAttributeSet, MaxHealth)

    // AttackPower, Defense, AttackSpeed, MoveSpeed,
    // CritChance, CritDamage, SkillAmp, CooldownReduction,
    // Lifesteal, AttackRange, DefensePenPct, DefensePenFlat ...
};
```

매크로 근거: `AttributeSet.h:418` 주석이 이 `ATTRIBUTE_ACCESSORS` 패턴을 예시로 제시한다.
개별 매크로는 `:427`(`GAMEPLAYATTRIBUTE_PROPERTY_GETTER`), `:434`(`GAMEPLAYATTRIBUTE_VALUE_GETTER`).

## ⭐ Meta Attribute — 데미지는 어트리뷰트가 아니다

```cpp
/** [Meta] 복제되지 않는다. ExecutionCalculation 이 여기 써넣고, PostGameplayEffectExecute 가 읽어 체력에서 뺀다 */
UPROPERTY(BlueprintReadOnly, Category="Meta")
FGameplayAttributeData IncomingDamage;
ATTRIBUTE_ACCESSORS(UERAttributeSet, IncomingDamage)
```

**"받은 피해"는 저장되는 값이 아니라 한 번 쓰고 버리는 통로다.**
F03의 `ExecutionCalculation` 이 계산 결과를 여기 넣으면, F02-04가 그걸 읽어 `Health` 에서 뺀다.

⭐ **Meta Attribute는 복제하지 않는다.** 서버에서만 존재한다.

## 검증

- **빌드 통과** (Editor + Server)
- 에디터 GameplayEffect 애셋에서 어트리뷰트가 **드롭다운에 보인다**
- ASC에 AttributeSet이 등록된다

## 주의점

- ⭐ **`FGameplayAttributeData` 를 써야 한다.** `float` 로 선언하면 Base/Current 구분이 사라진다.
- ⭐ **어트리뷰트 이름을 나중에 바꾸면 GameplayEffect 애셋이 깨진다.** `CLAUDE.md` §3의 "프로퍼티 이름 변경은 애셋을 깨뜨린다"와 같은 문제다. 처음에 신중히 정한다.
- `BlueprintReadOnly` 로 노출한다. `BlueprintReadWrite` 는 쓰지 않는다 (`CLAUDE.md` §7).
- `IncomingDamage` 같은 Meta는 **`Category="Meta"`** 로 구분해 실수로 GE에서 직접 수정하지 않게 한다.
- AttributeSet은 **ASC가 소유**한다. F00-02 결정에 따라 `AERPlayerState` 에서 생성한다.

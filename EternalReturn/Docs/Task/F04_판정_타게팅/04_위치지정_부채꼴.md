- **위치 지정 원형** — 시전자가 아닌 **지정한 좌표** 기준 원형. 레니 R · 시셀라 계열
- **부채꼴** — `Origin` 에서 `Direction` 방향으로 `AngleDeg` 각도. ⭐ **다니엘 Q = 65°**

## ⭐ 사거리 클램프가 여기서 중요해진다

위치 지정은 클라가 **좌표를 보낸다.** 그대로 믿으면 **맵 반대편에 스킬을 쓸 수 있다.**

```
서버는 반드시:  지정 좌표가 시전자로부터 RangeMax 안인지 확인 → 넘으면 클램프
```

[스킬 문서](../../GameDesign/Systems/스킬_프레임워크_역기획서.md) §9 — *"⭐ 클램프 없으면 사거리 핵"*.

**클램프는 이 함수가 아니라 서버 RPC 수신부(F07)의 책임**이지만, 이 함수가 **클램프된 값을 받는다는 전제**를 주석에 명시한다.

## 부채꼴 각도 판정

```
대상이 부채꼴 안인가 =
    거리 <= RangeMax
    AND  거리 >= RangeMin
    AND  acos(dot(정규화 Direction, 정규화(대상 - Origin))) <= AngleDeg / 2
```

⚠ **`AngleDeg` 가 전체 각도인지 반각인지 정한다.** 65°가 전체면 ±32.5°다. 문서는 *"65°"* 라고만 적혀 있다 — **전체 각도로 해석하고 주석에 남긴다.**

## 검증

- **빌드 통과**
- 위치 지정 원형 — 지정 좌표 기준으로 판정된다 (시전자 기준 아님)
- ⭐ 부채꼴 65° — 정면 액터는 맞고, **옆 90° 액터는 안 맞는다**
- 부채꼴 경계(정확히 32.5°)의 처리가 일관적이다
- `RangeMin` 안쪽 액터가 제외된다
- 각도 360°면 원형과 같은 결과가 나온다

## 주의점

- ⭐ **각도 판정을 `acos` 대신 `dot` 비교로** 할 수 있다 — `cos(AngleDeg/2)` 를 미리 계산해두고 dot과 비교하면 `acos` 호출이 사라진다. 다만 **측정 전 최적화는 하지 않는다** (`CLAUDE.md` §2). 단순하게 시작한다.
- ⭐ **높이(Z)를 어떻게 다룰지 정한다.** 2D 판정이면 위아래 액터가 다 맞는다. 탑다운이라 대개 2D가 맞지만, **자체 결정값으로 주석에 남긴다.**
- 정규화 전에 영벡터인지 확인한다. `Origin == 대상 위치`면 0으로 나눈다.
- 위치 지정 원형은 **좌표가 네비메시 위인지** 확인이 필요할 수 있다 — 그건 F05·F13 영역이므로 여기서는 하지 않는다.

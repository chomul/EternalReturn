> 체크리스트 [`04_팀조회_공용함수.md`](../../Checklist/F01_코어골격_팀ID/04_팀조회_공용함수.md)

## 할 일

임의의 액터에서 팀을 알아내는 **공용 함수 한 쌍**을 만든다.

```cpp
// ERTeamStatics.h
class ERTeamStatics
{
public:
    /** 액터의 팀 ID. 팀이 없으면(야생동물·중립 오브젝트) INDEX_NONE */
    static int32 GetTeamId(const AActor* Actor);

    /** 둘이 같은 팀인가. 어느 한쪽이라도 무소속이면 false */
    static bool  IsSameTeam(const AActor* A, const AActor* B);

    /** 서로 적인가. ⭐ !IsSameTeam 과 다르다 — 무소속(야생동물)도 적이다 */
    static bool  IsHostile(const AActor* A, const AActor* B);
};
```

`GetTeamId` 는 `APawn::GetPlayerState()` 로 **복제된 PlayerState 를 직접** 읽는다.
찾지 못하면 `INDEX_NONE` 을 반환한다.

> ⚠ **`GetController()` 를 경유하지 않는다.** `AController` 는 `bOnlyRelevantToOwner = true`
> (`Engine/Private/Controller.cpp:51`)라 **클라에는 남의 컨트롤러가 없다.**
> 컨트롤러를 타면 클라에서 적의 팀을 못 읽어 아군/적군 구분이 통째로 깨진다.

## 왜 이렇게 하나

- ⭐ **다른 기능이 `Cast<AERPlayerState>` 를 직접 하지 않게 하려는 것이다.** 데미지 판정(F03 호출자)·시야(F16)·UI(F17)가 각자 캐스팅하면, 나중에 팀 정보를 옮길 때 전부 고쳐야 한다.
- **왜 무소속(`INDEX_NONE`)이 필요한가:** 야생동물과 보스는 팀이 없다 (F12). `IsSameTeam` 이 무소속끼리 `true` 를 반환하면 **곰끼리 아군이 되어 서로 안 때린다.** 그래서 한쪽이라도 무소속이면 `false` 로 정한다.
- ⭐ **왜 `IsHostile` 이 따로 필요한가:** `!IsSameTeam` 으로 적을 판정하면 우연히 맞는 경우가 많지만,
  같은 방식으로 `Ally` 필터를 짜면 **무소속(야생동물)이 아군으로 잡힌다.** 자기 자신도 걸러야 한다.
  판정 규칙을 부정 연산에 맡기지 않고 함수로 못 박는다. F04(판정·타게팅)의 팀 필터가 이걸 쓴다.

| 상황 | `IsSameTeam` | `IsHostile` |
|---|---|---|
| 같은 팀 | true | false |
| 다른 팀 | false | true |
| 플레이어 vs 야생동물 | false | **true** |
| 곰 vs 늑대 (둘 다 무소속) | false | **true** |
| 자기 자신 | true | **false** |

- **왜 `UBlueprintFunctionLibrary` 가 아닌가:** BP에 노출할 이유가 아직 없다. 필요해지면 그때 노출하고 근거를 남긴다 (`CLAUDE.md` §7).

## 검증

- **빌드 통과**
- `Play As Client, Number of Players: 4` + `TeamSize = 2`
  - 같은 팀 두 명 → `IsSameTeam` **true**
  - 다른 팀 → **false**
  - 팀원 vs 팀 없는 액터 → **false**
  - `nullptr` 을 넘겨도 크래시하지 않고 `INDEX_NONE` / `false`

## 주의점

- ⭐ **`nullptr` 을 반드시 감당한다.** 이 함수는 프로젝트 전체에서 불리고, 사망·디스폰 중인 액터가 들어온다.
- `Cast<T>()` 결과는 항상 검사한다. `static_cast` 로 UObject를 캐스팅하지 않는다 (`CLAUDE.md` §5).
- 액터 → PlayerState 경로가 한 가지가 아니다. **Pawn 이 아닌 액터**(투사체·설치물)는 소유자(Owner)를 타고 올라가야 한다. 지금은 Pawn 경로만 처리하고, 설치물은 F07에서 소유권이 생길 때 확장한다 — **그 사실을 주석에 남긴다.**
- 매 프레임 호출될 함수다. **캐스팅 체인이 길어지면 캐싱을 검토**하되, 지금은 측정 전이므로 하지 않는다 (`CLAUDE.md` §2).

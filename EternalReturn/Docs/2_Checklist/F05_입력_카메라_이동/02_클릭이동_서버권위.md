# ✅ F05-02 — 클릭 이동 · 서버 권위 ⭐

> Task [`../../1_Task/F05_입력_카메라_이동/02_클릭이동_서버권위.md`](../../1_Task/F05_입력_카메라_이동/02_클릭이동_서버권위.md)
> ⭐ **역기획서가 "이 문서 최대의 논점" 으로 지목한 부분**

## 선행

- [x] [01 EnhancedInput 구조](01_EnhancedInput_구조.md) 완료
- [x] 레벨에 **네비메시가 빌드돼 있다**

## 구현

- [x] 클릭 지점을 트레이스로 얻는다
- [x] ⭐ **`Server` RPC + `WithValidation`** 으로 목적지를 보낸다
- [x] ⚠ **서버는 목적지를 검증만 한다** — 이동은 구동하지 않는다 (`Docs/5_ErrorReport/E07`)
- [x] ⭐ 클라가 로컬에서 `SimpleMoveToLocation` 으로 즉시 움직인다 (CMC 예측)
- [x] 경로 계산은 `SimpleMoveToLocation` 을 쓴다 (자체 경로 추적 X)
- [x] `MoveSpeed` 어트리뷰트를 CMC 에 반영하는 지점을 주석에 남겼다

## 빌드

- [x] `EternalReturnEditor` 빌드 통과
- [x] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [x] 우클릭한 지점으로 이동한다
- [ ] ⭐ 클라에서 클릭해도 **서버 로그에 목적지 확정**이 찍힌다  → ⚠ **2인 PIE 미확인**
- [ ] ⭐ **다른 클라 화면에서도 같은 위치**로 보인다  → ⚠ **2인 PIE 미확인**
- [x] 이동 중 다시 클릭하면 새 목적지로 바뀐다
- [ ] ⭐ **장애물(상자·벽)을 클릭하면 그 옆 바닥으로 이동한다** — 제자리에 멈추지 않는다  → ⏸ **F13(맵)** 으로 미룸
- [ ] 하늘을 클릭하면 아무 일도 안 일어난다 (크래시 아님)  → ⏸ **F13(맵)** 으로 미룸
- [ ] 이동이 **끊기거나 고무줄이 생기지 않는다**  → ⚠ **2인 PIE 미확인**

## ⭐⭐ 하지 말아야 할 것 — 걸렸는지 확인

- [x] ❌ **매 프레임 목적지 RPC 를 보내지 않는다**
- [x] ❌ **클라가 계산한 위치를 서버에 통보하지 않는다** (텔레포트 치트)
- [x] ❌ **CMC 를 끄고 직접 보간하지 않는다**
- [x] `Server` RPC 에 `WithValidation` 이 있다

## 흔한 실수

- [x] 클릭 트레이스 채널이 `SkillTarget`(F04) 과 **다르다**
- [x] 네비메시가 없을 때 크래시하지 않는다
- [ ] 이동 중 사망해도 크래시하지 않는다  → ⏸ **F11(사망·부활)** 필요

## 판단 기록

- [x] 이동 입력이 우클릭이라는 것이 **〔제안〕** 임을 남겼다
- [x] `MoveSpeed`(m/s) → CMC(cm/s) 환산 위치를 정했다

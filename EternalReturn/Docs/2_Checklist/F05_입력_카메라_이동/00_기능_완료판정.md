## ⭐ 이 기능의 존재 이유 — 실제로 움직인다

- [ ] 우클릭으로 캐릭터가 이동한다
- [ ] ⭐ **클라 2대에서 같은 위치로 보인다**
- [ ] 카메라가 따라온다 / 잠금 해제 시 스크롤된다
- [ ] ⭐ **이제 콘솔 커맨드 없이 검증할 수 있다**

## ⭐ 서버 권위 확인

- [ ] 목적지를 **서버가 확정**한다 (`Server` RPC + `WithValidation`)
- [ ] ⭐ **클라가 계산한 위치를 서버에 통보하지 않는다** — 텔레포트 치트가 된다
- [ ] 매 프레임 RPC 를 보내지 않는다
- [ ] `CharacterMovementComponent` 의 예측을 **대체하지 않았다**

## 흔한 실수 — 걸렸는지 확인

- [ ] ⚠ `IMC_Practice` 가 **연습 모드 밖에서 안 켜진다** (텔레포트 치트)
- [ ] 카메라를 복제하지 않았다 (로컬 전용)
- [ ] 액션을 문자열로 찾지 않았다
- [ ] 자체 재바인딩 시스템을 만들지 않았다 (`UEnhancedInputUserSettings` 사용)

## 경계 확인

- [ ] **스킬을 발동하지 않는다** — 입력을 받아 넘기는 데까지 (F07 소관)
- [ ] **CC 를 판정하지 않는다** — 태그를 읽어 막기만 한다 (F06 소관)
- [ ] 미니맵 · UI 를 모른다 (F17 소관)

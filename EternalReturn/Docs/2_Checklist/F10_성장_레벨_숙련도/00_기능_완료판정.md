## ⭐⭐ GE 종류를 맞게 썼는지 — 가장 중요

- [ ] ⭐⭐ **레벨 성장 GE 가 `Instant`** 다 (BaseValue) — Infinite 면 레벨분이 전부 "추가 공격력" 이 된다
- [ ] ⭐ **숙련도 증폭 GE 가 `Infinite`** 다 (CurrentValue) — 무기를 바꾸면 사라져야 한다
- [ ] 장비(Infinite) + 레벨(Instant) + 숙련도(Infinite) 를 함께 걸어도 `기본 / 추가` 가 각각 맞다

## ⭐ 서버 권위

- [ ] 경험치 축적 · 레벨업 판정이 **서버 전용**이다
- [ ] 스킬 포인트 지급 · R 해금 · P 자동 강화가 서버다
- [ ] 숙련도 경험치 분배가 서버다 (`PostGameplayEffectExecute`)
- [ ] 클라가 경험치 · 포인트를 직접 올릴 수 없다

## 복제

- [ ] 레벨은 **전원** (적 레벨은 HUD 에 보인다)
- [ ] 경험치 · 숙련도는 **본인만** (`COND_OwnerOnly`)
- [ ] `Replicated` 마다 `DOREPLIFETIME` 이 있다

## 구현

- [x] 찾지 못하면 `INDEX_NONE` 반환
- [x] ⭐ **한쪽이라도 무소속이면 `IsSameTeam` 이 `false`**
- [x] `nullptr` 입력을 감당한다
- [x] `Cast<T>()` 결과를 전부 검사한다
- [x] 투사체·설치물 경로는 **미구현이며 주석에 남겼다** (F07 이후 확장)

## 검증 — `Play As Client, Number of Players: 4`, `TeamSize = 2`

- [x] 같은 팀 두 명 → `IsSameTeam` **true**
- [x] 다른 팀 두 명 → **false**
- [x] 팀원 vs 팀 없는 액터 → **false**
- [x] ⭐ 팀 없는 액터 두 개 → **false** (곰끼리 아군이 되면 안 된다)
- [x] `nullptr` 을 넘겨도 **크래시하지 않고** `INDEX_NONE` / `false`
- [x] 사망·디스폰 중인 액터를 넘겨도 크래시하지 않는다

## 흔한 실수 — 걸렸는지 확인

- [x] ⭐ **무소속끼리 `true` 를 반환하지 않는다** — 야생동물이 서로를 아군으로 보면 F12에서 아무도 안 싸운다
- [x] `static_cast` 로 UObject를 캐스팅하지 않았다
- [x] **팀 조회 목적**의 `AERPlayerState` 접근이 `ERTeamStatics` 한 곳뿐이다
  ```
  grep -rn "TeamId" Source/    ← 읽기는 ERTeamStatics, 쓰기는 ERGameMode::PostLogin 만
  ```
  > ⚠ `AERPlayerState` 캐스팅 자체는 3곳이다 — `ERTeamStatics`(팀 읽기) · `ERGameMode`(팀 쓰기) ·
  > `ERCharacterBase`(ASC 조회, F00 소관). **팀과 무관한 캐스팅까지 금지하는 규칙은 아니다.**
- [x] 측정도 안 하고 캐싱을 넣지 않았다 (`CLAUDE.md` §2 — 추측성 최적화 금지)

## 막혔을 때

| 증상 | 확인할 것 |
|---|---|
| 항상 `INDEX_NONE` | 액터가 Pawn이 아니거나 Controller가 아직 없다. 스폰 직후 호출인지 확인 |
| 클라에서만 실패 | 클라에는 **자기 Controller만** 있다. 남의 Pawn은 `GetController()` 가 `nullptr` 이다 — **Pawn에서 PlayerState로 바로 가는 경로**(`APawn::GetPlayerState()`)를 쓴다 |

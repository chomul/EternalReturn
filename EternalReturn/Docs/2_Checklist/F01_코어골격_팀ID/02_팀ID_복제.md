- [x] ⭐ **`DOREPLIFETIME` 누락** — 컴파일도 되고 에러도 없는데 값만 안 온다. **이 항목이 이 Task에서 가장 자주 나는 실수다**

- [x] `APlayerState` 에 큰 배열을 얹지 않았다 (`bAlwaysRelevant = true` 라 24명 전원에게 간다)
- [x] 헤더에 `UPROPERTY` 를 추가했으므로 **에디터 재시작이 필요할 수 있다** — 사용자에게 알렸다

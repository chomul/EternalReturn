## 실행 기록 (2026-09-06)

**공통 규칙을 여기서 확정했다** — 나머지 판정 5종이 전부 이걸 쓴다.

| 규칙 | 결정 | 근거 |
|---|---|---|
| 기준점 | **발밑** (`GetTargetingLocation`) | [Argument 2](../../4_Argument/2_판정콜리전_설계.md) B-2 |
| 콜리전 채널 | **`SkillTarget`** (커스텀 트레이스, 기본 Ignore) | 같은 문서 A-2 |
| 질의 방식 | `OverlapMultiByChannel` + `MakeSphere` | |
| m → uu | `MetersToUU = 100`, 익명 namespace 의 `M()` **한 곳** | |
| 정렬 | 거리를 **한 번만** 재고 그 값으로 정렬·기록까지 (`SortAndMeasure`) | 카티야 R 이 가까운 순 요구 |
| 중복 제거 | `AddUnique` — 한 액터에 콜리전 컴포넌트가 여럿이면 중복으로 나온다 | |

**오버랩 결과 필터링**: 스태틱 메시·트리거 볼륨은 `SkillTarget` 채널에 응답하지 않으므로
애초에 결과에 안 들어온다 — 채널을 판 덕분에 코드로 거를 필요가 없어졌다.

**`Config/DefaultEngine.ini` 변경을 보고했다** (`CLAUDE.md` §9).

### Task 문서와 달라진 점 1건

`FTargetQuery` 가 `int32 InstigatorTeamId` 대신 **`Instigator` 액터**를 받는다.
팀 ID 만 들고 있으면 `ERTeamStatics::IsHostile()` 의 규칙을 `ERTargeting` 안에 다시 구현해야 해서,
**팀 로직이 두 벌**이 된다. 상세는 [01 체크리스트](01_타입정의_구조체.md) 하단.

### ⚠⚠ 임시 검증 코드를 넣었다 — 지워야 한다

`Source/EternalReturn/Combat/ERTargetingDebug.cpp` (콘솔 커맨드 `ER.Targeting.Test`)

사용자 승인을 받고 넣었다(`CLAUDE.md` §2 추측성 코드 금지와 걸리는 면이 있어 먼저 물었다).

- ⭐ **F07(스킬) 착수 시 삭제한다.** 그때 `ERTargeting` 의 진짜 호출자가 생긴다

### ⚠ 벽 차폐는 구현하지 않았다

`SkillTarget` 채널에 벽이 응답하지 않으므로 **현재 모든 판정이 벽을 통과한다.**
레이피어 D(벽 통과)는 의도대로지만, 벽에 막혀야 하는 스킬은 별도 차폐 트레이스가 필요하다.
**F07 에서 스킬별로 붙인다.**

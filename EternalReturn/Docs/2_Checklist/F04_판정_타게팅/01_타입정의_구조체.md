## 실행 기록 (2026-09-06)

`Source/EternalReturn/Combat/ERTargetingTypes.h`

### Task 문서와 달라진 점 — `InstigatorTeamId` → `Instigator` 액터

Task 는 `int32 InstigatorTeamId` 를 받자고 했는데, 그러면 **팀 판정 로직이 두 벌이 된다.**
`ERTeamStatics::IsHostile()` 은 액터를 받으므로, 팀 ID 만 들고 있으면 그 규칙을
`ERTargeting` 안에 **다시 구현**해야 한다.

`TObjectPtr<const AActor> Instigator` 로 바꿔서 **`ERTeamStatics` 가 팀 로직의 유일한 소유자**로 남게 했다.
`FTargetQuery` 는 이미 `IgnoredActors` 로 액터를 들고 있어서 새로운 의존이 생기지도 않는다.

### 추가한 필드 3개

| 필드 | 이유 |
|---|---|
| `ProjectileRadius` (기본 0.25m) | 폭 0인 라인 트레이스는 실전에서 잘 안 맞는다 |
| `bIgnoreZ` (기본 true) | Argument 2 B-5 결정. 탑다운 수평 판정이 기본, 스킬 단위로 끌 수 있게 |
| `bIncludeInstigator` (기본 false) | 시셀라 R 이 자기 자신을 대상으로 한다 |

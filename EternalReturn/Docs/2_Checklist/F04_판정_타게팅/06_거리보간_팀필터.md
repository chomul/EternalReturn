## 실행 기록 (2026-09-06)

### ⭐ `ERTeamStatics` 의 첫 호출자가 됐다

```
grep -n "ERTeamStatics::" Source/EternalReturn/Combat/ERTargeting.cpp
  54:  return ERTeamStatics::IsSameTeam(Q.Instigator, Candidate);   // Ally
  59:  return ERTeamStatics::IsHostile(Q.Instigator, Candidate);    // Enemy
```

F01 에서 만들어만 두고 호출자가 없던 함수들이 **드디어 실행 경로를 갖게 됐다.**
F01 의 미검증 3건이 이 함수의 PIE 검증으로 같이 해결된다.

### 필터를 부정 연산으로 짜지 않았다

```cpp
case ETargetTeamFilter::Ally:  return ERTeamStatics::IsSameTeam(...);
case ETargetTeamFilter::Enemy: return ERTeamStatics::IsHostile(...);   // !IsSameTeam 아님
```

`!IsSameTeam` 으로 짰다면 **자기 자신이 적으로 잡히고**(bIncludeInstigator 와 충돌),
`Ally` 를 같은 방식으로 짜면 **무소속 야생동물이 아군이 된다.**

### 자기 자신 처리

팀 필터보다 **먼저** 걸러진다. `bIncludeInstigator` 가 true 면 필터와 무관하게 포함,
false 면 무관하게 제외 — 시셀라 R(자기 대상 피해)이 이걸 쓴다.

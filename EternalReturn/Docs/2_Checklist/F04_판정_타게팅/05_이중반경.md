## 실행 기록 (2026-09-06)

**중복 포함이 구조적으로 불가능하게 짰다.** 하나의 `if/else` 로 갈라서
같은 액터가 두 배열에 들어갈 경로 자체가 없다.

```cpp
if (Dist <= InnerUU) { Inner.Add(Actor); }   // 경계는 중앙 우선
else                 { Outer.Add(Actor); }
```

`RadiusInner > RadiusOuter` 는 **스왑 + 경고 로그**로 처리했다. 조용히 잘못된 결과를 내지 않는다.

⚠ **`RadiusInner == 0` 일 때**: `Dist <= 0` 은 시전자와 정확히 같은 위치일 때만 참이라
사실상 전부 외곽으로 간다 → 일반 원형처럼 동작한다. 의도한 대로다.

## 선행

- [x] [03 ASC 부착 · 초기화](03_ASC_부착_초기화.md) 완료

## 구현

- [x] 플레이어 ASC → ⭐ **`SetReplicationMode(EGameplayEffectReplicationMode::Mixed)`**
- [x] 호출 시점이 **ASC 생성 직후**다 (이펙트가 붙기 전)
- [x] 야생동물 계획 → `Minimal` (F12에서 적용)
- [x] ⭐ `AERPlayerState::NetUpdateFrequency` 를 올렸다 (기본 1)
- [x] 올린 값이 **자체 결정 초기값이며 미측정**임을 주석에 남겼다

## 빌드

- [x] `EternalReturnEditor` 빌드 통과
- [x] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 3` + Dedicated Server 체크

- [ ] 서버에서 이펙트를 걸면 **소유 클라가 전체 정보**를 받는다
- [ ] 다른 클라는 **최소 정보**만 받는다
- [ ] ⭐ 체력 변화가 **즉시** 반영된다 (1초 지연이 아니다)
- [ ] 클라 2대의 표시가 일치한다

## ⭐ 엔진 제약 — 위반하지 않았는가

- [x] **플레이어 ASC에 `Minimal` 을 쓰지 않았다**
  근거: `AbilitySystemComponent.h:87` — *"this does not work for Owned AbilitySystemComponents (Use Mixed instead)"*
- [x] 야생동물에 `Mixed` 를 쓰지 않기로 했다 (120~200마리라 낭비)
- [x] `Full` 을 쓰지 않았다

## 흔한 실수 — 걸렸는지 확인

- [x] ⭐ **`NetUpdateFrequency` 를 안 올려서 체력바가 초당 1회 갱신되지 않는다**
- [x] `SetReplicationMode` 를 이펙트가 붙은 뒤에 부르지 않았다
- [x] 측정도 없이 `NetUpdateFrequency = 100` 을 **확정값처럼** 적지 않았다

## 미측정로 남긴 것

| 항목 | 어떻게 잴 것인가 |
|---|---|
| `NetUpdateFrequency` 적정값 | 봇 24명 + `NET ACTIVE` + `stat unit` ([네트워크 문서](../../0_GameDesign/Systems/네트워크_서버아키텍처_역기획서.md) §5.2) |
| GAS 복제 총비용 | 위와 동일 |

## 실행 기록 (2026-09-06)

`AERPlayerState` 생성자에 세 줄 (`Source/EternalReturn/Core/ERPlayerState.cpp`):

```cpp
AbilitySystemComponent->SetIsReplicated(true);
AbilitySystemComponent->SetReplicationMode(EGameplayEffectReplicationMode::Mixed);
NetUpdateFrequency = 100.f;   // ⚠ 자체 결정 초기값, 미측정
```

⭐ **엔진 소스에서 확인한 것:** ASC 생성자의 기본 복제 모드는 **`Full`** 이다
(`AbilitySystemComponent.cpp` — `ReplicationMode = EGameplayEffectReplicationMode::Full;`).
바꾸지 않으면 24명분 활성 이펙트 전체가 전원에게 간다. 이 Task 가 선택이 아닌 이유다.

⬜ **PIE 검증 4건 미완** — 게임모드 애셋 문제로 아직 못 켰다 (F00-03 기록 참조).
⬜ **`NetUpdateFrequency` 측정 미완** — 봇 24명 + `NET ACTIVE` + `stat unit`.

# ✅ F07-07 — 다음 평타 강화 · 리캐스트

> Task [`../../1_Task/F07_스킬_GameplayAbility/07_다음평타_리캐스트.md`](../../1_Task/F07_스킬_GameplayAbility/07_다음평타_리캐스트.md)

## 선행

- [ ] [04 실행 파이프라인](04_실행파이프라인_채널링.md) 완료

## 구현

- [ ] ⭐ **공용 1벌**로 만든다 (캐릭터마다 따로 X)
- [ ] `Ability.Form.NextAttackBuff` 태그를 쓴다
- [ ] 리캐스트 윈도우를 **GE Duration** 으로 잰다 (`FTimerManager` X)
- [ ] 평타 강화가 **1회성**임을 보장한다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] 재키 W 후 **다음 평타에만** 둔화가 붙는다
- [ ] 그 다음 평타에는 안 붙는다
- [ ] 재키 Q 적중 후 **3초 내에만** 재사용된다
- [ ] 윈도우가 지나면 재사용이 안 된다
- [ ] ⭐ **무장 해제 중에는 평타 강화도 막힌다** (F06 연결)

## ⭐ 가장 위험한 실수

- [ ] ⭐ **캐릭터마다 따로 만들지 않았다**
- [ ] ⚠ 평타 강화가 1회성이다
- [ ] `FTimerManager` 를 쓰지 않았다

## 선행

- [ ] [02 쿨다운 GE](02_쿨다운_GE.md) 완료

## 구현

- [ ] Cost GE 로 자원을 차감한다 (수동 차감 X)
- [ ] ⭐ **체력 코스트 하한을 어빌리티가 미리 깎아서** 넘긴다
- [ ] ⭐ **어트리뷰트셋에 하한 장치를 넣지 않는다** (F02-04 결정)
- [ ] 스킬 포인트 상한 5/5/5/3 을 **서버가 검증**한다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 코스트가 모자라면 **발동하지 않는다**
- [ ] ⭐ 시셀라 W 사용 시 체력이 **1 이하로 안 내려간다**
- [ ] ⭐ 시셀라 R 자기 피해가 **100 에서 멈춘다** (F03-06 완결)
- [ ] 스킬 포인트 상한 초과 배분을 **서버가 거부**한다

## ⭐ 가장 위험한 실수

- [ ] ⭐ **어트리뷰트셋에 하한을 넣지 않았다** — 넣으면 죽어야 할 때 안 죽는다
- [ ] ⭐ 스킬 포인트 배분이 **서버 검증**이다
- [ ] ⚠ 코스트 **검사**와 **차감**의 시점을 구분했다

## 검증 — `Play As Client, Number of Players: 2`

- [x] ⭐ 클라가 Q 를 누르면 **서버에서 어빌리티가 발동**한다  → ✅ 1인 PIE 확인 (E10 수정 후) · ⚠ 2인 PIE 미확인
- [x] 슬롯 태그로 어빌리티를 찾을 수 있다  → ✅ ⚠ **DynamicAbilityTags 를 직접 순회** — TryActivateAbilitiesByTag 는 못 찾는다 (E10)
- [x] 부여가 서버에서만 일어난다  → ✅ 로그 확인
- [ ] 부여한 것을 회수하면 발동이 안 된다  → ⏸ **F11** — 회수 함수는 있지만 부를 곳(무기 교체)이 아직 없다

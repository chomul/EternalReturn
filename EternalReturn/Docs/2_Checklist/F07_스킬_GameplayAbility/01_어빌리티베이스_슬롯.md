## 선행

- [ ] F00 · F02 · F03 · F04 · F06 완료
- [ ] ⚠ 스킬 데이터 저장 위치를 `Docs/4_Argument/` 에서 **먼저** 정했다

## 구현

- [ ] `UERGameplayAbility : public UGameplayAbility` 베이스 1개
- [ ] 슬롯 태그(`Ability.Slot.*`)로 어빌리티를 찾는다
- [ ] `FERSkillRow` 정의 — F03 의 `Data.Damage.*` 계수를 담는다
- [ ] ⭐ 부여를 **핸들로 회수**할 수 있다 (Lyra `FLyraAbilitySet_GrantedHandles` 형태)
- [ ] ⚠ D 슬롯은 **자리만** 만든다 (런타임 교체는 F11)

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 클라가 Q 를 누르면 **서버에서 어빌리티가 발동**한다
- [ ] 슬롯 태그로 어빌리티를 찾을 수 있다
- [ ] 부여가 서버에서만 일어난다
- [ ] 부여한 것을 회수하면 발동이 안 된다

## ⭐ 가장 위험한 실수

- [ ] ⭐ **어빌리티 부여 · 발동이 서버 권위**다
- [ ] ⭐ **계산식을 어빌리티에 넣지 않았다** — 계수만 넘긴다
- [ ] ⚠ 어빌리티가 **대상 스탯을 읽지 않는다** (F03 이 읽는다)
- [ ] 슬롯 태그를 문자열로 박지 않았다

## 판단 기록

- [ ] 스킬 데이터 저장 위치를 정하고 근거를 남겼다

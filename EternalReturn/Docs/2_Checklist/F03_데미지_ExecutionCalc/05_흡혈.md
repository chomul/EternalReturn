## 구현

- [x] 흡혈 계산을 Execution 안에서 처리
- [x] 광역 치유 감소 **50%**
- [x] 야생동물 치유 감소 **60%**
- [x] ⭐ 광역 여부를 **스킬이 붙인 태그**(`Damage.Shape.AoE`)로 판별
- [x] ⭐ 야생동물 여부를 **Target 태그**(`Actor.Type.Wildlife`)로 판별
- [x] ⭐ **`Cast<>` 로 클래스를 검사하지 않았다**
- [x] 회복 대상이 **Source(공격자)** 다 — 코드상 `GetSourceAbilitySystemComponent()` 확인
- [x] Source 회복 방식(출력 수정자 / 별도 GE)을 정하고 **주석에 남겼다**

## 빌드

- [x] `EternalReturnEditor` 빌드 통과
- [x] `EternalReturnServer` 빌드 통과

## 수치 검증

- [x] 피해 100, 흡혈 20%, 단일 대상, 캐릭터 → **20 회복**
- [x] ⭐ 피해 100, 흡혈 20%, **AoE 태그** → **10 회복**
- [x] 피해 100, 흡혈 20%, **야생동물 태그** → **8 회복**
- [x] AoE + 야생동물 동시 → 정한 규칙대로
- [x] 피해 0 → 0 회복
- [ ] ⭐ **회복이 공격자에게 간다** (피격자 아님)
  ⬜ **런타임 검증 불가.** `ER.Damage.Test` 는 자기 자신을 때려서 공격자와 피격자가 같다.
  회복 대상이 틀려도 이 테스트는 통과한다. **F07(다른 액터 타격) 에서 확인한다.**
- [x] 최대 체력을 넘지 않는다 (F02-03 클램프가 처리)

## ⭐ 가장 위험한 실수

- [x] **회복이 Target에 가지 않는다** — 가면 때린 상대를 회복시킨다
- [x] **최대 체력 클램프를 여기서 또 하지 않았다**

- [x] 회복 이펙트를 Execution에서 재생하지 않았다 (`GameplayCue` 소관)

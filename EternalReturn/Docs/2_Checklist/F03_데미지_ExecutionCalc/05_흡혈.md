# ✅ F03-05 — 흡혈

> Task [`../../Task/F03_데미지_ExecutionCalc/05_흡혈.md`](../../1_Task/F03_데미지_ExecutionCalc/05_흡혈.md)

## 선행

- [ ] [04 치명타 · 채널 분기](04_치명타_채널분기.md) 완료

## 구현

- [ ] 흡혈 계산을 Execution 안에서 처리
- [ ] 광역 감쇠 **50%**
- [ ] 야생동물 감쇠 **60%**
- [ ] ⭐ 광역 여부를 **스킬이 붙인 태그**(`Damage.Shape.AoE`)로 판별
- [ ] ⭐ 야생동물 여부를 **Target 태그**(`Actor.Type.Wildlife`)로 판별
- [ ] ⭐ **`Cast<>` 로 클래스를 검사하지 않았다**
- [ ] 회복 대상이 **Source(공격자)** 다
- [ ] Source 회복 방식(출력 수정자 / 별도 GE)을 정하고 **주석에 남겼다**

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 수치 검증

- [ ] 피해 100, 흡혈 20%, 단일 대상, 캐릭터 → **20 회복**
- [ ] ⭐ 피해 100, 흡혈 20%, **AoE 태그** → **10 회복**
- [ ] 피해 100, 흡혈 20%, **야생동물 태그** → **8 회복**
- [ ] AoE + 야생동물 동시 → 정한 규칙대로
- [ ] 피해 0 → 0 회복
- [ ] ⭐ **회복이 공격자에게 간다** (피격자 아님)
- [ ] 최대 체력을 넘지 않는다 (F02-03 클램프가 처리)

## ⭐ 가장 위험한 실수

- [ ] **회복이 Target에 가지 않는다** — 가면 때린 상대를 회복시킨다
- [ ] **최대 체력 클램프를 여기서 또 하지 않았다**

## 흔한 실수 — 걸렸는지 확인

- [ ] 감쇠를 곱셈으로 처리했다 (뺄셈 아님)
- [ ] 판정 형상을 Execution이 추측하지 않는다 (스킬이 태그로 알려준다)
- [ ] 회복 이펙트를 Execution에서 재생하지 않았다 (`GameplayCue` 소관)

## 미확인으로 남긴 것

- [ ] ⭐ **Source 회복 구현 방식**을 구현하며 확정하고 주석에 남겼다
- [ ] AoE + 야생동물 감쇠 **중복인지 택일인지** 정하고 주석에 남겼다
- [ ] 흡혈이 고정 피해에 적용되는지 **(미확인)** 으로 남겼다
- [ ] 스킬 흡혈과 평타 흡혈이 별도 스탯인지 **(미확인)** 으로 남겼다

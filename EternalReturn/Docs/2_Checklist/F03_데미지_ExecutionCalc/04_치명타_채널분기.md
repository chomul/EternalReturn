# ✅ F03-04 — 치명타 · 채널 분기 ⭐

> Task [`../../Task/F03_데미지_ExecutionCalc/04_치명타_채널분기.md`](../../1_Task/F03_데미지_ExecutionCalc/04_치명타_채널분기.md)

## 선행

- [ ] [03 방어 관통](03_방어관통.md) 완료
- [ ] [F00-05 GameplayTag 체계](../F00_GAS기반세팅/05_GameplayTag_체계.md) 완료 — 채널 태그가 있어야 한다

## 구현

- [ ] 채널을 **GameplayTag로 판별** (`Damage.Type.BasicAttack` / `Skill` / `True`)
- [ ] ⭐ **채널 검사가 조건문 맨 앞**에 있다
- [ ] 기본 공격에서만 치명타 판정
- [ ] 기본 배율 **175%**
- [ ] ⭐ **태그 없는 GE에 경고 로그**
- [ ] 치명타 여부를 `GameplayCue` 로 전달할 방법을 마련했다
- [ ] ⭐ **Execution 안에서 이펙트를 재생하지 않는다**
- [ ] 태그를 문자열로 박지 않았다 (F00-05 상수 사용)

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 수치 검증

- [ ] ⭐ **스킬 태그 + 치명타 확률 100% → 치명타 발생 안 함** (문서 §7 4순위 기준)
- [ ] ⭐ **고정 피해 태그 + 확률 100% → 치명타 발생 안 함**
- [ ] 기본 공격 태그 + 확률 100% + 175% → **1.75배**
- [ ] 기본 공격 태그 + 확률 0% → 항상 기본 피해
- [ ] 기본 공격 태그 + 확률 50% × 1000회 → 대략 절반
- [ ] ⭐ **태그 없음 → 경고 로그가 남는다**

## ⭐ GAS에서 더 위험해진 지점

자체 구현의 `enum` 은 값을 안 넣으면 컴파일이 걸렸다. **태그는 안 붙여도 조용히 통과한다.**

- [ ] 태그 누락을 **조용히 넘기지 않는다**
- [ ] 어느 분기에도 안 들어간 경우를 명시적으로 처리했다

## 흔한 실수 — 걸렸는지 확인

- [ ] ⭐ **확률을 먼저 계산하고 채널을 나중에 보지 않았다** — 순서가 뒤집히면 스킬에 치명타가 붙는다
- [ ] 치명타 적용 순서(방어력 전/후)를 정하고 주석에 남겼다
- [ ] 확률 0%/100% 로 검증했다 (`FMath::FRand()` 는 비결정적)
- [ ] 치명타 확률 상한을 여기서 또 자르지 않았다 (F02-03 소관)

## ⚠ 이 항목은 밸런스의 뼈대다

- [ ] 스킬에 치명타가 안 붙는다는 것을 **F07에서 다시 확인**할 회귀 항목으로 기록했다

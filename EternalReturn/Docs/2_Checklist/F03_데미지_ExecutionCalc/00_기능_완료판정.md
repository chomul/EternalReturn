## 수치 검증 — 전부 정수로 떨어진다

- [ ] 원시 200, 방어력 100, 스킬 → **100**
- [ ] 원시 200, 방어력 100, **고정 피해 태그** → **200**
- [ ] 방어력 100 + 관통 50% + 고정 30 → 적용 방어력 **20**
- [ ] 방어력 100 + 관통 50% + 고정 999 → **0** (음수 아님)
- [ ] ⭐ **스킬 태그 + 치명타 확률 100% → 치명타 발생 안 함**
- [ ] 기본 공격 태그 + 확률 100% + 175% → **1.75배**
- [ ] 피해 100 + 흡혈 20% + AoE 태그 → **10 회복**
- [ ] ⭐ 최대 체력 10000 + 8% 비례 + **보스** → **400**
- [ ] 시셀라 R 자기 피해 → **체력 100에서 멈춤**
- [ ] ⭐ **태그 없는 GE → 경고 로그**

## ⭐ 단일 경로 확인 — 이게 이 기능의 존재 이유다

- [ ] **피해를 계산하는 곳이 이 Execution 하나뿐이다**
  ```
  grep -rn "GameplayEffectExecutionCalculation" Source/    ← ERDamageExecution 외에 없어야 함
  ```
- [ ] 어빌리티가 직접 피해를 계산하지 않는다 (SetByCaller로 원시 피해만 넘긴다)
- [ ] 방어력 공식이 다른 파일에 복사되어 있지 않다

## ⭐ 책임 분리 확인

- [ ] **체력을 직접 건드리지 않는다** — `IncomingDamage` 에 출력만 (F02-04가 처리)
- [ ] **클램프하지 않는다** — F02-03이 한다
- [ ] **쿨다운 환산을 하지 않는다** — Cooldown GE가 한다 (F07)
- [ ] **`Cast<>` 로 대상 클래스를 검사하지 않는다** — 태그/어트리뷰트로 판별
  ```
  grep -n "Cast<" Source/EternalReturn/GAS/ERDamageExecution.cpp    ← 안 나와야 함
  ```
- [ ] **이펙트·사운드·로그를 재생하지 않는다** — `GameplayCue` 소관
- [ ] Target 어트리뷰트를 수정하지 않는다 (관통은 지역 변수)

## ⭐ GAS 특유의 실수 — 전체 점검

- [ ] Source / Target 캡처를 **혼동하지 않았다**
- [ ] 스냅샷 플래그를 표대로 나눴다 (Source `true`, Target `false`)
- [ ] `RelevantAttributesToCapture` 에 전부 등록했다 (누락 시 0으로 읽힌다)
- [ ] `IncomingDamage`(Meta)를 **캡처하지 않았다** (출력 대상이지 입력이 아님)
- [ ] 채널 태그가 없는 GE를 조용히 통과시키지 않는다

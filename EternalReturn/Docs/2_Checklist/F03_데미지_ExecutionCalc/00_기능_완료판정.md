## ⭐ 단일 경로 확인 — 이게 이 기능의 존재 이유다

- [x] **피해를 계산하는 곳이 이 Execution 하나뿐이다**
  ```
  grep -rn "GameplayEffectExecutionCalculation" Source/    ← ERDamageExecution 외에 없어야 함
  ```
- [x] 어빌리티가 직접 피해를 계산하지 않는다 — **계수만** 넘긴다 (`Data.Damage.*`)
  ⬜ 어빌리티가 아직 없다. **F07** 에서 실제로 지켜지는지 다시 본다
- [x] 방어력 공식이 다른 파일에 복사되어 있지 않다
  ⚠ `grep "100.f / (100.f"` 는 **2건**을 낸다 — `ERDamageExecution.cpp:236` 과
  `ERDamageDebug.cpp:170`. 후자는 **의도적 중복**이다: 기대값을 Execution 과
  독립적으로 계산해야 검증이 성립한다. **F07 에서 디버그 파일과 함께 사라진다**

## ⭐ 책임 분리 확인

- [x] **체력을 직접 건드리지 않는다** — `grep -c "SetHP|GetHPAttribute()"` → **0**
- [x] **클램프하지 않는다** — F02-03 이 한다
- [x] **쿨다운 환산을 하지 않는다** — Cooldown GE가 한다 (F07)
- [x] **`Cast<>` 로 대상 클래스를 검사하지 않는다** — 태그로 판별 (주석 1건 외 코드 0)
  ```
  grep -n "Cast<" Source/EternalReturn/GAS/ERDamageExecution.cpp    ← 안 나와야 함
  ```
- [x] **이펙트·사운드를 재생하지 않는다** — `GameplayCue` 소관
  ⚠ **로그는 1건 있다** (`:191` 채널 태그 누락 경고). 이건 다른 체크 항목이
  *"태그 없는 GE 에 경고 로그"* 로 **요구한 것**이라 의도적이다.
  금지 대상은 **연출용 로그**이지 진단 경고가 아니다 — 두 항목이 겹쳐서 여기 남긴다
- [x] Target 어트리뷰트를 수정하지 않는다 — `grep -c "ApplyModToAttribute|SetNumericAttribute"` → **0**

## ⭐ 가장 위험한 실수 세 가지

- [x] **감쇠가 일반 피해에 곱해지지 않는다**
  곱해지면 보스가 모든 피해를 절반만 받는 **완전히 다른 게임**이 된다
- [x] **「최대」와 「현재」를 혼동하지 않았다**
  재키 Q는 **현재** 체력 5%다. 최대로 계산하면 **처형기**가 된다 — 정반대 성격
- [x] **`Cast<>` 로 대상 클래스를 검사하지 않는다**
  ⚠ `grep -c "Cast<"` 는 **1** 을 낸다 — 주석 안의 `Cast<ABossActor>` 다 (설명용).
  코드에는 없다. 확인 명령: `grep -n "Cast<" ... | grep -v "//"` → **0**
  ```
  grep -n "Cast<" Source/EternalReturn/GAS/ERDamageExecution.cpp    ← 안 나와야 함
  ```

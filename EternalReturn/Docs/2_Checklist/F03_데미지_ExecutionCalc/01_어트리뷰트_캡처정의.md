## ⭐ Source / Target 배정 — 하나씩 확인

**Source (때리는 쪽)**
- [ ] `AttackPower`
- [ ] `CritChance`
- [ ] `CritDamage`
- [ ] `DefensePenPct`
- [ ] `DefensePenFlat`
- [ ] `MaxHealth` / `Health` (자신의 잃은 체력 비례용 — F03-06)

**Target (맞는 쪽)**
- [ ] `Defense`
- [ ] `MaxHealth`
- [ ] `Health`

- [ ] ⭐ **뒤집히지 않았다** — 뒤집으면 자기 방어력으로 자기 피해를 깎는다
- [ ] 각 정의에 **주석으로 근거**를 남겼다

## ⭐ 스냅샷 플래그 — 마지막 bool

- [ ] Source 어트리뷰트 → **`true`** (GE Spec 생성 시점 값)
- [ ] Target 어트리뷰트 → **`false`** (적용 시점 값)
- [ ] ⭐ **Target을 `true` 로 하지 않았다** — 하면 방어 아이템을 낀 게 반영 안 된다
- [ ] 매그너스 W(*"시전 시점 확정"*)가 Source 스냅샷으로 처리 가능함을 확인했다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증

- [ ] Execution에서 캡처값을 읽을 수 있다
- [ ] Source 값이 **공격자** 것이다
- [ ] Target 값이 **피격자** 것이다
- [ ] 캡처 실패 시 0이 아니라 **의도한 기본값**이 온다 (또는 경고)

## 흔한 실수 — 걸렸는지 확인

- [ ] ⭐ **`RelevantAttributesToCapture` 등록 누락이 없다** — 누락하면 값이 조용히 0
- [ ] 스냅샷 플래그를 복붙하지 않았다
- [ ] ⭐ **`IncomingDamage`(Meta)를 캡처하지 않았다**

## 판단 기록

- [ ] 기력(VP) 캡처 필요 여부를 **(미확인)** 으로 남겼다
- [ ] 「최종 피해 추가(%)」는 **캡처하되 적용 보류**임을 주석에 남겼다

## ⭐ 역기획서 §3.1 규칙 4개

- [ ] ① 조합은 항상 2개 — 3개 조합 · 1개 변환이 데이터 구조상 불가능하다
- [ ] ② 제작이 스탯을 모른다 — 등급은 숙련도 경험치에만
- [ ] ③ 보스 재료 획득은 여기 없다 (F12 · F14)
- [ ] ④ 건너뛰기(일반 + 최고급 → 초월)가 데이터만으로 된다 — 깊이 · 단계 강제 없음

## ⭐ 서버 권위

- [ ] 제작 요청 → **서버 검증** (재료 · 자리) → 소비 → 추가. 부분 실패 없음
- [ ] 클라가 없는 조합 · 없는 재료로 요청해도 거부
- [ ] 상자 · 채집물 내용을 서버가 채운다 · 습득은 F08-05 RPC

## 경계 확인

- [ ] **파밍 오버레이 UI 를 만들지 않았다** — 데이터만 (F17)
- [ ] **드론을 만들지 않았다** — F15
- [ ] **야생동물 드랍을 만들지 않았다** — F12 (루트 행 형식만 공유)
- [ ] **지역별 배치를 하지 않았다** — F13
- [ ] 새 습득 경로 · 새 액터 클래스를 만들지 않았다 — `AERItemDropActor` · `ServerPickup` 재사용

## 흔한 실수

- [ ] 재료 이름 오타가 **인덱스 생성 때** 에러로 드러난다 (조용한 "제작 불가" 없음)
- [ ] 순환 데이터에서 무한 루프 · 스택 오버플로 없음
- [ ] 트리 탐색이 순수 함수다 (인벤토리 · 액터 무관)
- [ ] `FERItemRow` 필드를 끝에 붙였다

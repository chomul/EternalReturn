## 구현

- [ ] 넉백 · 그랩이 **같은 공용 함수**를 쓴다 (방향이 인자)
- [ ] ⭐ 강제 이동 시작 · 방향 · 거리가 **서버 권위**다
- [ ] ⭐ **벽 충돌 판정이 서버에만** 있다
- [ ] 추가 피해 · 기절이 서버에서만 발생한다
- [ ] 엔진 기능(`LaunchCharacter` / RootMotion Task)을 먼저 검토했다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 넉백 3m 가 **서버 · 클라 같은 위치**로 끝난다
- [ ] ⭐ 벽 충돌 시 **서버에서만** 추가 피해 + 기절, 클라는 결과만 받는다
- [ ] 넉백 중 이동 입력이 무시된다
- [ ] 넉백 중 사망해도 크래시하지 않는다

## ⭐ 가장 위험한 실수

- [ ] ⭐⭐ **벽 충돌 판정을 클라에서 하지 않았다** — 클라마다 결과가 갈린다
- [ ] ⚠ 강제 이동이 CMC 일반 이동과 충돌하지 않는다
- [ ] `State.CCImmune` 이 이걸 무시하는 경로를 F06-05 에 남겼다

## 검증 — `Play As Client, Number of Players: 2`

- [x] ⭐ 넉백 3m 가 **서버 · 클라 같은 위치**로 끝난다  → ✅ 로그: 실제 이동 3.00m/5.00m (오차 0) · 멀티는 사용자 확인
- [ ] ⭐ 벽 충돌 시 **서버에서만** 추가 피해 + 기절, 클라는 결과만 받는다  → ⏸ **F07**
- [x] 넉백 중 이동 입력이 무시된다  → ✅ 사용자 확인 (RootMotion Override)
- [ ] 넉백 중 사망해도 크래시하지 않는다  → ⏸ **F11(사망)** 필요

### ⭐ 벽 충돌 감시 (구현 후 추가)

- [x] ⭐⭐ **넉백 중 매 틱 벽을 검사한다** (역기획서 §3.5) — Tick 을 넉백 중에만 켠다
- [x] ⭐ 로그 확인: `벽 충돌! 대상=StaticMeshActor_40` **2회 발동** (벽 X=2899.88 로 일치)
- [x] ⭐⭐ **빈 곳에서는 오탐이 없다** (넉백 3회 중 0회) — `CMC->IsWalkable` 이 바닥을 걸러낸다
- [x] 벽에 닿으면 소스 제거 + `Multicast_StopForcedMove` 로 전파한다
- [x] ⚠ Tick 이 **평소에는 꺼져 있다** (`bStartWithTickEnabled = false`)

## ⭐ 가장 위험한 실수

- [x] ⭐⭐ **벽 충돌 판정을 클라에서 하지 않았다** — 클라마다 결과가 갈린다
- [x] ⚠ 강제 이동이 CMC 일반 이동과 충돌하지 않는다  → ✅ 사용자 확인
- [ ] `State.CCImmune` 이 이걸 무시하는 경로를 F06-05 에 남겼다  → ⏸ **F06-05**

## 선행

- [ ] [01 CC GE 기반](01_CC_GE기반_차단배선.md) 완료
- [ ] ⚠ 저항 적용 방식(MMC / SetByCaller)을 `Docs/4_Argument/` 에서 **먼저** 정했다

## 구현

- [ ] CC GE 의 Duration 계산에 대상의 `CCResist` 를 반영한다
- [ ] 면역(`State.CCImmune`)은 `ApplicationTagRequirements` 로 막는다
- [ ] ⭐ **저항 상한을 여기서 또 자르지 않는다** — F02-03 소관
- [ ] 중첩 규칙(`StackingType`)을 정하고 주석에 남겼다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 저항 40% 에서 기절 지속시간이 **60%** 가 된다
- [ ] ⭐ `State.CCImmune` 중 넉백이 **무시된다**
- [ ] 저항 상한(0.8)이 걸린다
- [ ] 같은 CC 가 겹칠 때 규칙대로 처리된다

## ⭐ 가장 위험한 실수

- [ ] ⚠ **`SlowResist` 와 `CCResist` 를 혼동하지 않았다** — 둔화는 전자, 기절은 후자
- [ ] ⭐ 저항이 **지속시간**을 줄이고, 면역은 **아예 안 걸리게** 한다 (다른 것이다)
- [ ] 상한 클램프를 두 곳에서 하지 않았다

## 판단 기록

- [ ] 저항 적용 방식을 정하고 근거를 남겼다
- [ ] 중첩 규칙을 주석에 남겼다

## ⭐ GAS 를 다시 만들지 않았는지

- [ ] **자체 CC 상태 enum 이 없다**
- [ ] **`FTimerManager` 로 지속시간을 재지 않는다** — GE Duration 사용
- [ ] **수동 해제 코드가 없다** — GE 만료 시 태그가 같이 사라진다
- [ ] **자체 취소 상태 머신이 없다** — `CancelAbilitiesWithTag` 사용
- [ ] 태그를 문자열로 박지 않았다 (`ERGameplayTags.h`)

## 수치 · 동작 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 기절 중 이동 · 평타 · 스킬이 전부 막히고 **만료 시 자동 해제**
- [ ] 둔화 60% 가 서버 · 클라 동일
- [ ] ⭐ 채널링 중 기절 → 시전 취소 (쿨다운은 남음 — ⬜ F07)
- [ ] ⭐ 넉백 3m 가 서버 · 클라 같은 위치
- [ ] ⭐ 벽 충돌 추가 피해가 **서버에서만** 발생
- [ ] ⭐ 저항 40% 에서 기절이 60% 로 감소
- [ ] ⭐ 면역 중 넉백 무시
- [ ] ⭐ 무적 중 피해 0, **기절은 정상 적용**
- [ ] 침묵 중 스킬만 막힘 (평타 가능)

## ⭐ 서버 권위

- [ ] CC 부여가 **서버에서만** 일어난다
- [ ] ⭐ **벽 충돌 판정이 클라에 없다**
- [ ] 클라가 자기에게 CC 를 거는 경로가 없다

## 경계 확인

- [ ] **스킬을 발동하지 않는다** (F07 소관)
- [ ] **행동 강제 계열을 만들지 않았다** — 요구 캐릭터가 없어 검증 불가
- [ ] **도트(출혈) 중첩을 만들지 않았다** — F07 이후
- [ ] ⬜ 은신 릴리번시는 **F16 과 함께**임을 주석에 남겼다

## 판단 기록

- [ ] CC GE 를 애셋/네이티브 중 무엇으로 할지 `Docs/4_Argument/` 에서 정했다
- [ ] 저항 적용 방식(MMC / SetByCaller)을 `Docs/4_Argument/` 에서 정했다
- [ ] 중첩 규칙(`StackingType`)을 정하고 주석에 남겼다
- [ ] 넉백 거리 보장 방식을 정하고 **(미확인)** 을 표기했다

# ✅ F08-04 — 인벤토리 컨테이너 · 복제

> Task [`../../1_Task/F08_아이템_인벤토리/04_인벤토리_복제.md`](../../1_Task/F08_아이템_인벤토리/04_인벤토리_복제.md)

## 선행

- [ ] ⚠ 인벤토리 소유 주체를 `Docs/4_Argument/` 에서 **먼저** 정했다 (역기획서 §7.5 가 결정하지 않았다)

## 구현

- [ ] 인벤토리 컨테이너 구현
- [ ] ⭐ 인벤토리 내용은 **본인에게만** 복제 (`COND_OwnerOnly` 검토)
- [ ] ⭐ 장착 무기는 **모두에게** 복제
- [ ] 서버 권위 — 클라가 직접 추가 못 한다
- [ ] 슬롯 수 · 스택 규칙이 하드코딩이 아니다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] 아이템을 넣고 뺄 수 있다
- [ ] ⭐ **본인 클라에만** 인벤토리 내용이 보인다
- [ ] ⭐ 장착한 무기는 **다른 클라에도** 보인다
- [ ] 가득 찼을 때 규칙대로 처리된다

## ⭐ 가장 위험한 실수

- [ ] ⚠ **남의 인벤토리를 복제하지 않았다** — 정보 노출이다
- [ ] ⭐ "보이는 장비" 와 "인벤토리 내용" 의 복제 조건을 나눴다

## 판단 기록

- [ ] 인벤토리 소유 주체를 정하고 근거를 남겼다 (부활 · 드롭과의 관계 포함)

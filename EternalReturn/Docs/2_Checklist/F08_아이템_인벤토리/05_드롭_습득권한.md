## 구현

- [ ] `OnOutOfHealth` 를 구독해 드롭한다
- [ ] ⭐ 드롭 액터 스폰이 **서버**다
- [ ] ⭐⭐ **습득 경쟁을 서버가 단독 판정**한다
- [ ] ⚠ 사망 처리 자체를 하지 않는다 (F14 소관)

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] 사망 시 아이템이 월드에 드롭된다
- [ ] 드롭 액터가 **모든 클라에 보인다**
- [ ] ⭐⭐ **두 명이 동시에 주우면 한 명만** 성공한다
- [ ] ⭐ 클라가 습득을 우회해도 **서버가 거부**한다
- [ ] 주우면 월드에서 사라진다

## ⭐ 가장 위험한 실수

- [ ] ⭐⭐ **클라에서 선착순을 판정하지 않았다** — 둘 다 성공하거나 아이템이 복제된다
- [ ] ⭐ 드롭 액터 스폰이 서버다
- [ ] ⚠ 사망 처리(F14)와 드롭(F08)의 경계를 지켰다

## 판단 기록

- [ ] 부활 시 드롭한 아이템 처리를 **(미확인)** 으로 남겼다 (§7.2)

## ⭐ 서버 권위

- [x] 장착 · 해제가 서버 권위다
- [x] ⭐ 무기군 검사를 **서버가** 한다 — 클라 `Equip hammer_t1` → 서버 거부
- [x] ⭐⭐ **습득 경쟁을 서버가 단독 판정**한다 — 같은 칸 두 요청, 두 번째 거절
- [x] 드롭 액터 스폰이 서버다
- [x] 클라가 아이템을 직접 추가할 수 없다 — 클라 `Give` 거부, RPC 는 인덱스만

## 복제

- [x] ⭐ 인벤토리 **내용은 본인만** 본다 — `COND_OwnerOnly`, 클라에서 남의 가방 `0/0칸`
- [x] ⭐ 장착한 무기는 **남에게도 보인다** — `Equipped` 전원
- [x] 둘의 복제 조건을 나누어 설계했다

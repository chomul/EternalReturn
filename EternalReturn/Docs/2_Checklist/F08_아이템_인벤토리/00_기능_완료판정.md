## ⭐⭐ F02 의 전제를 지켰는지 — 가장 중요

- [ ] ⭐⭐ **장비 GE 가 `Infinite` 다** (`Instant` 아님)
  `Instant` 면 추가 공격력(`EvaluateBonus`)이 통째로 깨지고,
  증상은 *"스킬이 약하다"* 정도로만 보인다
  근거: [`../../4_Argument/5_추가공격력_산출방식.md`](../../4_Argument/5_추가공격력_산출방식.md)
- [ ] ⭐ 장비를 벗으면 **정확히 원복**된다 (수동 차감 X)
- [ ] ⭐ 장비를 낀 상태에서 **추가 공격력이 장비분만큼** 잡힌다

## ⭐ 서버 권위

- [ ] 장착 · 해제가 서버 권위다
- [ ] ⭐ 무기군 검사를 **서버가** 한다 (클라 UI 만으로 막지 않는다)
- [ ] ⭐⭐ **습득 경쟁을 서버가 단독 판정**한다
- [ ] 드롭 액터 스폰이 서버다
- [ ] 클라가 아이템을 직접 추가할 수 없다

## 복제

- [ ] ⭐ 인벤토리 **내용은 본인만** 본다
- [ ] ⭐ 장착한 무기는 **남에게도 보인다**
- [ ] 둘의 복제 조건을 나누어 설계했다

## 경계 확인

- [ ] **제작을 만들지 않았다** — F09
- [ ] **재료 획득을 만들지 않았다** — F09 / F12
- [ ] **고유 효과(격동 · 처형 · 파열)를 만들지 않았다** — F07 이후
- [ ] **사망 처리를 하지 않는다** — F14. `OnOutOfHealth` 알림만 받는다
- [ ] D 슬롯 스킬 교체를 만들지 않았다 — F11

## 흔한 실수

- [ ] 아이콘 · 메시를 **소프트 참조**로 뒀다 (수백 개 동시 로드 방지)
- [ ] 등급 열거형 순서를 나중에 바꾸지 않았다
- [ ] GE 핸들을 잃어버리지 않는다 (인벤토리가 보관)

## 선행

- [ ] [02 장착 제한](02_장착제한_무기군.md) 완료
- [ ] ⚠ [`../../4_Argument/5_추가공격력_산출방식.md`](../../4_Argument/5_추가공격력_산출방식.md) 을 읽었다

## 구현

- [ ] ⭐⭐ 장비 GE 가 **`Infinite`** 다 (`Instant` 아님)
- [ ] ⭐ 벗을 때 **`RemoveActiveGameplayEffect(Handle)`** 로 제거한다
- [ ] ⭐ **수동으로 스탯을 빼지 않는다**
- [ ] 인벤토리가 GE 핸들을 보관한다
- [ ] 장착 · 해제가 서버 권위다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 장착 시 어트리뷰트가 변하고 **클라에 복제**된다
- [ ] ⭐⭐ **벗으면 정확히 원복**된다 (오차 없이)
- [ ] ⭐⭐ 장비를 낀 상태에서 **추가 공격력이 장비분만큼** 잡힌다
- [ ] 장비 2개 중 하나만 벗으면 나머지는 유지된다
- [ ] ⭐ GE 종류가 `Infinite` 임을 실제로 확인했다

## ⭐ 가장 위험한 실수

- [ ] ⭐⭐ **`Instant` 로 만들지 않았다** — 만들면 추가 공격력이 조용히 0 이 되고
- [ ]   증상이 *"스킬이 약하다"* 정도로만 보여 원인을 못 찾는다
- [ ] ⭐ **수동 차감을 하지 않았다** — 부동소수 오차가 쌓인다
- [ ] ⚠ GE 핸들을 잃어버리지 않는다

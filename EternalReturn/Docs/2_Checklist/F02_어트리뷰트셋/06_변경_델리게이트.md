# ✅ F02-06 — 변경 델리게이트

> Task [`../../Task/F02_어트리뷰트셋/06_변경_델리게이트.md`](../../1_Task/F02_어트리뷰트셋/06_변경_델리게이트.md)

## 선행

- [ ] [05 초기값 데이터 테이블](05_초기값_데이터테이블.md) 완료

## 구현

- [ ] ⭐ **자체 멀티캐스트 델리게이트를 만들지 않았다** — ASC의 `GetGameplayAttributeValueChangeDelegate()` 를 쓴다
- [ ] 사망 알림 델리게이트를 노출했다 (F02-04에서 만든 것)
- [ ] 구독 방법을 **문서화**했다 (F17이 나중에 보고 붙인다)
- [ ] 테스트용 임시 구독으로 동작을 확인했다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 서버에서 GE로 체력을 바꾸면 **클라에서 델리게이트가 발동**한다
- [ ] 체력만 구독한 리스너가 **공격력 변화에는 안 깨어난다**
- [ ] 체력 0 시 사망 델리게이트가 발동한다
- [ ] ⭐ **`Tick` 없이 동작한다**

## ⭐ UI 비의존 확인 — 이게 이 Task의 핵심

- [ ] 위젯/UMG/HUD를 아는 코드가 **한 줄도 없다**
  ```
  grep -rniE "widget|umg|hud" Source/EternalReturn/GAS/ERAttributeSet.*   ← 안 나와야 함
  ```
- [ ] **구독은 듣는 쪽이 한다** — AttributeSet이 구독자를 등록하지 않는다
- [ ] UMG Property Binding을 쓰지 않기로 했다 (매 프레임 호출됨)

## 흔한 실수 — 걸렸는지 확인

- [ ] 구독 시점이 ASC 초기화 이후다 (클라는 `OnRep_PlayerState` 이후)
- [ ] ⭐ **구독 해제**를 한다 — 안 하면 dangling 델리게이트
- [ ] 테스트용 임시 구독 코드를 **작업 후 지웠다** (`CLAUDE.md` §3)
- [ ] 델리게이트에 "누가 때렸나" 같은 맥락을 억지로 싣지 않았다 (그건 `GameplayCue`·이펙트 컨텍스트)

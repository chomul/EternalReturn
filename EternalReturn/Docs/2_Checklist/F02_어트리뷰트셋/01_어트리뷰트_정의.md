## 구현

- [ ] `UERAttributeSet : public UAttributeSet` 생성
- [ ] `ATTRIBUTE_ACCESSORS` 매크로를 **한 번만** 정의
- [ ] ⭐ 모든 어트리뷰트가 **`FGameplayAttributeData`** 다 (`float` 아님)
- [ ] [스탯 문서 §6.1](../../0_GameDesign/Systems/스탯_데미지공식_역기획서.md) 목록의 스탯이 전부 있다
- [ ] ⭐ **문서에 없는 스탯을 상상해서 넣지 않았다**
- [ ] `IncomingDamage` Meta 어트리뷰트 선언
- [ ] Meta에 `Category="Meta"` 로 구분 표시
- [ ] `BlueprintReadOnly` 다 (`BlueprintReadWrite` 아님)
- [ ] AttributeSet이 ASC에 등록된다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증

- [ ] 에디터 GameplayEffect 애셋에서 어트리뷰트가 **드롭다운에 보인다**
- [ ] `GetHealthAttribute()` 등 접근자가 컴파일된다
- [ ] ASC에서 AttributeSet을 찾을 수 있다

## 흔한 실수 — 걸렸는지 확인

- [ ] ⭐ **`float` 로 선언하지 않았다** — 하면 Base/Current 구분이 사라진다
- [ ] ⭐ **어트리뷰트 이름을 신중히 정했다** — 나중에 바꾸면 GE 애셋이 깨진다 (`CLAUDE.md` §3)
- [ ] `ATTRIBUTE_ACCESSORS` 를 어트리뷰트마다 빠짐없이 붙였다
- [ ] Meta 어트리뷰트를 일반 어트리뷰트와 섞지 않았다
- [ ] AttributeSet을 F00-02 결정에 맞는 곳(`AERPlayerState`)에서 생성한다

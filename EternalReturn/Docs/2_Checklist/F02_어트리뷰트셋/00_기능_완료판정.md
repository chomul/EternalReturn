## 통합 검증 — `Play As Client, Number of Players: 2`

- [ ] ⭐ 서버에서 GE로 체력을 바꾸면 **클라 값이 갱신된다**
- [ ] 체력이 0 미만·MaxHealth 초과로 안 간다
- [ ] 피해 감소 150%에서 **회복이 발생하지 않는다**
- [ ] 같은 피해 GE를 두 번 실행 → **두 번 다 정확한 양**만 줄어든다
- [ ] 스폰 시 어트리뷰트가 테이블 값으로 초기화된다
- [ ] 체력 0 시 사망 델리게이트가 발동한다
- [ ] `Tick` 없이 전부 동작한다

## ⭐ GAS를 다시 만들지 않았는가

- [ ] **`UERStatComponent` 를 만들지 않았다**
  ```
  grep -rn "StatComponent" Source/    ← 안 나와야 함
  ```
- [ ] 4레이어 자체 구현을 하지 않았다 (GE가 대신한다)
- [ ] 자체 `AddModifier` / `RemoveModifier` 를 만들지 않았다
- [ ] 자체 변경 델리게이트를 만들지 않았다 (`GetGameplayAttributeValueChangeDelegate` 사용)
- [ ] 어트리뷰트를 코드에서 직접 `SetXXX()` 로 초기화하지 않았다 (GE로 한다)

## ⭐ 책임 분리 확인

- [ ] **F03(데미지 공식)을 모른다** — 계산은 ExecutionCalculation이 한다
- [ ] **UI를 모른다**
  ```
  grep -rniE "widget|umg|hud" Source/EternalReturn/GAS/ERAttributeSet.*   ← 안 나와야 함
  ```
- [ ] **사망 처리를 하지 않는다** — 알리기만 한다 (야생동물 재사용을 위해)
- [ ] 캐릭터 전용 멤버가 없다 — **F12에 그대로 붙일 수 있다**
- [ ] 클램프가 **한 곳**에만 있다 (`PreAttributeChange`)

## ⭐ GAS 특유의 실수 — 전체 점검

- [ ] `FGameplayAttributeData` 를 썼다 (`float` 아님)
- [ ] **`GAMEPLAYATTRIBUTE_REPNOTIFY` 를 모든 `OnRep_` 에서 썼다**
- [ ] `DOREPLIFETIME_CONDITION_NOTIFY` + `REPNOTIFY_Always`
- [ ] **`IncomingDamage`(Meta)를 복제하지 않았다**
- [ ] **`SetIncomingDamage(0.f)` 로 Meta를 비운다**
- [ ] `PreAttributeChange` 에 사망 처리·이펙트를 넣지 않았다

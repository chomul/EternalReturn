## 실행 기록 (2026-09-07)

### 구현

`ERAttributeSet` 에 셋을 추가했다.

| 오버라이드 | 하는 일 |
|---|---|
| `PostGameplayEffectExecute` | `IncomingDamage` → HP 감소 → 0 이면 사망 알림 |
| `PostAttributeChange` | 최대치가 **줄었을 때만** 현재값을 따라 내린다 |
| `OnOutOfHealth` 델리게이트 | 체력 0 을 **알리기만** 한다 |

### ⭐ Meta 를 반드시 비운다

```cpp
const float Damage = GetIncomingDamage();
SetIncomingDamage(0.f);      // ← 이 줄이 없으면 다음 피해에 이전 값이 남아 중복으로 들어간다
```

`IncomingDamage` 는 저장되는 값이 아니라 **한 번 쓰고 버리는 통로**다. 읽는 즉시 비운다.

### ⭐ 사망 처리를 하지 않는다

```
grep -c "Destroy|ERCharacterBase|Widget|UMG"  ERAttributeSet.cpp  →  0
```

체력 0 을 **알리기만** 하고 액터를 죽이지 않는다.
이 세트는 **야생동물·보스도 쓴다** — 여기서 캐릭터 사망 로직을 돌리면 재사용이 안 된다.

델리게이트가 마지막 가해자(`GetOriginalInstigator()`)를 실어 보낸다.
킬 로그와 경험치 분배가 그걸 쓴다. **없을 수 있다**(환경 피해) — 듣는 쪽이 null 을 감당해야 한다.

### 최대치 변경 시 현재값 — 자체 결정 2건

```cpp
if (Attribute == GetMaxHPAttribute() && NewValue < OldValue)
    if (GetHP() > NewValue) SetHP(NewValue);
```

- ⚠ **늘어날 때는 건드리지 않는다.** 최대 체력 버프가 현재 체력까지 채우면
  버프가 곧 회복기가 되어 밸런스가 달라진다
- ⚠ **비율 유지(`NewMax/OldMax` 배)도 아니다.** 단순 클램프다

둘 다 **원작 미확인**이며 자체 결정값이다. 주석에 남겼다.

`PostAttributeChange`(반응)에 뒀지 `PreAttributeChange`(클램프)에 두지 않았다 —
엔진 주석이 그 자리를 구분해 놨다.

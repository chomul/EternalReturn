## 검증

- [ ] `IncomingDamage` GE 실행 → 체력이 **정확히 그만큼** 줄어든다
- [ ] ⭐ **같은 GE를 두 번 실행 → 두 번 다 정확한 양**만 줄어든다 (Meta가 안 남는다)
- [ ] 체력이 0 미만으로 안 간다
- [ ] 하한 100을 지정하면 **100에서 멈춘다**
- [ ] 체력 0 시 델리게이트가 **서버에서** 발동
- [ ] ⭐ **지속 버프 GE에서는 `PostGameplayEffectExecute` 가 안 불린다**
  근거: `AttributeSet.h:199-200` — *"It is not called during an application of a GameplayEffect, such as a 5 second +10 movement speed buff"*

## ⭐ 가장 위험한 실수

- [ ] **`SetIncomingDamage(0.f)` 를 빠뜨리지 않았다** — 빠뜨리면 피해가 누적된다
- [ ] **여기에 클램프를 또 넣지 않았다** — F02-03이 이미 한다

## ⭐ 재사용 가능성 확인

- [ ] 사망 처리를 하지 않는다 — **알리기만** 한다
- [ ] 캐릭터 전용 로직이 없다 — **야생동물(F12)이 같은 AttributeSet을 쓸 수 있다**
  ```
  grep -rn "ERCharacterBase\|Destroy" Source/EternalReturn/GAS/ERAttributeSet.cpp   ← 안 나와야 함
  ```

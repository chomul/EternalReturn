# ✅ F02-03 — 클램프 · 상한

> Task [`../../Task/F02_어트리뷰트셋/03_클램프_상한.md`](../../1_Task/F02_어트리뷰트셋/03_클램프_상한.md)

## 선행

- [ ] [02 복제 · OnRep](02_복제_OnRep.md) 완료

## 구현

- [ ] `PreAttributeChange` 오버라이드 — Current 값 클램프
- [ ] `PreAttributeBaseChange` 오버라이드 — Base 값 클램프
- [ ] ⭐ 둘 다 **`Super::` 를 먼저 호출**
- [ ] `Health` 를 `[0, MaxHealth]` 로 클램프
- [ ] 쿨다운 감소 상한
- [ ] 피해 감소 상한
- [ ] 이동속도 하한 (음수 방지)
- [ ] ⭐ 모든 상한값에 **"원작 확인값이 아니라 자체 결정값"** 주석

## ⭐ 엔진이 지정한 자리를 지켰는가

- [ ] `PreAttributeChange` 에 **클램프만** 있다
  근거: `AttributeSet.h:210-212` — *"meant to enforce things like Health = Clamp(...) and **NOT** things like trigger this extra thing if damage is applied"*
- [ ] `PreAttributeChange` 에 **사망 처리·이펙트가 없다**
- [ ] `PreAttributeBaseChange` 에 **게임플레이 이벤트·콜백이 없다**
  근거: `AttributeSet.h:224` — *"should NOT invoke gameplay related events or callbacks"*

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증

- [ ] 체력이 **0 미만으로 안 간다**
- [ ] 체력이 **MaxHealth 초과로 안 간다**
- [ ] ⭐ **피해 감소 150%에서 회복이 발생하지 않는다** (문서 §7 6순위 기준)
- [ ] 쿨다운 감소가 상한에서 멈춘다
- [ ] MaxHealth가 줄면 Health가 따라 줄어든다

## 흔한 실수 — 걸렸는지 확인

- [ ] ⭐ **클램프를 여러 곳에서 하지 않았다** — F03 ExecutionCalculation 에서도 자르면 추적 불가
- [ ] `Super::` 호출을 빠뜨리지 않았다
- [ ] MaxHealth 감소 시 Health 조정을 **클램프가 아닌 반응**으로 처리했다 (`PostAttributeChange` 또는 F02-04)

## ⚠ 기록해야 할 것

[스탯 문서 §6.5](../../0_GameDesign/Systems/스탯_데미지공식_역기획서.md) — **원본에 상한값이 하나도 없다.**

- [ ] 넣은 값 목록과 근거(또는 "근거 없음, 임시값")를 남겼다
- [ ] 인게임 계측이 필요한 항목으로 표시했다

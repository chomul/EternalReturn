# E14 — 열거형 값 뒤에 단 `//` 주석이 **다음 값**의 툴팁이 된다

> 발견 **2026-09-17** · F08-05 · ⭐ **사용자 보고** ("Grade 에 Legend 인데 왜 영웅 등급이라고 설명이 나오지?")

## 증상

데이터 테이블에서 `Grade = Legend` 를 고르면 툴팁이 "영웅 — 제작 / 영웅 보급 상자" 로 나온다. 값 자체는 맞다(`legend_t1` 이 드롭에서 제외됨) — **설명만 한 칸 밀렸다.**

## 원인

```cpp
Hero,          // 영웅 — 제작 / 영웅 보급 상자     ← 이 주석이
Legend,        // 전설 — …                          ← Legend 의 툴팁이 된다
```

UHT 는 열거값의 툴팁을 **그 값 앞에 오는 주석**에서 가져간다. 같은 줄 뒤에 단 `//` 는 "다음 토큰 앞의 주석" 으로 읽힌다.
`UPROPERTY` 는 같은 줄 뒤 주석도 자기 것으로 삼지만, 열거값은 아니다 — 둘의 규칙이 다르다.

## 수정

내가 만든 열거형 전부(`Item/ERItemTypes.h` 3개 · `GAS/ERSkillData.h` 3개)를 **앞줄 `/** … */`** 로 바꿨다.
무기 23종은 한 줄에 여러 값을 쓰던 것을 값마다 한 줄 + 한글 이름 툴팁으로 (`/** 망치 */ Hammer,`) — 디자이너가 드롭다운에서 한글로 본다.

## ⚠ 재발 방지

- 열거값 설명은 **앞줄 `/** */`**. 같은 줄 뒤 `//` 는 쓰지 않는다
- 한 줄에 값 여러 개 + 그룹 주석(`// 근접 13`)도 첫 값의 툴팁이 되니 쓰지 않는다

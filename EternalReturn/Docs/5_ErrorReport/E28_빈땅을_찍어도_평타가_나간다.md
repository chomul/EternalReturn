# E28 — 적 · 야생동물이 없는 빈 땅을 찍어도 평타가 나간다

> 발견: 2026-09-28 F12.5-03 PIE (사용자) · 관련 `GAS/ERGameplayAbility` · F07-07 평타 · F04 SingleTarget

## 증상

빈 곳에 평타 → 휘두르는 모션 · 쿨다운(공속 간격)이 나간다. 로그: `DA_BasicAttack 판정 SingleTarget: 적중 0` 반복.

## 원인

대상 지정형(SingleTarget) 스킬도 **발동부터 하고 판정 단계에서야** 대상이 없음을 알았다.
- 입력(`ERPlayerController::OnSkillSlotPressed`)은 커서 아래 지점을 조준으로 실어 **무조건** 발동 요청
- 파이프라인: 발동 → 모션(F12.5-01) → 커밋(쿨다운) → `ExecuteSkill` 에서 `ERTargeting::Query` → **적중 0**
- F12.5 전에는 모션이 없어 "적중 0" 로그만 남고 눈에 안 띄었다

## 고침 (Editor · Server 빌드 에러 0)

- `UERGameplayAbility::MakeTargetQuery` — 판정 질의(디자이너 필드 + 조준 + 조준 보조)를 한 곳으로 뺐다. 판정과 발동 전 확인이 **같은 질의**를 쓴다
- `ActivateAbility` — SingleTarget 이면 모션 · 커밋 **전에** 질의 → 비었으면 `보류 — 대상 없음 · 사거리 밖` 로그 · **없던 일** (쿨다운 · 모션 없음) — 조각 CanExecute 보류와 같은 방식
- ⏸ 사거리 밖 대상에게 다가가서 치기 (원작 우클릭 · A 공격 명령) — F17
- ⏸ 클라 입력 단계는 그대로 — 빈 땅 평타 키에도 이동 정지(`StopMovement`)는 일어난다. 거슬리면 클라 선판정에 같은 질의를 넣는다

## 검증

```
빈 땅 평타          → "[스킬] … DA_BasicAttack 보류 — 대상 없음 · 사거리 밖" · 모션 · 쿨다운 없음
사거리 안 적 평타    → 기존과 같다 (재생 · 적중)
사거리 밖 적 평타    → 보류 (다가가기는 F17)
야생동물 AI 평타     → 기존과 같다 (AI 는 사거리 안에서만 친다)
```

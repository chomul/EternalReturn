# E25 — 스킨 메시에 기본 리그 애니를 걸면 캐릭터가 뒤집힌다 (위아래 · 앞뒤)

> 발견: 2026-09-27 F12.5-01 PIE (`ER.Skin.Set`) · 관련 Argument 39 R1 · `Presentation/ERPresentationComponent`

## 증상

`ER.Skin.Set 1~3` 으로 재키 스킨을 바꾸면 캐릭터가 **정반대 방향 · 위아래까지 뒤집혀** 보인다. 기본 스킨(S000)은 정상.
에디터 BP 뷰포트에 같은 스킨 메시를 넣으면 멀쩡하다 (사용자 보고).

로그상으로는 **재생 성공**이었다 — `재생 실패` 경고 없음, 스킨 교체 뒤 `Jackie_Axe_atk02 재생` (2026-09-27 09:44:00). 그래서 1차 판정에서 "R1 ✅" 로 잘못 적었다 → 정정.

## 원인 — 본 축이 다른 리그 (사용자 확인)

- 기본 메시 스켈레톤은 `Character_UE_Skeleton` / 재키 `Character_Source_Skeleton`, 스킨 메시는 각자 `Mesh_Skeleton` (파일 목록).
- **확인**: `Jackie_S001/Mesh/Mesh` 에디터에서 Preview Animation = `Jackie_Axe_wait` → **뒤집힌다** (사용자 2026-09-27). 기본 포즈(애니 없음)는 정상.
- 애님 시퀀스는 본의 **로컬 회전 절대값**을 담는다. 스킨 리그의 본 축이 기본 리그와 다르면 호환 스켈레톤으로 **재생은 되지만** 결과가 돌아간다.
- 에디터에서 멀쩡해 보인 건 **애니 없이 기본 포즈**만 봤기 때문이다. 명령어는 메시만 바꾸고 `ABP_Jackie`(기본 리그 애니)를 그대로 남긴다 — 스킨 DA 의 AnimClass 가 비어 있다.

## 고침

**코드 문제가 아니다 — 애셋.** 사용자가 스킨 메시를 기본 리그와 같은 축으로 다시 만들어 온다 (2026-09-27 "내가 따로 수정해올께").
- 목표: 스킨 메시가 기본 스켈레톤(또는 본 축이 같은 스켈레톤)을 쓰게 → 애니 · AnimBP 한 벌을 전 스킨이 공유 (Argument 39 S2 전제 유지)
- 대안(안 씀): 스킨마다 IK Retargeter 런타임 리타깃 — 29개 스킨 × 비용

## 교훈

- **"재생 성공" 은 "맞게 보인다" 가 아니다.** Montage_Play 성공은 스켈레톤 호환만 뜻한다. 스킨 · 변이 검증은 **눈으로** (또는 Preview Animation 으로) 한다.
- 메시 호환 확인은 기본 포즈가 아니라 **애니를 걸어서** 본다 (memory: verify-in-blender-before-ue 와 같은 결).

# E20 — 고정 피해 채널(`Damage.Type.True`)이 체력 비례 계수를 버린다 (단검 D 8% 가 0)

> 발견 **2026-09-20** · F11-05 C 검증 로그 (단검 블링크 재테스트 — 기본 피해 스펙은 숙련도 +8.4 가 찍히는데 고정 피해 스펙은 아무 흔적이 없다)

## 증상

```
15:50:25.996 [숙련도] Dagger +8.4 (실험체 피해)           ← 기본 스펙 (10 + 추가AP 20×0.5 → 방어 뒤 13.3) ✓
15:50:25.996 [스킬] … 피해 1명 (기본 10 · 스킬)
15:50:25.996 [스킬] … 고정 피해 현재체력 8%               ← 스펙은 적용했는데
(기대: [숙련도] Dagger +50 근처 — 현재 체력 ~987 × 8% ≈ 79)  ← 없음. HP 도 안 깎였다 (피해 0 → OnDamageTaken 안 옴)
```

## 원인

`UERDamageExecution` 고정 피해 분기가 `Damage = Base * ModeMul` 이다. 계산식 §2.2 의 "2 단계(고정 피해 → 즉시 종료)가 3·3-b(계수 · 체력 비례)보다 앞" 을 그대로 옮긴 것.
코드 주석 자체가 **(미확인)** 으로 "3-b 도 안 탄다" 고 적어 두고 있었다. 단검 D 는 `Data_Damage_CurHPRatio` 만 싣고 Base 0 이라 0 이 됐다.

원작의 고정 피해는 대부분 체력 비례다 (단검 D 현재 체력 8% · 재키 Q 등) — 이대로면 그 스킬을 만들 수 없다.

## 수정

`Damage = (Base + Proportional) * ModeMul` — 체력 비례는 탄다. 방어력 · 피해 감소 · 증폭 · 치명타는 여전히 안 탄다. 보스 감쇠는 `Proportional` 계산에서 이미 곱해져 있으므로 그대로 적용된다.
공격력 계수(APRatio 류)는 여전히 안 탄다 — 필요해지면 그때 (자체 결정).

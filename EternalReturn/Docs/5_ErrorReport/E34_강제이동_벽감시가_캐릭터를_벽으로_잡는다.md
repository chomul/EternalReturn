## 원인

- 벽 감시(`CheckWallImpact`)가 **채널** `ECC_WorldStatic` 으로 스윕했다 (`ERForcedMove.cpp:305` 옛 코드)
- 채널 스윕은 "그 채널을 Block 하는 것" 을 다 잡는다 — **캐릭터 캡슐(Pawn 프로필)도 WorldStatic 채널을 Block** 한다
- 그래서 붙어서 같은 방향으로 가는 멧돼지와 맞은 사람이 **서로를 벽으로** 잡고 → `Multicast_StopForcedMove` → 둘 다 루트모션 제거
- 벽 충돌 로그가 Verbose 라 안 보였다
- 원래 있던 결함 — 방망이 D 넉백도 뒤에 캐릭터가 있으면 멈췄을 것 (F11 테스트는 벽 · 빈 곳이었다)

## 해결

- **오브젝트 종류**(`WorldStatic` · `WorldDynamic`)로 스윕 (`SweepSingleByObjectType`) — 캐릭터(Pawn)는 벽이 아니다
- 벽 충돌 로그를 Log 로 · 맞은 컴포넌트 이름까지
- 빌드 에러 0 (Editor · Server · 2026-09-30)

## 재발 방지

- "무엇에 막혔나" 를 찾는 쿼리는 **채널이 아니라 오브젝트 종류**로 — 채널 응답은 프로필마다 달라 뜻밖의 것이 걸린다
- 판정 · 감시가 이동을 끊는 곳은 로그를 Log 레벨로 둔다

# E33 — 판정 중 자기에게 건 기절이 "선딜 취소 (CC)" 로 잡혀 벌칙이 두 번 걸린다

> 발견: 2026-09-30 F12.6-03 PIE (곰 임시 스킬 `DA_Skill_Wild_Test` + 실패 벌칙 조각) · 관련 `GAS/ERGameplayAbility.cpp` BeginCast(WaitCC) · OnCastFinished · `GAS/Fragment/ERSkillFragment_FailPenalty.cpp` · `Wildlife/ERWildlifeAIController.cpp` TryAttack

```
DA_Skill_Wild_Test 판정 SelfRadius: 적중 0
DA_Skill_Wild_Test 선딜 취소 (CC, 서버 · 쿨다운 커밋)        ← 선딜은 이미 끝났다
```

- 같은 선딜 1초 사이에 곰 평타(`DA_Attack_Wild 피해 1명`)도 나갔다

## 원인

1. **선딜 CC 감시가 선딜 뒤에도 살아 있었다.** `WaitGameplayTagAdd(State.Block.Skill)` 태스크를 선딜 시작에 만들고 선딜이 끝나도 멈추지 않았다.
   - 빗나감 벌칙이 판정 도중 자기에게 `GE_Frustrated`(기절 · `State.Block.Skill`)를 걸자 → 감시가 발동 → `CancelCast("CC")` → 쿨다운을 **다시** 커밋하고 → EndAbility → 벌칙 조각이 "시전 중 CC" 로 한 번 더
   - 로그 순서가 "취소 → 시전 중 CC → 빗나감" 인 이유: 빗나감 `Apply` 가 GE 를 거는 **도중**에 동기로 취소가 돌고, 빗나감 로그는 GE 적용이 끝난 뒤 찍힌다
   - 조각과 무관하게 **원래 있던 결함**이다 — 실험체도 후딜 중 CC 를 맞으면 "선딜 취소" 로 쿨다운이 새로 걸렸다 (`CommitAbilityCooldown(Force)`)
2. **AI 가 스킬 시전 중에 평타를 쳤다.** `TryAttack` 은 평타 스펙만 활성 검사 · 평타는 `State.Casting` 에 막히지 않는다

## 해결

- `OnCastFinished` 에서 선딜 감시 태스크를 **멈춘다** (`CastCCTask->EndTask`)
- 후딜 중 CC 는 따로 감시 — `OnRecoveryInterruptedByCC`: **모션만 끊고**(EndAbility 취소) 쿨다운은 다시 안 건다 · 벌칙 표시 없음
- AI `TryAttack`: 평타 외 어빌리티가 활성이면 평타를 시작하지 않는다
- 빌드 에러 0 (Editor · Server · 2026-09-30)

## 재발 방지

- 단계(선딜 · 판정 · 후딜)마다 거는 감시 태스크는 **그 단계 끝에서 멈춘다** — 이어지면 다음 단계의 사건을 앞 단계로 오해한다
- 조각이 자기에게 CC 를 거는 스킬(좌절)은 이 경로를 다시 밟는다 — 04 멧돼지 테스트에서 `실패 벌칙` 줄이 실행당 한 번인지 본다

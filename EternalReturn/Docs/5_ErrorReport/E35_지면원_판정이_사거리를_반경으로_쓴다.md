> 발견: 2026-09-30 F12.6-05 PIE (오메가 VF 방출 · 사용자 "시전 시 위치를 받아 그 자리에서 띄운다 — 캐스팅 중에 피할 수 있어야 함") · 관련 `Combat/ERTargeting.cpp` QueryGroundCircle · `GAS/ERGameplayAbility.cpp` 디버그 그리기 (:47)

## 증상 (로그 2026-09-30 16:34:33 · `DA_Skill_Boss_VFPulse` RangeMax 8 · RadiusOuter 2.5)

- 판정 `GroundCircle: 적중 2` — 조준점 (870, 1810) 에 있던 Katja_C_1 과 **5.5m 떨어진** Katja_C_0 (1188, 1360) 둘 다 맞음
- 반경 2.5m 면 C_0 은 안 맞아야 한다 → 선딜 동안 피해도 맞는다

## 원인

- `QueryGroundCircle` 이 `QuerySelfRadius(World, Q)` 를 그대로 불렀다 → 반경 = **`Q.RangeMax`** (시전 사거리 8m)
- 데이터 정의는 "GroundCircle 반경 = `RadiusOuter`" (`ERSkillData.h:195`) · 디버그 그리기도 `RadiusOuter` (`ERGameplayAbility.cpp:47`) — **보이는 원(2.5m)과 판정 원(8m)이 달랐다**
- 조준점 고정은 맞았다 — `ResolveAim` 이 발동 때 한 번 정하고 선딜 동안 바뀌지 않는다
- F04 부터 있던 결함 (지금까지 GroundCircle 스킬은 RangeMax 와 반경을 같게 두었거나 RadiusOuter 를 안 넣어 드러나지 않았다)

## 해결

- `QueryGroundCircle`: `RadiusOuter > 0` 이면 반경 = `RadiusOuter` · RangeMin 0. 0 이면 옛 동작(RangeMax) — 기존 애셋 호환
- 빌드 에러 0 (Editor · Server · 2026-09-30)

## 재발 방지

- 한 칸이 두 뜻(사거리 · 반경)을 갖지 않게 — 판정 함수와 디버그 그리기가 **같은 칸**을 읽는지 확인
- ⚠ 다른 GroundCircle 스킬 DA 에 `RadiusOuter` 가 들어 있으면 이제 그 값으로 판정 원이 줄어든다 (의도대로) — F19 에서 GroundCircle 스킬 만들 때 확인

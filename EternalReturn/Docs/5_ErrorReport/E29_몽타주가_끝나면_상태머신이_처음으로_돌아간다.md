# E29 — 몽타주(사격)가 끝나면 상태머신이 처음으로 돌아간다 (저격 모드 Loop → Start)

> 발견: 2026-09-28 F12.5-03 PIE (사용자 "쐈을 때 Loop 로 돌아가야 하는데 Start 로 돌아간다") · 관련 `ABP_ERCharacter_Base` (Argument 42 ④ MB)

## 증상

저격 모드 중 사격 → Shot 몽타주가 끝나면 조준 유지(ModeLoop)가 아니라 **진입 모션(ModeStart)** 이 다시 나온다.

## 원인 — 엔진 기본값 둘이 겹친다

로그: 사격 중 모드 태그가 꺼진 적 없다 (`모드 Mode.Sniper → 없음` 은 해제 때만) → C++ `bInMode` 는 계속 true. AnimBP 쪽이다.

1. **Slot 노드는 몽타주가 전신을 덮는 동안 소스(상태머신)를 업데이트하지 않는다** — `bAlwaysUpdateSourcePose` 기본 false (`Engine/Source/Runtime/AnimGraphRuntime/Public/AnimNodes/AnimNode_Slot.h:27-29` *"Whether we should continue to update the source pose regardless of whether it would be used"*)
2. **상태머신은 틱이 끊겼다가 다시 쓰이면 초기화된다** — `bReinitializeOnBecomingRelevant` 기본 true (`Engine/Source/Runtime/Engine/Classes/Animation/AnimNode_StateMachine.h:148-151 · 230`)

→ 사격 몽타주 동안 상태머신 정지 → 끝나는 순간 초기화 → Entry → Idle → (bInMode) → **ModeStart**

## 고침 (에디터 · 코드 변경 없음)

`ABP_ERCharacter_Base` › Slot 'DefaultSlot' › **Always Update Source Pose ✓** — 몽타주 중에도 상태머신이 돈다. 템플릿이라 전원 적용 (평타 뒤 대기/달리기 상태 튐도 같이 막는다)
- 대안: 상태머신 노드 › Reinitialize On Becoming Relevant 끄기 — 상태가 멈춰 있다가 이어지는 것이라 덜 자연스럽다

## 결과 (2026-09-29)

✅ 사용자가 Slot 옵션을 켜고 확인 ("잘 나온다"). 로그 00:16 — 진입 → 사격 3발 → 해제(소진) · 모드 태그 서버/클라 짝 맞음.

## 교훈

**몽타주를 전신 Slot 에 올리는 구조에서는 Slot 의 Always Update Source Pose 를 켠다** — 아래 상태머신이 "지속 상태"(모드 · 기절 · 사망)를 들고 있으면 특히 (Argument 36 원칙 2).

```
평타 중 이동 멈춤 → 평타 끝나고 대기 · 달리기가 자연스럽게 이어짐
```

## 원인

- 피해가 들어가면 `ERAttributeSet` 이 가해자 ASC 에 `Event.Hit.Dealt` 를 보낸다 (부가 피해 `Damage.Secondary` 만 제외)
- 패시브 어빌리티(`UERPassiveAbility::OnHitDealt`)는 이 이벤트를 **어느 스킬의 피해인지 보지 않고** 조각(출혈 `DoT` · `HitProc` · `SelfStacks` · `CooldownOnHit`)에 넘긴다
- 전술 스킬 피해도 같은 `Damage.Type.Skill / True` 라 구분할 표시가 없었다

## 해결

- 태그 `Damage.Source.Tactical` — 피해 조각이 **어빌리티 슬롯이 `Ability.Slot.F`** 이면 피해 스펙에 붙인다 (스트라이더 추가 피해 데이터 `Strider_Hit` 은 슬롯이 없지만 돌리는 어빌리티가 F 라 같이 붙는다)
- `UERPassiveAbility::OnHitDealt` 가 이 태그면 조각을 안 돌리고 `[패시브] … 전술 스킬 피해라 무시` 로그
- 빌드 Editor · Server 에러 0 · 경고 0 (2026-10-13)

## 그대로 둔 것

- 처치(`OnKillDealt`) — 전술 스킬로 막타를 쳐도 처치 패시브는 돈다 (사용자 기준은 "적용" — 처치는 따로 묻지 않았다)
- 표식(`State.Mark.*` — 레니 곰돌이 · 다니엘 W 자리)과 버프 중 적중(라이트 윙 · 스트라이더)은 패시브가 아니라 그대로 반응한다
- 숙련도 · 경험치는 그대로 오른다

## 재발 방지

- 새 피해 경로를 만들면 피해 조각을 거치게 한다 — 표시는 피해 조각 한 곳에서만 붙는다

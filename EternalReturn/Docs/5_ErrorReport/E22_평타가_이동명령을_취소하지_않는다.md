# E22 — 평타 · 스킬이 이동 명령을 취소하지 않아, 시전 뒤 가던 방향으로 걸어간다

> 발견: 사용자 2026-09-23 (F12-01 히트박스 검증 중) — *"평타 하는데 이것도 저번처럼 이동하던 게 남아있으면 평타하다가 갑자기 또 이동하던 방향으로 가버리는 문제가 있음"*
> 같은 부류의 선례: 저격 D 모드가 이동 중 시전하면 멈추지 않던 문제 (F11-05 · `_Mode.bStopMovementOnEnter`)

## 증상

우클릭으로 이동 중(또는 이동 명령이 끝나기 전)에 평타를 치면, 공격은 나가지만 **원래 가던 목적지로 계속 걸어간다.** 공격 사이사이에 캐릭터가 앞으로 미끄러진다. 스킬도 같다.

## 원인

이동은 **클라이언트가 몬다** — `SimpleMoveToLocation` 이 `UPathFollowingComponent` 에 경로를 넣고, 그 경로는 **도착하거나 `StopMovement()` 를 부를 때까지 살아 있다** (E07).
평타 입력 경로(`AERPlayerController::OnSkillSlotPressed` → `ServerActivateSkill`)는 그 경로를 건드리지 않았다. 어빌리티가 서버에서 실행되는 동안에도 클라의 PathFollowing 은 그대로 목적지로 캐릭터를 밀고 간다.

저격 D 는 `_Mode` 조각이 진입에서 `PC->StopMovement()` 를 불러 이미 해결돼 있었다 (`ERSkillFragment_Mode.cpp:198`). 평타에는 그 경로가 없었다.

## 고침 (2026-09-23)

`Core/ERPlayerController.cpp` — 클라 선판정을 통과한 뒤 로컬에서 이동을 멈춘다 (평타 · 스킬 모든 슬롯).

```cpp
StopMovement();   // 이동은 클라가 몬다 (E07) → 소유 클라에서 멈춘다
```

- **평타 · 스킬 전부** 같은 규칙이다 (사용자 2026-09-23 "평타 이외의 다른 스킬들도 다 동일하게")
- 선판정을 통과했을 때만 멈춘다 — 쿨다운 중 연타로는 걸음이 끊기지 않는다
- 돌진 · 도약(`_SelfMove`)은 `ERForcedMove` 가 따로 미는 것이라 여기서 멈춰도 영향이 없다
- 저격 모드 중 재입력은 `ResolveModeSlot` 이 평타 슬롯으로 바꾸므로 같은 규칙을 탄다 (모드 진입에서도 이미 멈춘다 — 중복 호출은 무해)

## 원작 기준

평타는 제자리에서 친다 = **공격 명령이 이동 명령을 대체한다** (사용자 확인 2026-09-23). 스킬도 같다 — 시전이 끝나고 이전 목적지로 저절로 다시 걷지 않는다.
⚠ 사거리 **밖** 대상을 평타로 지정했을 때 **대상에게 다가가는** 동작은 아직 없다 (지금은 빗나감 처리). 별도 작업으로 남긴다.

## 검증

```
우클릭으로 이동 시작 → 도착 전에 늑대를 평타
  → [평타] … 간격 1.00초 · [스킬] … 적중 1
  → 공격 후 **제자리** (원래 목적지로 다시 걷지 않는다)
쿨다운 중(간격 1초 안) 연타 → 걷던 이동은 그대로 (선판정 실패라 StopMovement 안 함)
이동 중 Q · W · E · R · D → 시전하며 멈추고, 끝나도 제자리 (돌진 스킬은 정상적으로 돌진)
```

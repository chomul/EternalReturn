# 에러 기록

**코드 개발 중 발생한 문제**를 여기에 쌓는다. 원인을 찾은 것만 적는다 — 추측은 적지 않는다.

## 기록 대상

| 적는다 | 적지 않는다 |
|---|---|
| 빌드 에러 | git 조작 (커밋·머지·revert·충돌) |
| 조용히 안 먹는 설정 | 단순 오타, 즉시 알아챈 실수 |
| 설계 오류 | 원인을 못 찾은 것 |
| 사용자가 지적한 문제 | 에디터 사용법 질문 |
| ⭐ **레퍼런스 대조로 찾은 결함** | |

## 왜 남기나

같은 실수를 두 번 하지 않기 위해서다. 특히 **엔진이 조용히 삼키는 종류**의 문제는
기록이 없으면 몇 달 뒤에 똑같이 하루를 쓴다.

- 고친 뒤 **어떻게 재발을 막는지** 적는다. 못 막으면 "못 막는다"고 적는다

# E24 — 피해 알림 안에서 AI 가 귀환 · 회복해서, 체력 0 이 된 야생동물이 죽지 않는다

> 발견: 2026-09-24 F12-06 검증 로그 (곰 레벨 드랍 테스트) · 관련 F12-04 `AERWildlifeAIController`

## 증상

`ER.Wild.HP 1` 로 체력 1 인 곰을 평타로 때렸는데 **죽지 않았다.** 루트 로그도 없다.

```
07:16:19  ER.Wild.HP 1
07:16:23  [야생AI] BP_ERWildlife_C_9 대기 → 전투 (피격) · 어그로 팀 0
          [야생AI] BP_ERWildlife_C_9 귀환 → 대기 (귀환 즉시 완료)     ← 같은 프레임
          (사망 · [루트] 없음)
```

직전(07:15:28)에 플레이어가 위클라인에게 죽어서 어그로 팀에 생존자가 없었다 — 사망 처리(F14)가 없어 죽은 플레이어가 계속 공격할 수 있는 상태.

## 원인 — 알림 순서

`UERAttributeSet::PostGameplayEffectExecute` 의 순서:

```
SetHP(HP − Damage)            // 1 → 0
OnDamageTaken.Broadcast(...)  // ← AI 가 여기서 깨어난다
if (HP <= 0) OnOutOfHealth    // ← 사망 판정은 알림 **뒤**
```

`OnDamageTaken` → `AERWildlifeAIController::NotifyDamaged` → `EnterCombat` → **`Think()` 를 즉시** 호출 →
어그로 팀 생존자 없음 → `SetState(Return)` → **`Heal()` 이 체력을 가득 채움** → 알림이 끝나고 사망 판정에서 HP > 0 → **안 죽는다.**
(코드 주석대로 "듣는 쪽이 회복시켰을 수 있다" 를 AttributeSet 이 허용하므로, 알림 안에서의 회복은 사망을 취소한다.)

평상시(대상 팀이 살아 있음)에는 즉시 귀환하지 않아서 드러나지 않았다. **자리에서 10m 밖에서 맞은 개체**도 같은 경로로 부활할 수 있었다.

## 고침 (2026-09-24 · 빌드 에러 0)

`Wildlife/ERWildlifeAIController.cpp` 세 곳:

1. `NotifyDamaged` — 자기 체력이 **0 이하면 아무것도 안 한다** (치명타 — 곧 사망 판정이 온다)
2. `EnterCombat` — 첫 판단을 `SetTimerForNextTick` 으로 **다음 틱**에 (피해 알림 안에서 상태를 바꾸지 않는다)
3. `Heal` — 체력 0 이하는 회복하지 않는다 (`bDead` 는 사망 판정 뒤에 서므로 그것만으로는 못 막는다)

## 교훈

**`OnDamageTaken` 구독자는 체력을 바꾸면 안 된다** — 사망 판정보다 먼저 불린다. 반응이 필요하면 다음 틱으로 미룬다.

## 검증

```
(플레이어가 죽은 상태 또는 곰을 10m 밖으로 끌어낸 상태에서)
ER.Wild.Spawn Bear → ER.Wild.HP 1 → 평타   → [야생동물] … 사망 · [루트] … (죽는다)
평상시 곰 평타                              → 대기 → 전투 (다음 틱) · 추적 · 귀환은 예전과 같다
```

- W 가 한 번 돌고 멈춘다. 4초 뒤 장판이 끝날 때 `모션 유지 끝 … End` 줄이 **없다** → 그때 몽타주가 이미 멈춰 있었다
- `모션 끊음 …skill02` 줄도 없다 → `StopActionAnim` 은 끊지 않았다

## 원인

- 이동하면 동작 몽타주를 끊는 길이 **둘**이다
  1. `UERPresentationComponent::StopActionAnim` — 이동 명령이 수락될 때(소유 클라 · 서버). 로그 있음
  2. `UERAnimInstance::NativeUpdateAnimation` — 속도가 생기면 **모든 머신**이 자기 화면에서 `Montage_Stop` (Argument 48 M1). **로그 없음**
- M1 구현 때 ①에만 `State.AnimHold` 예외를 넣었다. ②가 W 몽타주를 조용히 끊었다

## 해결

- ②에도 같은 예외를 넣었다. 끊기 직전에만 ASC 의 `State.AnimHold` 를 본다(복제 loose 태그라 모든 머신에 있다)
- 진단 로그를 넣었다: 태그가 붙을 때 `모션 유지 시작 — 몽타주 … · Loop 다음 = … · End …`, 빠질 때 이미 끝났으면 `몽타주가 이미 끝나 있다`
- 빌드 에러 0 (Editor · Server · 2026-10-04)

## 재발 방지

- 모션 끊기 규칙을 바꿀 때는 **두 곳**을 같이 본다 (`StopActionAnim` · `ERAnimInstance` 이동 끊기). 한쪽만 고치면 로그 없는 쪽이 끊는다

## 6인이 요구하는 실제 케이스

- [ ] 다니엘 Q 65° — 정면은 맞고 옆 90°는 안 맞는다
- [ ] ⭐ 레니 W — 중앙/외곽이 갈리고 **중복 포함이 없다**
- [ ] ⭐ 레니 Q·W·E — **하나의 판정으로 적/아군이 갈린다**
- [ ] 시셀라 Q — `RangeMin` 1.0m 안쪽 대상이 제외된다
- [ ] 카티야 R — 결과가 **가까운 순 정렬** (3발 순차용)

## ⭐ 상향식 원칙 확인

- [ ] 전부 **정적 함수**다 — 컴포넌트가 아니고 상태를 갖지 않는다
- [ ] **피해를 주지 않는다** — 히트 배열만 반환
- [ ] **액터를 스폰하지 않는다** (투사체 액터는 F07 소관)
- [ ] 헤더에 F01/F02/F03 의존이 없다
  ```
  grep -n "#include" Source/EternalReturn/Combat/ERTargeting.h    ← 게임플레이 헤더가 없어야 함
  ```
- [ ] `ERTeamStatics` 는 `.cpp` 에서만 include 한다
- [ ] 특정 캐릭터 전용 분기가 없다

## 공통 규칙 — 한 곳에서만 처리되는가

- [ ] ⭐ **m ↔ uu 변환이 한 곳**에 있다
- [ ] 결과 정렬(가까운 순)이 공통 경로에 있다
- [ ] `IgnoredActors` / 시전자 제외가 공통 경로에 있다

## 흔한 실수 — 전체 점검

- [ ] `TArray<AActor*>` 에 `UPROPERTY()` 를 붙였다 (GC dangling 방지)
- [ ] `Cast<>` 결과를 전부 검사했다 (오버랩에 스태틱 메시가 섞여 온다)
- [ ] `World` 가 `nullptr` 일 때 조기 반환한다
- [ ] 영벡터 정규화로 0으로 나누지 않는다
- [ ] ⭐ **팀 없는 액터(야생동물)가 `Enemy` 필터에 포함된다** — 안 그러면 곰을 못 때린다
- [ ] 콜리전 채널을 추가했다면 `Config/DefaultEngine.ini` 변경을 **보고**했다

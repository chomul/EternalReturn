## 검증

- [ ] 위치 지정 원형 — **지정 좌표 기준**으로 판정된다
- [ ] ⭐ 부채꼴 65° — 정면 대상은 맞고 **옆 90° 대상은 안 맞는다**
- [ ] 경계(정확히 32.5°) 처리가 일관적이다
- [ ] `RangeMin` 안쪽 대상 제외
- [ ] 각도 360° → 원형과 같은 결과
- [ ] `Origin == 대상 위치` 여도 크래시하지 않는다

## ⭐ 사거리 핵 방지 — 이 Task에서 확인할 것

- [ ] 이 함수가 **좌표를 검증하지 않는다**는 것과, **서버 RPC 수신부(F07)가 클램프해야 한다**는 것을 주석에 남겼다
- [ ] F07 착수 시 확인할 항목으로 기록했다

## 흔한 실수 — 걸렸는지 확인

- [ ] 위치 지정을 시전자 기준으로 계산하지 않았다
- [ ] 각도를 반각으로 잘못 해석하지 않았다 (65°가 ±65°가 되면 2배 넓다)
- [ ] 측정도 없이 `acos` → `dot` 최적화를 하지 않았다 (`CLAUDE.md` §2)

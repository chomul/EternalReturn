## 구현 — 거리 보간

- [ ] `GetDistanceAlpha(Distance, RangeMin, RangeMax)` 구현
- [ ] ⭐ **알파만 반환한다** — 보간은 호출자가 한다 (카티야 Q는 두 값을 각각 보간)
- [ ] `RangeMin == RangeMax` 일 때 0으로 나누지 않는다
- [ ] 결과가 0~1로 클램프된다
- [ ] 적중 "시점" 계산은 **F07의 책임**임을 주석에 명시

## 구현 — 팀 필터

- [ ] `Enemy` / `Ally` / `All` 필터 적용
- [ ] ⭐ `ERTeamStatics` 를 **`.cpp` 에서만** include (헤더 의존 없음)
- [ ] ⭐ **필터 로직을 `IsSameTeam` 부정으로 짜지 않았다** — 명시적으로 작성

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — 거리 보간

- [ ] 하한에서 **0.0**
- [ ] 상한에서 **1.0**
- [ ] 중간에서 0.5
- [ ] 하한 == 상한이어도 크래시하지 않는다
- [ ] 범위 밖 값이 0~1로 클램프된다

## 검증 — 팀 필터 (`Play As Client, Number of Players: 4`, `TeamSize = 2`)

- [ ] `Enemy` — 아군이 결과에 없다
- [ ] `Ally` — 적이 결과에 없다
- [ ] `All` — 둘 다 있다
- [ ] ⭐ **팀 없는 액터(야생동물)가 `Ally` 에 안 잡힌다**
- [ ] ⭐ **팀 없는 액터가 `Enemy` 에는 잡힌다** — 안 그러면 곰을 못 때린다
- [ ] ⭐ 레니 W — 이중 반경 + 팀 필터로 **중앙/외곽 × 아군/적 4분류**가 가능하다

## ⭐ 가장 위험한 실수

- [ ] **`Enemy` 필터를 `!IsSameTeam` 으로 짜지 않았다**
  `IsSameTeam` 은 무소속이면 `false` 를 반환한다(F01-04). 부정으로 짜면 우연히 맞지만,
  `Ally` 를 같은 방식으로 짜면 무소속이 아군이 된다. **명시적으로 쓴다.**
- [ ] 야생동물을 때릴 수 있는지 **실제로 확인**했다

## 흔한 실수 — 걸렸는지 확인

- [ ] 보간을 함수 안에서 하지 않았다 (알파만 반환)
- [ ] 헤더에 `ERTeamStatics` include 가 없다
  ```
  grep -n "ERTeamStatics" Source/EternalReturn/Combat/ERTargeting.h    ← 안 나와야 함
  ```

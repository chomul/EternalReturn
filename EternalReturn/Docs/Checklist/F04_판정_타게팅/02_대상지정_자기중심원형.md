# ✅ F04-02 — 대상 지정 · 자기중심 원형

> Task [`../../Task/F04_판정_타게팅/02_대상지정_자기중심원형.md`](../../Task/F04_판정_타게팅/02_대상지정_자기중심원형.md)
> ⚠ **여기서 정한 공통 규칙이 나머지 판정 전부의 기준이 된다**

## 선행

- [ ] [01 타입 정의 · 구조체](01_타입정의_구조체.md) 완료

## 구현

- [ ] `QuerySingleTarget()` 정적 함수
- [ ] `QuerySelfRadius()` 정적 함수
- [ ] ⭐ **m → uu 변환을 함수 진입부 한 곳**에서 처리
- [ ] ⭐ 결과를 **가까운 순으로 정렬**
- [ ] `IgnoredActors` 제외 처리
- [ ] 시전자 본인 처리 규칙을 정했다
- [ ] `World == nullptr` 조기 반환
- [ ] `Cast<>` 결과를 전부 검사

## 공통 규칙 확정 — 이 Task에서 정하고 주석에 남긴다

- [ ] **판정 기준점**을 정했다 (캡슐 중심 / 발밑 / 바운딩) — 자체 결정값 표기
- [ ] **오버랩 질의 방식**을 정했다
- [ ] **사용할 콜리전 채널**을 정했다
- [ ] 채널을 새로 만들었다면 `Config/DefaultEngine.ini` 변경을 **보고**했다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — 테스트 액터 하나로

- [ ] 반경 5m 안 액터만 반환된다
- [ ] 반경 밖 액터는 반환되지 않는다
- [ ] ⭐ 결과가 **가까운 순 정렬**되어 있다
- [ ] 시전자 본인 처리가 정한 규칙대로다
- [ ] `IgnoredActors` 액터가 제외된다
- [ ] 대상이 없을 때 **빈 배열** (크래시 아님)

## 흔한 실수 — 걸렸는지 확인

- [ ] ⭐ **m ↔ uu 변환을 판정 함수마다 하지 않았다** — 한 곳에서만
- [ ] ⭐ **정렬을 나중으로 미루지 않았다** — 미루면 판정 5종을 다 고친다
- [ ] 오버랩 결과의 스태틱 메시·트리거 볼륨을 걸러냈다
- [ ] 특정 캐릭터 전용 분기를 넣지 않았다

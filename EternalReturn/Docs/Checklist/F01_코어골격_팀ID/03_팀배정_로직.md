# ✅ F01-03 — 팀 배정 로직

> Task [`../../Task/F01_코어골격_팀ID/03_팀배정_로직.md`](../../Task/F01_코어골격_팀ID/03_팀배정_로직.md)

## 선행

- [ ] [02 팀 ID 복제](02_팀ID_복제.md) 완료
- [ ] 클라 2대 이상으로 PIE를 띄울 수 있다

## 구현

- [ ] `AERGameMode::TeamSize` (`EditDefaultsOnly`, 기본 3) 선언
- [ ] `AERGameMode::TeamCount` (`EditDefaultsOnly`, 기본 8) 선언
- [ ] ⭐ **두 값이 상수로 박혀 있지 않다** — 에디터에서 바꿀 수 있다
- [ ] 접속 시 서버가 빈 자리를 찾아 `TeamId` 를 배정
- [ ] 배정이 `HasAuthority()` 가드 안에 있다
- [ ] `AERGameState` 에 팀 구성 배열 + 복제
- [ ] 팀 정원 초과 시 처리를 정하고 **자체 결정값임을 주석에 표기**했다
- [ ] `PlayerState` 유효성을 확인하고 역참조한다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 4`, `TeamSize = 2`

- [ ] 4명이 **2팀으로 나뉜다**
- [ ] 각 팀에 정확히 2명씩 들어간다
- [ ] 서버 로그에 배정 결과가 찍힌다
- [ ] 각 클라가 자기 팀 ID를 올바로 읽는다
- [ ] `TeamSize = 1` 로 바꾸면 4팀이 된다 (데이터값이 실제로 동작)

## 흔한 실수 — 걸렸는지 확인

- [ ] 3 × 8 = 24를 상수로 박지 않았다 — **박으면 PIE 테스트가 불가능해진다**
- [ ] 배정 로직이 `AERGameMode` 에 있다 (클라에 존재하지 않는 클래스)
- [ ] 클라가 자기 팀을 정하는 경로가 없다
- [ ] `AGameStateBase` 팀 배열에 인벤토리 같은 큰 데이터를 넣지 않았다
- [ ] `PostLogin` 시점에 `PlayerState` 가 `nullptr` 일 수 있음을 감안했다

## 막혔을 때

| 증상 | 확인할 것 |
|---|---|
| 전원이 같은 팀 | 배정 인덱스가 증가하지 않는다. 접속 카운터를 확인 |
| `PostLogin` 에서 크래시 | `PlayerState` 가 아직 없다. 더 늦은 시점(예: `OnPostLogin` 이후)으로 옮긴다 |
| 클라마다 팀 구성이 다르게 보임 | GameState 배열 복제 누락 (`DOREPLIFETIME`) |

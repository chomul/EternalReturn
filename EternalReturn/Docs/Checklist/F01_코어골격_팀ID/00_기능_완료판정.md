## 상향식 원칙 확인

- [ ] `AERCharacterBase` 에 **스탯·스킬·인벤토리 멤버가 없다** (각 기능이 컴포넌트로 들고 온다)

  ```
  grep -rn "Cast<AERPlayerState>" Source/    ← ERTeamStatics.cpp 외에는 나오면 안 됨
  ```
- [ ] `TeamSize` / `TeamCount` 가 상수로 박혀 있지 않다

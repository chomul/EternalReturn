# ✅ F01-01 — 프레임워크 5종 생성

> Task [`../../Task/F01_코어골격_팀ID/01_프레임워크_5종_생성.md`](../../Task/F01_코어골격_팀ID/01_프레임워크_5종_생성.md)

## 선행

- [ ] 없음 (이 프로젝트의 첫 작업)
- [ ] 에디터가 **닫혀 있다** (열려 있으면 링크 실패)

## 구현

- [ ] `AERGameMode` (`AGameModeBase` 파생) 생성
- [ ] `AERGameState` (`AGameStateBase` 파생) 생성
- [ ] `AERPlayerState` (`APlayerState` 파생) 생성
- [ ] `AERPlayerController` (`APlayerController` 파생) 생성
- [ ] `AERCharacterBase` (`ACharacter` 파생) 생성
- [ ] `AERGameMode` 생성자에서 `DefaultPawnClass` / `PlayerStateClass` / `PlayerControllerClass` / `GameStateClass` 지정
- [ ] 파일이 `Core/` 와 `Character/` 폴더 규칙에 맞게 놓였다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증

- [ ] PIE 실행 시 스폰되는 폰이 `AERCharacterBase` 다 (`UE_LOG` 로 클래스명 확인)
- [ ] 크래시 없이 레벨이 로드된다

## 흔한 실수 — 걸렸는지 확인

- [ ] `.generated.h` 가 include 목록의 **맨 마지막**에 있다
- [ ] 헤더에서 불필요한 include 대신 **전방 선언**을 썼다
- [ ] 생성자 안에 **게임 로직·월드 접근이 없다** (`CreateDefaultSubobject` 만)
- [ ] 클래스에 `ER` 프리픽스가 붙어 있다
- [ ] 빈 껍데기다 — **스탯·스킬·인벤토리 멤버를 넣지 않았다**

## 막혔을 때

| 증상 | 원인 |
|---|---|
| `Cannot open ... UnrealEditor-EternalReturn.dll` | 에디터가 열려 있다. **닫고 재빌드** (프로세스를 임의로 죽이지 않는다) |
| 빌드 액션이 수천 개 | 엔진 전체 재빌드 중. UBT 로그 앞부분의 `UnrealHeaderTool needs to run because ...` 확인 |
| PIE에서 기본 폰이 스폰됨 | `AERGameMode` 가 실제로 쓰이지 않는다. 월드 세팅 또는 `DefaultEngine.ini` 의 `GlobalDefaultGameMode` 확인 |

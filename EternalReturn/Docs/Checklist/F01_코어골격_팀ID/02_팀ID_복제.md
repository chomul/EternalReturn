## 구현

- [ ] `AERPlayerState::TeamId` 를 `UPROPERTY(Replicated)` 로 선언
- [ ] 기본값이 `INDEX_NONE` (미배정)
- [ ] `GetLifetimeReplicatedProps` 오버라이드 선언
- [ ] ⭐ **`DOREPLIFETIME(AERPlayerState, TeamId)` 를 넣었다**
- [ ] `Super::GetLifetimeReplicatedProps()` 를 먼저 호출했다
- [ ] `BlueprintReadOnly` 다 (`BlueprintReadWrite` 아님)

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증 — `Play As Client, Number of Players: 2`

- [ ] 서버에서 `TeamId` 를 넣으면 **클라 양쪽이 그 값을 읽는다** (`UE_LOG`)
- [ ] 클라에서 `TeamId` 를 직접 대입해도 **서버 값이 변하지 않는다**
- [ ] 값이 변하는 순간에만 전송된다 (매 프레임 갱신이 아님)

## 흔한 실수 — 걸렸는지 확인

- [ ] ⭐ **`DOREPLIFETIME` 누락** — 컴파일도 되고 에러도 없는데 값만 안 온다. **이 항목이 이 Task에서 가장 자주 나는 실수다**
- [ ] `Super::GetLifetimeReplicatedProps()` 호출 누락 (부모 값들이 전부 복제 안 됨)
- [ ] `APlayerState` 에 큰 배열을 얹지 않았다 (`bAlwaysRelevant = true` 라 24명 전원에게 간다)
- [ ] 헤더에 `UPROPERTY` 를 추가했으므로 **에디터 재시작이 필요할 수 있다** — 사용자에게 알렸다

## 막혔을 때

| 증상 | 확인할 것 |
|---|---|
| 클라에서 값이 항상 기본값 | `DOREPLIFETIME` 이 있는가. `bReplicates` 가 켜져 있는가 |
| 클라에서 값이 늦게 옴 | `APlayerState` 는 `NetUpdateFrequency = 1` 이다 (`PlayerState.cpp:26`). 정상 동작이다 |
| 서버에서만 값이 보임 | PIE 모드가 `Play As Client` 인지 확인. Standalone 이면 복제가 일어나지 않는다 |

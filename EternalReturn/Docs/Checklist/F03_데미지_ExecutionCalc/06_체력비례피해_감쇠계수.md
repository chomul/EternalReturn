- [ ] 비례 피해 4종 처리

  - [ ] 대상 **현재** 체력 비례
  - [ ] 자신의 **잃은** 체력 비례
  - [ ] 자기 자신 대상 피해
- [ ] ⭐ **감쇠 계수를 비례 피해에만** 곱한다

- [ ] 자기 대상 피해에 **체력 하한**을 쓴다 (F02-04가 받게 만든 것)

## 수치 검증

- [ ] ⭐ 최대 체력 10000, 8% 비례, **보스** → **400** (실효 4%)
- [ ] 최대 체력 10000, 8% 비례, 일반 대상 → **800**
- [ ] 현재 체력 3000 (최대 10000), 5% 현재 비례 → **150**
- [ ] 자신 잃은 체력 4000, 2배 → **8000**
- [ ] ⭐ 시셀라 R 자기 피해 → **체력 100에서 멈춘다**
- [ ] ⭐ 매그너스 W 11타 × 2.5% + 보스 → 실효 **약 13.75%** (감쇠 없으면 27.5%)

## ⭐ 가장 위험한 실수 세 가지

- [ ] **감쇠가 일반 피해에 곱해지지 않는다**
  곱해지면 보스가 모든 피해를 절반만 받는 **완전히 다른 게임**이 된다
- [ ] **「최대」와 「현재」를 혼동하지 않았다**
  재키 Q는 **현재** 체력 5%다. 최대로 계산하면 **처형기**가 된다 — 정반대 성격
- [ ] **`Cast<>` 로 대상 클래스를 검사하지 않는다** — 하면 F03이 F12에 의존한다
  ```
  grep -n "Cast<" Source/EternalReturn/GAS/ERDamageExecution.cpp    ← 안 나와야 함
  ```

## 흔한 실수 — 걸렸는지 확인

- [ ] 다단 히트에서 **첫 타의 체력으로 전 타를 계산하지 않는다**
- [ ] 자기 대상 피해의 하한이 0이 아님을 처리했다
- [ ] Source 잃은 체력 계산에 **Source 캡처**를 썼다 (Target 아님)

## 판단 기록

- [ ] 감쇠 판별 방식(태그 / 어트리뷰트)을 정하고 주석에 남겼다
- [ ] 보스 외 대상 감쇠 계수를 **1.0으로 두고 (미확인)** 표기했다
- [ ] 비례 피해의 방어력 적용 여부를 정하고 주석에 남겼다
- [ ] 감쇠 0.5가 **커뮤니티 자료 기반이며 공식 확인이 안 됐음**을 남겼다

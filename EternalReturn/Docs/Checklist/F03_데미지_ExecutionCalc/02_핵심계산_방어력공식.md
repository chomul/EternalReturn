# ✅ F03-02 — 핵심 계산 · 방어력 공식 ⭐

> ⭐ **문서 §7: "2순위가 이 문서의 전부다."**

## 선행

- [ ] [01 어트리뷰트 캡처 정의](01_어트리뷰트_캡처정의.md) 완료

## 구현

- [ ] `UERDamageExecution : public UGameplayEffectExecutionCalculation`
- [ ] `Execute_Implementation` 오버라이드
- [ ] 방어력 모델 **`100 / (100 + DEF)`**
- [ ] ⭐ 원시 피해를 **SetByCaller** 로 받는다
- [ ] 고정 피해 태그면 방어력을 **적용하지 않는다**
- [ ] ⭐ 결과를 **`IncomingDamage` 출력 수정자**로 낸다
- [ ] `FMath::Max(Defense, 0.f)` 로 분모 보호
- [ ] 「최종 피해 추가(%)」를 **적용하지 않았다** (해석 미확인)

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 수치 검증

- [ ] 원시 200, 방어력 100, 스킬 → ⭐ **정확히 100**
- [ ] 원시 200, 방어력 0 → 200
- [ ] 원시 200, 방어력 100, **고정 피해 태그** → **200**
- [ ] 원시 200, 방어력 300 → 50
- [ ] 방어력이 음수여도 크래시하지 않는다

## ⭐ 책임 분리 확인

- [ ] **체력을 직접 건드리지 않는다** — `IncomingDamage` 에 출력만
- [ ] **클램프하지 않는다** (F02-03 소관)
- [ ] **이펙트·사운드·로그가 없다** (`GameplayCue` 소관)
- [ ] 어빌리티가 계산식을 모른다 — "얼마"만 넘긴다

## 흔한 실수 — 걸렸는지 확인

- [ ] 정수로 떨어지는 케이스로 검증했다 (부동소수 비교 아님)
- [ ] ⭐ **「최종 피해 추가」를 추측해서 적용하지 않았다** — `(1+x)` 인지 `x` 인지 모른다
- [ ] `EGameplayModOp::Additive` 로 출력했다
- [ ] 이 파일에 로그·이펙트를 섞지 않았다 (GAS 이관성과 무관하게, 단일 책임)

## 에디터 작업

- [ ] 이 Execution을 쓰는 **GE 애셋이 필요**하다
- [ ] 애셋 생성을 직접 하지 않고 `Docs/EditorTasks/` 로 넘겼다

## 막혔을 때

| 증상 | 확인할 것 |
|---|---|
| 피해가 0 | SetByCaller 태그 이름 불일치, 또는 `RelevantAttributesToCapture` 누락 |
| 피해가 예상보다 큼 | 「최종 피해 추가」를 적용했는지, 채널 태그가 `True` 인지 |
| 체력이 안 줄어듦 | F02-04의 `PostGameplayEffectExecute` 가 `IncomingDamage` 를 읽는지 |

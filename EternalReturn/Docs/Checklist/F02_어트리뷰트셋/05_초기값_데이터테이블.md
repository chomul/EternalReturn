# ✅ F02-05 — 초기값 데이터 테이블

> Task [`../../Task/F02_어트리뷰트셋/05_초기값_데이터테이블.md`](../../Task/F02_어트리뷰트셋/05_초기값_데이터테이블.md)

## 선행

- [ ] [04 체력 처리 · 사망 알림](04_체력처리_사망알림.md) 완료

## 구현

- [ ] `FCharStatRow : public FTableRowBase` 정의
- [ ] RowName = 실험체 이름
- [ ] 필드가 `UPROPERTY(EditDefaultsOnly)`
- [ ] ⭐ **초기화를 GE로 한다** — 코드에서 `SetHealth()` 직접 호출 안 함
- [ ] 초기화가 **서버에서만** 실행된다
- [ ] ⭐ **MaxHealth 를 먼저 세팅**하고 Health 를 채운다
- [ ] 방식 A(Instant GE + SetByCaller)를 골랐다면 그 근거를 주석에 남겼다

## 빌드

- [ ] `EternalReturnEditor` 빌드 통과
- [ ] `EternalReturnServer` 빌드 통과

## 검증

- [ ] 캐릭터 스폰 시 어트리뷰트가 테이블 값으로 초기화된다
- [ ] `Health == MaxHealth` 로 시작한다
- [ ] ⭐ **클라에서도 초기값이 보인다**
- [ ] 테이블 값을 바꾸면 반영된다 (하드코딩 아님)

## ⭐ 가장 흔한 순서 실수

- [ ] **초기화가 `InitAbilityActorInfo`(F00-03) 이후**에 일어난다 — 그 전에 GE를 걸면 조용히 실패한다
- [ ] **MaxHealth가 Health보다 먼저** 세팅된다 — 뒤집히면 체력이 0으로 클램프된다

## 흔한 실수 — 걸렸는지 확인

- [ ] 어트리뷰트를 코드에서 직접 세팅하지 않았다 (클램프·`PostGameplayEffectExecute` 우회 방지)
- [ ] ⭐ `FCharStatRow` 필드 이름을 신중히 정했다 — **바꾸면 데이터 테이블 값이 날아간다**
- [ ] 클라에서 초기화하지 않았다

## 에디터 작업

- [ ] ⭐ GE 애셋 · 데이터 테이블 애셋을 **직접 만들지 않았다** (`Content/` 금지)
- [ ] `Docs/EditorTasks/` 문서로 넘겼다
- [ ] 문서에 애셋 경로 · 부모 클래스 · 컬럼 · 예시 행을 적었다

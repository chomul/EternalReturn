## 막혔을 때

| 증상 | 확인할 것 |
|---|---|
| `Cannot open ... UnrealEditor-EternalReturn.dll` | 에디터가 열려 있다. **닫고 재빌드** (프로세스를 임의로 죽이지 않는다) |
| 빌드 액션이 수천 개 | GAS 모듈 첫 컴파일이면 평소보다 오래 걸리는 건 정상. 단 **수천 개는 엔진 전체 재빌드**다. UBT 로그 앞부분의 `UnrealHeaderTool needs to run because ...` 확인 후 사용자에게 알린다 |
| `Unresolved external symbol` GAS 관련 | `Build.cs` 에 모듈 3개가 다 있는지 |
| 에디터 첫 실행이 매우 느림 | 정상. 셰이더·모듈 컴파일 |

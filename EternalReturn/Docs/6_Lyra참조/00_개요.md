# Lyra 참조 — 개요

Epic 의 공식 샘플 **LyraStarterGame** 은 GAS 를 실제 규모로 쓴 유일한 1st-party 레퍼런스다.
구조를 고민할 때 **먼저 Lyra 가 어떻게 했는지 보고**, 그 다음 우리 사정과 대조한다.

## 위치

```
C:/UnrealEngine-5.4.4/Samples/Games/Lyra
```

⚠ **소스만 있고 `Content/` 는 없다.** 애셋 구성은 확인할 수 없다 — 코드로 드러나는 것만 근거로 쓴다.

주요 경로:

| 경로 | 내용 |
|---|---|
| `Source/LyraGame/AbilitySystem/Attributes/` | 어트리뷰트 세트 |
| `Source/LyraGame/AbilitySystem/LyraAbilitySet.h/.cpp` | 어빌리티·GE·세트 묶음 부여 |
| `Source/LyraGame/Character/LyraPawnData.h` | 폰별 데이터 애셋 |
| `Source/LyraGame/AbilitySystem/LyraAbilitySystemComponent.*` | ASC 파생 |

## ⭐ 이 폴더를 쓰는 법

- 문서마다 **Lyra 가 어떻게 하는지** → **우리는 왜 같게/다르게 하는지** 순서로 쓴다
- **모든 주장에 `파일:라인` 을 단다** (`CLAUDE.md` §1.2)
- **Lyra 를 무조건 따라가지 않는다.** 전제가 다른 곳이 많다 (아래)
- 새로 읽은 게 있으면 문서를 늘린다. 한 번에 다 쓰지 않는다

## ⚠ 전제가 다른 지점 — 그대로 베끼면 안 되는 것

| | Lyra | 우리 |
|---|---|---|
| 장르 | 팀 슈터 | 탑다운 MOBA·배틀로얄 |
| 캐릭터별 스탯 | ❌ **전부 동일** (차이는 무기에서) | ✅ 실험체마다 다름 |
| 어트리뷰트 총개수 | **6개** (`HealthSet` 4 + `CombatSet` 2) | **33개** |
| 스탯 데이터 테이블 | ❌ **없음** (`grep "public FTableRowBase" Source/` → 0건) | 필요 |
| 초기값 출처 | C++ 생성자 하드코딩 (`LyraHealthSet.cpp:21-23`) | 데이터 테이블 |
| 스킬 구성 | 게임 피처 플러그인으로 갈아 끼움 | 실험체 고정 |
| 팀 판정 | `LyraTeamSubsystem` | `ERTeamStatics` (F01) |

**Lyra 가 안 푼 문제가 우리한테는 있다.** 특히 "캐릭터마다 다른 기본 스탯"은
Lyra 에 아예 없는 요구사항이라 참고할 코드가 없다.

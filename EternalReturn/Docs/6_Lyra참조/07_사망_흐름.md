# 07 — 사망 흐름 (빈사 · 소생 설계 전)

> 대조 시점 **2026-10-08** · [Argument 75](../4_Argument/75_빈사_사망_소생.md) · Lyra 경로 `C:/UnrealEngine-5.4.4/Samples/Games/Lyra`
> 전제 차이: [`00_개요.md`](00_개요.md)

## 무엇을 찾으러 갔나

체력 0 다음에 **빈사**를 끼우려면 사망을 어디서 · 무엇으로 처리해야 하나. Lyra 에 빈사 · 소생이 있나.

## Lyra 가 하는 것

- 빈사 · 소생 **없음** — `Source` 전체 grep `Downed|Revive|Incapacitat|DBNO` 0건 (팀 슈터 · 바로 리스폰)
- 체력 0 → `ULyraHealthComponent::HandleOutOfHealth` (**서버만** `WITH_SERVER_CODE`) → `GameplayEvent.Death` 를 자기 ASC 에 (`LyraHealthComponent.cpp:148-167`)
- 그 이벤트가 **사망 어빌리티**를 발동 (`LyraGameplayAbility_Death.cpp` — `AbilityTriggers` 에 `GameplayEvent.Death` · `ServerInitiated`)
  - 발동하면 **다른 어빌리티를 전부 취소**하고(`CancelAbilities` · `Ability.Behavior.SurvivesDeath` 태그만 예외) 새 발동을 막는다
  - `StartDeath` → 체력 컴포넌트가 복제 상태 `ELyraDeathState` (NotDead → DeathStarted → DeathFinished) + **loose 태그** `Status.Death.Dying` · `Status.Death.Dead` (`LyraHealthComponent.cpp:235-270`)
  - 클라는 `OnRep_DeathState` 로 같은 단계를 밟는다 — 거꾸로 가는 전이는 경고 (`:190-232`)

## 우리에게 성립하나

| Lyra 가 한 것 | 우리 | 이유 |
|---|---|---|
| 사망을 **서버 사건 하나**에서 시작 | ✅ 같다 — 우리도 `UERAttributeSet::OnOutOfHealth` 한 번 (빗장) | 같은 문제 (피해 실행 안에서 바로 처리하지 않는다) |
| 사망 때 **다른 어빌리티 전부 취소** | ✅ 가져온다 — 빈사 · 사망 들어갈 때 시전 중 스킬 취소 (패시브 제외) | 시전 중 쓰러지면 판정 타이머가 계속 돈다 |
| 복제 enum + loose 태그 | ❌ 그대로는 안 씀 — 빈사는 **효과(이속 · 피해 감소 · 체력 감소)가 붙은 상태**라 GE 하나가 태그 + 효과를 같이 준다 (CLAUDE.md §8 "상태 = GE + 태그") | Lyra 는 사망에 효과가 없어 enum 으로 충분했다. enum 을 쓴 이유(클라 예측 되감기 방지)는 우리에게 없다 — 예측을 켜지 않는다 (§8) |
| 사망 어빌리티 | 보류 — 취소는 ASC 함수 한 줄로 된다. 사망 연출이 길어지면 그때 | 한 곳에서만 쓰는 추상화 금지 (§2) |

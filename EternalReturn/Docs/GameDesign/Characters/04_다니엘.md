**핵심 설계**
> 다니엘은 **"표식 부여 → 4초 대기 → 2.5초 안에 공격해서 폭발"** 이라는 **지연 폭발 콤보**가 정체성이다.
> 그리고 **패시브가 밤에만 작동한다** — 6인 중 유일하게 **낮/밤 사이클에 의존**하는 캐릭터다.
> 낮/밤 시스템이 없으면 이 캐릭터는 **패시브가 없는 상태로 구현된다.** 선행 작업을 먼저 확인할 것.

## 3. 스킬 명세

### P — 고독한 예술가

| 항목 | 값 |
|---|---|
| **발동 조건** | **밤이 되면 활성화. 낮에는 작동하지 않는다.** |
| 시야 증가 | `[14/17/20]%` |
| 이동 속도 증가 | `[2/4/6]%` |
| 쿨다운 | 없음 |

**구현 메모**
- **낮/밤 사이클 시스템에 대한 의존이다.** 매치 타임라인(상위 문서 §2, §4.4)이 구현돼 있어야 한다.
- 밤 진입/종료 시점에 스탯을 켜고 끄는 **상태 전이 이벤트**가 필요하다. 서버가 시간 권위를 가진다.

### Q — 그림자 가위

| 항목 | 값 |
|---|---|
| 지정 방식 | **위치/방향 지정 · 부채꼴** |
| 피해 | `[30/40/50/60/70]` (+공격력의 **110%**) |
| **강화 피해** | `[40/60/80/100/120]` (+공격력의 **140%**) |
| 강화 조건 | **중앙 범위 적중으로 추정** — ⚠ **(미확인, 반드시 검증할 것)** |
| 공격 속도 증가 | `[80/110/140/170/200]%` |
| 둔화 | **35%, 1.5초** |
| 쿨다운 | `[10/9/8/7/6]`초 |
| 사거리 / 범위 | 7m / **3.5m × 65°** |

**구현 메모**
- **부채꼴 판정의 첫 사용처** (65°). 레니 E(60°)와 공용화 가능하다.
- 공격 속도 증가 **최대 200%** 는 6인 통틀어 가장 큰 버프다. **공격속도 상한 2.5** 클램프를 반드시 적용할 것.
- 강화 조건이 확정되지 않았다. 위키 본문에 "강화 피해량"만 있고 조건 서술이 없어 **중앙 적중으로 추정**했다. 구현 전 인게임 확인 필요.

### W — 영감

| 항목 | 값 |
|---|---|
| 지정 방식 | **대상 지정** (적 실험체에게 표식 부여) |
| 피해 축적률 | 입힌 피해의 `[4/6/8/10/12]%` (+**추가 공격력의 8%**) |
| 폭발 피해 | `[20/40/60/80/100]` (+공격력의 **60%**) + **축적된 피해(고정 피해)** |
| **작동 순서** | ① 표식 부여 → ② **4초 유지** → ③ 그 후 **2.5초 이내에 공격 시 폭발** |
| 시야 감소 | **2초** |
| 쿨다운 | 7초 |
| 사거리 | 7m |

**구현 메모**
- **이 게임 6인 중 가장 복잡한 상태 머신이다.** 표식마다 `부여 시각 / 축적량 / 폭발 가능 윈도우` 를 들고 있어야 한다.
  - 상태: `대기(0~4초)` → `폭발 가능(4~6.5초)` → `소멸`
  - 축적은 **대기 구간에도 계속 쌓이는지** **(미확인)**.
- 축적 피해는 **고정 피해(방어 무시)** 다. 데미지 파이프라인에 고정 피해 경로가 있어야 한다.
- 표식은 **적에게 붙는 상태**이므로, 대상 액터에 상태 컨테이너가 필요하다 (레니 아군 표식과 같은 구조).

### E — 그림자 이동

| 항목 | 값 |
|---|---|
| 지정 방식 | **방향 지정 돌진** |
| 피해 | `[20/40/60/80/100]` (+**추가 공격력의 50%**) |
| 은신 시간 | `[1/1.2/1.4/1.6/1.8]`초 |
| 이동 거리 | **3m** |
| 이후 상태 | **3초간 "그림자 돌진" 상태** |
| 그림자 돌진 중 | 기본 공격 **사거리 3m 고정**, 적 기본 공격 시 **적의 건너편으로 순간이동** + 추가 피해 |
| 쿨다운 | `[11/10/9/8/7]`초 |

**구현 메모**
- **은신 + 순간이동 + 임시 상태**가 한 스킬에 다 들어 있다. 6인 중 가장 손이 많이 가는 스킬.
- ⚠ **은신은 보안 이슈다.** 서버가 가시성을 판정하고 **적 클라이언트에 위치를 보내지 않아야** 한다. 클라에서 숨기기만 하면 핵에 뚫린다. (공통 규약 §3)
- "적의 건너편으로 순간이동"은 **대상 위치 기준 반대편 좌표 계산** — 벽 관통 여부 **(미확인)**.

### R — 걸작

| 항목 | 값 |
|---|---|
| 지정 방식 | **최근 대상 자동 지정** — **피해를 입힌 지 4초 이내의 적** 그림자 속으로 진입 |
| 지속 피해 | `[10/30/50]` (+공격력의 **30%**) |
| 마지막 피해 | `[40/105/170]` (+공격력의 **90%**) |
| 지속 시간 | **최대 2초** (채널링) |
| 침묵 | **0.5초** |
| 둔화 | **50%** |
| 쿨다운 | `[70/60/50]`초 |
| 사거리 | 3m |

**구현 메모**
- **대상 선정이 특이하다.** "최근 4초 내 내가 피해를 입힌 적"을 추적해야 하므로, **최근 피해 대상 이력**을 캐릭터가 들고 있어야 한다.
- 그림자 진입 중 다니엘은 **무적/비타격 상태인지 (미확인)** — 생존기로 쓰이는지가 여기서 갈린다. 중요.
- **침묵**의 유일한 사용처(6인 중). CC 시스템에 침묵을 넣어야 한다.

## 4. 무기 스킬 (D) — 단검

| 항목 | 값 |
|---|---|
| 이름 | **은신 단도** |
| 효과 | **1~2초 은신**, 재사용 시 **대상 뒤로 순간이동** |
| 쿨다운 | 30 / 25 / 20초 |
| 계수 | `10/30/50` (+추가 공격력 50%, **+현재 체력 8%**) |

> ⚠ 12.2에서 **단검 숙련도 계수가 하향**됐으나(2.8% → 2.4%), 이는 **재키 전용 조정**이다.
> 다니엘의 단검 숙련도 계수는 별도 값이며 이번 조사에서 **(미확인)**.

**구현 메모**
- E와 D가 **은신·순간이동을 중복 사용**한다. 두 기능을 공용 함수로 만들면 다니엘 구현이 크게 단순해진다.

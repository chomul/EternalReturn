## 1. 요약

| 항목 | 값 |
|---|---|

| **구현 난이도** | **★☆☆☆☆ — 6인 중 가장 쉽다. 여기서 시작할 것** |

**왜 첫 번째인가**
- 아군 대상 스킬 없음, 은신 없음, 자원 소모 없음, 소환물은 드론 1개(단순)
- 스킬 4개 중 3개가 "투사체 발사 + 피해"라는 가장 기본 형태
- **투사체 속도가 명시**돼 있어(26 / 40 m/s) 투사체 시스템 검증에 적합
- 유일한 신규 개념이 **채널링(R, 0.8초)** 과 **거리 비례 피해(Q)** 뿐

> ⚠ 커뮤니티 평가상 "돌격소총 아야와 함께 가장 쉬운 원딜"이자 **대표적 혐오 실험체**로 꼽힌다.
> 긴 사거리로 일방적 견제가 가능하기 때문이며, 수치를 그대로 베끼면 **같은 불쾌감이 재현된다.**

## 3. 스킬 명세

### P — 잿빛 사신

| 항목 | 값 |
|---|---|
| 발동 조건 | **Q 또는 E 사용 후 5초 이내의 다음 기본 공격** |
| 추가 스킬 피해 | `[50/75/100]` (+공격력의 `30/45/60%`) |
| 부가 효과 | 처치 관여한 적 실험체 **시체 탐색 시 4크레딧 추가 획득** |
| 쿨다운 | 없음 |

**구현 메모**
- 스킬 사용 시 5초짜리 "강화 기본 공격" 플래그를 세우고, 기본 공격 적중 시 소모한다.
- 크레딧 보상은 **시체 탐색(루팅) 시스템 연동**이라, 루팅이 없으면 이 부분은 후순위로 미룬다.
- 패시브 레벨은 3단계 — 스킬 포인트가 아니라 캐릭터 레벨에 따라 자동 상승한다.

### Q — 조준 사격

| 항목 | 값 |
|---|---|
| 지정 방식 | **방향 지정 · 비관통 투사체** |
| 최소 피해 | `[40/80/120/160/200]` (+공격력의 **70%**) |
| 최대 피해 | `[60/120/180/240/300]` (+공격력의 **105%**) |
| 피해 보간 | **날아간 거리에 비례해 증가**, 사거리 11m 끝에서 최대 |
| 부가 효과 | 적중 시 **4초간 공격 속도 `[20/25/30/35/40]%` 증가** |
| 쿨다운 | `[7/6/5/4/3]`초 |
| 사거리 | 11m |
| 투사체 속도 | **26 m/s** |

**구현 메모**
- 거리 보간은 **투사체가 날아간 거리** 기준이다. 발사 시점이 아니라 **적중 시점에 계산**해야 한다.
- 계수도 함께 보간된다(70% → 105%). 기본 피해와 계수를 **각각** 보간할 것.
- 공격속도 버프는 상한 2.5에 걸린다(상위 문서 §6).

### W — 목표물 포착

| 항목 | 값 |
|---|---|
| 지정 방식 | **위치 지정** |
| 지속 효과 | **드론이 카티야 대신 보안 콘솔을 활성화** (본인은 이동 자유) |
| 사용 효과 | 드론이 투사체 발사 → 지정 위치에서 파동 발생 |
| 파동 효과 | 적을 **드러냄**, **덫·카메라의 체력을 1로** 만듦, **3초간 시야 제공** |
| 피해 | **없음** |
| 쿨다운 | `[30/27/24/21/18]`초 |
| 사거리 | **23m** (6인 중 최장) |

**구현 메모**
- **유틸리티 전용 스킬 — 피해가 0이다.** 데미지 파이프라인을 타지 않는 첫 사례이므로, 스킬 프레임워크가 "피해 없는 스킬"을 지원하는지 여기서 검증된다.
- "보안 콘솔", "덫", "카메라"는 맵 오브젝트 시스템이 있어야 의미가 있다. 없으면 **시야 제공만 구현**하고 나머지는 미구현으로 명시한다.
- 드론이 상시 존재하는 액터인지 능력 표현인지는 **(미확인)**.

### E — 접근 금지

| 항목 | 값 |
|---|---|
| 지정 방식 | **방향 지정** (전방 발사 + **후방 도약**) |
| 피해 | `[50/75/100/125/150]` (+공격력의 **100%**) |
| 적중 시 둔화 | `[50/55/60/65/70]%`, **1초** |
| 자신 이동속도 | **2초간 40% 증가** |
| 이동 거리 / 시간 | **4m / 0.3초** (뒤쪽) |
| 쿨다운 | `[12/11/10/9/8]`초 |
| 사거리 | 4.5m |

**구현 메모**
- **발사 방향과 이동 방향이 반대다.** 조준 방향의 역벡터로 대시한다.
- 도약 중 벽에 막혔을 때의 처리는 **(미확인)** — 팀이 정해야 한다.

### R — 정밀 조준

| 항목 | 값 |
|---|---|
| 지정 방식 | **위치 지정 · 채널링** |
| 채널링(스캔) 시간 | **0.8초** — CC로 중단된다 |
| 대상 선정 | **카티야로부터 가까운 순 최대 3명**, 가까운 순서대로 발사 |
| 1타 | `[300/450/600]` (+공격력의 **150%**) |
| 2타 | `[350/500/650]` (+공격력의 **180%**) |
| 3타 | `[400/700/1000]` (+공격력의 **150%**) |
| 쿨다운 | `[80/70/60]`초 |
| 사거리 | **23m** |
| 투사체 속도 | **40 m/s** |
| 기타 | 야생동물 **관통** |

**구현 메모**
- **6인 통틀어 단일 스킬 최고 피해**(3레벨 3타 1000 + 공격력 150%). 밸런스 검증 기준점으로 쓴다.
- 타수마다 피해량과 계수가 모두 다르다. **타별 데이터 배열**이 필요하다.
- 스캔 중 대상이 사거리를 벗어나면 어떻게 되는지 **(미확인)**.

|---|---|

> **조사 기준일: 2026-08-29 / 기준 패치: 시즌 12 · 12.2 (2026-08-20 적용)**

## 0. 이 문서 묶음의 사용법

`Characters/` 폴더의 문서는 **"이 캐릭터를 UE에서 구현하려면 무엇을 알아야 하는가"** 만 다룬다.
게임 전체 구조(맵·제작·랭크·BM)는 상위 역기획서에 있으니 중복해서 읽지 않는다.

| 문서 | 대상 | 구현 난이도 |
|---|---|---|
| [`01_카티야.md`](01_카티야.md) | 원거리 딜러 / 저격총 | ★☆☆☆☆ |
| [`02_매그너스.md`](02_매그너스.md) | 탱커·전사 / 방망이·망치 | ★★☆☆☆ |
| [`03_재키.md`](03_재키.md) | 브루저 / 단검·양손검·도끼·쌍검 | ★★☆☆☆ |
| [`04_다니엘.md`](04_다니엘.md) | 암살자 / 단검 | ★★★☆☆ |
| [`05_시셀라.md`](05_시셀라.md) | 스킬 딜러 / 투척·암기 | ★★★★☆ |
| [`06_레니.md`](06_레니.md) | 지원가 / 권총 | ★★★★★ |

**표기 규칙**
- `(미확인)` = 확정하지 못한 값. **추측값은 적지 않는다.**
- `⚠패치 반영` = 위키 값과 12.1/12.2 패치노트 값이 다른 항목. **패치노트 값을 채택**한다.
- 수치 표기 `[a/b/c/d/e]` = 스킬 레벨 1~5. 궁극기는 `[a/b/c]` (1~3).

**데이터 신뢰도 경고**
나무위키 계열 수치는 패치 반영이 늦다. 이번 조사에서도 매그너스 기본 체력(위키 1070 / 실제 1030),
레니 레벨당 방어력(위키 2.8 / 실제 3), 레니 W 아군 이동속도(위키 8~12% / 실제 12~20%)가 어긋났다.
**공식 패치노트에 언급된 항목은 무조건 패치노트가 우선이다.**

## 1. 왜 이 6명인가 — 역할군 커버리지

우연인지 의도인지, 이 조합은 **게임의 6개 역할군을 정확히 하나씩** 덮는다.

| 실험체 | 역할군 | 검증되는 시스템 |
|---|---|---|
| 매그너스 | 탱커 / 전사 | 방어 스탯 → 딜 환산, 넉백·벽 충돌 기절 |
| 재키 | 브루저 | 도트(출혈) 중첩, 킬 관여 트리거, 지속시간 연장 |
| 다니엘 | 암살자 | 은신, 순간이동, 표식 축적 후 폭발, **밤/낮 상태 의존** |
| 시셀라 | 스킬 딜러 | **체력을 자원으로 쓰는 코스트**, 피해 면역, 그랩(강제 이동) |
| 카티야 | 원거리 딜러 | 거리 비례 피해, 채널링, 다중 대상 순차 발사 |
| 레니 | 지원가 | **아군 대상 스킬**, 보호막, 회복, 설치물, 아군 표식 |

> **기획 판단:** 이 6명을 다 만들면 이터널 리턴 스킬 시스템이 요구하는 **판정 타입이 거의 전부** 나온다.
> 즉 7번째 캐릭터부터는 신규 시스템이 아니라 **데이터 입력**에 가까워진다. 선정이 매우 합리적이다.
> 다만 **레니는 마지막에 만들어야 한다** — 아군 타게팅·보호막·설치물이 전부 걸려 있어 선행 시스템이 가장 많다.

## 2. 먼저 만들어야 하는 선행 시스템

캐릭터 코드를 쓰기 전에 **아래가 없으면 6명 중 누구도 완성되지 않는다.**

### 2.1 스킬 프레임워크 (최우선)

| 요구사항 | 이유 |
|---|---|
| 스킬 슬롯 P/Q/W/E/R + 무기 스킬 D | 전 캐릭터 공통 |
| 스킬 레벨 1~5 (궁극기 1~3) 데이터 테이블 | 모든 수치가 레벨 배열이다 |
| 쿨다운 관리 (스킬 가속 적용/미적용 구분) | 아야 패시브처럼 **쿨감 미적용 고정값**이 존재한다 |
| 시전 중 상태(채널링) + CC로 중단 | 카티야 R(0.8초), 다니엘 R(2초), 매그너스 W(4초) |
| 스킬 사용 코스트 | **시셀라는 체력을 소모한다** (마나가 아님) |

> ⚠ `CLAUDE.md` §8 — **이 프레임워크는 GAS로 만든다.** 스킬 1개 = `UGameplayAbility` 파생 클래스 1개.
> 슬롯 관리는 `UAbilitySystemComponent`, 쿨다운·코스트는 `UGameplayEffect`, 채널링 대기는 `UAbilityTask` 다.
> **자체 스킬 컴포넌트를 만들지 않는다.** 스킬 로직을 `AERCharacterBase` 에 직접 박지 않는 것은 그대로 유효하다.

### 2.2 판정(타게팅) 타입 — 6명이 요구하는 전부

| 타입 | 사용 예 | 구현 메모 |
|---|---|---|
| **대상 지정(타겟팅)** | 다니엘 W, 재키 Q | 사거리 검사 후 확정 적중 |
| **방향 지정 투사체** | 매그너스 Q(21m/s), 시셀라 E(15m/s), 카티야 Q(26m/s)·R(40m/s) | **투사체 속도가 스킬마다 다르다.** 데이터로 뺄 것 |
| **위치 지정 (착탄형)** | 재키 E, 시셀라 Q, 카티야 W | 사거리 클램프 필요 |
| **부채꼴(원뿔)** | 다니엘 Q(3.5m × 65°), 레니 E(4.5m × 60°) | 각도 판정 필요 |
| **자기 중심 원형** | 매그너스 W(반경 2.5m), 시셀라 R(반경 20m) | |
| **직선 관통/논관통** | 레니 Q(7.5m × 1.5m), 시셀라 E(폭 1.1m) | 폭이 있는 캡슐 트레이스 |
| **설치물(발판)** | 레니 R | 액터 스폰 + 소유권 + 수명 관리 |
| **소환/원격 유닛** | 카티야 W(드론), 시셀라 윌슨 | **별도 액터**로 관리 |
| **강제 이동(그랩·넉백)** | 시셀라 E(끌어옴), 매그너스 E(3m 넉백), 레니 R(넉백) | 아래 2.4 참조 |
| **자기 이동(대시·도약)** | 재키 E, 다니엘 E(3m), 카티야 E(4m/0.3초), 매그너스 R | `CharacterMovementComponent` 활용 |

### 2.3 데미지 파이프라인 — **반드시 한 곳에**

상위 역기획서 **§6.2 공식 피해 공식**을 그대로 따른다. 캐릭터별로 계산식을 흩뿌리면 안 된다.

구현해야 할 피해 종류 (6인이 실제로 쓰는 것):

| 종류 | 사용 예 |
|---|---|
| 기본 피해 (공격력 계수) | 대부분 |
| 스킬 피해 (스킬 증폭 계수) | 시셀라·레니 전부 |
| **추가 공격력 계수** (기본 공격력 제외) | 매그너스 Q/W/E, 다니엘 W/E |
| **고정 피해**(방어 무시) | 다니엘 W 폭발 |
| **대상 최대 체력 비례** | 매그너스 W(2.5%)·E(8%/6%), 레니 R(8%) |
| **대상 현재 체력 비례** | 재키 Q(5%) |
| **자신의 잃은 체력 비례** | 시셀라 R(2~3배), 재키 R |
| **거리 비례 보간** | 카티야 Q (최소→최대 선형) |
| **레벨 계수** (스킬 증폭이 아닌 캐릭터 레벨) | **레니 전 스킬** |

> **레니의 레벨 계수는 이 게임에서 예외적인 설계다.** 스킬 증폭 아이템 의존을 낮추려는 의도.
> 구현 시 `계수 = f(스킬레벨)` 과 `계수 = f(캐릭터레벨)` 두 경로를 **모두** 지원해야 한다.

### 2.4 상태이상(CC) — 6인이 요구하는 목록

| CC | 사용 | 비고 |
|---|---|---|
| 둔화 | 매그너스 Q, 다니엘 Q/R, 카티야 E, 레니 W/R, 시셀라 | **수치·지속시간이 전부 다름** |
| 기절 | 매그너스 E(벽 충돌), 시셀라 E(0.6초), 레니 E(0.5초) | |
| 침묵 | 다니엘 R(0.5초) | |
| 넉백 | 매그너스 E(3m), 레니 R | **벽 충돌 판정 필요** |
| 끌어당김(그랩) | 시셀라 E | |
| 은신 | 다니엘 E | 시야 시스템과 연동 |
| 시야 감소 | 다니엘 W(2초) | |
| 드러내기 | 카티야 W | |
| 피해 면역 | 시셀라 W(1.5초) | **CC는 못 막는다** — 피해만 무시 |
| 방해 저항 | 매그너스 W(40%), R(이동 방해 면역) | |

> **벽 충돌 판정은 3개 스킬(매그너스 E, 레니 R, 그리고 무기 스킬 방망이·석궁)이 공유한다.**
> 넉백 이동 중 지오메트리 충돌을 감지해 추가 피해·기절을 주는 **공용 함수**로 만들 것.

### 2.5 무기 스킬(D) — 6인이 요구하는 무기

캐릭터마다 사용 가능한 무기가 정해져 있고, **무기가 D스킬을 소유**한다.

| 무기 | 필요 캐릭터 | D스킬 |
|---|---|---|
| 방망이 | 매그너스 | 풀스윙 (넉백 + 벽 충돌 기절) |
| 망치 | 매그너스 | 방어구 파괴 |
| 단검 | 재키, **다니엘** | 은신 단도 |
| 양손검 | 재키 | 패링 (0.75초 무적) |
| 도끼 | 재키 | 피의 나선 (피해 60% 회복) |
| 쌍검 | 재키 | 춤 (6타 + 재사용) |
| 투척 | 시셀라 | 연막 |
| 암기 | 시셀라 | 마름쇠 투척 |
| 저격총 | 카티야 | 스나이핑 (저격 모드 3발) |
| 권총 | 레니 | 이동 사격 재장전 |

**= 10종 무기.** 상세 수치는 상위 역기획서 §5.3 참조.

> **초기 구현 제안:** 6명을 다 만들되 **무기는 캐릭터당 1종만** 먼저 붙인다.
> 매그너스=망치, 재키=도끼, 다니엘=단검, 시셀라=암기, 카티야=저격총, 레니=권총 → **6종**으로 시작.
> 무기 숙련도 시스템(§9.2)은 이 단계에서 넣지 않는다.

## 3. 네트워크 설계 (CLAUDE.md §6 준수)

**모든 스킬은 서버 권위다.** 클라이언트는 입력만 보낸다.

| 항목 | 권위 | 복제 방식 |
|---|---|---|
| 스킬 사용 요청 | 클라 → **서버 RPC** (`WithValidation`) | 쿨다운·코스트·시전 가능 상태를 **서버가 검증** |
| 데미지·체력·스탯 변경 | **서버 전용** | `Replicated` + `OnRep_` (UI 갱신) |
| 쿨다운 타이머 | **서버 권위** | 남은 시간은 복제, UI는 로컬 보간 |
| CC 적용/해제 | **서버** | 상태 플래그 복제 |
| 이펙트·몽타주·사운드 | 서버 판정 후 | **`NetMulticast`** |
| 본인 전용 피드백(적중 표시 등) | | **`Client` RPC** |
| 소환물(윌슨·드론·레니 발판) | **서버 스폰** | 액터 복제 |
| 은신(다니엘 E) | **서버가 가시성 판정** | ⚠ 클라에 위치를 보내면 **핵에 뚫린다.** 서버에서 relevancy로 걸러야 함 |

> **클라이언트 예측은 이번 범위에서 구현하지 않는다** (CLAUDE.md §6).
> 먼저 서버 권위로 정확히 동작시킨 뒤, 필요하면 별도 작업으로 진행한다.

## 4. 데이터 스키마 제안

현재 `FCharStatRow`(기초 스탯)는 있으나 **스킬 데이터 테이블이 없다.** 6인 구현 전에 필요하다.

```
FSkillRow : FTableRowBase
  SkillSlot        : ESkillSlot (P/Q/W/E/R/D)
  MaxSkillLevel    : int32                  // 5 또는 3
  TargetingType    : ESkillTargeting        // 위 2.2 목록
  BaseDamage       : TArray<float>          // 레벨별 배열
  AttackPowerRatio : TArray<float>          // 공격력 계수
  BonusAPRatio     : TArray<float>          // 추가 공격력 계수
  SkillAmpRatio    : TArray<float>          // 스킬 증폭 계수
  CharLevelRatio   : TArray<float>          // ⚠ 레니용 (캐릭터 레벨 계수)
  Cooldown         : TArray<float>
  Range            : float
  ProjectileSpeed  : float                  // 0 = 투사체 아님
  Radius / Angle   : float
  HealthCost       : TArray<float>          // ⚠ 시셀라용
  CCType / CCDuration / CCMagnitude
```

> 스탯은 `UERAttributeSet` 의 어트리뷰트다. 변경은 반드시 `UGameplayEffect` 로 한다 — 코드에서 직접 세팅하면 클램프(`PreAttributeChange`)를 우회한다 (`CLAUDE.md` §8).

## 5. 권장 구현 순서

```
M1. 스킬 프레임워크 + 데미지 파이프라인 + 기본 CC(둔화/기절)
    → 검증: 카티야 Q/E 가 서버 권위로 동작하고 클라에 체력 복제
M2. 카티야 완성 (투사체·채널링·거리 비례)
    → 검증: R 채널링이 CC로 중단됨
M3. 매그너스 완성 (넉백·벽 충돌·방어력→타격수 환산)
    → 검증: 벽 충돌 기절이 서버에서만 판정
M4. 재키 완성 (출혈 중첩·킬 관여 트리거)
    → 검증: 도트가 서버 틱으로 갱신, 중첩 5 도달 시 상태 전이
M5. 다니엘 완성 (은신·순간이동·표식 폭발·밤 조건)
    → 검증: 은신 중 적 클라이언트에 위치가 복제되지 않음
M6. 시셀라 완성 (체력 코스트·피해 면역·그랩·소환물 윌슨)
    → 검증: 피해 면역 중 피해 0, CC는 정상 적용
M7. 레니 완성 (아군 타게팅·보호막·회복·설치물)
    → 검증: 아군/적 판정이 팀 기준으로 갈리고, 발판이 서버 스폰
```

각 단계는 **빌드 통과**가 1차 검증이다 (CLAUDE.md §4).

## 6. 이번 조사에서 확인하지 못한 공통 항목

| 항목 | 영향 |

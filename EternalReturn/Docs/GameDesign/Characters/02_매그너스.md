## 3. 스킬 명세

### P — 근성

| 항목 | 값 |
|---|---|
| 중첩 조건 | **기본 공격 1중첩 / 스킬 공격 최대 2중첩**, 최대 **10중첩** |
| 중첩당 효과 | **방어력 `2 / 2.5 / 3%` 증가** |
| 최대 중첩 시 | 체력 재생 **+`3 / 4 / 5`** per sec |

**구현 메모**
- 중첩의 지속시간·감소 규칙이 **(미확인)**. 영구인지 시간이 지나면 빠지는지 확인이 필요하다.
- 방어력이 **% 증가**이므로 W의 "추가 방어력 35당 타격 +1"과 얽힌다. **계산 순서를 반드시 먼저 정할 것.**

### Q — 파쇄탄

| 항목 | 값 |
|---|---|
| 지정 방식 | **방향 지정 투사체** (돌 투척) |
| 피해 | `[80/125/170/215/260]` (+**추가 공격력 115%**, +스킬 증폭 90%) |
| 둔화 | `40% → 60%`, **2초** |
| 쿨다운 | `11초 → 7초` |
| 사거리 | 10.5m |
| 투사체 속도 | **21 m/s** |

### W — 17대 1

| 항목 | 값 |
|---|---|
| 지정 방식 | **자기 중심 원형 · 채널링 4초** |
| 타격 | **총 11회** (4초 동안) |
| 타당 피해 | `[16/22/28/34/40]` (+추가 공격력 45%, +스킬 증폭 20%, **+대상 최대 체력 2.5%**) |
| 타격당 효과 | **쿨다운 −0.5초** |
| 방해 저항 | **40%** |
| **⭐ 특수 규칙** | **추가 방어력 35당 타격 횟수 +1** |
| 쿨다운 | `14초 → 10초` |
| 반경 | 2.5m |

**구현 메모**
- 타격 횟수가 **런타임 스탯에 의해 변한다.** 시전 시점에 `11 + floor(추가방어력 / 35)` 로 계산한다.
- "추가 방어력"은 기본 방어력을 제외한 아이템·버프 방어력이다. **패시브의 % 증가분이 여기 포함되는지 (미확인)** — 밸런스에 직결되므로 반드시 확인할 것.
- 타격당 쿨다운 −0.5초가 있어 **타격 횟수 ↑ → 쿨 회전 ↑** 로 이중 스케일링된다.
- 4초 채널링 중 이동 가능 여부 **(미확인)**.

### E — 강타

| 항목 | 값 |
|---|---|
| 지정 방식 | **대상 지정** (넉백) |
| 초타 피해 | `[40/75/110/145/180]` (+추가 공격력 50%, +스킬 증폭 50%, **+대상 최대 체력 8%**) |
| 벽 충돌 피해 | `[20/40/60/80/100]` (+추가 공격력 30%, +스킬 증폭 20%, **+대상 최대 체력 6%**) |
| 벽 충돌 기절 | `0.7초 → 1.3초` |
| 넉백 거리 | **3m** |
| 쿨다운 | `11초 → 7초` |
| 사거리 | 3m |

**구현 메모**
- **벽 충돌 판정 공용 함수의 첫 사용처.** 레니 R, 무기 스킬(방망이·석궁)이 같은 로직을 쓴다.
- 넉백 이동은 서버 권위. 이동 중 매 프레임 지오메트리 충돌을 검사한다.

### R — 폭주 바이크

| 항목 | 값 |
|---|---|
| 피해 | `100 → 400` (3레벨 400) |
| 근성 중첩 부여 | `4회 → 10회` |
| 쿨다운 | `80초 → 60초` |
| 지속시간 | **7초** |
| 바이크 속도 | **1 → 8 m/s (가속형)** |
| 발사 거리 / 속도 | 9m / 16 m/s |
| 기타 | **이동 방해 면역** |

**구현 메모**
- **탑승·가속 이동 상태**가 필요하다. `CharacterMovementComponent`의 커스텀 무브먼트 모드를 검토한다.
- 속도가 1 → 8 m/s로 **가속**하므로 시간 기반 보간이 필요하다.
- 궁 사용만으로 **근성 중첩이 최대까지 차오른다** = 궁 켜면 방어력 폭증 → W 타격 횟수 증가로 연결된다. **이 콤보 구조를 이해하고 구현할 것.**
- 레벨 2 상세 수치와 충돌 시 효과가 **(미확인)**.

## 4. 무기 스킬 (D)

| 무기 | D스킬 | 효과 | 쿨다운 |
|---|---|---|---|
| **방망이** | 풀스윙 | 전방 스윙 + 넉백, **벽 충돌 시 0.8~1초 기절** | 25초 |
| **망치** | 방어구 파괴 | 전방 타격, **5초간 방어력 10~20% 감소** | 25 / 20 / 15초 |

12.2에서 방망이·망치 변경 **없음**.

> **초기 구현은 망치 1종만** 권장(공통 규약 §2.5). 방망이는 벽 충돌 로직이 E와 중복이라 나중에 붙여도 된다.

## 5. 구현 체크리스트

- [ ] 중첩 시스템 (최대 10, 기본공격 1 / 스킬 2)
- [ ] **방어력 → 타격 횟수 환산** (`11 + floor(추가방어력/35)`)
- [ ] 다단 히트 채널링 (4초 11타)
- [ ] **넉백 + 벽 충돌 판정** (공용 함수로)
- [ ] 대상 최대 체력 비례 피해
- [ ] 추가 공격력 계수 (기본 공격력 제외)
- [ ] 커스텀 이동 상태 (바이크, 가속 1→8 m/s)
- [ ] 방해 저항 / 이동 방해 면역

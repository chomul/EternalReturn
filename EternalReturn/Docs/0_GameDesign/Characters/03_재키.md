## 3. 스킬 명세

### P — 피의 축제

| 항목 | 값 |
|---|---|
| 출혈 부여 | 기본 공격·스킬 적중 시 **출혈 최대 5중첩**, 지속 **6초** |
| 출혈 피해 | `[10/20/30]` (+공격력의 **25%**) |
| 아드레날린 발동 | **최대 중첩 도달** 또는 **킬 관여** 시 **5초간** |
| 아드레날린 추가 피해 | `[10/25/40]` (+공격력의 `14/16/18%`) |
| 아드레날린 회복 | `10~20` → `20~40` (+공격력의 `10~20%`) |

**구현 메모**
- **도트 시스템의 첫 사용처.** 중첩·지속시간·갱신 규칙을 여기서 확정해야 한다.
  - 중첩마다 개별 타이머인지, 최신 적중이 전체를 갱신하는지 **(미확인)** — 밸런스 차이가 크다.
- **킬 관여(어시스트 포함) 이벤트**가 필요하다. 서버에서 사망 처리 시 관여자 목록을 만들어 브로드캐스트할 것.
- 아드레날린은 **상태(버프) 시스템**을 요구한다. 재키 R과 상호작용한다.

### Q — 롱소드

| 항목 | 값 |
|---|---|
| 지정 방식 | **전방 돌진 베기** (1.5m 돌진) |
| 피해 | `[30/50/70/90/110]` (+공격력의 **55%**) (+**대상 현재 체력 5%**) |
| 회복 | 입힌 **피해의 30% 회복** |
| 특수 | **최대 출혈 중첩 대상에게 증가 피해**, 적중 시 **3초 내 재사용 가능** |
| 쿨다운 | `12초 → 8초` |

**구현 메모**
- **대상 현재 체력 비례 피해**의 유일한 사례(6인 중). 최대 체력 비례와 계산이 다르니 분리할 것.
- "적중 시 3초 내 재사용" = **차지형 재사용 윈도우**. 쿨다운과 별개 타이머가 필요하다.
- 증가 피해량 수치가 **(미확인)**.

### W — 힘줄 절단

| 항목 | 값 |
|---|---|
| 지정 방식 | **다음 기본 공격 강화** |
| 피해 | `[10/20/30/40/50]` (+공격력의 **20~60%**) |
| 둔화 | `60~80%`, **0.85초** |
| 쿨다운 | 6초 |

**구현 메모**
- 카티야 패시브와 같은 **"다음 기본 공격 강화" 플래그** 구조. 공용화 가능하다.
- 강화 대기 상태의 만료 시간이 **(미확인)**.

### E — 강습

| 항목 | 값 |
|---|---|
| 지정 방식 | **위치 지정 도약 + 착지 범위 피해** |
| (지속) | **처치 시 쿨다운 초기화**, 최대 출혈 대상 기본 공격 시 **쿨다운 −0.5초** |
| 피해 | `[50/90/130/170/210]` (+공격력의 **80%**) |
| 쿨다운 | `16초 → 12초` |
| 사거리 / 반경 | 5.5m / 0.7m |

**구현 메모**
- **쿨다운 초기화 트리거**가 필요하다(처치 이벤트 → 쿨 리셋).
- 반경 0.7m는 매우 좁다. 히트박스를 넉넉하게 잡으면 원작보다 강해진다.

### R — 전기톱 살인마

| 항목 | 값 |
|---|---|
| 지속시간 | `[8/9/10]`초, **킬 관여 시 +5초 연장** |
| 이동 속도 | `[8/10/12]%` 증가 |
| 공격 속도 | `[20/30/40]%` 증가 |
| 재사용 (학살) | 지속 중 재사용 가능 |
| 학살 피해 | `50~100` · `125~250` · `200~400` (+공격력 `40~80%`, **잃은 체력 비례**) |
| 쿨다운 | `[70/65/60]`초 |

**구현 메모**
- **궁 지속 중 다른 스킬로 변형되는 구조**(R → 학살). 스킬 슬롯의 **상태 기반 교체**가 필요하다. 다니엘 R, 시셀라 Q와 같은 계열의 요구사항.
- **자신의 잃은 체력 비례 피해** — 시셀라 R과 동일 계산 경로를 쓴다.
- 지속시간 연장이 **누적되는지 상한이 있는지 (미확인)**.

## 4. 무기 스킬 (D) — 4종 사용 가능

| 무기 | D스킬 | 효과 | 쿨다운 | ⚠12.2 숙련도 변경 |
|---|---|---|---|---|
| **단검** | 은신 단도 | 1~2초 은신, 재사용 시 대상 뒤로 순간이동 | 30 / 25 / 20초 | 기본 공격 증폭 **2.8% → 2.4%** (하향) |
| **양손검** | 패링 | **0.75초 무적** 후 3m 돌진 타격 | 30초 | 기본 공격 증폭 **2.3% → 2.2%** (하향) |
| **도끼** | 피의 나선 | 전방 돌진, 피해의 **60% 회복** | 7 / 6 / 5초 | 기본 공격 증폭 **1.9% → 2.1%** (상향) |
| **쌍검** | 춤 | 돌진 6타, 4타 이상 적중 시 재사용으로 강타 | 30 / 25 / 20초 | 변경 없음 |

> **이 게임의 밸런싱 단위는 "캐릭터"가 아니라 "캐릭터 × 무기" 조합 셀이다.**
> 재키 하나에 4개 셀이 있고, 12.2에서 그중 3개가 각각 다른 방향으로 조정됐다.
> 클론 개발 시 이 구조를 그대로 가져오면 **밸런싱 부담이 캐릭터 수 × 무기 수로 늘어난다.**

> **초기 구현은 도끼 1종만** 권장(공통 규약 §2.5). 단검은 다니엘과 공유하므로 두 번째 우선순위.

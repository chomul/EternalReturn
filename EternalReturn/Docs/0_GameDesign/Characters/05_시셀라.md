> **체력이 낮을수록 패시브가 강해지며**, 궁극기는 **잃은 체력에 비례해 피해가 커진다.**
> 즉 "위험할수록 강해지는" 리스크-리워드 루프이며, **자해 → 보상**의 순환이 하나의 캐릭터 안에서 닫혀 있다.
>
> 구현 관점에서는 **체력 코스트 · 피해 면역 · 그랩(강제 이동) · 소환물(윌슨)** 을 한꺼번에 요구하는
> 6인 중 두 번째로 무거운 캐릭터다.

### P — 삶은 고통이에요

| 항목 | 값 |
|---|---|
| 스케일링 기준 | **현재 체력이 낮을수록 강해짐** |
| 체력 재생 | 최소 `[2/4/6]` → 최대 `[10/20/30]` per sec |
| 스킬 증폭 | 최소 `[4/7/10]` → 최대 `[28/39/50]` |
| R 사용 중 | **패시브 효과 2배 증폭** (`[7/8/9]`초) |

**구현 메모**
- **보간 곡선이 (미확인)이다.** 체력 비율에 대해 선형인지 곡선인지, 최대치에 도달하는 체력 비율이 몇 %인지 확인되지 않았다. **이 캐릭터 밸런스의 핵심 미지수.**
- 스킬 증폭이 실시간으로 변하므로, **스킬 피해 계산 시점의 현재 체력**을 참조해야 한다. 캐싱하면 안 된다.
- ⚠ 출처 충돌: 궁 사용 시 스증 최대치가 "74"라는 서술이 있으나 `50 × 2 = 100`과 맞지 않는다. **(미확인)** 으로 둔다.

### Q — 윌슨! 도와줘

| 항목 | 값 |
|---|---|
| 지정 방식 | **위치 지정** (윌슨을 던짐) |
| 경로 피해 | `[40/50/60/70/80]` (+**30%**) |
| 도착 피해 | `[80/115/150/185/220]` (+**65%**) |
| 쿨다운 | `[8/7/6/5/4]`초 |
| 사거리 | **1 ~ 7.5m** (최소 사거리 존재) |
| **체력 소모** | **40 (고정)** |
| 회수 | 윌슨이 도착 후 돌아오며 **다음 기본 공격을 강화** |

**구현 메모**
- **최소 사거리 1m가 있다.** 사거리 클램프가 상한만이 아니라 하한도 필요하다.
- 윌슨은 **별도 액터**로 관리해야 한다. `던짐 → 비행 → 착탄 → 귀환 → 부착` 상태 머신.
- **윌슨의 부착 여부가 W의 판정을 바꾼다** (아래 참조). 두 스킬이 하나의 상태를 공유한다.

### W — 어딨어 윌슨?

| 항목 | 값 |
|---|---|
| 지정 방식 | **자동** (윌슨 회수) |
| 피해 | `[100/135/170/205/240]` (+**80%**) |
| **피해 면역** | **1.5초간 모든 피해 무시** |
| 면역의 한계 | ⚠ **해로운 효과·방해 효과(CC)는 무시하지 못한다** |
| 이동 속도 | +15% |
| 쿨다운 | `[17/16/15/14/13]`초 |
| **체력 소모** | `[50/60/70/80/90]` |
| 지속시간 / 반경 | 1.5초 / 반경 2m |

**구현 메모**
- **"피해 면역"과 "무적"을 구분해서 구현해야 한다.** 피해만 0으로 만들고 **CC는 정상 적용**된다. 데미지 파이프라인에 면역 체크를 넣되, CC 적용 경로는 건드리지 않는다.
- ⚠ **윌슨이 이미 붙어 있는 상태에서 W를 쓰면 회수 판정이 아니어서 패시브가 발동하지 않는다.** 원작의 함정 설계이며, 구현 시 이 예외를 재현할지 팀이 결정해야 한다.

### E — 나랑 놀자

| 항목 | 값 |
|---|---|
| 지정 방식 | **방향 지정 투사체 → 적중 시 끌어옴(그랩)** |
| 피해 | `[110/125/140/155/170]` (+**70%**) |
| 보호막 | `[60/105/150/195/240]` (+**20%**) — ⚠ **대상이 자신인지 아군인지 (미확인)** |
| 기절 | **0.6초** |
| 쿨다운 | `[11/10.5/10/9.5/9]`초 |
| 사거리 / 폭 | **5.5m × 1.1m** |
| 투사체 속도 | **15 m/s** |
| 체력 소모 | **없음** |

**구현 메모**
- **그랩(강제 이동)의 유일한 사용처.** 넉백(밀어냄)과 반대 방향 이동이라, 공용 강제이동 함수는 **방향 인자를 받아야 한다.**
- 폭 1.1m 캡슐 트레이스. 투사체 속도가 15m/s로 6인 중 가장 느리다 — **회피 가능한 스킬샷**으로 설계돼 있다.
- 쿨다운이 **0.5초 단위**로 감소하는 유일한 스킬(11 / 10.5 / 10 …). 데이터 타입을 정수로 잡으면 안 된다.

### R — 모두 해방이에요

| 항목 | 값 |
|---|---|
| 지정 방식 | **자동 · 반경 20m 전역** |
| 기본 피해 | `[150/200/250]` (+**95%**) |
| **잃은 체력 계수** | **`[2/2.5/3]` 배** |
| 패시브 강화 지속 | `[7/8/9]`초 (패시브 2배) |
| 쿨다운 | `[90/80/70]`초 |
| 효과 범위 | **반경 20m** |
| **자해** | 자신을 포함한 모든 대상에게 피해. 단 **시셀라는 체력이 100 이하로 떨어지지 않는다** |

**구현 메모**
- **반경 20m는 6인 통틀어 최대 범위다.** 실질적으로 "주변 전원 확정 적중"이며 회피 불가.
- **자기 자신에게 피해를 주는 유일한 스킬.** 데미지 파이프라인이 `Instigator == Target` 케이스를 처리해야 한다.
- **체력 하한 100 클램프**가 필요하다. 자살하지 않도록 보장하는 안전장치.
- 잃은 체력 계수의 정확한 계산식이 **(미확인)** — `(최대체력 − 현재체력) × 배수` 로 추정되나 확인 필요.

## 4. 무기 스킬 (D) — 2종 사용 가능

| 무기 | D스킬 | 효과 | 쿨다운 | 계수 |
|---|---|---|---|---|
| **투척** | 연막 | 2.5초 연막, 적 시야 감소 | 40 / 32 / 24초 | 시야 감소 반경 1.5m 고정 |
| **암기** | 마름쇠 투척 | 마름쇠 살포, 피해 + **1.5초 30~50% 둔화** | 30초 | `60/90/120` (+**추가 공격력 65%**[12.2], +스증 20~30%) |

⚠ **12.1에서 시셀라의 암기 숙련도 레벨당 스킬 증폭이 3.9% → 4%로 상향**됐다.
⚠ **12.2에서 암기 마름쇠 투척의 추가 공격력 계수가 50% → 65%로 상향**됐다. 위키 값(50%)은 낡았다.

> **초기 구현은 암기 1종만** 권장(공통 규약 §2.5). 투척의 연막은 시야 시스템이 있어야 의미가 있다.

| **구현 난이도** | **★★★★★ — 반드시 마지막에 만들 것** |

**핵심 설계**
> 레니는 **모든 기본 스킬이 적과 아군에게 동시에 다른 효과를 준다.**
> Q는 적에게 피해 / 아군에게 회복, W는 적에게 둔화 / 아군에게 이동속도, E는 적에게 기절 / 아군에게 보호막.
> 즉 **하나의 스킬 판정이 팀 소속에 따라 두 갈래로 갈라진다** — 다른 5인에게는 없는 요구사항이다.
>
> 그리고 **계수가 스킬 증폭이 아니라 캐릭터 레벨을 따라간다.**
> 스킬 증폭 아이템 의존을 낮추려는 의도이며, 구현상 **별도의 계수 경로**가 필요하다.

## 3. 스킬 명세

> ⚠ **레니의 수치는 출처 간 충돌이 가장 심하다.** 아래 §6에 충돌 목록을 정리했다.
> 확정된 값은 공식 패치노트에서 확인된 것뿐이며, 나머지는 위키 기준(12.2 직전)이다.

### P — 곰돌이! 공격

| 항목 | 값 |
|---|---|
| 표식 부여 | **레니의 기본 스킬이 아군에게 적중하면 곰돌이 표식 생성 (5초)** |
| 표식 효과 | 표식이 달린 아군의 공격에 **추가 피해**, 그리고 **레니의 기본 스킬 쿨다운 감소** |
| 추가 피해 | `[15/25/35]` (+**레니 레벨 × 4**, +스킬 증폭 10%) |
| 쿨다운 감소 | `[0.5/0.75/1]`초 |

**구현 메모**
- **아군에게 붙는 상태(버프)** 이며, **그 아군이 적을 때릴 때 발동**한다. 즉 **제3자 발동 구조**다.
  - 필요한 것: 아군 액터의 상태 컨테이너 + "공격 적중" 이벤트를 **레니에게 되돌리는 경로**.
  - ⚠ 서버에서 표식 소유자(레니)를 역참조해야 한다. 레니가 죽거나 멀리 있을 때 처리 **(미확인)**.
- 추가 피해의 공은 누구에게 가는지(킬 관여 인정 여부) **(미확인)** — 어시스트 판정에 영향.

### Q — 당근! 바주카

| 항목 | 값 |
|---|---|
| 지정 방식 | **논타겟 직선 투사체**, 사거리 끝 도달 또는 대상 적중 시 **폭발** |
| **적** | 피해 `[40/55/70/85/100]` (+**레벨 × 18**, +스증 35%) |
| **아군** | 회복 `[10/20/30/40/50]` (+**레벨 × 2**, +스증 20%) |
| 쿨다운 | `[12/11/10/9/8]`초 |
| 사거리 / 폭 | **7.5m × 1.5m** |
| 폭발 반경 | **2.5m** |

**구현 메모**
- **하나의 투사체가 팀 판정에 따라 피해 또는 회복으로 갈린다.** 적에게 먼저 맞으면 거기서 터지는지, 아군을 관통하는지 **(미확인)**.
- 레벨 계수 **×18**은 6인 중 가장 큰 캐릭터 레벨 계수다. 20레벨이면 +360. **기본 피해보다 레벨 계수가 크다.**

### W — 뿅! 망치

| 항목 | 값 |
|---|---|
| 지정 방식 | **지정 위치 타격** |
| **적** | 피해 `[20/45/70/95/120]` (+**레벨 × 10**, +스증 35%) / 둔화 **40%**(중앙 **80%**), **1.2초** |
| **아군** | ⚠ **이동 속도 `[12/14/16/18/20]%` 증가 (+스킬 증폭의 2.5%)** — 12.2 상향 |
| 쿨다운 | `[16/15/14/13/12]`초 |
| 사거리 | 4.5m |
| 효과 반경 | **1.25m (중앙) / 2.25m (외곽)** |

**구현 메모**
- ⚠ **위키의 아군 이동속도 값(8~12%, +레벨×1)은 낡았다.** 12.2 패치노트 원문이 `12/14/16/18/20 (+스킬 증폭의 2.5%)%` 이며, **이쪽이 맞다.** 계수도 레벨이 아니라 스킬 증폭이다.
- **중앙/외곽 이중 반경**이 필요하다(1.25m 중앙은 둔화 80%, 2.25m 외곽은 40%). 다니엘 Q의 "강화" 판정과 유사한 구조 — 공용화 검토.
- 레니 본인은 **R로 설치한 발판에 W로 뛰어들어** 장거리 이동이 가능하다. **W가 아군 대상 이동 효과를 겸한다.**

### E — 에어 호른! 건

| 항목 | 값 |
|---|---|
| 지정 방식 | **전방 부채꼴 (4.5m × 60°)** |
| **적** | 피해 `[20/40/60/80/100]` (+**레벨 × 9**, +스증 35%) / **기절 0.5초** |
| **아군** | 보호막 `[50/65/80/95/110]` (+**레벨 × 3**, +스증 20%) |
| 쿨다운 | **9초 (고정)** |
| 사거리 / 각도 | 4.5m × **60°** |

**구현 메모**
- 부채꼴 판정은 다니엘 Q(65°)와 공용화 가능.
- 쿨다운이 스킬 레벨과 무관하게 **9초 고정**인 유일한 스킬. 데이터 구조가 배열 고정폭이면 문제없지만, "레벨업하면 쿨이 준다"고 가정한 코드를 쓰면 틀린다.
- **보호막 지속시간 (미확인).**

### R — 스프링! 트랩

| 항목 | 값 |
|---|---|
| 지정 방식 | **설치형 발판** |
| 피해 | `[100/150/200]` (+**레벨 × 12**, +스증 40%) |
| 넉백 | 적을 **지정한 방향으로** 밀어냄 |
| 벽 충돌 | `[40/80/120]` (+스증 20%, **+대상 최대 체력 8%**), **80% 감속 1.5초** |
| 쿨다운 | `[22/20/18]`초 ⚠ **출처 충돌** (다른 출처는 16~20초) |
| 사거리 / 반경 | **7m / 1.5m** |
| 본인 활용 | 레니가 **W로 발판을 향해 뛰어들어 장거리 기동** 가능 |

**구현 메모**
- **설치물(액터) 스폰**이 필요하다. 서버 스폰 + 소유권 + 수명 관리. 지속시간 **(미확인)**.
- **벽 충돌 판정은 매그너스 E와 같은 공용 함수**를 쓴다.
- R → W 콤보(발판 설치 후 뛰어들기)가 이 캐릭터의 기동 핵심이다. **W의 아군 대상 판정에 레니 자신이 포함되는지 반드시 확인할 것 (미확인).**

## 8. 기획 관점 경고

> 커뮤니티 평가상 레니는 **"퓨어 서포터라 자체 전투력이 낮고 아군 의존도가 극단적으로 높은"** 고난도 실험체다.
> 그리고 **"저열한 스킬 기초 성능을 레벨 계수로 정상화하는"** 구조라, 저레벨 구간에서 특히 약하다.
>
> **클론 개발 관점의 판단:** 초기 버전에 서포터가 1명뿐이면 이 캐릭터는 **거의 픽되지 않는다.**
> 아군 대상 스킬 시스템 자체는 반드시 필요하지만, **레니를 6인 중 마지막에 두는 것이 맞다.**
> 앞의 5인이 완성돼야 레니가 검증 가능한 환경(아군이 실제로 싸우는 상황)이 만들어진다.

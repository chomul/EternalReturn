**구현 메모**

- 방어력이 **% 증가**이므로 W의 "추가 방어력 35당 타격 +1"과 얽힌다. **계산 순서를 반드시 먼저 정할 것.**

**구현 메모**
- 타격 횟수가 **런타임 스탯에 의해 변한다.** 시전 시점에 `11 + floor(추가방어력 / 35)` 로 계산한다.
- "추가 방어력"은 기본 방어력을 제외한 아이템·버프 방어력이다. **패시브의 % 증가분이 여기 포함되는지 (미확인)** — 밸런스에 직결되므로 반드시 확인할 것.
- 타격당 쿨다운 −0.5초가 있어 **타격 횟수 ↑ → 쿨 회전 ↑** 로 이중 스케일링된다.
- 4초 채널링 중 이동 가능 여부 **(미확인)**.

**구현 메모**

- 넉백 이동은 서버 권위. 이동 중 매 프레임 지오메트리 충돌을 검사한다.

### R — 폭주 바이크

| 항목 | 값 |
|---|---|
| 피해 | `[100/250/400]` (+추가 공격력 150%, +스킬 증폭 90%, **+대상 현재 체력 30%**) — 게임 툴팁 |
| 근성 중첩 부여 | `[4/7/10]` — **사용 즉시** |
| 쿨다운 | `80초 → 60초` |
| 지속시간 | **7초** |
| 바이크 속도 | **1 → 8 m/s (가속형)** |
| 발사 거리 / 속도 | 9m / 16 m/s |
| 기타 | **이동 방해 면역** |

**구현 메모**
- **탑승·가속 이동 상태**가 필요하다. `CharacterMovementComponent`의 커스텀 무브먼트 모드를 검토한다.
- 속도가 1 → 8 m/s로 **가속**하므로 시간 기반 보간이 필요하다.
- 궁 사용만으로 **근성 중첩이 최대까지 차오른다** = 궁 켜면 방어력 폭증 → W 타격 횟수 증가로 연결된다. **이 콤보 구조를 이해하고 구현할 것.**
- 레벨 2 상세 수치와 충돌 시 효과가 **(미확인)**.

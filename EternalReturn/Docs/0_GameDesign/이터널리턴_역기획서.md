# 1. 개요

## 1.1 한 줄 정의

> **쿼터뷰(탑다운) MOBA의 조작·성장·전투 문법 + 배틀로얄의 매치 구조(축소되는 안전지대·단판 생존) + 생존 크래프팅(재료 파밍 → 장비 조합)을 한 판 안에 융합한 하이브리드 장르.**

Steam 태그가 이 정체성을 그대로 드러낸다: `무료 플레이 / 애니메이션 / MOBA / PvP / 생존 / 멀티플레이어 / e스포츠 / 탑다운 / 액션 / 크래프팅` [S21]

## 1.3 타겟 유저

이 게임의 실제 타겟은 **"MOBA 문법을 이미 아는, 그러나 5v5 라인전의 정형성에 지친 코어 PvP 유저"** 다.

| 세그먼트 | 특징 | 게임이 제공하는 것 |
|---|---|---|
| **1차: MOBA 숙련자** | LoL/도타 이탈·병행층. 조작·아이템·스킬 빌드 이해 보유 | 라인전 없는 MOBA. 매판 다른 전개. 3인 소규모 팀 |
| **2차: 배틀로얄 유저** | PUBG/에이펙스 계열. 생존·수집 루프 선호 | 축소 안전지대, 단판 생존, 파밍 |
| **3차: 서브컬처/캐릭터 소비층** | 애니메이션풍 캐릭터·성우·스킨 | 90명 실험체, 스킨·이모티콘·아카이브(스토리) |
| **4차: e스포츠 관전층** | KEL·Masters 시청 | 옵저버 교전 로그 UI(12.0 신규) [S3] |

**타겟에서 사실상 배제된 층**: 캐주얼 신규 유저. 커뮤니티 지적대로 "학습을 위해 디스코드 가입, 서드파티 사이트(dak.gg) 참조, 커뮤니티 활동이 사실상 요구"되는 구조다 [S26]. → 12장에서 상세 분석.

## 2.1 단계별 유저 행동 · 의사결정 · 긴장도

### ① 로비 / 매치 준비
- **행동**: 실험체 선택 → **무기 계열 선택** → **특성 5개 세팅** → **전술 스킬 선택** → **파밍 루트 로드**(전략 탭에 사전 저장)
- **핵심 의사결정**: *"내가 목표하는 최종 장비 5종 → 그 재료가 나오는 지역 → 지역 순회 순서"* 를 **매치 시작 전에 전부 확정**한다.
- **긴장도**: 낮음. 그러나 **이 게임 진입장벽의 대부분이 여기에 응축**되어 있다(12장).

### ② 시작 지역 선택
- **행동**: 팀 3인이 협의해 시작 지역 지정.
- **의사결정**: "내 루트의 1번 지역 = 시작 지역"이 정석. 상대 팀과 겹치면 초반 교전 리스크 + 루트 전면 재설계.
- **긴장도**: 중. 상대 시작 지역을 모르는 **정보 비대칭 도박**.

### ③ 초반 파밍 (1일차 낮 ~ 2일차 낮, 약 6~7분)
- **행동**
  - 상자 오픈(미니맵 파란 점 표기, **점 5개 = 우선 상자**) [S29]
  - 채집(나뭇가지·돌멩이·꽃·물·감자·대구 등)
  - 야생동물 사냥(닭/박쥐/들개/멧돼지/늑대/곰) → 경험치·재료·크레딧
  - **이동 중 제작** (하이퍼루프 도착 무적 프레임 동안 제작하는 것이 상급 테크닉) [S29]
  - **휴식(X)** 으로 체력/기력 회복
- **의사결정**: 상자 vs 사냥 vs 이동의 시간 배분, 팀원 간 재료 트레이드(Alt+클릭 요청).
- **긴장도**: 낮음 → 점진 상승. 1~2일차 낮까지는 팀원 생존 시 **자동 부활**이라 사망 페널티가 낮다 [S5].
- **설계 의도**: 이 6분은 **MOBA의 라인전(CS 파밍) 구간을 압축 치환**한 것. 단, 상대와 접촉하지 않는 **비동기 파밍**이라는 점이 결정적으로 다르다.

### ④ 중반 교전 (2일차 밤 ~ 5일차, 약 10분)
- **트리거 이벤트** [S5]
  - **2일차 낮 정오** — 키오스크 개방 (크레딧 소비 시작)
  - **2일차 밤** — **알파 2기** 등장 (미스릴 드롭)
  - **3일차 밤** — **오메가** 등장 (포스코어 확정 드롭)
  - **4일차 낮** — VF 혈액 샘플 키오스크 구매 개방 (500 크레딧)
  - **4일차 밤** — **위클라인** 등장 (VF 혈액 샘플 + 아글라이아의 선물-희귀 확정, 생명의 나무/운석/미스릴 중 1종 랜덤 추가)
- **행동**: 오브젝트 콜 → 한타 → 장비 격차 벌리기 / 상대 재료 강탈(사망 시 아이템 드롭).
- **의사결정**: *"오브젝트를 먹을 것인가 / 오브젝트 먹는 팀을 잡을 것인가 / 회피하고 파밍 격차를 낼 것인가."*
- **긴장도**: 급상승. 3일차부터 자동 부활 종료 → **크레딧 200 수동 부활**로 전환되어 사망 비용이 실질화된다 [S5].

### ⑤ 후반 제한구역 압축 (6일차 낮 ~ 7일차)
- **6일차 밤**: 남은 2개 지역에 **임시 안전지대** 지정(잔존 2팀이 서로 다른 구역이면 스킵) [S5], [S3]
- **7일차 낮**: 임시 안전지대 밖은 사망 확정. **하이퍼루프/VLS 사용 불가**, 방화벽 진입자 즉사 [S5]
- **행동**: 안전지대 선점, 부활 카운트 정리, 최종 빌드 완성
- **긴장도**: 최대 직전. "여기서 죽으면 끝"

### ⑥ 최종 전투 — 크로노 스피어 (7일차 밤 ~ 8일차)

12.0에서 **기존 점령전 방식 → 크로노 스피어(Chrono Sphere) 방식으로 전면 교체**되었다 [S3].

| 단계 | 시간 | 반경 |
|---|---|---|
| 1. 안전지대 생성 | 5초 | 30m |
| 2. 1차 축소 | 20초 | 30m → 10m |
| 3. 이동 대기(목표 지점 표시) | 10초 | 10m |
| 4. 이동 | — | 스피어가 목표 지점으로 이동 |
| 5. 2차 축소 | 15초 | 10m → 5m |
| 6. 유지 | 40초 | 5m |
| 7. 3차 축소 | 5초 | 5m → 0m |
| 8. 승리팀 확정 | — | 반경 최대 확장 |

> ⚠출처 불일치: 위키는 1차 축소 후 반경을 **14m**로 기재 [S5]. **공식 12.0 패치노트의 10m를 채택**한다.
> 부가 규칙: 스피어 외부 실험체 자동 폭사 / 비대상 이동기의 차단벽 충돌 처리 / 미니맵·확장맵 범위 시각 강조 [S3].

- **긴장도**: 최대. 반경 5m = 스킬 1~2개 사거리. **회피 공간이 물리적으로 소멸한 초근접 난전**으로 강제 수렴.

## 2.2 코어 루프 요약

```
[로비: 실험체 + 무기 + 특성 + 루트 사전 설계]   ← 진입장벽의 대부분이 여기
        ↓
[시작 지역 선택]
        ↓
[초반 파밍 6~7분: 상자 / 채집 / 사냥 + 이동 중 제작]     ← MOBA 라인전의 치환
        ↓  (2일차 밤 · 알파)
[중반 교전 10분: 오브젝트 콜 → 한타 → 격차 확대]        ← MOBA 오브젝트 사이클

[최종 5m 난전 → 승리팀 확정]
```

**루프의 본질**: *"파밍(비동기 성장) → 오브젝트(동기 충돌 강제) → 구역 압축(공간 박탈)"* 3박자를 25분 안에 3~4회 가속 반복하는 구조.

**12.0 개체 수 조정** [S3]
- 변이 닭 7마리 → **6마리**
- 항구: 멧돼지 −1, 곰 +1

**드롭 규칙**: 각 지역의 야생동물을 처치하면 **해당 지역 장비 제작에 쓰이는 일반 등급 재료 1개**를 드롭한다 [S11]. 닭은 깃털을 드롭 [S11].

## 5.2 스킬 구성 (슬롯 구조)

| 슬롯 | 내용 | 비고 |
|---|---|---|
| **P (패시브)** | 실험체 고유 패시브 | 레벨업으로 자동 강화(대개 3단계) |
| **Q / W / E** | 기본 스킬 3종 | **최대 5레벨** (실험체 스탯 표기가 5구간) |

> **핵심 설계 포인트**: MOBA의 "소환사 주문"에 해당하는 슬롯이 **D(무기) / F(전술)** 두 개로 분리되어 있고,
> **D는 실험체가 아니라 무기가 소유**한다. 같은 실험체라도 무기를 바꾸면 스킬 1개가 통째로 교체된다.
> 이것이 90명 × 다무기군 조합에서 나오는 폭발적인 빌드 다양성의 원천이자, 동시에 밸런싱 난도의 근본 원인이다.
> 실제로 개발팀은 개발 일지에서 **"다무기군 실험체의 밸런스 조정 난도와 개발 효율성 문제"** 를 공식 검토 과제로 언급했다 [S25].

| **R** | 총사의 예법 | 전방 강력 사격. **수정이 있는 적 적중 시 수정 제거·재부여 + 기절** |

> **설계 관찰**: "스킬로 마킹 → 기본 공격으로 회수" 구조는 **스킬 딜러와 평딜의 리듬을 강제로 교차**시키는 최신 설계 트렌드.
> Q가 E로 인해 Q1↔Q2로 변형되는 것은 **한 슬롯에 두 개의 사거리/판정을 담아 무기 스킬 없이도 상황 대응력을 부여**하는 방식이다.

### 5.7.5 무기별 대표 캐릭터 밸런스 조정 사례 (12.2) [S1]

12.2 밸런스 패치는 **"실험체 × 무기 숙련도 계수"** 를 개별 조정한다. 클론 개발 시 반드시 이해해야 할 밸런싱 축이다.

| 실험체 | 조정 |
|---|---|
| 나딘 | 석궁 무기 숙련도 1.3% → **1.2%** |
| 아델라 | 레이피어 숙련도 **상향** |
| 피오라 | 레이피어 숙련도 **하향** |
| 자히르 | 암기 숙련도 **상향** |
| 재키 | 단검/양손검 **하향**, 도끼 **상향** |

> **즉, 이 게임의 밸런싱 단위는 "캐릭터"가 아니라 "캐릭터 × 무기"의 조합 셀이다.**
> 90명 × 평균 2~3무기 ≈ 200개 이상의 밸런싱 셀. 이것이 라이브 운영 부담의 근원.

## 6.2 공식 피해 공식 (공식 고객센터 원문 기반) [S4]

### ① 적용 방어력

```
대상의 적용 방어력 = (대상의 방어력 × (1 − 방어 관통(%))) − 방어 관통(고정)
```

### ② 기본 공격 피해

```
공격력 계산 피해 = (공격력 × 100 / (100 + 대상의 적용 방어력))
                  × (1 + [치명타 발생 시] (0.75 + 치명타 피해 증가(%)))

피해 증가       = 공격력 계산 피해 × (1 + 피해 증가(%) − 대상의 피해 감소(%))

기본 공격 증폭  = 피해 증가 × (1 + 기본 공격 증폭(%) − 대상의 기본 공격 피해 감소(%))

최종 피해량     = (기본 공격 증폭 × 최종 피해 추가(%)) + 최종 피해 추가(고정)

모드 보정 최종  = 최종 피해량 × (1 + 모드 피해 증가(%) − 대상의 모드 피해 감소(%))
```

### ③ 스킬 피해

```
기본 스킬 피해   = 스킬 피해 × 100 / (100 + 대상의 적용 방어력)

피해 증가        = 기본 스킬 피해 × (1 + 피해 증가(%) − 대상의 피해 감소(%))

스킬 피해 감소   = 피해 증가 × (1 − 대상의 스킬 피해 감소(%))

최종 피해량      = (스킬 피해 감소 × 최종 피해 추가(%)) + 최종 피해 추가(고정)

모드 보정 최종   = 최종 × (1 + 모드 피해 증가(%) − 대상의 모드 피해 감소(%))
```

> ※ 스킬의 `스킬 피해`에는 **스킬 기본 피해 + 공격력 계수 + 스킬 증폭 계수**가 합산되어 들어간다.
> ※ **스킬은 치명타가 발생하지 않는다** [S31].

### ④ 고정 피해

```
최종 고정 피해 = 고정 피해 × (1 + 모드 피해 증가(%) − 대상의 모드 피해 감소(%))
```

> **고정 피해는 방어력·피해 감소·증폭 등 어떤 보정도 받지 않고**, 오직 모드 보정만 적용된다 [S4].
> → 탱커 카운터 수단이자, 클론 구현 시 반드시 별도 데미지 타입으로 분리해야 하는 채널.

## 6.3 방어력 감소 곡선

방어력은 **체감 감소(diminishing returns)** 모델이다.

```
피해 감소율 = 1 − (100 / (100 + 적용 방어력))
           = 1 − (1 / (1 + 방어력/100))
```

| 적용 방어력 | 피해 감소율 | 유효 체력 배율 |
|---|---|---|
| 0 | 0% | ×1.00 |
| 50 | 33.3% | ×1.50 |
| **100** | **50.0%** | ×2.00 |
| 150 | 60.0% | ×2.50 |
| 200 | 66.7% | ×3.00 |
| **300** | **75.0%** | ×4.00 |
| 400 | 80.0% | ×5.00 |

출처: [S31], 공식 공식과 수학적으로 일치 [S4].

> **설계적 함의**: 방어력 100당 유효 체력이 **선형적으로 +1배씩** 증가한다.
> 즉 방어력은 "수익 체감"이 아니라 **체력과 곱해질 때 선형 가치**를 가진다.
> → 탱커 빌드에서 "체력 vs 방어력" 균형이 성립하는 이유.

```

# 7. 전투 시스템

## 7.1 데미지 타입

| 타입 | 방어력 적용 | 치명타 | 증폭 적용 | 흡혈 |
|---|---|---|---|---|
| **기본 공격 피해** | O | **O** | 기본 공격 증폭 | 생명력 흡수 / 모든 피해 흡혈 |
| **스킬 피해** | O | **X** | 스킬 증폭 | 모든 피해 흡혈만 |
| **고정 피해 (True Damage)** | **X** | X | **X (모드 보정만)** | 모든 피해 흡혈 (추정, 미확인) |
| **함정 피해** | 피해 감소(%) 적용 | X | — | — |
| **대상 최대/현재 체력 비율 피해** | 스킬 판정에 포함되어 방어력 적용 | X | 스킬 증폭 | — |

> **비율 피해**는 매그너스 W(대상 최대 체력 2.5%/타), E(8%), 재키 Q(대상 현재 체력 5%),
> 채찍 D(12%), 폭발 선인장 특성(5%) 등 광범위하게 존재하며, **고체력 탱커/야생동물 견제용 밸런스 밸브**로 쓰인다 [S16], [S18], [S1].

## 7.2 데미지 계산 순서

```
1. 적용 방어력 산출        : (방어력 × (1 − 관통%)) − 관통(고정)
2. 방어력 완화 적용        : 원피해 × 100/(100 + 적용 방어력)
3. 치명타 판정(기본 공격만)  : × (1 + 0.75 + 치명타 피해 증가%)
4. 범용 피해 증감           : × (1 + 피해 증가% − 대상 피해 감소%)
5. 채널별 증감              : 기본 공격 → × (1 + 기본공격증폭% − 대상 기본공격피해감소%)
                             스킬     → × (1 − 대상 스킬피해감소%)
6. 최종 피해 보정           : × 최종 피해 추가% , + 최종 피해 추가(고정)
7. 모드 보정                : × (1 + 모드 피해 증가% − 대상 모드 피해 감소%)
8. 흡혈 계산                : 최종 피해 × 흡혈% × 감쇠(광역 50% / 야생동물 60%)
```

> **구현 주의**: 4번(범용)과 5번(채널별)이 **분리된 곱연산**이라는 점이 이 게임 밸런스의 핵심이다.
> 아이템 "피해 증가"와 "스킬 증폭"이 서로 곱해지므로 **하이브리드 빌드가 단일 빌드보다 유리해지는 구간**이 생긴다.

> 이것이 "파밍에 실패해도 시간이 지나면 최소한의 복구 수단은 생긴다"는 **하한 보장 장치**로 작동한다.

## 8.7 크래프팅이 코어 루프에 주는 영향

1. **매치 시작 전에 이미 게임의 절반이 끝나 있다.** 목표 장비 5종 → 재료 → 지역 → 동선을 사전 확정해야 하므로, 로비의 "전략 탭"이 실질적인 첫 번째 게임플레이 화면이다.
2. **맵 지식이 곧 실력이다.** 재료가 5~23개 지역에 중복 분포하므로, 상대 팀과 지역이 겹쳤을 때 **대체 루트를 즉석에서 재계산**할 수 있는가가 실력 격차를 만든다.
3. **교전 동기를 만든다.** 사망 시 아이템 드롭 → 상대를 죽이면 내 제작 트리를 건너뛸 수 있다. 즉 **크래프팅이 PvP의 보상 구조 자체**다.
4. **파워 스파이크를 계단식으로 만든다.** MOBA의 "코어템 완성" 개념이 그대로 이식되어, 전설 장비 1개 완성 시점마다 교전 우위가 급변한다.
5. **동시에 최대 진입장벽이다.** 개발팀도 개발 일지에서 **"전설 장비 제작 재료 수집의 진입장벽 문제"** 를 공식 검토 과제로 명시했다 [S25].

## 9.2 숙련도(Proficiency) — 이 게임의 두 번째 성장축

**6종의 숙련도**가 레벨과 별개로 존재하며, 각각 다른 행동으로 성장한다 [S5], [S28].

### 9.2.1 무기 숙련도 (가장 중요)

| 항목 | 값 |
|---|---|
| 상승 효과 | 레벨마다 **공격 속도(%)** + (**기본 공격 증폭(%)** 또는 **스킬 증폭(%)**) 중 1개 + 공격력 |
| 무기 스킬 해금 | **5레벨부터 D스킬 사용 가능**, **10레벨 / 15레벨에서 강화** |
| 실험체별 계수 | 실험체 × 무기 조합마다 다른 계수 (예: 나딘 석궁 1.2%) [S1] |

**경험치 획득**

| 행동 | 획득량 |
|---|---|
| 실험체에게 피해 100당 | **63** |
| 야생동물에게 피해 100당 | 5 |
| 실험체 처치 | 100 |
| 무기 제작 (등급 1~5) | 100 / 200 / 350 / 550 / 800 (**최초 제작 시 +25%**) |

### 9.2.2 나머지 5종 숙련도

| 숙련도 | 레벨당 효과 | Lv2 필요 EXP | 이후 증가 | 주요 획득처 |
|---|---|---|---|---|
| **방어** | 기본 공격 피해 **−1%**, 스킬 피해 **−0.8%** | 230 | +270 | 실험체 피해 100당 60 / 함정 피해 100당 20 / 동물 피해 100당 10 / 실험체 처치 시 (80 − 상대 레벨×?) 최소 50 / **머리 방어구 제작 100·200·350·600·1000** |
| **사냥** | 야생동물 피해 **+2%** | 180 | +200 | 동물에게 받은 피해 100당 10 / 동물에게 준 피해 100당 35 |
| **제작** | 비전투 체력 재생 **+10%** (최대 +200%) | 430 | +120 | 모든 방어구·무기 제작 100·200·350·600·1000 / 음식 제작 50·120·200·360·406 |
| **탐색** | 시야 **+0.01** | 350 | +60 | 항공 보급 개봉 350 / 아이템 상자 개봉 70 / 채집 100 / 보안 콘솔 활성화 100 / 카메라·드론 제작 62~625 |
| **이동** | 이동 속도 **+0.01** | 300 | +20 | 지역 이동 180 / 50m 이동당 55 / **다리 방어구 제작 100·140·250·500·800** |

> **설계 관찰**: 숙련도는 **"플레이 스타일을 스탯으로 환전하는 시스템"** 이다.
> 사냥만 해도 사냥 숙련도가 올라 사냥이 더 빨라지고, 이동만 해도 이동 속도가 오른다.
> → **선형 보상 루프**를 6개 병렬로 깔아, 어떤 행동을 해도 "성장하고 있다"는 감각을 준다.
> 다만 이것은 동시에 **신규 유저가 파악해야 할 시스템 6개 추가**를 의미하기도 한다.

## 9.3 파워 스파이크 구간

| **후반 평탄화** | 7~8일차 | 성장 종료. 이후는 순수 실력 + 포지셔닝 싸움 |

# 12. 기획적 분석

## 12.1 MOBA + 배틀로얄의 구조적 충돌과 이 게임의 해결책

두 장르는 **근본 전제가 서로를 부정한다.**

| 축 | MOBA | 배틀로얄 | 충돌 |
|---|---|---|---|
| 조우 빈도 | 라인/정글로 **상시 강제 조우** | 넓은 맵에서 **회피가 최적 전략** | 회피가 이득이면 MOBA의 성장 격차 게임이 성립 안 됨 |
| 성장 | 결정론적 (CS·경험치 곡선 고정) | 확률적 (루팅 운) | 실력 vs 운의 비중이 충돌 |
| 매치 길이 | 30~40분, 역전 가능 | 20~30분, 단판 | 스노볼 처리 방식이 정반대 |
| 사망 | 리스폰(비용=시간) | 영구(탈락) | 실수 허용치가 정반대 |
| 팀 규모 | 5인, 역할 분업 | 1~4인 | 조합 설계 난도 |

### 이 게임의 5가지 해결책

**① 오브젝트 등장 시각 = 강제 조우 스케줄러**

가장 결정적인 설계. 알파(2일차 밤) → 오메가(3일차 밤) → 위클라인(4일차 밤) → 초월 보급(4일차 밤)이
**파워 스파이크와 정확히 동기화**되어 있다(9.3절). 회피가 최적 전략이 되는 순간을 없애기 위해,
**"성장하려면 반드시 정해진 시각에 정해진 좌표로 나와야 한다"** 는 규칙을 넣었다.
배틀로얄의 회피 인센티브를 MOBA의 오브젝트 콜로 덮어쓴 것.

**② 자동 부활 → 유료 부활 → 부활 불가의 3단 계단**

MOBA는 리스폰, 배틀로얄은 탈락. 이 게임은 **시간축을 따라 둘 사이를 미끄러진다.**
1~2일차 자동 부활(=MOBA) → 3~5일차 크레딧 200 부활(=비용 있는 리스폰) → 6일차 밤 이후 탈락(=배틀로얄).
**초반은 MOBA로, 후반은 배틀로얄로 게임의 장르가 바뀐다.** 이것이 이 게임 설계의 가장 우아한 부분이다.

**③ 크래프팅 = 확률적 루팅의 결정론화**

배틀로얄 루팅은 운이다. 이 게임은 **"어느 지역에서 어떤 재료가 나오는지 100% 고정"** 시키고,
운은 오직 "상대와 겹치는가"에만 남겼다. 즉 **루팅 운을 경로 계획 실력으로 치환**했다.
이것이 이 게임이 e스포츠 종목으로 성립하는 이유다.

**④ 3인 스쿼드 = 역할 분업의 최소 단위**

5인은 배틀로얄 맵에서 너무 크고, 1인은 MOBA 조합이 성립하지 않는다.
3인은 **탱커+딜러+서포터**라는 최소 조합을 성립시키면서도 파밍 동선이 분산되지 않는 임계점이다.

**⑤ 크로노 스피어 = 자기장의 MOBA화**

12.0에서 도입. 배틀로얄 자기장은 "공간 박탈"만 하지만, 크로노 스피어는
**반경 30m → 10m → (이동) → 5m** 로 **위치가 이동**한다.
이는 자기장을 "축소되는 원"이 아니라 **"이동하는 오브젝트 = 한타 지점"** 으로 재정의한 것이다.
5m 반경은 MOBA 한타의 표준 교전 반경과 같다.

## 12.2 크래프팅이 만드는 "파밍 경로 사전 계획" 메타의 의도

### 무엇이 일어나는가

로비 "전략" 탭에서 유저는 다음을 **매치 시작 전에** 확정한다:
1. 최종 목표 장비 5종(무기1 + 방어구4)
2. 각 장비의 재료 트리 역추적
3. 재료가 나오는 지역 집합
4. 지역 순회 순서 + 하이퍼루프 타이밍
5. 각 지역에서의 예상 체류 시간

### 왜 이렇게 설계했는가 — 5가지 의도

**① 매치 밖에서도 게임이 계속되게 한다 (세션 외 인게이지먼트)**
25분짜리 매치 게임의 최대 약점은 "접속하지 않으면 게임이 멈춘다"는 것이다.
루트 설계는 **오프라인에서도 할 수 있는 메타게임**이다. dak.gg에서 루트를 보고, 커뮤니티에서 빌드를 논쟁하는
행위 자체가 리텐션이다. (동시에 이것이 12.4절의 진입장벽 문제의 원인이기도 하다.)

**② 배틀로얄 루팅 운을 실력으로 환전한다**
"어디에 무엇이 있는지 안다"는 정보 우위를 **암기 가능한 결정론적 지식**으로 만들어,
"운이 좋아서 이겼다"는 서사를 제거했다. e스포츠 성립의 전제 조건.

**③ 지역 충돌을 전략적 자원 경쟁으로 만든다**
루트가 겹치면 상대의 재료를 뺏거나, 내 루트를 포기해야 한다.
즉 **"파밍 = PvP"** 라는 등식이 성립하고, 이것이 초반 교전 동기를 만든다.
전통 배틀로얄에서 초반 교전은 순수 손해지만, 여기서는 **재료 획득 + 상대 빌드 파괴**의 이중 이득이다.

**④ 캐릭터 숙련이 아니라 "게임 숙련"을 요구한다**
LoL은 챔피언 하나만 파도 티어를 올릴 수 있다. 이 게임은 **90명이 어떤 재료를 노리는지 알아야**
상대 동선을 예측할 수 있다. 즉 숙련의 대상이 캐릭터가 아니라 **게임 전체의 메타 지식**이다.
이는 코어 유저의 몰입도를 극대화하지만, 신규 유저에게는 벽이다.

**⑤ 패치 한 줄로 메타를 흔들 수 있다**
12.0에서 "키오스크를 바지선 → 공장으로 이전", "큐브를 연구소 외 지역에서 제거"만 해도
수십 개의 루트가 무효화된다. **라이브 운영 레버가 매우 저렴하다.**

### 부작용

- 사전 계획을 세우지 않은 유저는 **매치 시작 3분 만에 게임에서 진다.** 그것도 상대를 만나기 전에.
- "정답 루트"가 커뮤니티에 공유되면 **전략적 다양성이 오히려 축소**된다.
- 개발팀 스스로 **"전설 장비 제작 재료 수집의 진입장벽"** 을 공식 검토 과제로 올렸다 [S25].

## 12.3 진입장벽이 높은 원인

### 원인 진단 — 학습해야 할 시스템의 절대량

신규 유저가 "제대로 한 판"을 하기 위해 알아야 할 것:

| 6 | 아이템 | 6등급 × 5슬롯 × 23무기군의 제작 트리 |
| 7 | 재료 | 일반 재료만 **35종**, 지역 분포 암기 |

→ **12개 시스템을 동시에 학습해야 첫 승리가 가능하다.**
커뮤니티의 진단이 정확하다: *"시스템이 너무 많아서 대부분의 사람이 감당하지 않을 학습 곡선을 만든다"*,
*"디스코드 가입, 커뮤니티 활동, 서드파티 사이트 의존까지 모든 단계가 능동적으로 유저를 걸러낸다"* [S26].

### 추가 가중 요인

- **매치 길이 25분**: 한 번 실수하면 25분을 손해 본다. 학습 사이클이 느리다.
- **3인 팀**: 내 실수가 팀원 2명에게 직접 전가된다. 사회적 압박.
- **매칭 격차**: "신규와 프로가 같은 방에 들어가고, 대개 가장 숙련된 플레이어가 게임을 지배한다" [S26]

| **Alt + M 파밍 위치 오버레이 / F8 토글** | 재료 → 지역 역추적을 UI가 대행 | **가장 효과적.** 암기 부담을 UI로 흡수 |

| **전략 탭 (루트 사전 저장)** | 로비에서 루트를 미리 설계·저장 | 매치 중 인지 부하 감소 |
| **봇 로비** | 신규 유저 초기 배정 [S26] | 학습 공간 제공, 그러나 실전 이행 시 괴리 |
| **코발트 프로토콜(4v4)** | **파밍·제작을 통째로 삭제**한 모드 | **가장 과감한 완화책.** 12개 시스템 중 절반을 제거하고 전투만 학습시키는 온보딩 트랙 |
| **연습 모드 개선 (12.2)** | 단축키, `Ctrl+Alt+우클릭` 즉시 이동 | 콤보 학습 지원 |
| **휴식 시스템 개편 (12.0)** | "전투 여부와 무관하게 사용 가능"으로 **직관성 강화**가 명시된 의도 [S23] | **실패.** 커뮤니티 투표 87%가 롤백 요구, 12.1에서 즉시 재조정 |
| **12.1 초반 경험치 완화** | 1→2레벨 900→800, 5→6레벨 2700→2500 | 초반 격차 완화 |
| **12.2 여분 재료 파란색 강조** | 후반 제작 재료 시인성 | 인지 부하 감소 |

### 휴식 시스템 개편 실패 사례 분석 (중요한 교훈)

12.0 개편의 **명시된 의도는 "초보자가 언제 휴식을 쓸 수 있는지 쉽게 파악하도록"** 이었다 [S23].
그러나 결과는 **템포 저하 + 캐스팅 대기 스트레스**였고, 커뮤니티 투표 87%가 롤백을 요구했다 [S22].

> **교훈**: **"신규 유저의 인지 부하를 줄이려는 개편이, 숙련 유저의 조작 리듬을 파괴하면 실패한다."**
> 개발팀은 12.1에서 **"비전투 자동 회복(신규 친화) + 캐스팅 휴식(숙련자 리듬)"** 을 **병존**시키는 방식으로 봉합했다 [S2].
> 이것이 정답에 가깝다: **온보딩 장치는 기존 시스템을 대체하는 게 아니라 병렬로 추가해야 한다.**

## 12.4 라이브 서비스 관점의 리텐션 구조와 약점

### 리텐션 구조 (잘 작동하는 것)

| 레이어 | 장치 | 주기 |
|---|---|---|
| **일 단위** | 일일 미션(A-Coin), **시즌 출석부 28일** | 매일 |
| **주 단위** | ER 패스 **주간 미션 8주 차**(매주 목요일 12시 오픈) | 매주 |
| **격주** | **2주 패치 사이클**(밸런스 + 스킨 + 실험체) | 2주 |
| **시즌 단위** | 시즌팩 / 랭크 리셋 / 랭크 보상(NP 직접 지급) / 아카이브 신규 에피소드 | 3~4개월 |

**특히 강한 지점**
- **랭크 보상으로 NP를 직접 지급**(다이아 300 / 메테오 500 / 미스릴 800 / 데미갓·이터니티 1,200).
  → 실력이 곧 재화가 되는 구조로, 코어 유저의 "이 게임에 시간을 쓰는 이유"를 강화한다.
- **ER 패스 최고 레벨 보상 900 NP ≒ 다음 시즌 패스 얼리버드 890 NP.**
  → 완주한 유저는 사실상 영구 무료로 패스를 이어갈 수 있다. 강력한 락인.
- **약 2주 주기의 밸런스 패치**로 메타가 계속 움직인다. 12.2 한 번에 **30명 이상의 실험체**가 조정되었다 [S1].

### 약점 (구조적 리스크)

**① 유입 파이프라인이 사실상 막혀 있다**
Steam 30일 평균 동시접속 약 9,140명 [S27]은 안정적이지만 성장 곡선이 아니다.
12.3절에서 분석한 12개 시스템 학습 부담 + "숙련자가 지배하는 매칭" 구조 [S26]가
신규 유입을 상단에서 차단한다. **리텐션은 좋고 어콰이지션이 나쁜 전형적 코어 게임 프로파일.**

**② 3인 팀 = 매칭 풀 파편화**
스쿼드(3인) / 코발트(4v4) / 론울프(솔로 18) / 유니온(3~4인)으로 풀이 갈린다.
실제로 12.0에서 **아시아1 외 서버는 랭크 매칭을 일시적으로 닫아야 했다** [S3].
**론 울프를 "시간대 한정"으로 운영하는 것 자체가 매칭 풀 부족의 증거**다 [S15].
→ 글로벌 서비스에서 지역별 인구 임계점 미달 리스크가 상시 존재한다.

**③ 밸런싱 셀이 200개 이상**
90 실험체 × 평균 2~3 무기군 = 200+ 조합. 여기에 **코발트 전용 보정치까지 별도 운영**한다 [S1].
2주마다 30개 이상을 손보는 것은 지속 가능한 부하가 아니다.
개발팀도 **"다무기군 실험체의 밸런스 조정 난도와 개발 효율성"** 을 공식 과제로 인정했다 [S25].

**④ 대규모 개편의 실패 비용이 크다**
- 시즌 8 스킬 가속 도입 → 개발팀 공개 반성문 [S25]
- 시즌 12 휴식 개편 → 커뮤니티 87% 롤백 요구 → 1주 만에 재조정 [S22], [S2]
코어 유저 비중이 높은 게임에서 **핵심 조작 리듬을 건드리는 개편은 즉시 이탈로 이어진다.**

**⑤ BM이 코스메틱 단일 축**
스킨·패스·실험체 판매 외 수익원이 없고, 랭크 보상으로 NP를 뿌리는 정책은
**코어 유저의 결제 필요성을 오히려 낮춘다.** 리텐션에는 좋지만 ARPU에는 불리한 트레이드오프.

**⑥ 긍정 신호도 명확하다**
- Unity 6 엔진 교체는 **"환골탈태"** 라는 평가와 함께 고사양 PC 120fps 안정화 [S22]
- 문체부 이스포츠 전문 종목 지정 + KEL/Masters 정례화 [S30]
- 크래프톤 진영 편입(넵튠 인수)으로 **e스포츠·퍼블리싱 시너지 기대** [S30]

## 12.5 클론 개발 시 구현 우선순위

### 반드시 구현해야 할 핵심 3가지

---

#### 【1순위】 오브젝트 스케줄러 = "성장과 조우를 시각으로 동기화하는 타임라인 시스템"

**왜 1순위인가**: 이것 없이는 MOBA+배틀로얄이 성립하지 않는다.
회피가 최적 전략이 되는 순간 게임이 "숨바꼭질"로 붕괴한다.

**최소 구현 사양**
```
- 매치 타임라인(일차 × 낮/밤) 상태 머신
- 페이즈별 이벤트 큐: 오브젝트 스폰 / 금지구역 확장 / 부활 규칙 전환 / 키오스크 개방
- 필드 보스 3종(초반/중반/후반) + 각각 고유 성장 재료 확정 드롭
- 보스 등장 시각 = 유저 파워 스파이크 시각과 정렬
- 축소되는 최종 안전지대(반경 30m → 10m → 5m 3단 축소)
```

**검증 기준**: 매치의 **60% 이상에서 보스 스폰 시각 ±30초 내에 교전이 발생**하는가.
발생하지 않으면 보스 보상 가치가 부족하거나 스폰 위치가 나쁜 것이다.

---

#### 【2순위】 결정론적 크래프팅 = "지역 ↔ 재료 매핑 + 제작 트리 + 루트 사전 설계 UI"

**왜 2순위인가**: 이것이 이 게임의 **유일무이한 차별점**이다.
전투만 만들면 그냥 탑다운 MOBA고, 자기장만 넣으면 그냥 배틀로얄이다.
**"파밍 경로 계획"이 이 장르의 IP다.**

**최소 구현 사양**
```
- 지역 N개 × 재료 M종의 결정론적 스폰 테이블 (확률 아님, 고정)
- 재료 2개 조합 기반 제작 트리 (등급 4~6단)
- 장비 슬롯 5칸(무기1 + 방어구4)
- 【필수】 확장맵 오버레이: 목표 아이템 → 필요 재료 → 재료 위치 자동 하이라이트
- 【필수】 로비 루트 플래너: 목표 빌드 저장 → 지역 순서 저장 → 매치 로드
- 동적 대체 아이템 추천(보유 재료 기반)
```

**검증 기준**: 신규 유저가 **튜토리얼 없이** 확장맵 오버레이만 보고
"내가 지금 어디로 가야 하는지"를 **5초 안에** 판단할 수 있는가.

> **경고**: 오버레이 UI를 나중에 만들겠다고 미루면 안 된다.
> 크래프팅 시스템과 **동시에** 만들어야 한다. 오버레이 없는 크래프팅은 암기 지옥이다.

---

#### 【3순위】 무기 계열 시스템 = "캐릭터가 아니라 무기가 스킬을 소유하는 구조"

**왜 3순위인가**: 캐릭터 수를 늘리지 않고 **빌드 다양성을 폭발**시키는 가장 저렴한 수단이다.
캐릭터 20명 × 무기 3종 = 60개의 플레이 경험. 캐릭터 60명을 만드는 것보다 압도적으로 싸다.

**최소 구현 사양**
```
- 무기 계열 6~8종으로 시작 (23종은 과함)
- 계열별 고유 D스킬 1개
- 무기 숙련도: 레벨 5 → D스킬 해금 / 10 · 15 → 강화
- 캐릭터별 사용 가능 무기군 1~3개
- 캐릭터 × 무기 조합별 숙련도 계수(밸런싱 파라미터)
```

**검증 기준**: 같은 캐릭터를 **무기를 바꿔** 플레이했을 때
플레이 감각이 "다른 캐릭터"로 느껴지는가.

---

### 권장 개발 순서 (마일스톤)

```
M1 (프로토타입) — "탑다운 전투가 재미있는가"
   ├ 캐릭터 3명 (탱커/딜러/서포터) × 무기 1종
   ├ Q/W/E/R + 패시브
   ├ 데미지 공식 (방어력 100/(100+DEF) 모델 + 고정 피해 채널)
   └ 검증: 3v3 데스매치가 10분 이상 재미있는가

M2 (코어 루프) — "파밍 → 성장 → 교전이 돌아가는가"
   ├ 지역 8개 × 재료 12종 결정론 매핑
   ├ 제작 트리 4단 (일반→고급→희귀→전설)
   ├ 장비 슬롯 5칸
   ├ 【필수】 확장맵 파밍 위치 오버레이

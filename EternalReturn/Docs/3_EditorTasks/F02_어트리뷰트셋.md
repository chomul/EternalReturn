### ⭐ 모디파이어 33줄 — 순서가 중요하다

**Modifiers** 배열에 33개를 아래 **순서 그대로** 추가한다. 각 줄마다:

| 필드 | 값 |
|---|---|
| `Attribute` | 표의 어트리뷰트 (`ERAttributeSet.` 으로 시작한다) |
| `Modifier Op` | **`Override`** |
| `Modifier Magnitude > Magnitude Calculation Type` | **`Set By Caller`** |
| `Set By Caller > **Data Tag**` | 표의 태그 |

> ⚠ **`Data Name` 이 아니라 `Data Tag` 다.**
> `Data Name` 은 `VisibleDefaultsOnly` 라 **보이기만 하고 `None` 에서 안 바뀐다**
> (`GameplayEffect.h:253-255`). 편집 가능한 건 `Data Tag` 뿐이다.
> 기록: [`../5_ErrorReport/E06_SetByCaller_DataName_편집불가.md`](../5_ErrorReport/E06_SetByCaller_DataName_편집불가.md)

> 33개는 C++ 에 이미 선언돼 있으니 **목록에서 고르기만 하면 된다.**

# ② 테스트 — PIE 로 확인만 한다

> 여기서는 **아무것도 바꾸지 않는다.** 로그를 보고 판정만 한다.

## 2-1. ⭐ GE 애셋 검사 통과 확인 — 이걸 먼저 한다

- [x] **Play (Selected Viewport), Number of Players: 1**
- [x] Output Log 에서 `초기스탯` 검색

**성공 판정:** `[초기스탯] ... Error` 가 **한 줄도 없다.**

**에러가 있으면** 그 줄이 문제를 정확히 알려준다:

| 로그 | 뜻 | 고칠 곳 |
|---|---|---|
| `모디파이어가 N 개다. 33 개여야 한다` | 줄이 빠졌거나 남았다 | 1-2 |
| `Modifiers[7] 의 어트리뷰트가 'X' 다. 'Defense' 여야 한다. (순서 포함)` | **순서가 틀렸다** | 1-2, 7번 줄 |
| `연산이 Override 가 아니다` | `Modifier Op` | 1-2 |
| `Magnitude 가 Set By Caller 가 아니다` | `Magnitude Calculation Type` | 1-2 |
| `Data Tag 가 비어 있다` | 태그를 안 골랐다 | 1-2 |
| `Data Tag 가 'X' 다` | 다른 태그를 골랐다 | 1-2, 해당 줄 |
| `Duration Policy 가 Instant 가 아니다` | GE 설정 | 1-2 |
| `Character Data 가 비어 있다` | BP 연결 안 됨 | 1-3 |

## 2-2. 값이 실제로 들어갔는가

- [x] 같은 PIE 에서 로그 확인

**성공 판정:** 아래 한 줄이 나온다.

```
[초기스탯] BP_ERCharacterBase_C_0 적용 — MaxHP=1000 MaxVP=500 AttackPower=100 Defense=50 MoveSpeed=3.50
```

- [x] 콘솔에 `showdebug abilitysystem` 입력
- [x] `HP` 가 **1000 / 1000** 이다 (`HP == MaxHP`)
- [x] `MoveSpeed` 가 **3.5** 다 (0 이나 1.0 으로 잘리지 않았다)
- [x] `AttackSpeed` 가 **1.0** 이다

**실패로 보이는 것:** `HP` 가 **0** 이면 → `MaxHP` 가 `HP` 뒤에 있다 (1-2 순서)

## 2-3. ⭐ 클라이언트에도 보이는가

- [x] **Net Mode: `Play As Client`, Number of Players: 2**
- [x] 클라 창에서 `showdebug abilitysystem`

- [x] 클라에서도 `HP` 가 **1000 / 1000** 이다
- [x] ⭐ 클라 로그에 **`[초기스탯] ... 적용`** 이 **없다** — 서버에서만 돌아야 한다
- [x] 클라 로그에 `서버가 아닌 곳에서 불렸다` 가 **없다**

## 2-4. 하드코딩이 아닌지

- [x] PIE 종료 → `DA_TestDummy` 의 `Base Stats > Max HP` 를 `1234` 로 변경 → 저장
- [x] 다시 PIE

**성공 판정:** 로그에 `MaxHP=1234` 가 나온다.

- [x] 확인 후 `1000` 으로 되돌린다

## 2-5. 재초기화가 안 되는지

- [x] PIE 중 콘솔: `ce Restart` 또는 캐릭터를 다시 Possess 시키는 조작
- [x] 로그에 `[초기스탯] ... 적용` 이 **한 번만** 나온다

**실패로 보이는 것:** 두 번 나오면 `bDefaultStatsApplied` 빗장이 안 걸린 것이다.

# ③ 미뤘던 검증 + F02-06 — ⭐ 한 세션에서 끝낸다

> F03 이 끝나 `ER.Damage.Test` 가 생겼다. 여기서 미뤄뒀던 것을 전부 확인한다.

⚠ **에디터 재시작 필요 없음** (새 타입 없음). PIE 만 켜면 된다.

## 3-1. ⭐ E04 — 사망 알림이 한 번만 나오는지

**내가 고쳐놓고 한 번도 실행 검증을 못 한 결함이다.**

```
ER.Attr.Watch HP
ER.Damage.Test 100000 0
ER.Damage.Test 100000 0
```

- [x] 첫 번째에서 `[구독] ⭐ 사망 알림 - 가해자=...` 가 **한 줄** 나온다
- [x] ⭐⭐ **두 번째에서는 사망 알림이 안 나온다**
  ⚠ 두 번 나오면 `bOutOfHealth` 빗장이 안 걸린 것 → 킬 로그·경험치가 중복 지급된다

## 3-2. ⭐ F02-04 — Meta 가 안 남는지

```
ER.Damage.Test 200 100
ER.Damage.Test 200 100
```

- [x] 두 번 다 `실제=100.00`
  ⚠ 두 번째가 200 이면 `SetIncomingDamage(0.f)` 가 안 된 것

## 3-3. F02-03 — 피해 감소 150% 에서 회복이 안 되는지

```
ER.Damage.SetStat DamageDown 1.5
```

- [x] 로그에 **`클램프되어 0.800`** 이 나온다 (1.5 가 그대로 안 들어간다)

```
ER.Damage.Test 200 0 skill
```

- [x] 피해가 **40** (200 × 0.2). ⚠ **음수(회복)가 아니다**
- [x] 끝나면 `ER.Damage.SetStat DamageDown 0`

## 3-4. F02-04 — 지속 버프에서는 `PostGameplayEffectExecute` 가 안 불리는지

```
ER.Attr.Watch AttackPower
ER.Damage.BonusTest 100 50 0
```

- [x] `[구독] AttackPower : 100.00 -> 150.00` 이 나온다 (Infinite 버프가 걸렸다)
- [x] ⭐ 그때 **사망 알림이나 피해 처리 로그가 안 난다**
  근거: `AttributeSet.h:199-200` — *"It is not called during an application of a GameplayEffect,
  such as a 5 second +10 movement speed buff"*

## 3-5. F02-06 — 구독이 동작하는지

```
ER.Attr.Watch HP
ER.Damage.Test 200 0 skill
```

- [x] `[구독] HP : 2000.00 -> 1800.00` 처럼 **변화가 로그로 나온다**

### ⭐ 어트리뷰트 단위로 구독되는지

```
ER.Damage.SetStat AttackPower 123
```

- [x] ⭐ **`HP` 만 구독 중이므로 로그가 안 난다**
  ⚠ 나오면 어트리뷰트 단위 구독이 아니라 전체 구독이 된 것

### ⭐ 구독 해제가 실제로 되는지

```
ER.Attr.Unwatch
ER.Damage.Test 200 0 skill
```

- [x] `[구독] N 건 해제` 가 나온다
- [x] ⭐ **그 뒤로 `[구독] HP : ...` 이 안 나온다**
  ⚠ 계속 나오면 해제가 안 된 것 — dangling 델리게이트가 남는다

## 3-6. ⭐ 클라에서도 델리게이트가 발동하는지 — `Play As Client, 2인`

⚠ **여기부터는 Net Mode 를 바꿔야 한다.** `Play As Client, Number of Players: 2`

- [x] **클라 창**에서 `ER.Attr.Watch HP`
  → `[구독] HP 구독 시작 (클라)` 가 나온다
- [x] **서버 창**에서 `ER.Damage.Test 200 0 skill`
- [x] ⭐ **클라 창에 `[구독] HP : ...` 이 나온다**
  이게 UI 가 클라에서 동작하는 근거다

⚠ 클라에서 `ER.Damage.Test` 를 치면 `"서버가 아니다"` 가 나온다 — 정상이다.

## 3-7. E05 — 클라 권위 가드

```
(클라 창) ER.Attr.Watch MaxHP
(서버 창) ER.Damage.SetStat MaxHP 5000
```

- [x] 클라에 `MaxHP : 2000 -> 5000` 이 온다
- [x] ⭐ **Error 로그가 없다**
  ⚠ `[초기스탯] 서버가 아닌 곳에서 불렸다` 나 크래시가 나면 권위 가드가 깨진 것

## 주의점

- ⚠ **에디터 재시작을 빼먹으면** `ER 실험체 데이터` 가 데이터 애셋 클래스 목록에 안 뜬다
- ⚠ **`Data Name` 은 편집할 수 없다.** `Data Tag` 를 쓴다 — 값이 전부 0 이 되는 원인 1위 (E06)
- ⚠ **`MoveSpeed` 단위는 m/s** 다. 350 같은 언리얼 단위(cm/s)를 넣으면 상한 12 로 잘린다
- ⚠ 이 GE 는 `Override` 다. **전투 중에 다시 걸면 체력이 만피로 돌아간다** — 그래서 코드에 빗장이 있다

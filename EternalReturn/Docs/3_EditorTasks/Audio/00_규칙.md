# 소리 배치표 — 규칙

캐릭터마다 파일 하나 (`Audio/<캐릭터>.md`) · 표 하나에 그 캐릭터 소리 전부 (`# · 소리 · 어디서 · 이유 · 상태`).
**사용자가 표의 `어디서` 칸을 고치면 → Claude 가 그 내용대로 코드 · Fill · 노티파이 작업표를 맞추고 `상태` 칸을 갱신한다.**
Fill 의 소리 표 · 애니 규칙은 `Data/Presentation/<캐릭터>.json` (2026-10-07 — C++ 에서 옮김 · 고치면 `ER.Pres.Fill <캐릭터> Force` 만, 빌드 불필요).

## 어디서 나는가 — 세 갈래 (Argument 59 · 사용자 제공 정리 2026-10-02)

| `어디서` 칸 | 뜻 | 누가 작업 |
|---|---|---|
| `코드 (… 큐)` | 서버 판정 결과로 난다 — 발사(판정 순간) · 적중 · 강화 걸림 · 스캔에 잡힘 … **게임 결과를 알아야 하는 소리** | Claude (코드 · Fill 규칙) |
| `코드 (… 큐 · N발)` | 위와 같고 순차 사격의 **몇 번째 발**로 고른다 (`_02` · `_03`) | Claude |
| `노티파이 (<애니>)` | 애니의 그 프레임에 난다 — 조준 · 스캔 동작 · 장전 … **동작에만 붙는 소리**. 노티파이 `ER 소리 (스킨 교체)` | 사용자 (애니 에디터에서 찍기) |
| `액터` | 물체가 있는 동안 난다 — 투사체 비행음 · 장판 루프 | Claude (액터 코드) + 사용자 (BP 지정) |
| `안 씀` | 쓰지 않는다 | — |
| `보류` | 기능이 아직 없다 (예: W → F16) | — |

⚠ **한 소리는 한 갈래만.** 큐로 나는 소리를 노티파이에도 넣으면 두 번 난다.

## 스킨

- 표에 적는 소리는 **S000 (기본)** 이름이다. 다른 스킨은 `Character_FX/<캐릭터>/s00x/` 에 **같은 파일명**으로 넣으면 `ER.Pres.Fill <캐릭터> Force` 가 알아서 덮는다 (큐 = 스킨 DA `Overrides` · 노티파이 = 스킨 DA `SoundSwaps`)
- 스킨에 **없는** 소리는 기본(S000)이 난다 · 스킨에만 있는 소리(이름이 다름)는 Fill 로그 `S000 에 같은 이름 없음 N` 에 센다

## 상태 칸

| 값 | 뜻 |
|---|---|
| ✅ | 코드 · Fill 연결됨 (빌드 통과) — PIE 로그로 확인했으면 날짜 |
| 🆕 | 결정됨 · 코드 작업 대기 |
| ⚠ | 결정 대기 (들어보고 `어디서` 칸에) |
| 📝 | 노티파이 찍기 대기 (사용자) |
| ⏸ | 보류 |

## 캐릭터 음성 (Argument 73 · 2026-10-07 코드 빌드 ✅)

음성은 **캐릭터마다 다르지 않은 규칙 하나**라 캐릭터 표가 아니라 이 표에 둔다 — 원본 `Data/Presentation/_Voice.json` (상황 키 → 음성 키 · 확률 · 간격 · 끊기). 고치면 `ER.Pres.Fill <캐릭터> Force` 만 (빌드 불필요).

- 파일: `/Game/ER/Audio/Voice/ko/<캐릭터>/` 만 쓴다 · `Voice/<캐릭터>/` (같은 이름 한 벌 + wav) 는 안 쓴다 — 지우지 않음 (`ER_Asset/03_Log/보이스_분류.md` ⚠ 2)
- 스킨: `Data/Presentation/VoiceSkin.csv` (`보이스_스킨.csv` 사본 · md5 같음) — `_ko` · `_ko_0` 꼬리표는 스킨과 무관. S000 = 기본 DA · S00x = 스킨 DA (스킨 DA 가 없으면 Fill 로그 "규칙 밖" 에 남고 그 스킨에선 기본 대사)
- 듣는 사람: **주변** = 그 자리 3D (감쇠 500 → 2,500cm · 연출 컴포넌트 `VoiceInnerRadius` · `VoiceFalloff`) · **본인** = 그 플레이어 화면만 2D

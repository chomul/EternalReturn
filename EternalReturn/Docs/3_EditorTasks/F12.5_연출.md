## 만드는 순서

1. **`ALI_ERWeaponLayers`** — 우클릭 › Animation › Animation Layer Interface · 함수 2개 `Idle` · `Run` (입력 없음 · 출력 포즈)
2. **`ABPL_ERWeapon_Base`** — Animation Blueprint › **Template** 체크 · Class Settings › Interfaces 에 `ALI_ERWeaponLayers`
   - 변수 `IdleAnim` · `RunAnim` (Anim Sequence Base · Instance Editable)
   - `Idle` 레이어 그래프: Sequence Player(IdleAnim, Loop) → Output · `Run`: Sequence Player(RunAnim, Loop) → Output
   - ⭐ Sequence Player 의 Sequence 핀에 변수를 **직접** 연결 (Fast Path)
3. **`ABPL_Jackie_Axe`** — `ABPL_ERWeapon_Base` 우클릭 › Create Child · 스켈레톤 = 재키 기본 스켈레톤 · Class Defaults `IdleAnim = Jackie_Axe_wait` · `RunAnim = Jackie_Axe_run`

## 에디터 작업 — ⭐ A2 로 바뀜 (2026-09-28 · Argument 42 ⑥)

> 모드 애니는 **동작표(DA)의 모드 줄**에 있다. C++ 가 `ModeStartAnim · ModeIdleAnim · ModeRunAnim · ModeEndAnim` 에 넣고, 상태머신은 **Sequence Player 가 그 변수를 직접** 읽는다. 레이어의 Mode 함수 · 변수는 없어진다.
> 이미 MB 1~9 를 한 상태에서 **바꿀 것만**:

1. **에디터 재시작** (C++ 변수 · 태그 추가)
2. **`ALI_ERWeaponLayers`** — `ModeStart · ModeIdle · ModeRun · ModeEnd` 함수 4개 **삭제** (Idle · Run 만 남긴다)
3. **`ABPL_ERWeapon_Base`** — `ModeStartAnim · ModeIdleAnim · ModeRunAnim · ModeEndAnim` 변수 4개 **삭제** (Compile — 자식 레이어들의 모드 값도 같이 사라진다)
4. **`ABP_ERCharacter_Base`** 상태머신 — Mode 상태 안의 **레이어 노드를 Sequence Player 로** 바꾼다. 변수는 **부모(C++) 것** (My Blueprint 톱니 › Show Inherited Variables)
   - `ModeStart` 상태: Sequence Player · Sequence 핀(As pin) ← **`ModeStartAnim`** · **Loop 끔**
   - `ModeLoop` 상태: Blend Poses by bool (`bIsMoving`) — False = Sequence Player(`ModeIdleAnim`, Loop) · True = Sequence Player(`ModeRunAnim`, Loop)
   - `ModeEnd` 상태: Sequence Player ← **`ModeEndAnim`** · **Loop 끔**
   - ⭐ 이제 상태 안에 Sequence Player 가 **직접** 있으니 `ModeStart → ModeLoop` · `ModeEnd → Idle` 의 **Automatic Rule Based on Sequence Player** 가 확실히 동작한다
5. 에디터 콘솔 **`ER.Pres.Fill Katja`** → Save All
   - `DA_Pres_Katja_SniperRifle` 에 **모드 줄 5개**가 생긴다: `Mode.Sniper` × { `Pres.Anim.ModeStart` = Skill_Start · `ModeIdle` = Skill_Loop · `ModeRun` = Skill_Loop · `ModeEnd` = Skill_End · `Ability.Slot.Attack` = Skill_Shot }

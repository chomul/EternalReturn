# F08-01 — 아이템 데이터 · 등급 · 슬롯

> ⚠ 새 C++ 타입(`FERItemRow` · 열거형 3개 · `UERItemSettings`) — **에디터 재시작**
> ⚠ `Config/DefaultGame.ini` 에 `[/Script/EternalReturn.ERItemSettings]` 가 **에디터가** 저장한다 (Project Settings 에서 지정하면 자동)

## ⭐ 구조 — 정의와 인스턴스

```
DT_Items (UDataTable, 행 = FERItemRow)      ← 정의. 행 이름 = 아이템 ID. 전원이 같은 표. 게임 중 안 바뀜
  ├─ hammer_t1     : 영웅 · 무기 · Hammer · AttackPower +30
  ├─ sniper_t1     : 영웅 · 무기 · SniperRifle · AttackPower +25, AttackRange +1.0
  └─ hat_t1        : 희귀 · 머리 · Defense +10

FERItemInstance (F08-04)                     ← 인스턴스. "누구의 몇 번 칸에 무엇이 몇 개". 서버 권위 · 소유자에게만 복제
```

## 애셋 2개

### 1. `DT_Items` — `Content/Item/`
우클릭 → Miscellaneous → **Data Table** → Row Structure 검색 **`ERItemRow`** → 이름 `DT_Items`

행 3개 (Add 로 추가, **Row Name 이 ID** — 영문 스네이크, 나중에 안 바꾼다):

| Row Name | DisplayName | Grade | Slot | WeaponType | StatModifiers | Icon |
|---|---|---|---|---|---|---|
| `hammer_t1` | 망치 | Hero | Weapon | Hammer | `AttackPower = 30` | 비움 |
| `sniper_t1` | 저격총 | Hero | Weapon | SniperRifle | `AttackPower = 25`, `AttackRange = 1.0` | 비움 |
| `hat_t1` | 모자 | Rare | Head | None | `Defense = 10` | 아무 텍스처 하나 (로드 안 되는지 보려고) |

`StatModifiers` 는 키가 **어트리뷰트 선택기**다 — `ERAttributeSet.AttackPower` 처럼 고른다. 값은 어트리뷰트 단위 그대로.

- [x] `DT_Items` 생성 · 행 3개 — 2026-09-17

### 2. Project Settings > Game > **ER Items** → `Item Table = DT_Items`
- [x] 지정 — `DefaultGame.ini` `[/Script/EternalReturn.ERItemSettings] ItemTable=/Game/Item/DT_Items.DT_Items`

## 검증 — PIE 1인이면 충분 (네트워크 없음)

```

ER.Item.Show nope
ER.Item.List

- [x] `[아이템디버그] hammer_t1 | 망치 | EERItemGrade::Hero | EEREquipSlot::Weapon | EERWeaponType::Hammer | AttackPower+30.00 | 아이콘 없음(-)` — 로그 그대로
- [x] `nope` → `[아이템] 'nope' 행이 DT_Items 에 없다 …` (Error 1줄, 크래시 없음)
- [x] `List` → 3행 + `DT_Items — 3행`
- [x] ⭐ `hat_t1` 아이콘 — PIE 에선 **`⚠ 로드됨`** 으로 찍힌다. 에디터가 디테일 패널 썸네일로 이미 로드해 둔 것이지 테이블이 로드한 게 아니다(`TSoftObjectPtr` = `FSoftObjectPath`). Standalone 에서는 `미로드`. 구조 확인으로 통과

```

- [x] ⭐⭐ **추가분 = 장비분** — `AttackPower 기본 0.00 / 현재 20.00 / 추가 +20.00` (Infinite 가 CurrentValue 만 바꾼다)

- [x] 원복이 **정확히** 0.00 — `Unequip Weapon` 후 `현재 0.00 / 추가 +0.00`
- [x] 장비 2개 중 하나만 벗으면 나머지는 그대로 — `Defense 현재 60.00 / 추가 +10.00` 유지

### ④ 교체 · 복제 · Infinite

# F08-04 — 인벤토리 (가방) · 복제

> ⚠ USTRUCT · UPROPERTY 추가 (`FERItemInstance` · `Bag` · `FERItemRow.MaxStack` · `InventorySlots`) — **에디터 재시작**
> `Play As Listen Server`, 2명

## 애셋
- `DT_Items` 에 행 추가: `stone` | 돌멩이 | Common | Slot **None** | `MaxStack = 3` (스탯 없음) — 재료 중첩 검증용
- 기존 행들의 `MaxStack` 은 기본 1 (장비)
- Project Settings > Game > ER Items > `Inventory Slots` = 10 (기본값. 바꾸지 않아도 됨)
- [x] `stone` 행 — 2026-09-17

## 검증

### ① 스택 · 가득 참 — 서버 창 (`Give` 는 서버 전용)

```
ER.Item.Give stone 5     → [인벤토리] ERPlayerState_0 <- stone ×5 (0 남음)
ER.Item.Bag              → [0]stone×3 [1]stone×2        ← MaxStack 3 으로 두 칸
ER.Item.Give hat_t1 9    → 9칸 채움 (총 10/10)
ER.Item.Give hat_t1 1    → ⚠ 가득 참, 1 남음
ER.Item.Give stone 1     → 0 남음 (stone×2 칸에 쌓임 → ×3)
```
- [x] 중첩이 `MaxStack` 대로 갈라진다 · 가득 차면 **남은 수량**을 로그로 돌려준다 · 기존 스택엔 가득 차도 쌓인다 — 로그 `[0]stone×3 [1]stone×2` · `×8 (⚠ 가득 참, 1 남음)` · `stone ×1 (0 남음)`

### ② ⭐ 본인에게만 복제 — 두 창

서버 창에서 `ER.Item.Give hat_t1 2` (PS_0 가방) 뒤:
```
클라 창: ER.Item.Bag
  [클라] ERPlayerState_1 가방 0/10칸: 비어 있음
  [클라] ERPlayerState_0 가방 0/0칸: (복제 안 됨 — 남의 가방)     ← ⭐ 배열 자체가 안 온다
서버 창: ER.Item.Bag  → 둘 다 실제 내용
```
- [x] ⭐ 클라에서 **남의 가방은 `0/0칸 (복제 안 됨)`** — 로그 그대로

### ③ 가방 ↔ 장착 · 클라 우회 — 클라 창

```
클라 창: ER.Item.Give dagger_t1        → 서버 창에서만 된다 — 클라는 아이템을 직접 넣을 수 없다   ⭐
서버 창: (PS_1 에게 줄 수단이 없어서) 클라 창에서 ER.Item.Equip 도 "서버 창에서만"
```
⚠ 클라 플레이어(PS_1)의 가방을 채우려면 서버 쪽 API 가 PS_1 을 가리켜야 하는데 디버그가 로컬 폰만 본다. 그래서 ③ 은 **서버 창(PS_0)** 에서:
```
서버 창: ER.Item.Give dagger_t1 → ER.Item.Bag ([k]dagger_t1×1)
서버 창: ER.Item.EquipSlot k     → [장비] … <- dagger_t1 장착 · Bag 에서 사라짐 · Stats AttackPower +20
서버 창: ER.Item.Give hat_t1 → EquipSlot (hat 칸) → Head 장착
서버 창: ER.Item.Unequip Weapon  → [장비] … 해제 (Weapon) -> 가방 · Bag 에 dagger_t1 복귀
서버 창: (가방 10/10 채운 뒤) ER.Item.Unequip Head → "가방이 가득 차 hat_t1 를 벗을 수 없다"
서버 창: ER.Item.Discard k       → 칸 비움
```
- [x] 장착하면 가방에서 빠지고, 벗으면 가방으로 돌아온다 — 로그 `제거 (칸 0)` → `장착`, `해제 -> 가방` → `<- ×1`. ⚠ 가득 찬 상태의 벗기 거부는 미실시 (`HasSpaceFor` 경로, 구조 확인)
- [x] 클라에서 `Give` 는 거부 — `서버 창에서만 된다 — 클라는 아이템을 직접 넣을 수 없다`

## ⭐ 구조 — 먼저 이해하고 만든다

```
DA_Katja (UERCharacterData)          ← 실험체
  └─ Skills[] ─┬─ DA_Skill_Katja_Q (UERSkillData)   ← 스킬 데이터 (수치)
               │    ├─ SlotTag      = Ability.Slot.Q
               │    └─ AbilityClass = GA_Projectile  ← 로직 (재사용)
               └─ DA_Skill_Katja_W ...

DA_InputConfig (UERInputConfig)
  └─ SkillSlotActions ─ Ability.Slot.Q → IA_Skill_Q  ← 키
```

⭐ **어빌리티 BP = 로직, 스킬 데이터 애셋 = 수치.** 같은 `GA_Projectile` 을 여러 캐릭터가
데이터만 바꿔 공유한다. **수치를 어빌리티 BP 에 넣지 않는다.**

⚠ 지금 `UERSkillData` 는 **슬롯과 클래스뿐**이다. 피해·쿨다운·코스트 필드는
F07-02 이후에 하나씩 붙는다. 미리 넣지 않는다.

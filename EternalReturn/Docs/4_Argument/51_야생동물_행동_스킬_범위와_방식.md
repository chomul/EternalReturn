- **모든 수치** — 돌진 거리 · 피해 · 좌절 시간 / 강타 반경 · 피해 · 기절 시간 / 깨물기 추가 피해 · 치유 감소 % · 이속 / 울부짖기 지연
- **경계 반경 · 수면 판정 반경 · 잠들기까지 시간** · 잠 · 경계가 **게임 규칙을 바꾸는지** (예: 자는 동물을 치면 추가 피해 · 경계 중엔 선공) — 검색 결과 없음
- 원본 클라이언트 추출본(`ER_Asset/00_Raw/core3/.../Scripts/Blis/Server/AI/*.cs`)은 **빈 껍데기**(AssetRipper "Dummy class") — 이름만 보인다: `DefaultMonsterProcess` · `ActionIf` · `ConditionProbability` · `ActionTryAttackTargetByGroup` … **Sleep · Beware 이름의 클래스는 없다** → 잠 · 경계는 AI 가 아니라 연출 쪽일 가능성 (미확인)

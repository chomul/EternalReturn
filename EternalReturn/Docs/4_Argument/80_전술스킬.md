## 구현 계획 (승인 대기)

### ① 공통 — 슬롯 · 선택 · 부여

| 무엇 | 어디 | 책임 |
|---|---|---|
| 태그 `Ability.Slot.F` · `Cooldown.Slot.F` | `ERGameplayTags` · `ERSkillData::CooldownTagForSlot` · `ERSkillDebug` (`F`) | F 슬롯 |
| 목록 `TacticalSkills` (soft 배열) · `DefaultTacticalSkill` | `UERCombatSettings` (카테고리 "전술 스킬") | 고를 수 있는 것 · 안 고르면 이것 |
| `AERPlayerState::SetTacticalSkill(UERSkillData*)` [서버] | PS | 옛 F 회수 → 새 F 부여 (레벨 1) · `TacticalSkill` **복제 (OnRep)** — 선택 UI 가 읽는다 |
| `AERPlayerController::ServerSelectTacticalSkill(int32 Index)` | PC · Server RPC (WithValidation: 목록 범위) | **C2 캐릭터 선택 UI 가 부르는 입구** — UI 위젯은 에디터 작업 (`UI/02_캐릭터선택.md` 에 칸 추가) |
| 콘솔 `ER.Tactical <이름>` | `ERSkillDebug` | 로비가 없는 동안 PIE 검증 — 같은 RPC 를 부른다 |

네트워크: 선택 = 클라 → Server RPC → 서버가 부여 · 스펙 복제. 발동 · 쿨다운 = 기존 파이프라인 그대로.

### ② 스킬별 — 기존 부품 + 새 부품

공통 새 칸 ⭐ **조각 `MinLevel`** (`UERSkillFragment` 기본 클래스 한 칸 · 기본 1) — "Lv2 에만 있는 효과" 가 11종 중 9종이라 조각마다 레벨 배열 0 을 쓰는 대신 한 곳에서. 파이프라인이 `Level < MinLevel` 이면 그 조각을 건너뛴다.
공통 새 칸 ⭐ **추가 체력 계수** — 추가 체력 = `MaxHP` Current − Base (추가 공격력과 같은 방식 · `ERDamageExecution.cpp:73`). 피해 · 보호막 · 자기 버프 크기에 쓴다.

| 스킬 | 쓰는 기존 부품 | 새로 필요한 것 |
|---|---|---|
| 블링크 | 자기 버프 (Lv2 이속 15% 2.5초) | `SelfMove` 새 모드 **조준점 순간이동** (최대 3m · 벽 통과 · 막힌 자리면 내 쪽으로 당겨 빈 자리) · Lv2 **충돌 무시** 태그 `State.Ghost` → 캐릭터가 폰 충돌 끔 |

## 방안

| 방안 | 방식 | 판정 |
|---|---|---|
| **K1** | **`UERForcedMoveComponent`** — 전파 Multicast · 벽 감시 · 벽 충돌 델리게이트를 `AERCharacterBase` 에서 **옮긴다**. 실험체 · 야생동물이 같은 컴포넌트를 든다. 넉백 조각 · `ERForcedMove` 는 `ACharacter` + 컴포넌트만 본다 | 한 벌 코드 · 앞으로 강제 이동을 받는 것(소환물 등)도 컴포넌트만 붙이면 된다. 벽 감시 Tick 은 컴포넌트 Tick (평소 꺼짐 — 지금과 같음) |
| K2 | 야생동물 클래스에 같은 Multicast · Tick 감시 · 델리게이트를 **복사** | 빠르지만 같은 코드 두 벌 · 넉백 조각이 두 델리게이트를 분기 |
| K3 | 야생동물은 **서버에서만** 밀고(클라는 이동 복제로 봄) · 벽 감시만 복사 | 야생동물은 클라가 이동을 몰지 않아(시뮬레이티드 프록시) Multicast 없이도 된다 — 단 실험체와 경로가 갈려 "왜 둘이 다르지" 가 생긴다 |

- 야생동물 대기(도먼시)는 **CMC 틱이 꺼져 있다** (F12-04) — 맞으면 AI 가 다음 틱에 깨우므로(E24) 밀림은 한 틱 늦게 시작한다. 측정 후 필요하면 강제 이동 시작 때 몸을 깨운다
- 보스: 규칙 "전부 받는다" 대로 받는다. 원작 보스 CC 면역 여부 **(미확인)** — 다르면 `State.CCImmune` 태그로 막는다 (이미 있는 경로)

**추천 K1.** → **채택** (2026-09-29). 구현: `Combat/ERForcedMoveComponent` · `AERCharacterBase` 의 Multicast 2개 · 벽 감시 Tick · 델리게이트 제거 (액터 Tick `bCanEverTick = false`) · 델리게이트 인자 `AERCharacterBase*` → `ACharacter*` · 넉백 조각 · `ER.CC.Knockback` 이 컴포넌트를 찾는다

## 방안 — 시전 방식

### C1 — 원작 그대로 세 가지 (스킬마다 즉시 / 일반 · "누르는 동안 표시" 옵션)
- 장점: 원작 조작감 그대로 · 나중에 다시 안 만든다
- 단점: 설정 저장 · 스킬별 선택 UI 가 필요 (UI 는 아직 없다 — F17) · 일반 시전은 "조준 모드" 상태 · 좌클릭 가로채기 · 우클릭 취소까지

### C2 — "누르는 동안 표시 → 떼면 시전" 하나만 ⭐
`IA_Skill_*` 를 Started(표시 시작) · Completed(발동) 로 나눠 받는다. 표시 중엔 매 프레임 커서로 모양을 다시 그린다.
- 장점: 원작 옵션 중 하나 그대로 · 입력 한 곳만 바꾼다 · 조준 모드 상태 · 클릭 가로채기 없음
- 단점: 원작 평가처럼 **떼는 만큼 아주 짧게 늦다** (즉시 시전보다)
- 나중에 C1 로 넓힐 때 "표시 → 발동" 이 그대로 일반 시전의 앞부분이 된다

### C3 — 일반 시전만 (누르면 표시 · 좌클릭 시전 · 우클릭 취소)
- 장점: 정확히 보고 쓴다
- 단점: 모든 스킬이 두 번 눌러야 나간다 · 좌클릭(이동) 과 겹치는 처리 필요

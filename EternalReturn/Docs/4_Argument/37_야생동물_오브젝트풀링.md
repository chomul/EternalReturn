# 37. 야생동물을 오브젝트 풀링할까

> F12-03/04 · 제기: 사용자 2026-09-24 — *"야생동물들을 오브젝트 풀링 안 하나?"*
> 관련 [`31`](31_야생동물_ACharacter_vs_APawn.md) (클래스 비용 측정) · `UERWildlifeSpawnSubsystem` (재생성) · memory: 근거 없이 추정하지 않기

## 지금 구조

재생성 = **새 액터 SpawnActor → Initialize** (스탯 GE · 태그 · 스킬 부여) → 죽으면 60초 시체 → `SetLifeSpan` 으로 파괴.

## 비용을 먼저 계산해 보면

| 항목 | 값 | 근거 |
|---|---|---|
| 자리 수 | 120~200 | 역기획서 §7.3 추정 |
| 재생성 주기 | 120~270초 (늑대 · 곰은 낮/밤마다) | §3.3 [확인] |
| **평균 스폰 빈도** | 200 ÷ 150초 ≈ **초당 1~2마리** | 모두가 계속 사냥당한다고 가정한 상한 |
| 액터 1개 스폰 비용 | **(미측정)** — ACharacter + ASC + GE 1회 + 스킬 부여 | 아래에서 잰다 |

→ **평상시 부하는 작다.** 문제가 된다면 **한 순간에 몰리는 경우**다:
- 매치 시작: 닭 전부가 1일차 낮 **시작 즉시** 한꺼번에 스폰 (F12-03 로그: 같은 프레임 3마리 — 실제 맵이면 수십 마리)
- 밤 시작: 곰 전부 · 낮 시작: 늑대 전부

## 방안 A — 풀링 안 함 + 스폰 분산 ⭐ 추천 (지금)

- 스폰 서브시스템의 1초 훑기에서 **한 번에 최대 N마리**만 스폰 (예: 8). 나머지는 다음 훑기로 — 몰림 스파이크만 없앤다
- 장점: 코드 몇 줄 · 상태 리셋 버그 없음 (새 액터는 깨끗하다)
- 단점: 파괴된 액터가 GC 대상이 된다 (초당 1~2개 — UE5 증분 GC 에 무시할 수준으로 예상, 측정으로 확인)

## 방안 B — 자리마다 액터 하나를 **재사용** (슬롯 재사용)

- 시체 1분이 끝나면 파괴하지 않고 숨긴 채 재운다 → 재생성 때 되살려 같은 자리에 둔다
- 일반 풀보다 쉬운 이유: **자리마다 종이 고정**이라 `Data`(COND_InitialOnly 복제)가 안 바뀐다
- 단점 — 되살릴 때 **전부** 되돌려야 한다. 하나라도 빠지면 조용한 버그다:
  `bDead` · `State.Untargetable` 태그 · 캡슐/히트박스 콜리전 · AI `bStopped` · 체력 · 적용 중인 GE(CC 등) · 도먼시 · 숨김 · 시체 컨테이너 · 몽타주/애님 상태(F12.5 이후)
- 네트워크: 숨긴 액터도 채널은 유지 (재운 상태라 비용은 거의 0) — 되살리면 클라가 "순간이동 + 상태 변경" 으로 받는다

## 방안 C — 범용 액터 풀 (종 무관)

- 장점: 종을 바꿔 가며 재사용
- 단점: `Data` 가 초기 1회 복제라 **종이 바뀌면 클라가 모른다** → 복제 조건부터 바꿔야 한다. 메시 · 히트박스 · 스킬까지 갈아끼워야 해서 B 의 리셋 목록 + α. 이득 대비 위험이 가장 크다

## 비교표

| | A 분산만 | B 자리 재사용 | C 범용 풀 |
|---|---|---|---|
| 구현 | 몇 줄 | 리셋 목록 10여 항목 | B + 종 교체 · 복제 조건 변경 |
| 버그 위험 | 낮음 | 중 (리셋 누락) | 높음 |
| 스파이크 | ✅ 분산으로 해결 | ✅ | ✅ |
| 평상시 비용 | 스폰 1~2/초 | 거의 0 | 거의 0 |
| 엔진 지원 | — | 없음 (직접) | 없음 (직접) |

## 추천

⭐ **A 로 시작하고, 측정해서 B 로 갈지 정한다.** 기준:
- `ER.Wild.Stress 200` 순간의 Game ms 스파이크 ÷ 200 = **스폰 1회 비용**
- 스폰 1회 > **1 ms** 이거나, 분산 후에도 매치 시작 · 낮/밤 전환에 프레임이 튀면 → **B** (C 는 하지 않는다)

풀링은 "당연히 해야 하는 최적화" 가 아니라 **리셋 버그와 바꾸는 거래**다. 초당 1~2마리 규모에서는 측정 없이 들어갈 이유가 약하다.

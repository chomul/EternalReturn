# 65. 재키 — 출혈 도트를 무엇으로 · R 학살을 무엇으로

## 결정할 것

1. **출혈**(P 피의 축제) — 대상에 쌓이는 지속 피해(최대 5중첩 · 새로 맞을 때마다 전체 6초 갱신)를 무엇으로 만드는가
2. **R 학살** — R 사용 중 다시 누르면 다른 스킬(학살)이 나가는 구조를 무엇으로 만드는가

## 규칙 (게임 툴팁 12.3 · 사용자 확인 2026-10-05)

| 항목 | 값 | 출처 |
|---|---|---|
| 출혈 | 평타 · 스킬 피해 → 6초 · 최대 5중첩 · 중첩당 6초 동안 10/20/30 (+공격력 20%) · **새로 맞으면 전체 6초 갱신** · 틱 1초 `[자체]` | 툴팁 · 사용자 |
| 아드레날린 | 최대 중첩 도달 또는 처치 관여(지금은 막타) → 5초 · **적중마다** 출혈 즉시 최대 + 추가 피해 + 잃은 체력 비례 회복 | 툴팁 · 사용자 |
| R | 8/9/10초 이속 · 공속 · 처치 관여 +5초 (상한 없음) · 사용 중 재사용 = 학살 (원형 3m · 적 잃은 체력 비례 · 피해 25% 회복) · 처치 관여 시 학살 다시 | 툴팁 · 시즌 8 문구 · 사용자 |

이미 있는 것 (확인 2026-10-05):
- 지속 피해(주기 GE)는 **프로젝트에 하나도 없다** (`Period` · `StackCount` 검색 0) — 출혈이 첫 도트
- 적중 이벤트 `Event.Hit.Dealt` (어트리뷰트셋 → 가해자 · Argument 61 E1) · 패시브 어빌리티 `UERPassiveAbility`
- 처치: `ERPlayerState.cpp:122` `OnOutOfHealth(Killer)` 에서 가해자를 안다 → 가해자 ASC 에 이벤트를 보내면 된다
- 재사용 창 조각 `_Recast` (`Window` · `bOnHitOnly` · `RecastSkill`) — 매그너스 R 바이크 발사가 이 길 (E39)
- 피해 조각 `TargetLostHPScaleMax` (대상 잃은 체력 비례) · `CurHPRatio` · 피해 비례 회복
- 엔진: 주기 GE 의 실행 계산은 **중첩된 Spec** 으로 불린다 (`GameplayEffect.cpp:3137` `ExecutePeriodicGameplayEffect` → `ActiveEffect.Spec` · `FGameplayEffectSpec::GetStackCount` `GameplayEffect.h:1043`)

## ① 출혈 — 방안

### D1 — GAS 중첩 주기 GE ⭐
`GE_Bleed`: Duration 6 · **Period 1** · Stacking `AggregateBySource` · 상한 5 · **새로 쌓을 때 지속 갱신** (`StackDurationRefreshPolicy = RefreshOnSuccessfulApplication`) · 실행 = 기존 `ERDamageExecution`.
- 틱 피해 = 중첩당 (10/20/30 + 공격력 20%) ÷ 6 × **중첩 수** — 실행 계산이 `Spec.GetStackCount()` 를 곱한다 (도트 표시 태그가 있을 때만)
- 거는 것: P 패시브가 `Event.Hit.Dealt` 를 듣고 맞은 대상에 1중첩 (아드레날린 중이면 5중첩)
- ⚠ 출혈 틱도 피해라 다시 `Event.Hit.Dealt` 가 난다 → **도트 피해는 적중 이벤트를 안 보낸다** (`Damage.Type.DoT` 태그) — 안 막으면 출혈이 출혈을 영원히 갱신
- 장점: GAS 가 중첩 · 갱신 · 만료 · 복제 · 정화를 해 준다 (§8 "상태이상 = GE + 태그") · 다른 도트(독 · 화상)도 GE 만 새로
- 단점: 첫 도트라 실행 계산에 "중첩 수 곱하기" · 적중 이벤트 제외 규칙을 새로 넣는다

### D2 — 대상에 출혈 컴포넌트 (자체 타이머)
대상 액터에 중첩 수 · 남은 시간을 들고 `FTimerManager` 로 1초마다 피해 GE 를 건다.
- 장점: 규칙을 코드로 자유롭게
- 단점: §8 위반 (상태이상을 GAS 밖에서) · 복제 · 정화 · 사망 정리를 직접 · 야생동물 · 보스에도 컴포넌트

### D3 — 중첩마다 따로 GE (중첩 안 함)
1중첩 = GE 하나 (각자 6초).
- 단점: 사용자 결정("새로 맞으면 **전체** 갱신")과 다르다 · 상한 5 를 직접 센다 — 비교용

## ② R 학살 — 방안

### R1 — 재사용 창 조각 그대로 (`_Recast`) ⭐
R 발동 = 버프 GE (이속 · 공속 · 지속 8/9/10) + 재사용 창(지속 = R 지속 · 적중 조건 없음) · 재사용 = `RecastSkill` 학살 (반경 3m · `TargetLostHPScaleMax` · 피해 회복 25%).
- 처치(막타) → R 버프 · 재사용 창 둘 다 **+5초** · 학살을 이미 썼으면 창을 **다시 연다**
- `_Recast` 고칠 것: 창 길이를 **레벨별**로 (지금 `float Window` 하나) · "처치 시 연장 · 다시 열기"
- 장점: 매그너스 R 과 같은 길 (리캐스트 실행 · 소리 E39 · 슬롯 키) · 슬롯 교체 일반화가 필요 없다
- 단점: "버프 GE"와 "재사용 창 GE" 두 개의 시간을 같이 늘려야 한다

### R2 — 스킬 슬롯 상태 교체 (`_Mode` 일반화)
R 사용 중 R 슬롯 = 학살 어빌리티로 바꾼다 (지금 `_Mode` 는 평타 슬롯만 — Task 문서의 원래 계획).
- 장점: 원작 표현("스킬이 바뀐다")과 같다 · UI 아이콘 교체가 자연스럽다
- 단점: `_Mode` 일반화 (부여 · 회수 · 쿨 보존) 큰 작업 · 지금 R1 로 같은 동작이 된다 — §2 단순함

## 추천

**D1 + R1.** 출혈은 GAS 중첩 GE 가 규칙(전체 갱신 · 상한 5)과 그대로 맞고, 첫 도트를 GAS 로 만들어 두면 뒤 실험체(시셀라 · 레니)의 도트도 GE 만 더한다. 학살은 이미 쓰는 재사용 창으로 충분하다 — 슬롯 교체 일반화는 정말 필요한 실험체(다니엘 R · 시셀라 Q)에서 따로 비교한다.

## ✅ 결정 (사용자 2026-10-05) — D1 + R1

- 구현에서 바뀐 것: **GE 애셋을 새로 만들지 않는다.** 아드레날린은 범용 코드 GE `UERTimedTagEffect`(태그 + 지속)이고, R 상태는 기존 이속 · 공속 GE 에 **동적 태그** `State.Chainsaw` (자기 버프 `GrantTag`)를 단다. 처치 시 +5초는 이 태그로 찾아 늘린다
- 출혈 최대 대상 +30% 는 `Data.Damage.Multiplier` (실행 계산 8-d) — 대상 무리를 나눠 배율 사본을 쓴다
- E 의 지속 효과(처치 초기화 · 출혈 최대 평타 −0.5초)와 R 처치 연장은 **P DA** 에 둔다 — 적중 · 처치 이벤트는 패시브만 듣는다

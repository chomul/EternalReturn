# 38. 비례 피해 감쇠를 보스마다 다르게 — 태그 분리 vs 어트리뷰트

> F12-05 · 역기획서 몬스터 §5.1 (위클라인 체력 비례 피해 50%) · 선행 결정 [`7_비례피해_감쇠판별.md`](7_비례피해_감쇠판별.md) (F03 은 **태그**로 판별 — F12 클래스에 의존하지 않는다)

## ⭐ 결정 — 2026-09-24 **B** (대상 어트리뷰트)
> 사용자는 처음 **A** 를 골랐으나, 같은 날 준 나무위키 본문이 **알파 70% · 오메가 60% · 위클라인 50%** — 보스마다 값이 달라 A(태그 + 전역 0.5)로는 표현이 안 된다.
> 이름은 `ProportionalDamageResist`(저항, 기본 0 = 감쇠 없음) — "배율"(기본 1)로 두면 초기화 GE 를 안 거친 대상이 **비례 피해를 전혀 안 받는** 위험이 있다.
> 전역 설정 `UERStatCapSettings::BossProportionalDamageScale` 은 삭제했다 (이 변경으로 미사용).
> ⚠ 사용자 답변 "알파 · 오메가는 안 줄여 받음" 과 나무위키가 충돌 — 값은 DA 라 숫자만 바꾸면 된다. 지금은 나무위키 값.

## 문제

지금 F03 (`ERDamageExecution.cpp:170`) 은 **`Actor.Type.Boss` 태그가 있으면 전부** `BossProportionalDamageScale`(0.5)을 곱한다.
그런데 원작에서 확인된 건 **위클라인만** 이다. 알파 · 오메가는 (미확인) — 정황상 감쇠가 **없거나 약하다**:
> *"아델라 조합이면 알파나 오메가는 체력의 2/3 가 사라지고 위클라인이라도 단번에 절반 이상"* ([나무위키 아델라](https://namu.wiki/w/%EC%95%84%EB%8D%B8%EB%9D%BC(%EC%9D%B4%ED%84%B0%EB%84%90%20%EB%A6%AC%ED%84%B4)))
> → 같은 조합에 위클라인이 덜 깎인다 = 위클라인만 따로 버틴다.

`Actor.Type.Boss` 는 흡혈 감소 · 도먼시(`DORM_Never`)에도 쓰여서, 이 태그 하나로 감쇠까지 정하면 알파 · 오메가도 반감된다.

## 방안 A — 감쇠 전용 태그를 분리 ⭐ 추천

```cpp
// ERGameplayTags: Actor.Trait.ProportionalResist — "체력 비례 피해를 줄여 받는다"
// UERWildlifeData: bool bResistsProportionalDamage   (위클라인만 true)
// Initialize: 켜져 있으면 태그 부여 (loose + replicated) — Boss 태그와 별개
// ERDamageExecution: Actor_Type_Boss → Actor_Trait_ProportionalResist 로 판별만 교체. 계수는 기존 설정 0.5 그대로
```
- 장점: F03 변경 **한 줄** (태그 이름만) · Argument 7 의 "태그로 판별" 그대로 · 보스 여부와 감쇠 여부가 독립
- 단점: 계수는 전역 하나 (0.5). 보스마다 **다른 값**이 필요해지면 B 로 가야 한다 — 지금 확인된 값은 50% 하나뿐

## 방안 B — 대상 어트리뷰트 `ProportionalDamageTakenScale`

- `UERAttributeSet` 에 어트리뷰트 추가 (기본 1.0) · 종 DA 가 값을 정하고 Execution 이 대상에서 캡처
- 장점: 보스마다 · 버프로도 다른 값 (예: 특정 아이템이 비례 피해 저항)
- 단점: 어트리뷰트 추가 = 실험체 33종에도 붙는다 · 캡처 정의 · 초기화 GE 수정. **아직 필요한 값이 하나뿐**

## 방안 C — Execution 에서 `Cast<AERWildlifeCharacter>` 로 DA 읽기

- ❌ Argument 7 이 금지한 방식 (F03 → F12 의존)

## 추천

⭐ **A**. 확인된 규칙이 "위클라인 50%" 하나라서 태그 + 전역 계수로 충분하다. 알파 · 오메가 값이 확인되고 **서로 다르면** 그때 B.

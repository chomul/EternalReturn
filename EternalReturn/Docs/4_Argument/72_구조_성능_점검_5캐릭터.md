## A. 구조

### A1 — 캐릭터 연출 규칙을 C++ 에서 데이터로 ⭐ 효과 큼

- 범위: 중 (규칙 구조체를 JSON 으로 옮기는 일 · 기존 5명 규칙 이관)

### A2 — 어트리뷰트셋의 "곰돌이" 를 일반 **표식** 으로
어트리뷰트셋(피해 처리 한가운데)에 레니 전용 태그가 들어가 있다. 다니엘 W 도 "표식 상태 머신 (레니 표식과 같은 구조)" 이다 (체크리스트).
- 방안: 부모 태그 `State.Mark.*` GE 를 가진 가해자가 때리면 **GE 주인에게** `Event.Mark.Triggered` (태그 = 어느 표식). 곰돌이 = `State.Mark.LeniBear`
- 범위: 소

### A3 — 쿨다운 당기기 6곳 → 함수 하나

### A4 — 투사체 끝 원 판정 2곳 → 하나

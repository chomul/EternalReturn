# 59. 모션 소리 노티파이 — 키(태그)로 부를까, 소리를 직접 넣고 스킨이 이름으로 바꿀까

## 결정할 것

애니 노티파이로 내는 **모션 소리**(조준 · 스캔 · 장전처럼 판정 순간이 아닌 소리)를 스킨마다 바꾸는 방법.

## 배경

- 사용자 제공 정리 (2026-10-02): "언제(노티파이) / 무엇을(DA) 분리 · 스킨 덮어쓰기 → 기본" — 받아들임. 단 기본 소리는 **스킬 DA 가 아니라 연출 DA** (스킬 DA 는 데디 서버가 로드 · Argument 39 ① B)
- ⭐ **판정 순간 소리(발사음 · 타격음)는 노티파이가 아니다** — 이미 서버 큐(`GameplayCue.Pres.Attack` · `.Hit`)로 판정 순간에 난다. 선딜 = 타격 지점 마커라 큐 시각 = 애니의 쏘는 프레임 (Argument 52 T2). 노티파이로도 내면 **두 번** 난다
- 카티야 원본 소리 (`Character_FX/Katja/S000` · `ER.Pres.Fill Katja` 규칙 밖 목록 2026-10-01):
  - 판정 순간: `Skill01_Shot` · `_Hit` · `Skill03_Shot` · `_Hit` · `Skill04_Shot` · `_Shot_02` · `_Shot_03` · `Skill04_Hit` · `_Hit_02` · `_Hit_03`
  - 모션 / 기타: `Skill04_Aiming` · `_02` · `_03` · `Skill04_Drone_Scan` · `Skill04_Target_Scan` · `Skill04_Target_Fire` · `Reload_SniperRifle` · `Skill02_*` (W · 보류)
  - 스킨 `S002` · `S003` 폴더에 **같은 파일명** 이 있다 (Argument 49 "스킨 소리는 파일명이 같다")
- 지금 스킨 교체 구조: `UERSkinData.Overrides` 가 **키 단위**로 덮는다 · `PickSound(Key)` 가 스킨 → 무기 세트 → 캐릭터 기본 (`Source/EternalReturn/Presentation/ERPresentationComponent.cpp` `PickSound`)

## 방안

### N1 — 키 노티파이 (사용자 제공 정리 그대로)
노티파이 칸 = `Key` (GameplayTag `Pres.Sfx.*`) · 소리는 연출 DA 줄 `{Key → 소리}` · 스킨은 같은 키 줄로 덮는다.
- 장점: 지금 키 구조 그대로 · 스킨 덮어쓰기 경로가 이미 있다
- 단점: **소리 하나마다 태그 하나** — `Pres.Sfx.Skill.R.Aiming` · `.DroneScan` · `.TargetScan` … C++ 선언 (CLAUDE.md §8 "태그는 ERGameplayTags.h") · 캐릭터가 늘면 태그가 수백
- 단점: 노티파이를 찍을 때 "어떤 소리인지" 가 애니 에디터에서 안 보인다 (태그만)
- 단점: Fill 이 파일명 → 태그 표를 계속 늘려야 한다

### N2 — 소리 노티파이 + 스킨이 같은 이름으로 바꿈 ⭐
노티파이 칸 = `Sound` (기본 = S000 소리를 **직접** 고른다 · 엔진 PlaySound 노티파이와 같은 사용법). 재생 때 연출 컴포넌트가 **지금 스킨에 같은 이름의 소리가 있으면 그것** 으로 바꾼다. 바꿈 표는 Fill 이 스킨 폴더(S00x)와 S000 의 **같은 파일명**을 짝지어 스킨 DA 에 적는다 (`SoundSwaps: 기본 → 스킨`).
- 장점: **태그 0개** · 노티파이에 진짜 소리가 보인다 (애니 에디터에서 미리 듣기)
- 장점: 원본 데이터 규칙(스킨 소리 = 같은 파일명)을 그대로 쓴다 · 손 입력 없음 (Fill)
- 장점: 다른 캐릭터도 같은 규칙 — 코드 추가 없음
- 단점: 스킨 DA 에 칸 하나 (`TMap<소리, 소리>`) · Fill 에 짝짓기 한 단계
- 단점: 파일명이 다른 스킨 전용 소리는 짝이 없다 → 기본 소리 (로그로 보인다)

### N3 — 엔진 `AnimNotify_PlaySound` 그대로
- 장점: 코드 0
- 단점: **스킨이 못 바꾼다** (소리 고정) — 스킨마다 애니 복제는 안 된다 (사용자 제공 정리 §4)

# 68. 시셀라 — 윌슨 · 패시브 보간 · 보호막

## 결정할 것

시셀라 킷에서 **방안이 둘 이상인 것 셋**:
1. **윌슨**을 무엇으로 표현할까 (떨어짐 · 붙음 · 위치)
2. **패시브** — 잃은 체력에 따라 회복 · 스킬 증폭을 실시간으로 바꾸는 방법
3. **보호막** (E 시셀라 적중) — 피해를 어디서 먼저 깎을까

방안이 하나뿐인 것은 맨 아래 "단일안" 에 적는다.

## 1. 윌슨

### 방안 W1 — 떨어졌을 때만 액터 (`AERWilson`) ⭐ 추천
- Q 투사체가 착지하면 서버가 `AERWilson` 을 그 자리에 스폰 (복제 액터 · 소유자 = 시셀라) · 시셀라 ASC 에 `State.Wilson.Away` 태그
- 액터가 **0.1초 타이머**로 시셀라와 거리 확인: 줍기 반경 안 → 합침 · 9.25m 밖 → 복귀 합침
- 합침 = 액터 파괴 + 태그 제거 + `Event.Wilson.Join` 이벤트 → 패시브가 받아서 장전 (쿨 중이면 무시)
- 붙어 있을 때 = **액터 없음** (메시는 시셀라 연출이 들고 있음 — 무기 부착 작업 때)
- E · Q 는 `State.Wilson.Away` 면 윌슨 액터 위치를 시작점 / 목적지로 쓴다

| 장점 | 단점 |
|---|---|
| 붙어 있을 때 비용 0 · 상태가 "액터 있음 = 떨어짐" 하나 | 붙음 ↔ 떨어짐마다 스폰 · 파괴 (Q 쿨 4초 — 문제 안 됨) |
| 위치 · 연출이 액터 복제로 그대로 감 | |

### 방안 W2 — 항상 있는 액터 (붙으면 소켓에 부착)
- 캐릭터가 윌슨 액터를 늘 들고 · Q 때 분리 · 합칠 때 다시 부착
- 장점: 메시 부착이 처음부터 해결 / 단점: 부착 · 분리 복제 처리를 직접 · **무기 부착 작업(Argument 64 · 미룸)과 엉킨다** · 6명 중 시셀라만을 위한 상시 액터

### 방안 W3 — 액터 없이 위치만 (복제 FVector + 태그)
- 장점: 가장 가벼움 / 단점: 윌슨 메시 · 이펙트를 놓을 자리가 없다 → 결국 연출용 액터가 필요 · 거리 확인 타이머를 둘 곳이 애매 (패시브? 컨트롤러?)

## 2. 패시브 — 잃은 체력 → 회복 · 스킬 증폭

### 방안 P1 — 무한 GE + **MMC (모디파이어 크기 계산)** ⭐ 추천
- 패시브가 켜질 때 무한 GE 하나: `HPRegen` · `SkillAmp` 에 더하기. 크기는 MMC 가 `HP / MaxHP` 를 **스냅샷 없이** 잡아 `최소 + (최대 − 최소) × 잃은 비율` · 레벨은 GE 레벨
- HP 가 바뀌면 GAS 가 **알아서 다시 계산**한다 — 엔진이 이미 하는 일 (`FActiveGameplayEffectsContainer::OnMagnitudeDependencyChange` · `GameplayEffect.cpp:3278` · 캡처 `bSnapshot`)
- R 뒤 +100% = **같은 GE 를 7/8/9초짜리로 하나 더** 건다 (두 개가 더해져 2배 — 새 분기 없음)
- 레벨업 = 패시브 GE 다시 걸기 (레벨 바뀔 때)

| 장점 | 단점 |
|---|---|
| 직접 갱신 코드 없음 · "캐싱 금지" 가 저절로 지켜짐 | MMC 클래스 1개 · ⚠ HP **베이스값** 변경에도 재계산되는지 **PIE 로그로 확인** (`(미확인)`) |

### 방안 P2 — HP 변경 델리게이트에서 GE 다시 걸기
- `GetGameplayAttributeValueChangeDelegate(HP)` → SetByCaller 로 새 값 → GE 교체
- 장점: 동작이 눈에 보임 / 단점: 도트 · 회복마다 GE 교체 (재키 출혈 1초 틱 · 회복 0.x초 틱) · 엔진이 해 주는 걸 직접 만듦 (CLAUDE.md §1 "엔진이 이미 제공하는지 먼저")

## 3. 보호막

### 방안 S1 — `Shield` 어트리뷰트 + 피해 계산에서 먼저 깎기 ⭐ 추천
- 어트리뷰트 `Shield` (복제 · UI 용) · 보호막 GE = **지속 2.5초 · 태그 `State.Shielded`** · 걸릴 때 `Shield` 베이스에 + 양
- 피해 계산 끝(최종 피해 다음)에서 `Shield` 먼저 깎고 남은 것만 HP
- GE 가 끝나면(태그 사라짐) `Shield` 를 0 으로
- 장점: Lyra 가 예시로 드는 자리 (`LyraHealthSet.h:27`) · UI 바인딩 쉬움 / 단점: **보호막 여럿이 동시에 있으면 같이 사라진다** — 지금 보호막은 시셀라 E 하나 (다른 캐릭터 · 아이템 보호막은 그때 S2 로)

### 방안 S2 — 보호막 목록 (출처별 양 · 만료)
- 서버 컴포넌트가 `{양, 만료 시각}` 목록 · 피해 때 먼저 만료되는 것부터 깎음
- 장점: 여러 보호막 정확 / 단점: 지금 쓰는 곳 하나에 목록 · 만료 관리 (CLAUDE.md §2 "한 곳에서만 쓰는 코드에 추상화 금지")

## 추천

**W1 + P1 + S1** — 셋 다 "지금 쓰는 곳 하나" 에 맞는 가장 작은 구조이고, P1 은 엔진이 해 주는 재계산을 쓴다.
⚠ P1 은 HP 베이스값 변경 재계산을 PIE 로그로 먼저 확인한다 — 안 되면 P2 로.

## 결정

**W1 + P1 + S1** (사용자 2026-10-06)

- W1 보충 (사용자 질문 "풀링? 붙어 있을 땐 콜리전 없이 옆에?"): **풀링 안 함** — 스폰은 Q 한 번(쿨 4초+)에 1개라 비용이 없다. 풀링은 초당 수십 개(투사체)일 때 값어치가 있다.
  붙어 있을 때 = **액터 없음**. 윌슨 액터는 원래 콜리전이 없다 (줍기 · 복귀는 타이머 거리 확인). 붙어 있을 때 보이는 윌슨은 시셀라 **연출 부착 메시** — 무기 · 소품 부착 작업(Argument 64 · "날 잡고")에서 같이 한다. 그 전까지는 떨어진 윌슨만 보인다
- P1 확인 (PIE 2026-10-05 20:28): HP **베이스값**을 바꿔도 · 피해를 받아도 재생 값이 다시 계산된다 (`재생 6.600` · `3.180`) — P2 로 갈 일 없음

# 81 — 스킬 시전 때 몸을 커서로 돌릴지 (방향 유지 스킬)

> 관련 [80 전술스킬](80_전술스킬.md) · 체크리스트 [`F20_전술스킬/01`](../2_Checklist/F20_전술스킬/01_전술스킬.md) 6단계

## 결정 요약

| 항목 | 결정 |
|---|---|
| 방식 | **A** `UERSkillData::bKeepFacing` (사용자 2026-10-14) |
| 방향 유지 목록 | 아래 표 제안대로 7종 적용 — 원작 확인 못 한 4종은 PIE 보고 바꿀 수 있음 (JSON 한 줄) |

## 결정할 것

지금은 **모든 스킬이 시전 때 몸을 조준 방향으로 돌린다**. 진실의 칼날 · 초월 · 아티팩트처럼 방향이 없는 스킬은 돌지 않게 하려면, 이 구분을 어디에 둘지 정해야 한다.

## 지금 코드

- `Source/EternalReturn/GAS/ERGameplayAbility.cpp:571-581` — `ResolveAim` 끝에서 무조건 `SetActorRotation(조준 방향)` (사용자 요청 2026-09-20). 서버와 소유 클라 양쪽에서 돈다.
- `ResolveAim` 은 조각(`OnExecute`)보다 **먼저** 돈다. 조각은 지금 회전을 막을 수 있는 훅이 없다.
- 따로 도는 곳: 자기 이동 `ERSkillFragment_SelfMove.cpp:65 · 84`, 순차 사격 `ERSkillDelivery.cpp:294`. 이 둘은 방향이 있는 스킬이라 그대로 둔다.
- 같은 꼴의 선례: `UERSkillData` 의 `bNoCastCue` · `bCastWhileMoving` (`ERSkillData.h:450-456`, 카테고리 "시전" bool).

## 방안

### A. `UERSkillData` 에 bool 하나 — `bKeepFacing` (기본 false = 지금처럼 돈다)
```cpp
/** 시전 때 몸을 조준 방향으로 돌리지 않는다 — 방향 없는 스킬 (진실의 칼날 · 초월 · 아티팩트 · 사용자 2026-10-14) */
UPROPERTY(EditDefaultsOnly, Category = "시전")
bool bKeepFacing = false;

// ResolveAim 571~
if (!Skill.bKeepFacing) { ... SetActorRotation ... }
```
- 장점
  - 바뀌는 곳이 `ResolveAim` 한 줄 조건뿐. 기본값이 지금 동작이라 캐릭터 스킬은 그대로다
  - `bNoCastCue` · `bCastWhileMoving` 와 같은 자리 · 같은 꼴이라 찾기 쉽다
  - JSON `Props` 한 줄로 켠다 (임포트 그대로)
- 단점
  - 새 UPROPERTY → 에디터 재시작
  - 스킬마다 직접 켜야 한다 (자동 아님)

### B. 새 조각 `방향 유지` (KeepFacing)
- 조각 베이스에 "시전 전 회전 허용?" 훅을 하나 추가하고, 이 조각이 false 를 돌려준다.
- 장점
  - 사용자가 말한 "조각" 모양 그대로. 조각 목록만 보면 보인다
- 단점
  - 하는 일이 없는 조각 — 값이 없는 on/off 를 조각 클래스 하나 + 베이스 훅으로 만든다 (CLAUDE.md §2 "한 곳에서만 쓰는 추상화 금지")
  - `ResolveAim` 이 조각 목록을 한 번 더 돌아야 한다
  - 레벨별로 다를 일이 없어 조각의 장점(레벨 · 조건 `MinLevel` · `AttackRangeCond`)을 안 쓴다

### C. 자동 — 판정 모양이 자기 중심(SelfRadius · 모양 없음)이면 안 돈다
- 장점
  - 데이터를 안 고친다
- 단점
  - **캐릭터 스킬까지 바뀐다.** 자기 중심인데 지금 돌고 있는 스킬(재키 R 등)의 원작 동작을 하나씩 확인하지 않았다 (미확인)
  - 예외가 생기면 결국 A 의 bool 이 또 필요하다

## 비교

| | A bool | B 조각 | C 자동 |
|---|---|---|---|
| 구현 난이도 | 낮음 (2줄) | 중간 (훅 + 클래스) | 낮음 |
| 확장성 | 스킬마다 켬 | 스킬마다 붙임 | 규칙 하나 — 예외에 약함 |
| 네트워크 | 변화 없음 (회전은 지금처럼 이동 복제) | 같음 | 같음 |
| GAS 정합성 | 무관 (조준 · 회전은 자체 영역) | 무관 | 무관 |
| 성능 | 같음 | 조각 순회 1회 | 같음 |
| 기존 스킬 영향 | 없음 | 없음 | **있음** |

## 추천 — A

on/off 하나를 조각으로 만들 이유가 없다. 같은 성격의 `bNoCastCue` · `bCastWhileMoving` 가 이미 `UERSkillData` 에 있다. C 는 캐릭터 스킬까지 바뀌어 확인 범위가 커진다.

| 스킬 | 제안 | 근거 |
|---|---|---|
| 진실의 칼날 · 초월 · 아티팩트 | **유지** | 사용자 2026-10-14 |
| 플라즈마 대시 | 돈다 | 사용자 2026-10-14 |
| 블링크 · 붉은 폭풍 · 리펄서 미사일 | 돈다 | 조준 방향으로 이동한다 (미확인 — 원작 영상 확인 안 함) |

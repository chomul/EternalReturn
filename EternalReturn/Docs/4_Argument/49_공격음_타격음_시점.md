# 49 — 공격음 · 타격음을 언제 · 어디서 내나 (F12.5-05)

> 착수: 2026-09-29 F12.5-05. 선행 결정: [Argument 39](39_몽타주_위치_모션세트.md) ④ **K2** — 노티파이 · 큐는 **키만** 들고 소리는 연출 DA 에서 찾는다 (스킨이 소리를 바꿀 수 있게 · P4 큐 애셋 가볍게) · 무기 효과음은 **무기 공통** 층 `(*, 무기)` · [36](36_애니메이션_사운드_연출_레이어.md) 이펙트 · 사운드 = GameplayCue
> 관련: CLAUDE.md §8 · [45](45_후딜과_애니길이_캔슬.md) (선딜 = 애니 타격 프레임으로 맞춤)

## 결정 요약

| # | 항목 | 결정 |
|---|---|---|
| ① | 공격음(휘두름 · 총성) 을 내는 시점 | **W2 채택 — 서버 판정 시점 GameplayCue.** 공격음은 나중에 소유자 예측 허용 · 타격음은 서버 확정만 (사용자 2026-09-29 "W2로 진행하자" · 검토 반영) |
| ② | 타격 시점의 원천 (Source of Truth) | **어빌리티 데이터의 선딜(CastTime)** — 노티파이 아님. 애니메이터 파이프라인이 생기면 노티파이로 옮길 수 있다 (아래 "왜 노티파이가 아닌가") |

## 규칙 (① · ②)

| | 공격음 (Attack) | 타격음 (Hit) |
|---|---|---|
| 뜻 | 공격 행위가 **일어났다** | 공격이 **맞았다** (서버 확정) |
| 지금 | 서버 판정 → `GameplayCue.Pres.Attack` (시전자) | 서버 판정 → `GameplayCue.Pres.Hit` (맞은 대상마다) |
| 나중 (GAS 예측을 켤 때) | 소유자 = 예측 재생 · 남 = 서버 큐 | **예측 금지** — 서버 확정만 |
| 위치 | 시전자 (나중엔 무기 위치) | **타격 지점** `Params.Location` · `Normal` — 지금은 판정이 액터만 돌려줘서 "대상 몸 표면의 시전자 쪽" 근사. HitResult 가 생기면 그 ImpactPoint. 이펙트(Niagara)가 생겨도 **같은 지점**을 쓴다 |
| 변형 r1 · r2 · r3 | **각 클라 로컬 무작위** — 의미 없는 변형이라 복제 안 함 | 같음. 단 **의미가 있는 소리**(치명타 · 벽 충돌 등)는 서버가 **종류**를 정하고, 그 안의 r1~r3 만 로컬 무작위 |

- **큐 ≠ 키**: `GameplayCue.Pres.*` 는 네트워크 사건, `Pres.Sfx.*` 는 동작표 조회 키. 같은 큐 하나가 나중에 `Pres.Fx.*` · 카메라 흔들림까지 부를 수 있다 — 무기마다 큐 태그를 늘리지 않는다
- **판정이 없는 소리**(발소리 · 옷 소리 · 장전 중 탄창 소리 · 채집)는 애니 프레임 자체가 뜻이라 **노티파이(W1)** 로 — 나중에

## 왜 노티파이가 아닌가 (② · 사용자 정리 2026-09-29)

- **애니메이터 중심 파이프라인**이면 `애니 노티파이(타격 프레임) → 판정 → 타격 큐` 가 정석이다. 애니를 고쳐 타격 프레임이 0.32 → 0.38 로 옮겨도 애니메이터가 노티파이도 같이 옮기니 코드 숫자를 다시 맞출 일이 없다 — **애니가 타격 시점의 원천**
- 이 프로젝트는 전담 애니메이터가 공격마다 타격 프레임을 찍어 주는 파이프라인이 없고, 45 에서 이미 **선딜을 애니 타격 프레임에 맞춰** 관리한다 → 원천은 사실상 **어빌리티 데이터의 선딜**
- 여기에 노티파이를 더하면 `노티파이 0.43` · `선딜 0.43` **두 곳을 계속 맞춰야** 한다. W2 는 `선딜 → 판정 + 공격음` 이라 **원천이 하나**
- 즉 "노티파이가 정석이 아니다" 가 아니라 **정석 중 하나를 지금 제작 조건에 맞춰 고른 것**
- ⏸ **나중에 바꿀 수 있다** — 전담 애니메이터 · 애니 파이프라인이 생기면 선딜 숫자 수동 관리를 줄이고 **노티파이 / Sync Marker 를 타격 시점의 기준**으로 옮기는 것을 다시 본다 (그때는 판정도 노티파이를 따라간다)

| 무엇 | 위치 | 예 |

## 방안 — 공격음 시점

| 방안 | 방식 | 판정 |
|---|---|---|
| W1 | **애니 노티파이** `UERAnimNotify_PlayKey(Pres.Sfx.Attack)` 를 각 애니의 휘두르는 프레임에 — 애니를 트는 모든 머신에서 로컬 재생 | 소유자는 입력 즉시 들린다. 대신 애니 **약 100개**에 노티파이 · 선딜과 **두 곳 동기화** (위). 움직여서 모션이 끊기면 소리도 안 난다 |
| **W2** | **판정 시점 큐** — 어빌리티가 판정할 때(선딜 끝 = 45 에서 애니 타격 프레임에 맞춘 시각) 시전자에게 `GameplayCue.Pres.Attack` · 맞은 대상마다 `GameplayCue.Pres.Hit` | 노티파이 0개 · 원천 하나 · 소리가 **판정과 같은 순간**. 소유자도 서버를 거쳐 들린다 (RTT 만큼 — 예측 때 공격음만 앞당긴다) |
| W3 | 몽타주 시작 때 | 망치처럼 선딜이 긴 동작은 **내려찍기 전에** 소리가 난다 · 다른 클라는 GAS 몽타주 복제라 우리 코드가 안 돈다 |

## 구현 (2026-09-29)

```
UERGameplayAbility::ExecuteSkill (서버 · 판정 직후) → SendPresCues
 ├─ 시전자 ASC → ExecuteGameplayCue(GameplayCue.Pres.Attack)   ← 2차 판정(ExecuteOther) 에는 없음 — 시전 한 번에 한 번
 └─ 맞은 대상 ASC 마다 → ExecuteGameplayCue(GameplayCue.Pres.Hit, Location = 타격 지점 · Normal)
     Params: Instigator = 시전자 · SourceObject = 스킬 DA · AggregatedSourceTags = 슬롯 (평타 / 스킬 구분)
       ↓ GAS 멀티캐스트 → 각 클라 (데디 서버는 GAS 가 막는다 — GameplayCueManager.cpp:167)
 AERCharacterBase · AERWildlifeCharacter :: IGameplayCueInterface::HandleGameplayCue   ← 큐 BP 애셋 없이 C++ 로 (GameplayCueManager.cpp:222)
   → UERPresentationComponent::HandlePresCue
     → 시전자(Instigator)의 연출 컴포넌트에서 키:  평타 = Pres.Sfx.Attack / Hit · 스킬 = Pres.Sfx.SkillCast / SkillHit
     → PickSound — 그 줄의 소리 중 로컬 무작위 → PlaySoundAtLocation
```

- **무기 공통 DA** `DA_Pres_Weapon_<무기>` — 가리키는 곳: **`DT_WeaponClass` 의 새 칸 `Presentation`** (CSV 원본 · 데이터 테이블 참조라 쿠킹에도 따라간다). ~~DeveloperSettings~~ 는 쓰지 않았다. 연출 컴포넌트가 무기 세트와 **같이 비동기 로드** · 조회의 **가장 넓은 층**
- `ER.Pres.Fill Weapon` — **무기 기본** 소리 `SFX/Attack · Attack_Hit · Skill · Skill_Hit` → `DA_Pres_Weapon_<무기>` (`/Game/ERCharacter/CharData/Presentation/Weapon`). 예전 임포트 `SFX/Weapon/<무기>/` 는 안 읽는다 (중복)
- `ER.Pres.Fill <캐릭터>` — **캐릭터 · 스킨** 소리 `SFX/Character_FX/<캐릭터>/s000` → 캐릭터 무기 세트 · `s00x` → 그 스킨 DA (무기 칸) · 이름 규칙 밖(`Katja_SniperRifle_Shot` · `wskill_*` · `Skill01~04_*` …)은 로그 → 손으로 / F19

### ⭐ 원작 소리는 3층이다 (사용자 제공 `ER_Asset/03_Log/사운드_카탈로그.csv` · 2026-09-29)

|---|---|---|

→ 사용자 지적 *"캐릭터마다 무기가 같더라도 사운드가 다르고 특수 스킨들은 또 다르다"* 는 원작 데이터와 맞고, 조회 층(39)이 이미 이 모양이라 **코드 변경 없이 Fill 만** 고쳤다. 재키 s000 · 매그너스 s000 · 시셀라 · 다니엘은 평타 전용 소리가 없어 무기 기본을 쓴다 (원작도 같음)
- 야생동물 소리 — ⏸ 이름이 제각각이라 이번엔 안 채운다 (종 DA 에 `Pres.Sfx.Attack · Hit` 줄을 손으로 넣으면 바로 동작)

## 네트워크

새 복제 없음. 일회성 `ExecuteGameplayCue` 는 **ASC 의 멀티캐스트 RPC**로 간다 — 복제 모드(Mixed · Minimal)를 보지 않는다 (`GameplayCueManager.cpp:1453` FlushPendingCues). Minimal 전용 컨테이너(`AddGameplayCue_MinimalReplication`)는 **지속형 큐** 경로라 이번 것과 다르다.
⚠ 확인 필요: 잠든(도먼시) 야생동물의 ASC 로 가는 멀티캐스트는 **unreliable** 이라 버려질 수 있다 — 첫 타격음이 빠지는지 PIE 에서 본다 (맞으면 AI 가 다음 틱에 깨운다 · E24).
소리 선택은 각 클라가 시전자의 무기 · 스킨으로 (39 와 같음). 데디 서버는 오디오를 안 올린다 (39 P).

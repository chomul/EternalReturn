## 지금 코드 (확인 2026-09-29)

- 채집은 **서버 전용**: `TryBeginGather` 점유 → 인벤토리 타이머 `GatherSeconds` 뒤 `FinishGather` 가 아이템 지급. **아무것도 복제되지 않는다** — 클라는 채집 중인지 모른다
- ⚠ **이동해도 채집이 안 끊긴다** — 타이머가 그대로 돌아 멀리 가도 아이템이 들어온다. 채집 취소 규칙은 원작 **(미확인)** (조사 2026-09-29 — 찾지 못함)
- 애셋: 실험체 6명 모두 `Common_collect` (공용) · `collect_wood` · `collect_stone` · `collect_water` 가 있다

## 방안

| 방안 | 방식 | 판정 |
|---|---|---|
| **G1** | 서버가 채집 시작 때 ASC 에 **복제 느슨한 태그 `State.Gathering`**, 끝날 때 뗀다 → 연출 컴포넌트가 AnimInstance `bGathering` + `GatherAnim`(DA 공용 줄 `Pres.Anim.Gather`) → 상태머신 **Gather 상태** (Idle · Run 에서 **상태 에일리어스**로 진입) | 원칙 2 "지속 상태" 에 맞다 · 늦게 relevant 된 클라도 본다 · 저격 모드와 **같은 경로**(복제 느슨한 태그 → `BindModeTags` 식 구독 → AnimInstance) — `ReplicatedLooseTags` 는 COND_None 이라 모두에게 간다 (`AbilitySystemComponent.cpp:1609`). 이동 중이면 전이 조건 `bIsMoving` 으로 Run 으로 나간다 (태그는 남아도 보이는 건 달리기) |
| **G2** | 서버가 채집 시작 때 **연출 키 `Pres.Anim.Gather` 를 GatherSeconds 동안 재생** (평타 · 스킬과 같은 슬롯에 · 어빌리티가 없으니 **폰의 NetMulticast 1개**로 각 머신이 재생) | 새 복제 상태 없음 · 이동하면 기존 규칙대로 **모션이 끊긴다**(`StopActionAnim`). 채집은 2~3초라 늦은 relevant 를 놓쳐도 티가 안 난다 |
| G3 | 미룬다 — F17(채집 진행 바) · 채집 취소 규칙과 같이 | 04 는 빨리 끝나지만 채집이 서 있는 채로 보인다 |

- 재료별 모션(나무 · 돌 · 물): 채집물이 무슨 재료인지 연출에 알려야 한다 — **이번에는 공용 `collect` 하나** · 재료별은 루트 행에 연출 키 칸을 붙일 때 (F17 과 같이)
- 채집 취소(이동 시 아이템 안 줌)는 **연출이 아니라 게임 규칙(F09)** — 여기서 안 바꾼다. 원작 확인 후 따로

~~추천 G2~~ → **추천 G1** (사용자 제안). 채집은 몇 초 이어지는 **상태**라 원칙 2 에 맞고, 저격 모드 경로를 그대로 재사용한다 — 새 RPC 없음 · 태그 1개. G2 의 Multicast 보다 코드가 적다.

## 네트워크

G1: 서버가 점유 성공 시 `AddLooseGameplayTag` + `AddReplicatedLooseGameplayTag(State.Gathering)`, `EndGather` 때 제거 — 서버 권위 · 클라는 태그 수만 본다. (참고) G2: 서버가 채집 시작을 확정한 뒤 연출 재생을 각 머신에 알린다 — 폰 `NetMulticast(Unreliable)` 로 키 · 시간 하나 (어빌리티 몽타주 복제 경로는 어빌리티가 없어 못 쓴다). 게임 상태(점유 · 지급)는 지금처럼 서버 전용.

# 27. 저격총 D "모드" 를 무엇으로 표현하고, 3발(저지 2 + 데드아이 1) 전환은 어디서 하나

> F11-05 D 회차 · 근거 [`무기계열_D스킬_역기획서.md`](../0_GameDesign/Systems/무기계열_D스킬_역기획서.md) §2.3.5 저격총 · §8.3
> 관련 [`17_시전상태_표현과_취소경로.md`](17_시전상태_표현과_취소경로.md) (Event.Input.Move · State.Block.Skill 취소 경로) · [`25`](25_D쿨다운_무기별보존_스왑락.md) (D 활성 중 교체 거부)

## 결정할 것

원작 (나무위키 확인 2026-09-19): **저격 모드 10초** · 그 동안 기본 공격이 **저지사격 ×2 → 데드아이 ×1** 로 바뀜 · **이동 · CC 시 해제** · 한 발도 안 쐈으면 해제 시 **쿨 50% 반환** · 논타겟 투사체.
"평타 슬롯 교체" 는 F11 태스크에서 이미 정했다 (모드 전환 = 새 서브시스템 없이 슬롯 스펙을 갈아끼움). 남은 결정 둘:

1. **모드 상태를 무엇이 들고 있나** — 10초 타이머 · 해제 조건 · 정리
2. **발수 전환(2발 뒤 데드아이, 3발 뒤 종료)을 누가 세나**

---

## ① 모드 상태

### 방안 A — D 어빌리티가 모드 내내 **활성** (인스턴스가 상태를 든다) ⭐ 추천

D 발동 → 커밋(쿨 35) → PS 에 "평타를 저지사격으로" → **EndAbility 하지 않고** `WaitDelay(10)` · `WaitGameplayEvent(Event.Input.Move)` · `WaitGameplayTagAdded(State.Block.Skill)` 셋을 건다 (선딜이 쓰는 것과 같은 AbilityTask). 어느 것이든 오면 `ExitMode` → 평타 복구 → 미사용이면 쿨 반환 → EndAbility. 외부 취소(CC 의 CancelAbility · 사망)도 EndAbility 로 모이므로 **정리가 한 곳**.
- 장점: 취소 경로가 선딜과 **같은 배선** (Argument 17) · `CanChangeWeapon` 의 "D 활성 중 교체 거부" (Argument 25) 가 그대로 저격 모드에도 적용 · 타이머/이벤트가 어빌리티와 같이 죽음 (E19 가 여기서는 **원하는** 동작)
- 단점: 어빌리티가 10초 동안 "활성" 이라 같은 슬롯 재입력이 무시된다 (재입력으로 해제하는 원작 규칙은 미확인 — 필요하면 그때)

### 방안 B — 상태 GE (`State.SniperMode`, 10초) + PS 가 타이머 · 해제

PS 가 `OnGameplayEffectRemoved` 를 듣고 평타를 복구. 이동 · CC 해제는 PS 가 따로 구독.
- 장점: D 어빌리티는 즉시 끝남
- 단점: 해제 조건 3개를 PS 에 다시 배선 (선딜이 이미 가진 것의 복제) · "D 활성 중 교체 거부" 가 안 걸려 §8.3 강제 해제 경로를 따로 짜야 함 · 쿨 반환은 어빌리티 밖에서 쿨다운 GE 를 찾아야 함

## ② 발수 전환

### 방안 A — 스펙 교체 2회 + `ASC->OnAbilityEnded` 카운트 ⭐ 추천

모드 진입에 `Mode.AttackData`(저지) 부여 → 평타 어빌리티가 **끝날 때마다** (취소 아님) D 어빌리티가 센다 → 2발이면 `Mode.FinalAttackData`(데드아이) 로 교체 → 3발이면 ExitMode. 빗나가도 1발 (원작 탄 소모).
- 장점: 평타 어빌리티는 아무것도 모른다 · 데이터 2개가 그대로 두 발의 전부 (피해 · 형상 · 적중 효과 다름) · 델리게이트는 GAS 제공
- 단점: 스펙 교체가 모드당 2번 (Give/Clear — 서버 전용, 가벼움)

### 방안 B — 평타 어빌리티가 모드 카운터를 읽고 데이터 분기

`UERSkillData` 에 `ShotSequence[]` 를 두고 어빌리티가 n번째 발을 고름.
- 장점: 스펙 교체 없음
- 단점: 평타 어빌리티가 "모드" 를 알아야 함 (카운터 저장 위치 · 복구) · `GetExecSkill` 경로가 하나 더 · 저격총 하나 때문에 평타 공통 코드가 늘어남

## 원작과 다르게 두는 것 (D 회차 범위 밖)

| 항목 | 지금 | 이유 |
|---|---|---|
| 논타겟 **투사체 속도** | 즉발 캡슐 스윕 (`Projectile` 형상) | 진짜 투사체 액터는 F11 뒤 (F04 결정 유지) |
| 저지사격 **대상 시야 2초** · 탄 시야 3 | 없음 | F16 시야 |
| 데드아이 **잃은 체력 비례 최대 200%** | 구현 — `Data.Damage.TargetLostHPScaleMax` SetByCaller 한 줄 (대상 잃은 체력 비율 × 최대 배율) | 실행식이 대상 HP·MaxHP 를 이미 캡처한다 |

## 결정할 것

빈사 자세(쓰러짐 · 대기 · 기어감 · 일어섬)를 AnimBP 의 **모드 상태**(ModeStart · ModeLoop · ModeEnd — 저격 · 전기톱과 공유)로 틀지, **빈사 전용 상태**로 틀지.

## 문제 (Argument 75 첫 구현 — `Mode.Downed`)

- 모드는 한 번에 하나 · 상태머신은 `bInMode` 하나로 진입 · 해제를 본다 (`ERPresentationComponent.cpp` RefreshMode · `ERAnimInstance.cpp` bEnterModeStart …)
- 재키 R(전기톱 모드) 중 빈사 → `bInMode` 가 계속 참 → ModeStart 를 다시 안 탄다 → **쓰러짐(down_start) 없이** 기어감으로
- 소생 때 R 효과가 남아 있으면 빈사 → 전기톱으로 모드만 바뀐다 → **일어섬(resurrect) 없이**
- 원인: 빈사 진입은 시전 중 어빌리티만 취소하고 걸린 버프 GE(모드 태그)는 남긴다

## 방안

### D1 빈사 전용 상태 ⭐
- AnimBP: DownStart → DownLoop(대기 ⇄ 기어감) → DownEnd → Idle · 진입 에일리어스 = 평소 + 모드 상태 전부 · Dead 가 이긴다
- C++: `bDowned` · `DownStart/Idle/Run/EndAnim` · 전이 변수 4개 (쉬는 자세와 같은 패턴) · 태그 `State.Downed` 구독
- 장점: 어느 모드 중에 쓰러져도 동작이 맞다 · 게임 규칙을 새로 정하지 않는다
- 단점: AnimBP 상태 3개 + 에일리어스 2개 (Dead 상태와 같이 한 번)

### D2 모드 경로 + 빈사 때 다른 모드 효과 제거
- 장점: AnimBP 추가 작업 없음
- 단점: "빈사 = 버프 해제" 라는 **원작 미확인 규칙**을 연출 때문에 만든다

## 추천 · 결정
D1 — 연출 문제를 연출 쪽에서 · 게임 규칙을 추측으로 바꾸지 않는다.

## 구현 (2026-10-08)
- `Mode.Downed` 태그 삭제 · 애니 키 `Pres.Anim.DownStart · DownIdle · DownRun · DownEnd` (+ `DownDead`)
- 빈사에서 죽었다는 표시 = 사망 GE 의 `State.Dead.FromDowned` → 사망 애니 down_dead (빈사 태그가 빠지는 순서와 무관)
- `bDownOutro` 는 사망이면 거짓 — 사망 GE 와 빈사 GE 제거가 한 번에 복제돼도 일어서지 않는다

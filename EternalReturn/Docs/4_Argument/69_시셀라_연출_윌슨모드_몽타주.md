## ① 윌슨 떨어짐 자세 — 방안

### A1 — 모드 태그 `Mode.WilsonAway` ⭐
윌슨 액터가 붙이는 태그를 `Mode.WilsonAway` 로 (또는 `State.Wilson.Away` 와 같이). 동작표 모드 줄: 대기 `skill01_wait` · 달리기 `skill01_run` (무기별 · 투척은 공통) · 진입 · 해제 없음 (건너뛰기).
- 장점: 재키 전기톱과 같은 길 — 코드는 태그 한 줄 · Fill 모드 규칙 한 줄. 떨어짐 · 합침 · 복제가 이미 맞물려 있다
- 단점: 모드 줄이 평타 · 스킬 애니도 덮을 수 있다 — 윌슨 떨어짐 중 평타 · 스킬은 평소 것을 써야 해서 모드 줄에 **대기 · 달리기만** 둔다 (없는 키는 기본 줄로 내려간다)

### A2 — 무기 레이어를 바꾼다
윌슨 떨어짐 동안 `ABPL_Sissela_*` 를 다른 레이어로.
- 단점: 무기 레이어는 장착 무기 하나의 자리 — 무기 교체와 겹친다 · 새 코드

## ② W 감싸기 — 방안

### B1 — 모드 `Mode.Bubble` ⭐
감싸기 GE 에 `Mode.Bubble` 을 같이 단다 (1.5초). 모드 줄: 진입 `skill02_start` · 대기 = 달리기 = `skill02_idle` · 해제 `skill02_end`.
- 장점: 시작 · 유지 · 끝이 **GE 수명과 정확히** 맞는다 (어빌리티는 바로 끝나서 몽타주 섹션을 넘겨 줄 주체가 없다 — E40). 움직여도 감싼 자세 유지
- 단점: 모드가 둘 (윌슨 떨어짐 + 감싸기) — W 가 윌슨을 합치므로 **동시에 있을 일이 없다** (W = 합침 → `WilsonAway` 가 먼저 빠진다)

### B2 — 몽타주 섹션 `Start` → `Loop` → `End`
터짐 타이머가 `End` 로 넘긴다.
- 단점: 어빌리티가 끝난 뒤 섹션 넘기기 — 서버 · 복제 · 소유 클라를 따로 챙겨야 한다 · 움직이면 이동 끊기(E38)와 부딪힌다

# 62. 매그너스 R 폭주 바이크 — 7초 동안 "누누 눈덩이" 처럼 꺾이는 이동

## 결정할 것

바이크를 타는 7초 동안 **멈추지 않고 앞으로 달리며, 이동 명령 쪽으로 천천히 꺾이는** 이동(사용자 2026-10-03 "즉각적이진 않고 롤의 누누 눈굴리듯이")을 무엇으로 만들지.

## 규칙

| 항목 | 값 | 출처 |
|---|---|---|
| 시간 · 속도 | 7초 · 1 → 8 m/s · **2초에 최대** | 게임 툴팁 (사용자 2026-10-03) |
| 조종 | **늘 앞으로** · 이동 명령(우클릭) 쪽으로 **회전 속도 제한**을 두고 꺾임 | 사용자 2026-10-03 (b · 누누) |
| 충돌 | **적 실험체 또는 벽** → 폭발 피해 (+대상 현재 체력 30%) · **탑승 끝** | 툴팁 · 사용자 확인 |
| 재사용 | 바이크만 앞으로 발사 (16 m/s · 9m) · 매그너스는 즉시 내림 | 툴팁 · 역기획서 |
| 이동 방해 면역 | 탄 동안 | 역기획서 |
| 회전 속도 · 폭발 반경 | `(미확인)` → `[자체]` 로 시작 (예: 초당 120° · 반경 2m) | — |

이미 있는 것:
- 클릭 이동 = `AERPlayerController::OnMoveToCursor` → `StartMoveTo` + `ServerSetDestination` (`Source/EternalReturn/Core/ERPlayerController.cpp:496`)
- 이동 속도 = 어트리뷰트 `MoveSpeed` (m/s) → CMC `MaxWalkSpeed` (`Character/ERCharacterBase.cpp:318-326`)
- 강제 이동 = 루트모션 소스 (`Combat/ERForcedMove*` — E 뒤로 뛰기 · 넉백 · 돌진)
- 직선 투사체 = `AERProjectileBase` (재사용 발사)

## 방안

### V1 — CMC 커스텀 이동 모드 `Bike`
`UCharacterMovementComponent` 파생 · `MOVE_Custom` + `PhysCustom` 에서 속도(시간 보간) · 진행 방향(목표 쪽으로 초당 N°) · 벽 충돌 판정.
- 장점: 엔진이 준비한 "새 이동 방식" 자리 · 이동 예측(소유 클라 즉시 반응) · 벽 · 경사 처리가 이동 코드 안에
- 단점: 캐릭터의 CMC 클래스를 바꿔야 한다 (BP 의 무브먼트 컴포넌트 교체) · 저장 동작(SavedMove)에 모드 진입을 실어야 예측이 맞는다 — 가장 무겁다

### V2 — 서버 강제 이동 (루트모션 소스를 매 틱 방향 갱신)
지금 E 뒤로 뛰기와 같은 길. 서버가 목표 쪽으로 방향을 돌려 힘을 다시 건다.
- 장점: 이미 있는 코드 · 서버 권위가 단순
- 단점: **예측이 없다** — 시전자 화면에서 꺾는 반응이 핑만큼 늦다 (7초 내내 조종하는 스킬이라 조작감에 직결) · 루트모션 소스를 계속 갈아 끼움

### V3 — 걷기 이동 그대로 + "입력만 바이크처럼" ⭐
탄 동안: ① 이동 속도는 GE 로 1 → 8 m/s (2초 보간 · 어트리뷰트라 서버 · 클라 같음) ② 캐릭터는 **매 틱 앞으로 이동 입력** — 입력 방향을 이동 명령 목표 쪽으로 **초당 N° 까지만** 돌린다 (경로 따라가기는 탄 동안 끔) ③ 서버가 앞쪽을 쓸어 적 실험체 · 벽 충돌 → 폭발 · 내림.
- 장점: 기본 걷기의 **이동 예측 그대로** (입력이 이동 패킷에 실린다) · 새 이동 모드 · CMC 교체 없음 · 속도는 기존 어트리뷰트 경로
- 단점: 걷기 이동이라 벽에 비스듬히 닿으면 미끄러진다 → 벽 충돌을 따로 쓸어 잡아야 한다 · 회전 제한 계산이 서버 · 클라에서 같아야 한다 (같은 입력 · 같은 공식이면 같다 — 어긋나면 작은 보정)

## 비교

| | V1 | V2 | V3 ⭐ |
|---|---|---|---|
| 구현 난이도 | 높음 (CMC 파생 · SavedMove) | 낮음 | 중간 |
| 시전자 조작감 | ◎ 예측 | ✗ 핑만큼 늦음 | ○ 예측 (걷기 그대로) |
| 확장성 (다른 탈것 · 질주) | ◎ | △ | ○ |
| 네트워크 | 이동 복제 (예측) | 서버 → 루트모션 복제 | 이동 복제 (예측) |
| GAS 정합성 | 같음 | 같음 | 속도 = GE (◎) |
| 성능 | 같음 | 같음 | 같음 |

## 추천

**V3.** 7초 내내 조종하는 스킬이라 예측이 필요하고(V2 탈락), 걷기 이동에 "늘 앞으로 + 회전 제한 입력"만 얹으면 엔진 예측을 그대로 쓴다. 조작감이 부족하면 그때 V1 로 올린다 (입력 계산은 그대로 옮겨 감).

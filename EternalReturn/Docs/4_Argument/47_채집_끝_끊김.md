## 방안 (이전)

| 방안 | 방식 | 판정 |
|---|---|---|
| **E1** | AnimBP 에서 Gather → Idle 화살표 **Blend 0.2 → 0.4~0.5초 · Blend Mode 부드러운 곡선(Cubic · Sinusoidal)** | 에디터만 · 1분. 앉은 자세에서 **일어나는 과정**이 보인다. 다만 모션 중간을 가로지르는 건 그대로 |
| E2 | 채집 시간에 **애니 길이를 맞춘다** — 재생 속도 = 애니 길이 ÷ 채집 시간 (레니 3.0 ÷ 2.0 = ×1.5) → 끝날 때 애니도 끝(서 있는 자세) | 가장 자연스럽다. 단 **채집 시간을 모든 머신이 알아야** 한다 — 지금은 태그만 가서 모른다 → 복제 값 하나(폰 또는 PlayerState 에 채집 시간) 추가 · Sequence Player PlayRate 핀 |
| **E4** | 채집 태그가 붙으면 각 머신이 collect 를 **몽타주로 원래 속도** · 반복 = 올림(채집 시간 ÷ 길이) · 채집이 끝나도 **안 끊는다** (남은 일어서기는 꼬리 — Argument 45 C2 와 같은 규칙) · 각 머신이 자기 화면 속도로 움직이면 끊는다 (`UERAnimInstance::StopOnMoveMontage`) | 속도 그대로 · 일어서기까지 보인다. 채집이 끝난 뒤 모션이 조금 더 남는다 (재키 · 매그너스 4.67초 애니 → 2.7초) — 그동안 움직이면 바로 끊긴다. 늦게 relevant 된 클라는 채집 모션을 못 본다 (2~3초라 무시) |
| E3 | 애니 끝의 서 있는 부분만 따로 "채집 끝" 동작으로 트기 | 끝 동작 애니가 원본에 **없다** (collect 하나뿐) — 잘라서 만들어야 한다 |

**추천 E1** (지금 바로 · 코드 없음). 보고 아직 튀면 E2. → E1 부족 → E2 구현 → 사용자가 속도 변경 거부 → **E4 채택** (2026-09-29). E2 코드(`GatherPlayRate` · AnimBP Gather 상태 · `bShowGather`)는 지웠다. `GatherSeconds` 복제는 반복 횟수 계산에 남긴다. 옛 E2 메모: 구현: `AERPlayerState::GatherSeconds` (Replicated · 태그와 같은 액터라 같은 번들) · `UERAnimInstance::GatherPlayRate` (바퀴 수 = max(1, 반올림(채집 ÷ 길이))). 빌드 에러 0

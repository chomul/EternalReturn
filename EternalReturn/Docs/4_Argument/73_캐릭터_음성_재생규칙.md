## D1 — 누가 듣나

### V-A 전부 주변 3D
모든 대사를 그 캐릭터 자리에서 3D 로. 들리는 거리 안이면 적도 듣는다.
- 장점: 규칙 하나 · 코드 가장 적음
- 단점: 제작 · 채집 · 상자 혼잣말까지 적에게 들린다 — **숨어 있는 위치가 소리로 새는** 정보 누출 (배틀로얄에서 큼)
- 단점: 감쇠가 없으면 맵 전체가 듣는다 → 감쇠는 어차피 필요

### V-B 갈래별 ⭐
| 갈래 | 듣는 사람 | 상황 |
|---|---|---|
| **전투** | 주변 3D (감쇠 반경 안 누구나) | 스킬 P·Q·W·E·R · 사망 |
| **혼잣말** | **본인만** 2D | 처치(누적 · 야생) · 평타 대상 지정 · 첫 이동 · 제작 · 채집 · 상자 · 시체 수색 · D 습득 |

- 장점: 전투 소리는 원래 보이는 순간(스킬 이펙트 · 쓰러짐)과 같이 나서 새 정보가 아니다 · 혼잣말은 위치를 안 새게
- 장점: 본인만 쪽은 **서버에서 그 클라 하나에만** 보내면 돼 네트워크도 적다
- 단점: 규칙 칸이 하나 늘어난다 (JSON `Hear: Near | Self`)
- 단점: 팀원이 내 처치 대사를 못 듣는다 — 팀 공유가 필요하면 나중에 `Team` 값 추가

### V-C 전부 본인만
- 장점: 정보 누출 0 · 감쇠 불필요
- 단점: 적 스킬 대사가 안 들려 전투감이 줄고 · 상대 R 을 소리로 알아차릴 수 없다

## D2 — 겹침 · 간격

### G-A 한 캐릭터 한 대사 + 상황별 간격 ⭐
- 캐릭터마다 지금 말하는 음성 하나만 기억한다 (`UAudioComponent` 약한 포인터)
- 말하는 중에 새 대사 → **건너뜀**. 단 **스킬 대사**는 하던 말을 끊고 말한다 (전투가 우선)
- 상황마다 `Chance` (0~1) · `Cooldown` (초 — 같은 상황 다시 말할 때까지) 를 JSON 에. 기본 스킬 1.0 · 0초 / 평타 지정 0.3 · 10초 / 채집 · 상자 0.5 · 5초 (숫자는 들어보고 고친다)
- 장점: 연속 스킬 · 연속 채집에서 말이 겹치거나 매번 같은 말을 반복하지 않는다
- 단점: 코드 조금 (컴포넌트에 맵 하나 + 약한 포인터 하나)

### G-B 확률만
- 장점: 가장 단순
- 단점: 연타하면 말이 겹친다 (Q 쓰자마자 E — 두 대사 동시)

## 공통 구현 (어느 방안이든)

**네트워크**
- 서버 권위: 처치 · 제작 · 채집 · 상자 · 시체 · D 습득은 **서버**에서 일어난다 → 서버가 음성 신호를 보낸다
  - `Near` → `GameplayCue.Pres.Voice` (효과음 큐 `SendSfxCue` 와 같은 길 · relevant 한 클라 전부)
  - `Self` → 그 플레이어 PC 의 `Client` RPC 하나 (키 태그 1개 · 신뢰성 불필요 → `Unreliable`)
- 스킬 · 사망은 이미 오는 신호를 클라가 쓴다 — 추가 0
- 평타 지정 · 첫 이동은 본인 입력이라 **클라에서 바로** — 추가 0
- 데디 서버는 안 튼다

**데이터** — `Data/Presentation/_Voice.json` (캐릭터 공통 · 상황 키 → 음성 키 · 듣는 사람 · 확률 · 간격)
```json
{ "VoiceRules": [
  { "Match": "^PlaySkill\\d{4}2\\d\\d(seq0)?$", "Key": "Pres.Voice.Skill.Q", "Hear": "Near", "Chance": 1.0, "Cooldown": 0 },
  { "Match": "^(Dead|dead|die|killedCommon)$",   "Key": "Pres.Voice.Death",   "Hear": "Near" },
  { "Match": "^collectbrunch$",                  "Key": "Pres.Voice.Gather.Branch", "Hear": "Self", "Chance": 0.5, "Cooldown": 5 }
] }
```
- Fill: `Voice/ko/<캐릭터>/` 애셋 이름 → `<캐릭터>_<상황키>_<n>_ko[_0|_1]` 에서 상황키를 떼어 규칙에 맞추고 · 스킨 표로 S000 만 → 캐릭터 기본 연출 DA `Entries` 에 (같은 키 여러 개 = 무작위)
- 재생: `UERPresentationComponent::PlayVoice(Key)` — 간격 · 확률 · 겹침 검사 → `Near` = 붙여서 3D (**코드에서 감쇠 덮어쓰기** `bOverrideAttenuation` · 반경 `UERCombatSettings` 같은 설정 값) / `Self` = 2D
- 태그: `Pres.Voice.*` 를 `ERGameplayTags.h` 에 (문자열 박지 않음)
- `Voice/<캐릭터>/` 폴더(같은 이름 한 벌 + 원본 wav)는 **안 쓴다** — 정리 대상으로 보이지만 지우지 않는다 (분류 문서 ⚠ 2번)

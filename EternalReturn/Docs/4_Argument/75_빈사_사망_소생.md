## D1 — 상태를 무엇으로

### A1 GameplayEffect + 태그 ⭐
- 빈사 = 무한 GE `GE_Downed` → 태그 `State.Downed` + 모디파이어 (이동 속도 · 받는 피해 감소 SetByCaller · 체력 −1/초 주기)
- 사망 = 무한 GE `GE_Dead` → 태그 `State.Dead` (빈사 GE 제거)
- 막기: `UERGameplayAbility` 생성자 `ActivationBlockedTags` 에 두 태그 (기절 · 무기 없음과 같은 줄) · 이동은 CC 이동 막기와 같은 길 (사망만 — 빈사는 느리게 움직인다)
- 들어갈 때 시전 중 스킬 **전부 취소** (패시브 제외 · Lyra 사망 어빌리티와 같은 이유 — [Lyra 07](../6_Lyra참조/07_사망_흐름.md))
- 장점: CLAUDE.md §8 표 "상태이상 = GE + 태그 · 시전 차단 = ActivationBlockedTags" 그대로 · Mixed 복제에서 **태그는 모두에게** 가서 AnimBP 가 바로 쓴다 (`AbilitySystemComponent.h` 복제 모드 설명)
- 단점: 체력을 400 으로 맞추는 건 GE 로 안 된다 (어트리뷰트셋 쪽 한 줄 — D2)

### A2 PlayerState 복제 enum (`Alive / Downed / Dead`)
- 장점: 상태가 한눈에
- 단점: CLAUDE.md §8 "❌ 자체 상태 enum" · 막기 · 이동 · 피해 감소를 따로 다시 짠다

## D2 — 빈사 체력 400

### H1 같은 HP 어트리뷰트를 400 으로 ⭐
- 빈사 들어갈 때 서버가 `HP = min(400, MaxHP)` · 빗장(`bOutOfHealth`)을 풀어 빈사 중 0 → 다시 알림 → 사망
- 체력바 · 피해 · 회복이 지금 길 그대로
- 단점: 체력바가 `400 / MaxHP` 로 보인다 — 원작 UI `(미확인)` · UI 는 F17

### H2 새 어트리뷰트 `DownedHP`
- 장점: 원작처럼 "빈사 타이머" 따로
- 단점: 피해 실행(`ERDamageExecution`) · 보호막 흡수 · 회복이 모두 둘로 갈린다

## D3 — 아군 소생

### R1 소생 어빌리티 (채널) ⭐
- `GA_Revive` (`UERGameplayAbility` 파생 아님 — 스킬 DA 없이 · 대상 = 빈사 아군) · `UAbilityTask_WaitDelay` 채널 · 움직이거나 피해 · CC 면 취소
- 입력: 빈사 **아군**을 우클릭 (적 우클릭 = 자동 공격 자리와 같은 곳) → 서버 RPC → 거리 · 팀 · 태그 검사
- 장점: CLAUDE.md §8 "채널링 = AbilityTask" · 취소 규칙이 어빌리티 태그로
- 단점: 어빌리티 하나 + 입력 분기

### R2 PlayerController 타이머
- 장점: 짧다
- 단점: §8 "❌ 자체 타이머 상태 머신"

수치 `[자체]` (원작 미확인 — 들어보고 · 해 보고 고친다): 소생 시간 **5초** · 거리 **2m** · 일어선 뒤 체력 **최대의 25%** (자가 소생 25% 와 맞춤) — `UERCombatSettings` (프로젝트 설정)

## D4 — 처치 인정 (재키 P · 누적 처치 음성 · 처치 경험치)

## 추천

**S1 + S2 + S3 · A1 · H1 · R1 · K1.**

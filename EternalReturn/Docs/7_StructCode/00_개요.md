# 7_StructCode — 코드 구조 설명서

> **지금 코드가 어떻게 짜여 있고, 실행될 때 무엇이 무엇을 부르는지** 를 그림으로 정리한다. 기획자 · 새로 합류한 사람이 코드를 열기 전에 읽는 문서.
> 결정의 **이유 · 비교**는 `4_Argument/`, 에디터 작업 순서는 `3_EditorTasks/` 에 있다. 여기는 **"결과로 어떻게 되어 있나"** 만.

## 쓰는 규칙

- 그림(텍스트 도식) 먼저, 설명은 짧게. **"왜"** 는 한 줄 + Argument 링크
- 클래스 · 애셋 이름은 코드와 **똑같이** 쓴다 (검색되게)
- 코드가 바뀌면 이 문서도 같이 고친다 — 틀린 설명서는 없는 것보다 나쁘다

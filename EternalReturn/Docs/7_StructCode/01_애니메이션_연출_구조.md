## 0. 한 문장

> **캐릭터 = 몸(메시) + 두뇌(메인 AnimBP) + 무기 자세(레이어) + 동작표(연출 DA).** 스킨은 몸과 동작표 일부를, 무기는 자세와 동작표를, 모드는 상태와 동작표 일부를 바꾼다. **판정(맞았나)은 애니와 무관하다** — 스킬 타이머가 정한다.

## 1. 화면의 포즈는 3층

```
        ┌──────────────────────────────────────────────────────────────┐
  위 ▲  │ ③ 동작        평타 · D · Q~R · 모드 중 사격                     │  몽타주 (Slot 'DefaultSlot')
        │               버튼을 누를 때만 잠깐 덮는다 · 이동하면 끊긴다      │  ← 동작표(연출 DA)에서 찾는다
        ├──────────────────────────────────────────────────────────────┤
        │ ② 자세        대기 / 달리기 / 모드 진입·유지·해제               │  무기 레이어 (ABPL_*)
        │               든 무기마다 다르다 · 무기를 바꾸면 레이어 통째로 교체 │  ← 무기 세트 DA 가 알려 준다
        ├──────────────────────────────────────────────────────────────┤
  아래  │ ① 판단        지금 멈췄나 · 달리나 · 모드 중인가                 │  메인 AnimBP (ABP_*) + C++
        └──────────────────────────────────────────────────────────────┘
```

## 2. 메인 AnimBP 와 무기 레이어 — 실행 흐름 (재키 · 도끼)

```
캐릭터 메시의 Anim Class = ABP_Jackie (메인 · ABP_ERCharacter_Base 의 자식)
                         │
   ┌─────────────────────┴──────────────────────────────────────────┐
   │ ① C++ UERAnimInstance: 속도 → bIsMoving · 모드 태그 → bInMode    │
   │ ② 상태머신: "지금은 Idle 상태"                                   │
   │ ③ Idle 상태 안의 [Idle 레이어 노드] ──┐                          │
   │ ④ [Slot DefaultSlot] ← 평타·스킬 몽타주가 있으면 위에 덮음        │
   │ ⑤ Output Pose                         │                          │
   └───────────────────────────────────────│──────────────────────────┘
                                           │ "Idle 을 줘"
                    지금 꽂혀 있는 레이어 ▼
                    ABPL_Jackie_Axe (무기 레이어 · ABPL_ERWeapon_Base 의 자식)
                      Idle = Jackie_Axe_wait   Run = Jackie_Axe_run
```

### 무기를 바꾸면

```
ER.Item.Equip (단검)
  → UERInventoryComponent.Equipped 복제 (서버 · 모든 클라)
  → 연출 컴포넌트(C++)가 무기 세트 DA_Pres_Jackie_Dagger 를 로드 (비동기 · 처음 한 번)
  → 그 DA 의 AnimLayer = ABPL_Jackie_Dagger
  → 메시에 LinkAnimClassLayers(ABPL_Jackie_Dagger)   (도끼 레이어는 Unlink)
  → 메인은 그대로 — 같은 "Idle 을 줘" 에 이제 Jackie_1Hand_wait
무기 없음 → 캐릭터 기본 DA 의 AnimLayer = ABPL_Jackie_Unarmed (맨손 · Jackie_Common_wait/run)
```

로그: `[연출] BP_Jackie_C_0 무기 레이어 ABPL_Jackie_Unarmed_C → ABPL_Jackie_Axe_C (서버/클라)`

### 왜 메인과 레이어를 나눴나

| 한 AnimBP 에 다 넣으면 | 나누면 (지금) |
|---|---|
| 무기 4~5벌 애니를 전부 넣고 "무기 종류로 고르기" 분기 | 메인은 무기를 모른다 — "Idle 을 줘" 만 |
| AnimBP 가 모든 무기 애니를 참조 → **안 드는 무기 애니까지 메모리에** | 레이어는 무기 세트 DA 를 로드할 때 같이 올라온다 — **든 무기만** |
| 상태머신을 캐릭터마다 복사 | 상태머신은 템플릿 **한 벌** · 캐릭터별은 스켈레톤만 지정한 자식 |
| 무기 추가 = 그래프 수정 | 무기 추가 = 레이어 자식 하나 + 애니 지정 |

**메인 = 규칙 (한 벌) · 레이어 = 평소 자세 애니 (무기마다) · 둘을 잇는 약속 = 레이어 인터페이스 `ALI_ERWeaponLayers`** (함수 `Idle · Run`). 모드 애니는 레이어가 아니라 **동작표** (§6).
레이어 쪽도 템플릿(`ABPL_ERWeapon_Base`)이 그래프를 한 번 갖고, 자식 17개는 **변수만** 채운다.

## 3. 메인 상태머신 (`ABP_ERCharacter_Base`)

```
          ┌───── bIsMoving ─────┐
        Idle ◀──── !bIsMoving ── Run            ← 평소: 무기 레이어 Idle / Run
          │                      │
   [ToMode 에일리어스: Idle · Run] ── bInMode ──▶ ModeStart ──(애니 끝)──▶ ModeLoop [ModeIdle ⇄ ModeRun]
                                                     │                        │
                        [ExitMode 에일리어스: ModeStart · ModeLoop] ── !bInMode ──▶ ModeEnd ──(애니 끝)──▶ Idle
   출력: 상태머신 ──▶ Slot 'DefaultSlot' (몽타주) ──▶ Output Pose
```

- `bIsMoving` · `bInMode` · `GroundSpeed` 는 **C++ `UERAnimInstance`** 가 계산 — 게임 스레드에서 읽기만, 계산은 워커 스레드 (`NativeThreadSafeUpdateAnimation`). AnimGraph 는 변수를 직접 읽는다 (Fast Path)
- Mode 상태 안은 **Sequence Player 가 C++ 변수 `ModeStartAnim · ModeIdleAnim · ModeRunAnim · ModeEndAnim` 을 직접** 읽는다 — 그 값은 연출 컴포넌트가 동작표의 모드 줄에서 해석해 넣는다 (Argument 42 ⑥ A2). 모드가 끝나도 지우지 않는다 (End 가 아직 튼다)

## 4. 데이터 연결 — 무엇이 무엇을 가리키나 (재키)

```
BP_Jackie ──▶ DA_Char_Jackie (UERCharacterData) ──────────────── 스탯 · 스킬 · 들 수 있는 무기
               ├ Presentation ─(하드)─▶ DA_Pres_Jackie (UERPresentationData) ── 캐릭터 기본 동작표
               │                          │  Entries: 춤 · 사망 · (음성)
               │                          │  AnimLayer: ABPL_Jackie_Unarmed ─── 맨손 자세
               │                          └ WeaponSets ─(소프트)─┬▶ DA_Pres_Jackie_Axe ─── 도끼 동작표
               │                                                 │     Entries: 평타 atk01/02 · D · Q~E
               │                                                 │     AnimLayer: ABPL_Jackie_Axe
               │                                                 ├▶ DA_Pres_Jackie_Dagger · _TwoHandSword · _DualSword
               └ Skins ─(소프트)─┬▶ DA_Skin_Jackie_S000 (UERSkinData) ── 몸(Mesh) · 두뇌(AnimClass = ABP_Jackie) · Overrides
                                 └▶ …S001 ~ S005                        (고른 스킨만 로드)
```

### 동작표 한 줄 (`FERPresentationEntry`)

| 칸 | 뜻 | 예 |
|---|---|---|
| Weapon | 이 무기일 때만 (None = 무관) | 스킨 덮어쓰기에서 주로 |
| **Mode** | 이 모드 중일 때만 (비면 평소) | `Mode.Sniper` |
| Key | 어떤 동작 — **스킬은 슬롯 태그 그대로** | `Ability.Slot.Attack` · `.D` · `.Q` · `Pres.Anim.Dance` |
| Assets | 애니(여러 개면 번갈아) · 소리 · 이펙트 | `Jackie_Axe_atk01, Jackie_Axe_atk02` |

### 찾는 순서 — "이 동작은 어떤 애니?" (좁은 것이 이긴다)

```
스킨 · 모드 줄 > 스킨 줄 > 모드 줄 > 무기 세트 줄 > 캐릭터 기본 줄 > (없음 = 애니 없이 판정만 — 게임은 그대로 돈다)
예) 카티야 저격 모드 중 평타 → 무기 세트의 모드 줄 { Mode.Sniper · Attack · Skill_Shot }
    다니엘 S003 스킨 Q       → 스킨 줄 { Dagger · Q · Daniel_Scissors_S003_skill01 }
```

- 스킨 · 무기 · 모드가 바뀔 때만 이 순서로 한 번 계산해 **캐시**한다 — 재생할 때는 해시 1회

## 5. 게임에서 일어나는 일 → 무엇이 바뀌나

| 게임에서 | 누가 | 바뀌는 것 | 다른 사람 화면 |
|---|---|---|---|
| 스폰 | 연출 컴포넌트 | 몸 = 고른 스킨 · 자세 = 맨손 | ✅ 각자 계산 |
| 무기 장착 · 교체 | 연출 컴포넌트 (`Equipped` 복제) | 무기 세트 로드 · 자세 레이어 교체 · 동작표 | ✅ |
| 이동 / 멈춤 | C++ `UERAnimInstance` (속도) | 대기 ↔ 달리기 | ✅ 이동 복제 |
| 평타 · 스킬 | 스킬(`UERGameplayAbility::PlaySkillAnim`) → 연출 컴포넌트 | 동작표에서 애니 → 몽타주 (평타는 atk01↔02 · 공속만큼 빨라짐) | ✅ 서버가 틀고 GAS 가 복제 · 소유 클라는 직접 |
| 동작 중 이동 클릭 | 이동 명령 (`StopActionAnim`) | 동작 끊김 (후딜 캔슬) | ✅ |
| 스킨 변경 | `AERPlayerState.SkinIndex` 복제 | 몸 교체 · 스킨 줄 덮어쓰기 | ✅ |
| 특수 모드 진입 · 해제 (저격 D …) | 모드 조각 → `Mode.*` 복제 태그 | `bInMode` → 상태머신 · 모드 줄 | ✅ 태그 복제 |
| 판정 (맞았나) | 스킬 타이머 (서버) | — **애니와 무관** | — |

## 6. 특수 모드 (저격 D · 재키 R 전기톱 · 매그너스 R 오토바이 · 다니엘 가면)

```
평소 자세 ─▶ 진입(ModeStart) ─▶ 유지(ModeIdle ⇄ ModeRun) + 모드 중 평타(모드 줄) ─▶ 해제(ModeEnd) ─▶ 평소 자세

[서버] 모드 조각 진입 ── AddLooseGameplayTag + AddReplicatedLooseGameplayTag(Mode.Sniper)
          │ 태그 복제 (엔진)
          ▼
[각 머신] 연출 컴포넌트 (Mode 태그 구독) ── bInMode + 모드 애니 4개 → UERAnimInstance ── 상태머신 진입/유지/해제
                                         └─ 모드 줄 활성 → 사격 = Skill_Shot

동작표 (DA_Pres_Katja_SniperRifle) 의 모드 줄 — ER.Pres.Fill 모드 규칙이 채운다
  { Mode.Sniper · Pres.Anim.ModeStart · Katja_Sniperrifle_Skill_Start }   ← 상태 애니 (상태머신이 튼다)
  { Mode.Sniper · Pres.Anim.ModeIdle  · …_Skill_Loop } · { … ModeRun · …_Skill_Loop } · { … ModeEnd · …_Skill_End }
  { Mode.Sniper · Ability.Slot.Attack · …_Skill_Shot }                     ← 사건 (몽타주)
```

| 부분 | 성격 | 자리 |
|---|---|---|
| 진입 · 유지 · 해제 | **상태** (켜짐 / 꺼짐) | AnimBP 상태머신 (언제) + 동작표 모드 줄 (무엇) (Argument 36 원칙 2 · 42 ⑥) |
| 모드 중 평타 · 스킬 | **사건** (누를 때) | 동작표의 모드 줄 → 몽타주 |

- ⚠ 복제 loose 태그는 **받는 쪽에서만** 태그 개수에 반영된다 → 서버는 일반 loose 태그도 같이 붙인다
- 새 모드 추가 = 태그 1개(C++) · Fill 모드 규칙 몇 줄(C++) 또는 동작표에 모드 줄 손으로 · 스킬 DA 의 Presentation Mode — **AnimBP 는 안 건드린다**
- 스킨이 모드 모션을 바꾸려면 스킨 DA 에 같은 모드 줄 (스킨 · 모드 줄이 이긴다)
- ⭐ **모드에 들어가는 스킬(저격 D · 재키 R …)은 동작표에 그 슬롯 줄(`Ability.Slot.D` 등)을 넣지 않는다** — 진입 모션은 상태머신이 튼다. 넣으면 Start 가 두 번(상태머신 + 몽타주) 나간다. 한 동작짜리 스킬(도끼 D · 망치 D …)은 슬롯 줄이 있어야 한다 (사건)

## 7. 네트워크 — 새로 복제되는 것은 셋뿐

| 값 | 어디 | 누가 쓰나 |
|---|---|---|
| `SkinIndex` | `AERPlayerState` (전원) | 몸 교체 · 스킨 줄 |
| `Equipped` (기존 · OnRep 추가) | `UERInventoryComponent` (전원) | 무기 세트 로드 · 레이어 |
| `Mode.*` 복제 loose 태그 | ASC (엔진) | bInMode · 모드 줄 |

나머지(어떤 애니를 고르나 · 레이어 연결 · 캐시)는 **각 머신이 같은 입력으로 같은 답**을 낸다 — 복제 없음.
애니 재생 자체는 GAS 가 복제 (`RepAnimMontageInfo`) — ⚠ 엔진은 **소유자에게는 복제 재생을 안 한다** → 소유 클라의 스킬 인스턴스가 직접 튼다.

## 8. 메모리 · 성능

| 무엇 | 어떻게 |
|---|---|
| 로드 | 캐릭터 기본 DA = 하드 (그 캐릭터가 있으면) · **무기 세트 = 소프트 (든 무기만)** · **스킨 = 소프트 (고른 것만)** · 음성 = 엔진 `LoadOnDemand` |
| GC | 소프트로 불러온 DA 는 연출 컴포넌트가 `UPROPERTY` 로 붙잡는다 (안 그러면 사라진다) |
| 안 보일 때 | 메시 `OnlyTickMontagesWhenNotRendered` — 그래프는 안 돌고 몽타주만 (데디 서버는 전원) |
| 먼 캐릭터 | URO (업데이트 빈도 낮춤) · Fixed Skel Bounds |
| AnimBP | Thread Safe Update (C++) · Fast Path · 루트 모션 끔(병렬 업데이트 조건) |
| 데디 서버 | 레이어 연결 안 함 · 야생동물 대기 중 메시 틱 끔 |

## 9. 야생동물 (더 단순)

```
DA_Wild_Bear ─ Anim Class ─▶ ABP_Bear (자식) ◀─ ABP_ERWildlife_Base (템플릿 · 부모 C++ UERAnimInstance)
             │                IdleAnim = Bear_01_wait · RunAnim = Bear_01_run       대기 ↔ 달리기 + Slot
             └ Presentation ─▶ DA_Pres_Bear_01   평타 = Bear_01_atk01/02 · 사망 = Bear_01_death
```
- 무기 레이어 · 스킨 · 모드 없음. 변이 · 잠식은 스켈레톤이 따로라 **자식 AnimBP 도 따로**
- 대기(도먼시) 들어갈 때 속도 0 · 메시 틱은 데디 서버에서만 끔 (E27)

| 무기 enum ↔ 애니 토큰 | Dagger = `1Hand`(재키) · `OneHandSword`(다니엘) · TwoHandSword = `2Hand` · DualSword = `Dual` · SniperRifle = `Snipe` · Shuriken = `Shriken` |

## 12. 새 캐릭터를 추가할 때

1. `DA_Char_<이름>` (스탯 · 스킬 · 무기) — Presentation · Skins 칸은 **비워 둔다**
2. 메인 AnimBP 자식 `ABP_<이름>` · 레이어 자식 `ABPL_<이름>_Unarmed` · `_<무기>` (Idle · Run 애니만)
3. `BP_<이름>` (Character Data 지정)
4. `ER.Pres.Fill <이름>` → Save All — 동작표 · 무기 세트 · 스킨 · 레이어 자동 연결
5. `DA_Skin_<이름>_S000` › Anim Class = `ABP_<이름>`
6. (모드가 있으면) 태그 · Fill 모드 규칙 · 스킬 DA Presentation Mode

## 디버그

- `ER.Pres.Show [Wild]` — 해석 결과 · 붙은 레이어 · 모드 · 메시 스켈레톤 (서버 · 클라 창 각각)
- `ER.Skin.Set <n> [플레이어]` — 스킨 바꾸기 (서버 창)
- 로그 머리말 `[연출]` · `[연출 채우기]` · `[모드]`

## 13. ⭐ 규칙 — 무엇으로 트나 (Argument 48 · 2026-09-29)

| 성격 | 질문 | 무엇으로 | 예 |
|---|---|---|---|
| **상태** | "지금 ~인가?" | **AnimBP 상태머신** | 대기 · 달리기 · 모드(저격 · 전기톱) · 야생동물 시체 |
| **명령 · 사건** | "지금 ~해!" | **몽타주** (Slot `DefaultSlot`) | 평타 · D · Q~R · 모드 사격 · 채집 · (제작 · 상자 · 휴식 진입) |

- 구조: `상태머신 → Slot 'DefaultSlot' → Output Pose` — 몽타주가 상태머신 결과 위에 잠깐 덮는다
- **움직이면 몽타주를 끊는다 — `UERAnimInstance` 한 곳** (모든 머신 · 자기 화면 속도). 예외: 몽타주 시작 뒤 한 번도 안 멈췄으면(감속 중 시작) · 루트모션 소스 중(돌진 · 블링크 · 넉백). `StopActionAnim` 은 이동 **입력** 즉시 반응용 (서버 · 소유 클라)
- 애니 출처: 대기 · 달리기 = 무기 레이어 · 종별 자식 AnimBP 변수 / 나머지 = 동작표 (S1 — 지금대로)
- 사망은 상태머신 — 늦게 relevant 된 클라도 누운 몸을 봐야 해서 몽타주로는 안 된다
- 상체 분리(UpperBody Slot + Layered Blend Per Bone)는 **아직 없다** — 움직이며 쓰는 스킬이 생기면 (F19)

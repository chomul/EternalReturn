## 3. 규칙 밖 — 아직 아무 데도 안 들어간 것

### 실험체 공용 (6명 모두 있음)

| 애니 | 무엇 (추정 포함) | 맡을 곳 |
|---|---|---|
| `collect_wood` · `collect_stone` · `collect_water` | 재료별 채집 | 채집물 루트 행에 연출 키 칸 — F17 (Argument 46) |
| `craft` · `craftfood` · `craftmetal` | 제작 | 제작이 시간이 걸리는 행동이면 채집과 같은 방식 — F09 제작 규칙 확인 후 |

| `down_start` · `down_wait` · `down_run` · `down_dead` · `downdead` | 빈사 (쓰러져 기어감) | **F14** 사망 · 부활 |

## 4. 요약 — 다음에 붙일 수 있는 순서

1. **F12.5 안에서 가능**: 야생동물 `appear`(등장) · `endbattle`(귀환) — 한 번 트는 사건이라 몽타주 1번씩 · 새 복제 거의 없음
2. **F14**: 실험체 사망 · 빈사(`down_*`) · 부활
3. **F17**: 재료별 채집 · 상자 열기 · (제작)
4. **F19**: 실험체 Q~R 다단계 · 모드 (카티야 먼저)
5. **F13**: 야생동물 경계 · 잠
